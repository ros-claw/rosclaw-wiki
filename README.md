## The Vision: Beyond Strings, Into Solids

Large Language Models (LLMs) excel at manipulating symbols, but they often lack an intuition for gravity, torque, and thermal degradation. **ROSClaw Wiki** exists to provide that intuition.

We believe that **Intelligence emerges from Connection**. By interweaving hardware specifications, causal relationships from research papers, and code-level constraints into a unified **Physical Ontology**, we provide a "Causal Nexus" that allows AI Agents to navigate the physical world with safety and foresight.

## Core Pillars

### 1. Physical Commonsense Firewall
Rather than a rigid set of "No"s, ROSClaw acts as a **Guardian**. It traces the impact of a parameter change (e.g., increasing peak current) across the entire system — from motor heat to navigation drift — anchoring AI logic in uncompromising physical truths.

### 2. Knowledge-as-a-Service (KaaS)
Accessible via **REST API** and **MCP (Model Context Protocol)**, ROSClaw transforms static documentation into a living, queryable graph. Whether you are using **Claude Code**, **OpenClaw**, or custom VLA models, the Wiki provides instant grounding for every robotic action.

### 3. The Forge: Local Wisdom, Global Reach
Designed for a hybrid workflow, ROSClaw allows researchers to **Forge** specialized knowledge from local papers and codebases, refining raw data into structured "Judgments" that can be pushed to the cloud for collaborative intelligence.

## Quick Start

### Install

```bash
pip install rosclaw-wiki
```

### Forge a Wiki from Papers

```bash
rosclaw-wiki forge --input ./papers --name "my-robot-wiki" --push
```

### Query the API

```bash
curl -H "X-API-Key: $ROSCLAW_API_KEY" \
  https://api.rosclaw.io/wiki/v1/search \
  -H "Content-Type: application/json" \
  -d '{"query": "Unitree G1 max torque", "search_type": "hybrid"}'
```

### Install as OpenClaw Skill

```
Install ROSClaw Wiki from https://github.com/ros-claw/rosclaw-wiki/tree/main/skill
```
