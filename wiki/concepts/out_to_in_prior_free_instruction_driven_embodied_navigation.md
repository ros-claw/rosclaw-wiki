## Out-to-In Prior-Free Instruction-Driven Embodied Navigation

### Overview

This task bridges the gap between indoor and outdoor navigation for last-meter delivery applications. It eliminates the need for precise external priors, enabling agents to locate specific entrances based on visual cues.

### Definition

Out-to-In Prior-Free Instruction-Driven Embodied Navigation is a navigation task requiring an agent to transition from outdoor to indoor environments using only egocentric visual observations and natural language instructions, without relying on external priors such as GPS or maps.

### Capabilities

- Enables seamless outdoor-to-indoor navigation
- Enables fine-grained entry through specific building entrances
- Operates without prior maps or coordinate systems
