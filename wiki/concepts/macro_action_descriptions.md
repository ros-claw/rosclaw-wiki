## Macro-action descriptions

**Macro-action descriptions** are pre-defined action templates that describe navigational subgoals in a structured way. They serve as an intermediate representation between natural language instructions and low-level motor commands, enabling an embodied agent to decompose complex instructions into manageable, reusable steps.

### Description

Macro-action descriptions are pre-defined action templates that describe navigational subgoals in a structured way, enabling the system to decompose a full instruction into manageable steps. They bridge the gap between high-level language and low-level control by providing a fixed vocabulary of navigational primitives.

### Parameters

| Field | Value |
|-------|-------|
| Format | Sequence of high-level navigational commands |
| Examples | `go to the door`, `turn left`, `move forward` |

Each macro-action is a textual template that can be instantiated with specific locations or directions (e.g., `go to the {target}`). The set is typically domain-specific and defined prior to deployment.

### Capabilities

- **Bridges natural language and low-level actions** – Converts free-form instructions into a structured command stream that a motion planner can execute.
- **Reduces complexity of instruction parsing** – By limiting the action space to a handful of templates, the system avoids the ambiguity of open-ended language generation.

### Relationships

- **Generated by** → LLMs-based instruction parser – The LLM parser takes a raw instruction and outputs a sequence of macro-action descriptions.
- **Used by** → Language indexing-based localizer – The localizer maps each macro-action to the appropriate low-level control sequence and spatial goal.

*Typed annotations:*
- LLMs-based instruction parser **generates** macro-action descriptions.
- Language indexing-based localizer **consumes** macro-action descriptions.
