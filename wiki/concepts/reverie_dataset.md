## REVERIE Dataset

The **REVERIE dataset** is a high-level benchmark for Vision-and-Language Navigation (VLN). It provides a challenging evaluation framework where agents must follow natural language instructions to navigate through photorealistic environments and identify target objects.

### Capabilities

- Used to evaluate the state-of-the-art in VLN, measuring both navigation accuracy and object grounding performance.
- Provides a standardized testbed for comparing different approaches to high-level instruction following in embodied AI.

### Relationship to AACL

The REVERIE dataset evaluates the Actional Atomic-Concept Learning ⚠️ ⚠️ (AACL) method — a technique that learns atomic-level action representations from language instructions. AACL leverages REVERIE's benchmark tasks to demonstrate improvements in navigation and grounding.
