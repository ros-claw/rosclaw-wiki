# Hydra-Nav: Object Navigation via Adaptive Dual-Process Reasoning

**Year**: 2026  
**Venue**: arXiv`<br>ByteDance Seed  
**arXiv**: [2602.09972](https://arxiv.org/pdf/2602.09972)  

## Overview

单一VLM框架（Qwen2.5-VL-7B）实现在快慢双系统（快系统：高效低级别执行；慢系统：全局规划与时空推理）间自适应切换；真机部署于Unitree Go2四足机器人，通过非线性模型预测控制（NMPC）执行动作（推理在服务器上运行）
