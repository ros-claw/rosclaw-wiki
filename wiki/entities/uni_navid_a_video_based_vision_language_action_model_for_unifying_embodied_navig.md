# Uni-NaVid: A Video-based Vision-Language-Action Model for Unifying Embodied Navigation Tasks

**Year**: 2025  
**Venue**: RSS`<br>Peking University  
**arXiv**: [2412.06224](https://arxiv.org/pdf/2412.06224)  
**Code**: [https://github.com/jzhzhang/Uni-NaVid](https://github.com/jzhzhang/Uni-NaVid)  

## Overview

NaVid的扩展版,添加了token融合机制实现加速以及拓展VLN任务为4个子任务(视觉语言导航、目标导航、具身问答、人员跟随)；框架为：视觉编码器，online token merge mechanism 以及LLM（典型的将视觉观测编码为序列跟语言token一起输入到LLM的框架）
