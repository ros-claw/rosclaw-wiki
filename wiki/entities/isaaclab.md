## Overview

**IsaacLab** is a simulation benchmark designed for realistic scenes, providing a platform to evaluate legged robot navigation with low‑level controls. It bridges the gap between simulation and deployment by supporting real‑world robot experiments.

## Capabilities

- Evaluate legged robot navigation using low‑level control primitives.
- Simulate realistic, diverse environments for reproducible testing.

## Usage

IsaacLab is used by the NaVILA system to assess navigation performance in simulation before real‑world transfer. The benchmark’s support for real‑world experiments enables seamless evaluation across domains.
