# SeeNav-Agent: Enhancing Vision-Language Navigation with Visual Prompt and Step-Level Policy Optimization

**Year**: 2025  
**Venue**: arXiv`<br>Tencent AI Lab  
**arXiv**: [2512.02631](https://arxiv.org/pdf/2512.02631)  
**Code**: [https://github.com/WzcTHU/SeeNav-Agent](https://github.com/WzcTHU/SeeNav-Agent)  

## Overview

双视角提示词（第一人称视角+俯视图，把路标、动作/导航线直接画在图上）+RL;在EmbodiedBench Navigation 基准上GPT-4.1 +视觉提示成功率达86.7%，相比基座模型提升了 21.7%，比之前的闭源 SOTA（Claude-3.5-Sonnet）高出了 20 个百分点；使用开源模型 Qwen2.5-VL-3B，加上RL微调，比之前的开源 SOTA（InternVL3-78B）高出 5.6%
