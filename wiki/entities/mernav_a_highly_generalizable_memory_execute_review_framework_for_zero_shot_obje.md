# MerNav: A Highly Generalizable Memory–Execute–Review Framework for Zero-Shot Object Goal Navigation

**Year**: 2026  
**Venue**: arXiv`<br>Amap, Alibaba Group  
**arXiv**: [2602.05467](https://arxiv.org/pdf/2602.05467)  

## Overview

Object Goal Navigation,构建“记忆-执行-复盘”（Memory-Execute-Review）框架:通过分层记忆模块（“短-长-常识”三层记忆系统）积累信息，执行模块（观测分析、路径规划、动作选择、停止决策）应对常规导航，复盘模块（避障脱困、跨区域探索）修正异常行为。
