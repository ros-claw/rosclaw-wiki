## SCAND

**SCAND** is a benchmark for visual navigation, used in the evaluation of UniWM. It is part of the broader category of Navigation benchmarks ⚠️ ⚠️ that test embodied agents' ability to navigate environments using visual inputs.

### Description

SCAND provides standardized tasks and metrics for assessing visual navigation performance. In the context of UniWM, it serves as one of the evaluation benchmarks to measure the model's world modeling and planning capabilities. The benchmark emphasizes realistic visual inputs and requires agents to generalize across different environments and viewpoints.
