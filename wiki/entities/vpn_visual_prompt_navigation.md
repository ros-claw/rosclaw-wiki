# VPN: Visual Prompt Navigation

**Year**: 2026  
**Venue**: arXiv`<br> Nanjing University of Aeronautics and Astronautics  
**arXiv**: [2508.01766](https://arxiv.org/pdf/2508.01766v6)  
**Code**: [https://github.com/farlit/VPN](https://github.com/farlit/VPN)  

## Overview

视觉提示导航:仅依靠用户在2D顶视图地图中提供的视觉提示引导智能体导航，既降低了非专业用户的使用门槛，又减少了指令的歧义性。提出baseline：VPNet，两个基准数据集：R2R-VP和R2R-CE-VP
