# Spatial-Temporal Chain-of-Thought Reasoning

**Spatial-temporal chain-of-thought (ST-CoT) reasoning** is a prompted reasoning approach designed for zero-shot vision-and-language navigation tasks, introduced in the Open-Nav framework. It decomposes the navigation problem into a sequence of interpretable reasoning steps that jointly consider spatial layout and temporal dynamics to guide decision-making.

## How It Works

Rather than directly mapping visual and language inputs to motor commands, ST-CoT breaks the task into three distinct sub-problems:

1. **Instruction comprehension** – Parsing the natural language instruction into actionable sub-goals.
2. **Progress estimation** – Keeping track of where the agent is along the instruction timeline.
3. **Decision-making** – Using the combined spatial context (current view, map priors) and temporal context (remaining steps) to select the next action.

These sub-problems are solved sequentially using an LLM prompted to output chain-of-thought traces that explicitly reference spatial relationships and temporal progression.

## Capabilities

- Decomposes navigation tasks into instruction comprehension, progress estimation, and decision-making.
- Leverages open-source LLMs for reasoning, making the approach accessible and modifiable.
- Enables zero-shot navigation by eliminating the need for task-specific training or fine-tuning.
