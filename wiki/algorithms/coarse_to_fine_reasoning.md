# Coarse-to-Fine Reasoning

**Type:** Algorithm  
**Source:** [arXiv:2505.23019](data/raw/papers/2505.23019.pdf) – ASCENT framework

The **Coarse-to-Fine Reasoning** module is a navigation decision strategy that combines **frontier ranking** with LLM-driven contextual analysis to enable intelligent multi-floor navigation. It is a core component of the [[ASCENT]] system.

## Description

The Coarse-to-Fine Reasoning approach operates on two granularity levels: a coarse global view of floor-level topology and a fine local analysis of frontier regions. The module first ranks candidate frontiers (boundary areas between explored and unexplored space) using a geometric heuristic, then refines these rankings by invoking an [[LLM]] ⚠️ ⚠️ to interpret semantic context—such as doorways, stairs, or room labels—to make final navigation decisions across floors. This hybrid method allows the robot to prioritize exploration directions that are both geometrically promising and semantically meaningful.

## Methods

The module employs two complementary methods:

- **Frontier Ranking** – geometric evaluation of unexplored boundaries to produce an initial priority order.
- **LLM-driven Contextual Analysis** – semantic reasoning over frontier properties (e.g., inferred room type, connectivity) to refine the ranking and select the most appropriate navigation goal.

These methods are integrated sequentially: frontier proposals are generated by a lower-level exploration planner, passed to the LLM with scene context, and the final goal is output.
