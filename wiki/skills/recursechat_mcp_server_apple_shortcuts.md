> 📇 🏠 🍎 - An MCP Server Integration with Apple Shortcuts

This project provides an MCP server that integrates with Apple Shortcuts, allowing AI agents to trigger or interact with shortcuts on Apple devices. It enables model-based control of automations via the Model Context Protocol. The integration is listed under browser automation, suggesting it can also be used to automate browser tasks through Apple Shortcuts.
