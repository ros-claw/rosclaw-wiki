Agents pay $0.01 USDC per search via x402 micropayments on Base mainnet — no API keys required. Larger index than any other x402 discovery layer.

This MCP server indexes over 14,000 x402-enabled HTTP APIs and allows AI agents to search them by keyword. Each search costs a micropayment of $0.01 USDC on Base mainnet, eliminating the need for traditional API keys. It serves as the largest discovery layer for x402-compatible services, enabling autonomous agent payments for API access.
