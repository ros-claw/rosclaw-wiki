This project provides a curated set of prompts designed for guardian or safety agents in AI systems. It aims to help developers implement guardrails that detect harmful or out-of-scope behavior in agentic workflows. The prompts are contributed by the community and intended to be reusable across different AI agent frameworks. This resource supports safer deployment of autonomous agents by offering ready-to-use safety directives.
