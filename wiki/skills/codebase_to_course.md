> A Claude Code skill that turns any codebase into a beautiful, interactive single-page HTML course for non-technical vibe coders.

This Claude Code skill analyzes any codebase and automatically generates a beautiful, interactive single-page HTML course. The output is designed to be accessible for non-technical 'vibe coders' who want to learn from code without deep programming knowledge. It transforms raw code into structured, educational content with interactive elements, making code understanding easier for beginners.
