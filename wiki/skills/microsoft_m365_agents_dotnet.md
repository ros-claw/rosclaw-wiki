This project provides a .NET library for building intelligent agents that can interact with Microsoft 365 services. It enables developers to create automated workflows and conversational experiences using Microsoft Graph and AI capabilities. The library is designed to integrate with the .NET ecosystem and leverage Azure OpenAI or other AI services. It simplifies the development of agents that can handle tasks like email, calendar, and document management within Microsoft 365.
