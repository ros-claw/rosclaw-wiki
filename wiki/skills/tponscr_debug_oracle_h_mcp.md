This is a security MCP server that implements a mandatory human approval gate for autonomous AI agents. It intercepts critical, irreversible, or financially significant actions and routes them to a human via Telegram for real-time approval or rejection. The tool is designed to improve workflow success probability from 81.5% to 99.6%. It is listed under Security in server implementations and supports multiple platforms.
