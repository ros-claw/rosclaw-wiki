> 📇 ☁️ - AI-powered web search server using Perplexity Sonar models with source citations. Zero-install setup via NPX.

Nexus is an AI-powered web search server that leverages Perplexity Sonar models to provide search results with source citations. It requires no installation and can be run instantly via NPX, making it easy to deploy. The tool is designed for efficient data extraction and search capabilities, offering a zero-configuration setup for developers.
