> 📇 ☁️ - Comprehensive blockchain services for 30+ EVM networks, supporting native tokens, ERC20, NFTs, smart contracts, transactions, and ENS resolution.

EVM MCP Server provides comprehensive blockchain services for over 30 Ethereum-compatible networks, including native tokens, ERC20 tokens, NFTs, smart contracts, transactions, and ENS resolution. It enables AI agents to interact with blockchain data and operations in finance and fintech contexts. The server is listed under Finance & Fintech in the MCP server implementations directory.
