> A cat clone with syntax highlighting, line numbers, and Git integration.

bat-cat is a modern command-line tool that functions as an enhanced version of the traditional 'cat' command. It adds syntax highlighting for code, line numbers, and Git integration to show modifications. This makes it easier to read and review source files directly in the terminal. It aims to be a drop-in replacement for cat while providing better readability and developer-friendly features.
