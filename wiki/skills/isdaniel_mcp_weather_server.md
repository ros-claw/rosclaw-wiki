> 🐍 ☁️ - Get weather information from https://api.open-meteo.com API.

An MCP server that provides weather information by querying the Open-Meteo API. It is listed under Location Services, indicating it uses location data to fetch forecasts. The server is implemented in Python and follows the Model Context Protocol. It returns weather data such as temperature, precipitation, and wind conditions for a given location.
