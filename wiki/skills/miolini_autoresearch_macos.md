> ![GitHub stars](https://img.shields.io/github/stars/miolini/autoresearch-macos?style=social) - Widely adopted macOS fork that adapts upstream autoresearch for Apple Silicon / MPS while preserving the original loop shape.

A widely adopted macOS fork of the autoresearch AI agent tool, optimized for Apple Silicon and Metal Performance Shaders (MPS). It maintains the original iterative research loop while enabling native acceleration on Mac hardware. This adaptation allows macOS users to run the agent seamlessly without manual configuration for Apple's chips.
