> Auto-approve safe bash commands using AST-based parsing, while prompting for destructive operations. Solves permission fatigue without disabling safety. Supports Claude Code, Gemini CLI, and Cursor.

Dippy is a hook that automatically approves safe bash commands using AST-based parsing while prompting for destructive operations. It solves permission fatigue without disabling safety, meaning users don't have to manually approve every command, but risky ones are still caught. The tool works with popular AI code assistants like Claude Code, Gemini CLI, and Cursor. It helps developers maintain security while improving workflow efficiency.
