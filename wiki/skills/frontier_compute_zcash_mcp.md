Chain queries, memo decoding, on-chain attestation, and proof verification.

The Frontier-Compute/zcash-mcp project is an MCP server that enables AI agents to perform shielded operations on the Zcash blockchain. It supports chain queries, memo decoding, on-chain attestation, and proof verification. This allows AI agents to interact with private financial transactions while maintaining privacy features. The server integrates with the Model Context Protocol (MCP) for use in AI agent frameworks.
