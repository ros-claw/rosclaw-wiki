> [![mcp-server-npm-plus MCP server](https://glama.ai/mcp/servers/ofershap/mcp-server-npm-plus/badges/score.svg)](https://glama.ai/mcp/servers/ofershap/mcp-server-npm-plus) 📇 ☁️ - npm intelligence — search packages, check bundle sizes, scan vulnerabilities, compare downloads.

This MCP server provides tools for interacting with the npm registry. It enables users to search for npm packages, check bundle sizes, scan for known vulnerabilities, and compare download statistics across packages. It helps developers make informed decisions about dependencies by offering package intelligence directly through the Model Context Protocol.
