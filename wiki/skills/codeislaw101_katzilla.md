Katzilla is a unified data API for AI agents, providing access to over 300 free, public, and government data sources through a single API key. It covers categories such as economic (FRED, BLS), environmental (EPA, NOAA), health (CDC, FDA), weather (NWS), financial (SEC, CFPB), science (NASA, arXiv), and more. The project is implemented as an MCP server, allowing AI agents to retrieve diverse data without managing multiple integrations. It can be installed easily via npx and is listed under aggregators in the MCP server ecosystem.
