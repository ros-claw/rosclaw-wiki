> [![mcp-swiss](https://glama.ai/mcp/servers/vikramgorla/mcp-swiss/badges/score.svg)](https://glama.ai/mcp/servers/vikramgorla/mcp-swiss) 📇 ☁️ - 68 tools for Swiss open data: transport, weather, geodata, companies, parliament, and more. Zero API keys required.

This MCP server provides 68 tools for accessing Swiss open data across domains like transport, weather, geodata, companies, and parliament. It requires no API keys, making it easy to integrate into AI applications. The tools cover a wide range of publicly available Swiss datasets, enabling agents to fetch real-time and static information. It is listed under Data Platforms in the server implementations category.
