> 🐍 ☁️ - An MCP Server for the Alpaca trading API to manage stock and crypto portfolios, place trades, and access market data.

Alpaca MCP is a server implementation for the Model Context Protocol (MCP) that connects to the Alpaca trading API. It allows managing stock and cryptocurrency portfolios, placing trades, and accessing real-time market data. This tool is designed for finance and fintech applications, enabling AI agents to interact with live trading systems. By leveraging MCP, it provides a standardized interface for integrating trading capabilities into AI workflows.
