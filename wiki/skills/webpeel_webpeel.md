> 📇 ☁️ 🏠 - Smart web fetcher for AI agents with auto-escalation from HTTP to headless browser to stealth mode. Includes 9 MCP tools: fetch, search, crawl, map, extract, batch, screenshot, jobs, and agent. Achieved 100% success rate on a 30-URL benchmark.

Webpeel is a smart web fetcher designed for AI agents that automatically escalates from simple HTTP requests to headless browser and stealth mode as needed. It provides 9 MCP tools including fetch, search, crawl, map, extract, batch, screenshot, jobs, and agent for comprehensive web interaction. The project boasts a 100% success rate on a benchmark of 30 URLs, demonstrating reliability. It is listed under Server Implementations for Search & Data Extraction, indicating its use in AI-driven data collection.
