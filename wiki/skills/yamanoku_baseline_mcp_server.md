> 📇 🏠 - MCP server that searches Baseline status using Web Platform API

This is an MCP (Model Context Protocol) server that enables searching for Baseline status of web platform features using the Web Platform API. The Baseline status indicates whether a web feature is supported across major browsers. It falls under the Search & Data Extraction category of MCP servers. Developers can use this tool to quickly check cross-browser compatibility of web features.
