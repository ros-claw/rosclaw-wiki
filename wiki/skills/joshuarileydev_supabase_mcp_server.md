> Supabase MCP Server for managing and creating projects and organisations in Supabase

This project implements a Supabase Model Context Protocol (MCP) server that allows AI assistants to manage Supabase projects and organizations programmatically. It provides tools for creating, listing, and configuring Supabase resources through standardized MCP interfaces. The server acts as a bridge between AI agents and the Supabase platform, enabling automated database and project management tasks. It is categorized under database integrations in the MCP server ecosystem.
