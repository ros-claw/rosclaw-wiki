> 📇 🏠 - First & only persistent project context MCP. Provides .faf (Foundational AI-context Format) Project DNA with 33+ tools, Podium scoring (0-100%), and format-driven architecture. Official Anthropic Registry. 10k+ npm downloads.

This project is a Model Context Protocol (MCP) server designed to provide persistent project context for AI assistants like Claude. It introduces the Foundational AI-context Format (.faf) to store a project's 'DNA' and offers over 33 tools along with a Podium scoring system (0-100%) to evaluate context quality. The server uses a format-driven architecture and is listed in the official Anthropic registry, having garnered over 10,000 npm downloads. It is categorized under developer tools and aims to improve AI's understanding of codebases and projects over long sessions.
