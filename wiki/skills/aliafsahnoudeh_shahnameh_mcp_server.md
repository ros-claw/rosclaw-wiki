> 🐍 🏠 🍎 🪟 🐧 - MCP server for accessing the Shahnameh (Book of Kings) Persian epic poem by Ferdowsi, including sections, verses and explanations.

This is a Model Context Protocol (MCP) server that provides programmatic access to the Shahnameh, the Persian epic poem by Ferdowsi. It allows AI agents and applications to retrieve sections, verses, and explanatory notes from the classic work. The server is designed for developers integrating Persian literary and cultural content into AI-driven tools and systems.
