> [![Contentrain/ai MCP server](https://glama.ai/mcp/servers/Contentrain/ai/badges/score.svg)](https://glama.ai/mcp/servers/Contentrain/ai) 📇 🏠 - Local-first MCP server for AI content governance — 13 tools for model/content CRUD, validation, normalization, and i18n across any framework.

Contentrain/ai is a local-first MCP server that provides AI-powered content governance tools for developers. It offers 13 tools for model and content CRUD operations, validation, normalization, and internationalization (i18n), working across any framework. The server is designed to manage and enforce content rules locally, ensuring consistency and quality in AI-driven applications. It integrates with the Model Context Protocol (MCP) to serve as a developer tool for content management.
