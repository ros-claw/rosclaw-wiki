> Enables the bot to manage Docker containers, images, and stacks.

This tool enables a bot to manage Docker containers, images, and stacks. It allows users to control Docker through chat commands, simplifying container lifecycle management. The tool can list, create, and remove containers and images. It also supports managing Docker Compose stacks. This is useful for DevOps teams who want to automate container operations via a bot.
