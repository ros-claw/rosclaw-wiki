Mockd is a multi-protocol API mock server that provides 18 MCP tools for simulating HTTP, GraphQL, gRPC, WebSocket, MQTT, SSE, and SOAP APIs. It supports chaos engineering, stateful CRUD operations, and deterministic seeded responses. The server can import from eight formats, including OpenAPI, Postman, HAR, WireMock, cURL, Mockoon, and WSDL, making it versatile for developer testing and prototyping.
