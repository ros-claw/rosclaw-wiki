> Control DuoPlus cloud phones via ADB.

duoplus-agent is a tool that enables control of DuoPlus cloud phones using ADB (Android Debug Bridge). It allows users to automate tasks and manage multiple cloud-based Android devices remotely. This is useful for developers and testers who need to run commands or apps on virtual phones. The tool likely provides a command-line interface for issuing ADB commands to connected DuoPlus instances.
