> Reviews current documentation status, updates implementation progress, reviews phase documents, and maintains documentation consistency across the project.

This slash command reviews the current status of project documentation and updates implementation progress. It also reviews phase documents to ensure consistency across the project. The tool helps maintain accurate and up-to-date documentation aligned with development activities. It is useful for teams managing documentation as part of their workflow.
