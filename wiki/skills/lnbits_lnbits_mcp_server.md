> Am MCP server for LNbits Lightning Network wallet integration.

This project provides an MCP (Model Context Protocol) server that integrates with LNbits, enabling AI agents to interact with Lightning Network wallets. It allows AI models to perform operations like checking balances, creating invoices, and sending payments over the Lightning Network. The server acts as a bridge between AI tools and Bitcoin-based micropayments.
