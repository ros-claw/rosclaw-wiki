> Search and manage Confluence pages and spaces using confluence-cli.

Confluence is a command-line interface tool for searching and managing Confluence pages and spaces. It allows users to interact with Atlassian Confluence directly from the terminal, automating common documentation tasks. The CLI provides efficient access to Confluence content without needing the web interface.
