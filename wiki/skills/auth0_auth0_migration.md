Auth0-migration is a TypeScript tool for migrating user data between Auth0 tenants or from other identity providers into Auth0. It automates the export and import of user profiles, including metadata and password hashes. This project is sponsored under Auth0's open-source TypeScript Skills program, aiding developers in streamlining identity migration workflows. The tool reduces manual effort and potential errors during large-scale user transfers.
