> 📇 ☁️ - A Model Context Protocol (MCP) server that connects to Strava API, providing tools to access Strava data through LLMs

This project is an MCP server that connects to the Strava fitness tracking API, allowing large language models to access and interact with Strava data such as activities, stats, and athlete information. It exposes tools that LLMs can call to query Strava, enabling AI assistants to answer questions about workouts and performance trends. Built using the Model Context Protocol standard, it integrates seamlessly with MCP clients like Claude Desktop. Developers can use this to build conversational interfaces or automated coaching tools that leverage personal fitness data.
