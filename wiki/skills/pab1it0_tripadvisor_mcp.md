> 📇 🐍 - A MCP server that enables LLMs to interact with Tripadvisor API, supporting location data, reviews, and photos through standardized MCP interfaces

This project is a Model Context Protocol (MCP) server that enables large language models to query the Tripadvisor API. It provides standardized interfaces for retrieving location data, reviews, and photos. Listed under Travel & Transportation, it helps LLMs access real-world travel information for context-aware interactions.
