This project is a .NET library that extends Azure WebJobs with authentication event handling. It provides abstractions and bindings for processing authentication events in serverless workflows. The library is part of the Azure WebJobs SDK ecosystem, enabling developers to integrate authentication events into their Azure Functions and WebJobs applications. It is maintained by Microsoft and listed under .NET Skills.
