> 🦀 Lightweight browser automation MCP server in Rust with zero dependencies.

BB-fat/browser-use-rs is a lightweight, zero-dependency browser automation server written in Rust. It implements the Model Context Protocol (MCP) to enable AI agents to control web browsers. The project is listed under browser automation server implementations, emphasizing minimal overhead and Rust performance. This tool allows agents to interact with web pages programmatically through a simple MCP interface.
