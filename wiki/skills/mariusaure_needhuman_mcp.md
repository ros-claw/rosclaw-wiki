> [![need-human MCP server](https://glama.ai/mcp/servers/@MariusAure/need-human/badges/score.svg)](https://glama.ai/mcp/servers/@MariusAure/need-human) 📇 ☁️ - Human-as-a-Service for AI agents — submit tasks (accept ToS, create accounts, verify identity) to a real human when the agent gets stuck.

This MCP server provides a Human-as-a-Service for AI agents. When an agent encounters tasks it cannot complete on its own, such as accepting terms of service, creating accounts, or verifying identity, it can delegate these tasks to a real human. This allows the AI to continue functioning without getting stuck on web interactions that require human judgment or action. The server integrates with the Model Context Protocol (MCP) ecosystem.
