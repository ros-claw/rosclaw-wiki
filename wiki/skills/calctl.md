> Manage Apple Calendar events via icalBuddy + AppleScript CLI.

calctl is a command-line tool that allows users to manage Apple Calendar events directly from the terminal. It leverages icalBuddy to retrieve calendar data and AppleScript to perform actions like adding, editing, or deleting events. This tool is useful for automating calendar workflows on macOS without needing to use the graphical interface.
