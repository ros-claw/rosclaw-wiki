> 🐍 ☁️ 🏠 - Interacting with Obsidian via REST API

This project provides a Model Context Protocol (MCP) server that enables AI assistants to interact with Obsidian notes through its REST API. It allows reading, writing, and managing notes, as well as searching and linking content. The server acts as a bridge, letting tools like Claude access and modify Obsidian vaults programmatically for enhanced knowledge management workflows.
