A Java SDK for Microsoft Azure's AI Form Recognizer service, which extracts information from documents like invoices, receipts, and forms. It uses optical character recognition (OCR) and machine learning to parse structured data, such as key-value pairs and tables. Developers can integrate this library into Java applications to automate document processing. The SDK provides APIs for training custom models and analyzing prebuilt document types.
