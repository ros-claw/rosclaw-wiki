> 🐍 🏠 - Create, read, validate, and save Stella system dynamics models (.stmx files in XMILE format) for scientific simulation and modeling.

This is an MCP server that allows AI assistants to interact with Stella system dynamics models. It supports creating, reading, validating, and saving .stmx files in the XMILE format. The tool is designed for scientific simulation and modeling tasks within data science workflows. It bridges the gap between AI agents and established system dynamics modeling software.
