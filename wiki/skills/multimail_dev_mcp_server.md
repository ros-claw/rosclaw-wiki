> [![multi-mail MCP server](https://glama.ai/mcp/servers/@multimail-dev/multi-mail/badges/score.svg)](https://glama.ai/mcp/servers/@multimail-dev/multi-mail) 📇 ☁️ - Email for AI agents. Send and receive as markdown with configurable human oversight (monitor, gate, or fully autonomous).

This project provides an MCP server that enables AI agents to send and receive emails formatted as markdown. It offers configurable human oversight modes, including monitoring, gating, and full autonomy, allowing users to control the level of human intervention. The server is intended to integrate email capabilities into AI agent workflows, making it easier for agents to communicate via email in a structured format.
