> 📇 ☁️ 🏠 - An ntfy MCP server for sending/fetching ntfy notifications to your self-hosted ntfy server from AI Agents 📤 (supports secure token auth & more - use with npx or docker!)

ntfy-me-mcp is an MCP server that enables AI agents to send and fetch notifications through a self-hosted ntfy server. It supports secure token-based authentication for communication. Users can run it easily with npx or Docker, making it convenient for integrating ntfy notifications into agent workflows.
