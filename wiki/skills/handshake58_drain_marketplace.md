> 📇 ☁️ - Open marketplace for AI services — LLMs, image/video generation, web scraping, model hosting, data extraction, and more. Agents pay per use with USDC micropayments on Polygon. No API keys, no subscriptions.

This project creates an open marketplace for AI services such as LLMs, image/video generation, web scraping, and model hosting. Agents pay per use with USDC micropayments on the Polygon blockchain, eliminating the need for API keys or subscriptions. It enables autonomous, pay-as-you-go access to a variety of AI tools.
