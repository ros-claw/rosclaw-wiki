> Query weather data and forecasts for farm fields via the Agronomy module.

This project provides a module for farmOS that allows users to query weather data and forecasts for farm fields. It integrates with the Agronomy module to deliver relevant weather information directly in the farm management system. The module helps farmers make data-driven decisions based on local weather conditions and forecasts.
