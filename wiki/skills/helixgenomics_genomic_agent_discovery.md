Privacy-first, runs locally.

The Genomic-Agent-Discovery project provides a multi-agent MCP server for genomic analysis. It employs specialized AI agents to analyze raw DNA files, cross-referencing data from 16 major genomic databases such as ClinVar, GWAS, and gnomAD. These agents coordinate their findings through shared MCP tools, enabling comprehensive variant interpretation. The system is designed to run locally with a strong focus on privacy.
