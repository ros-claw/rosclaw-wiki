> 📇 ☁️ - A MCP Server and an extension enables natural language control of NVIDIA Isaac Sim, Lab, OpenUSD and etc.

This project provides a Model Context Protocol (MCP) server and extension for NVIDIA Isaac Sim, enabling natural language control of the simulation environment, OpenUSD scenes, and robotics lab tools. It allows users to interact with Isaac Sim using plain English commands, simplifying complex simulation tasks. The tool bridges large language models with industrial-grade robot simulation and USD-based 3D workflows.
