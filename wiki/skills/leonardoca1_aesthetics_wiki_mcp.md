This MCP server allows you to search, read, and discover thousands of visual aesthetics from the Aesthetics Wiki, such as cottagecore, dark academia, and y2k. It is designed for creative inspiration, moodboards, and brand direction. The server can be run easily with `uvx aesthetics-wiki-mcp`.
