> ![GitHub stars](https://img.shields.io/github/stars/chrisworsey55/atlas-gic?style=social) - Applies the autoresearch keep-or-revert loop to trading agents, optimizing prompts and portfolio orchestration against rolling Sharpe ratio instead of model loss.

This project applies an autoresearch keep-or-revert loop specifically to trading agents. It optimizes prompts and portfolio orchestration by using a rolling Sharpe ratio as the performance metric instead of traditional model loss. The system iteratively refines trading strategies through automated experimentation and selection. This is a domain-specific adaptation for financial AI agents to improve trading performance through prompt and portfolio optimization.
