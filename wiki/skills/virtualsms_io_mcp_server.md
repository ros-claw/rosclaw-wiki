This MCP server enables AI agents to receive SMS verification codes by providing virtual phone numbers. It supports over 500 services including WhatsApp, Telegram, and Google, using own modem infrastructure across 200+ countries. Real-time code delivery is achieved via WebSocket, and the server offers 12 tools for number discovery, purchase, and code extraction.
