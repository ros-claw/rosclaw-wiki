> ️🏠 📇 – Stop bloating your LLM context. Query & Extract only what you need from your JSON files.

This project provides an MCP server that filters JSON files to extract only the data needed for an LLM context, preventing context bloat. Users can query specific parts of their JSON files instead of sending the entire file to the model. It is categorized under Search & Data Extraction in the MCP server ecosystem.
