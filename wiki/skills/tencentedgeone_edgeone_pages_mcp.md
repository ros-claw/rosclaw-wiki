> 📇 ☁️ - An MCP service for deploying HTML content to EdgeOne Pages and obtaining a publicly accessible URL.

This MCP server enables developers to deploy HTML content directly to Tencent EdgeOne Pages, a cloud-based edge platform. It accepts HTML input and returns a unique, publicly accessible URL for the deployed page. The tool simplifies static site hosting by automating the deployment process and providing quick feedback via a URL. Built using the Model Context Protocol, it integrates seamlessly into AI development workflows.
