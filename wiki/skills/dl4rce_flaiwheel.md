Single Docker container, zero cloud dependencies.

flaiwheel is a self-hosted memory and governance layer for AI coding agents, running in a single Docker container with zero cloud dependencies. It provides 28 MCP tools that enable structured knowledge capture, hybrid search (combining semantic, BM25, and cross-encoder reranking), and behavioral documentation prompts. It includes a cold-start codebase analyzer and stores all data in a git-native format, making it suitable for development teams that want to manage agent knowledge locally.
