> ☕ 🏠 - Draw on JavaFX canvas.

This MCP server implementation enables AI agents to draw on a JavaFX canvas via the Model Context Protocol. Built as a Quarkus extension, it provides tools for rendering shapes, text, and images in real-time. It is categorized under server implementations for other tools and integrations, allowing graphical output from AI models.
