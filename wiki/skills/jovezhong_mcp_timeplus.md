> 🐍 ☁️ - MCP server for Apache Kafka and Timeplus. Able to list Kafka topics, poll Kafka messages, save Kafka data locally and query streaming data with SQL via Timeplus

This is an MCP server that integrates Apache Kafka and Timeplus, a streaming SQL database. It allows users to list Kafka topics, poll messages, save Kafka data locally, and query streaming data using SQL via Timeplus. The project enables real-time data processing and interaction with AI models through the Model Context Protocol.
