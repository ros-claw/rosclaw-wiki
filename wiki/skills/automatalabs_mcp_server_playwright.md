> 🐍 - An MCP server for browser automation using Playwright

This MCP server enables AI agents to control web browsers through the Model Context Protocol. It provides tools for navigating pages, clicking elements, filling forms, and extracting data using Playwright's automation capabilities. It supports both headed and headless modes, making it useful for testing, scraping, and web automation tasks.
