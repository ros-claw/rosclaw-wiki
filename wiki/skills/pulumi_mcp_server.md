> 🎖️ 📇 🏠 - MCP server for interacting with Pulumi using the Pulumi Automation API and Pulumi Cloud API. Enables MCP clients to perform Pulumi operations like retrieving package information, previewing changes, deploying updates, and retrieving stack outputs programmatically.

This project implements a Model Context Protocol (MCP) server that interfaces with Pulumi's Automation API and Cloud API. It allows MCP clients to programmatically perform infrastructure operations such as fetching package information, previewing changes, deploying updates, and retrieving stack outputs. By bridging MCP with Pulumi, it enables AI agents to manage cloud resources through natural language or programmatic instructions. The server is categorized under Cloud Platforms in the MCP server ecosystem.
