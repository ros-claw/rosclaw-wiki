One API key, REST + streaming, 90% creator revenue share, health monitoring. Self-hostable (MIT).

AgentForge is a unified API gateway and marketplace that provides access to over 300 AI agents through a single API key. It supports both REST and streaming endpoints, offers a 90% revenue share for creators, and includes health monitoring for agents. The platform is self-hostable under an MIT license, making it suitable for aggregating multiple AI services.
