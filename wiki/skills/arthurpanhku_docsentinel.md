Multi-format parsing, RAG knowledge base,Risks, compliance gaps, remediations.

DocSentinel is an MCP server that allows AI agents to automate the assessment of cybersecurity documents, questionnaires, and reports. It parses multiple file formats and uses a RAG knowledge base to identify risks, compliance gaps, and propose remediations. This tool helps security teams quickly evaluate documents for vulnerabilities and regulatory issues. It supports Windows, macOS, and Linux platforms.
