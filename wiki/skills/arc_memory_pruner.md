> Automatically prune and compact agent memory files to prevent unbounded growth.

This project provides a tool to automatically prune and compact memory files used by AI agents, preventing unbounded growth. It helps manage the size of agent memory to ensure efficient performance and storage usage. The tool likely targets agents that accumulate large amounts of memory over time, such as those in the ARC (AI Research) ecosystem. By automatically reducing memory file size, it supports long-running agent operations without manual intervention.
