Myco is an MCP server that provides an agent-first cognitive substrate for managing knowledge and memory across sessions and projects. It uses a self-validating filesystem graph derived from AST and markdown links rather than embeddings. The system enforces contract invariants through 18 manifest-driven verbs and 25 lint dimensions. It is provider-agnostic, forbidding LLM SDK imports in the kernel, and works with any MCP-compatible client like Claude Code, Cursor, and VS Code. Installation is editable-default.
