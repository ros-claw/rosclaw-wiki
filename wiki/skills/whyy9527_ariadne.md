> [![ariadne MCP server](https://glama.ai/mcp/servers/whyy9527/ariadne/badges/score.svg)](https://glama.ai/mcp/servers/whyy9527/ariadne) 🐍 🏠 - Cross-service API dependency graph for microservice codebases. Give it a business term or endpoint name; get back a ranked chain of GraphQL operations, REST endpoints, Kafka topics, and frontend queries across all services. Offline, local SQLite + TF-IDF + optional embeddings.

Ariadne is a server implementation for the Model Context Protocol that builds a cross-service API dependency graph for microservice codebases. It allows developers to input a business term or endpoint name and receive a ranked chain of related GraphQL operations, REST endpoints, Kafka topics, and frontend queries across all services. The tool operates offline using a local SQLite database and TF-IDF scoring, with optional embeddings for improved semantic search. It helps engineers understand how services interact and trace dependencies in complex distributed systems.
