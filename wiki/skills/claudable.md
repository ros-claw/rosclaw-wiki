> Claudable is an open-source web builder that leverages local CLI agents, such as Claude Code and Cursor Agent, to build and deploy products effortlessly.

Claudable is an open-source web builder that integrates local CLI agents like Claude Code and Cursor Agent to streamline the building and deployment of web applications. It provides a web interface through which users can interact with these agents, making product creation more efficient and accessible. The tool is listed under Alternative Clients and is designed to simplify the development workflow from coding to deployment.
