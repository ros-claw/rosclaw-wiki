> 🐍 🏠 - MCP server using the Aseprite API to create pixel art

This project provides a Model Context Protocol (MCP) server that integrates with the Aseprite pixel art editor through its API. It enables AI agents to programmatically create, edit, and export pixel art images. The server exposes tools such as drawing, color manipulation, and file management, allowing large language models to generate artwork directly. Listed under Art & Culture, it serves as a bridge between AI and creative digital art tools.
