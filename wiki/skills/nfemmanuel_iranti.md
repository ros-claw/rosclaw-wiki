> 📇 🏠 ☁️ 🍎 🪟 🐧 - Persistent shared memory for AI coding agents. Stores facts as `entity/key/value` triples with hybrid semantic search, task checkpoints, and conflict resolution — shared across Claude Code, Codex CLI, and GitHub Copilot.

Iranti is a persistent shared memory system for AI coding agents that stores facts as entity/key/value triples with hybrid semantic search capabilities. It supports task checkpoints and conflict resolution to maintain consistent context across sessions. The tool integrates with popular coding AI agents including Claude Code, Codex CLI, and GitHub Copilot, enabling memory sharing across multiple platforms.
