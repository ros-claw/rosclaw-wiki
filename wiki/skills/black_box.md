> Indestructible audit logs for agent actions, stored in TiDB Zero.

Black-box provides indestructible audit logs for agent actions. The logs are stored in TiDB Zero, a distributed SQL database. This ensures that agent actions are recorded tamper-proof and cannot be altered or deleted. It is designed for systems that require high integrity and verifiability of agent behavior.
