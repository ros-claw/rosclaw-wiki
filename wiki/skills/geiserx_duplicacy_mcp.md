Query backup job status and Prometheus metrics from a Duplicacy exporter. Docker image available.

This is a Go-based MCP server that integrates with Duplicacy backup software to provide monitoring capabilities. It connects to a Duplicacy exporter to query backup job status and Prometheus metrics, offering a Docker image for easy deployment. The server enables users to monitor backup operations through the MCP (Model Context Protocol) interface, making it suitable for AI agent tooling and observability workflows.
