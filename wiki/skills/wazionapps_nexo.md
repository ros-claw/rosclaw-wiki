> [![wazionapps/nexo MCP server](https://glama.ai/mcp/servers/wazionapps/nexo/badges/score.svg)](https://glama.ai/mcp/servers/wazionapps/nexo) 🐍 🏠 - Cognitive memory for AI agents with Atkinson-Shiffrin memory model (STM/LTM/sensory register), semantic RAG, Ebbinghaus decay, trust scoring, and 76+ MCP tools.

Nexo is an MCP server that gives AI agents a cognitive memory system inspired by human memory models. It implements the Atkinson-Shiffrin model with sensory register, short-term memory, and long-term memory, along with semantic RAG for retrieval, Ebbinghaus decay for forgetting, and trust scoring. The server provides 76+ MCP tools to manage and interact with this memory. It aims to enhance AI agents with persistent, structured memory that mimics human cognitive processes.
