This project provides a Java exporter that integrates OpenTelemetry with Azure Monitor, enabling Java applications to send telemetry data such as traces, metrics, and logs to Azure's monitoring service. It is part of Microsoft's sponsorship of Java ecosystem tools, helping developers gain observability into their applications. The exporter leverages the OpenTelemetry standard for vendor-neutral instrumentation. By using this library, Java developers can easily connect their applications to Azure Monitor without switching instrumentation frameworks.
