> 🏎️ 🏠 - Telegram API integration for accessing user data, managing dialogs (chats, channels, groups), retrieving messages, and handling read status

This is a Model Context Protocol (MCP) server that integrates with the Telegram API. It allows AI agents to access user data, manage dialogs (chats, channels, groups), retrieve messages, and handle read status through standardized MCP tools. Designed for communication workflows, it enables agents to interact with Telegram directly.
