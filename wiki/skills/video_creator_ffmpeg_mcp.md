> 🎥 🔊 - Using ffmpeg command line to achieve an mcp server, can be very convenient, through the dialogue to achieve the local video search, tailoring, stitching, playback and other functions

video-creator/ffmpeg-mcp is an MCP server that wraps the FFmpeg command-line tool, enabling users to perform local video operations through natural dialogue. It supports searching, trimming, stitching, and playing back videos using conversational commands. This integration allows AI agents or chat interfaces to directly manipulate multimedia files on the user's machine via the Model Context Protocol. The project simplifies video editing tasks by bridging LLM conversations with FFmpeg's powerful capabilities.
