This MCP server provides AI image generation and editing capabilities with a curated library of over 1,500 prompts. It features smart prompt enhancement and can route requests to multiple providers including local ComfyUI, MeiGen Cloud, and OpenAI-compatible APIs. The tool integrates with the Model Context Protocol to enable easy use within AI agents.
