> Sandboxed code execution infrastructure for AI agents, useful when harness work starts to merge into execution runtime design.

SWE-ReX is a sandboxed code execution infrastructure designed for AI agents. It provides a secure environment where agents can run code without risking the host system. This tool becomes particularly useful when the harness (which manages agent interactions) starts to merge with the execution runtime design. It is categorized under runtimes, harnesses, and reference implementations in the embodied-intelligence and AI-agent tooling ecosystem.
