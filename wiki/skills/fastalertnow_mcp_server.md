> 🎖️ 📇 ☁️ - Official Model Context Protocol (MCP) server for FastAlert. This server allows AI agents (like Claude, ChatGPT, and Cursor) to list of your channels and send notifications directly through the FastAlert API.

FastAlertNow/mcp-server is an official MCP server that lets AI agents like Claude or ChatGPT manage FastAlert notifications. It allows agents to list channels and send alerts directly through the FastAlert API. This integration enables real-time communication and alerting from within AI workflows.
