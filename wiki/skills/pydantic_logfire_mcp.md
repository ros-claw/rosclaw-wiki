> 🎖️ 🐍 ☁️ - Provides access to OpenTelemetry traces and metrics through Logfire

This MCP server provides access to OpenTelemetry traces and metrics through Logfire. It allows AI agents to query telemetry data using natural language. Built by Pydantic, it integrates monitoring capabilities into MCP workflows. The server exposes tools for retrieving trace spans and metric readings. It is part of the monitoring ecosystem for agent observability.
