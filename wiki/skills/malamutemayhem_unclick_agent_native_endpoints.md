Zero-config local tools plus platform connectors. `npx @unclick/mcp-server`

This MCP server aggregates over 110 tools for AI agents, covering social media, finance, gaming, music, Australia-specific services, and utilities. It offers zero-configuration local tools as well as platform connectors. The server can be launched using the command `npx @unclick/mcp-server`. It is ideal for agents requiring a broad set of endpoints without manual setup.
