> 🐍 ☁️ - MCP server that fetches YouTube video transcripts and optionally summarizes them. Supports multiple transcript formats (text, JSON, SRT, WebVTT), multi-language retrieval, and flexible YouTube URL parsing.

This is an MCP (Model Context Protocol) server that allows AI agents to fetch transcripts from YouTube videos. It supports multiple transcript formats like text, JSON, SRT, and WebVTT. The server can optionally summarize the transcripts using AI. It handles various YouTube URL formats and supports multiple languages. This tool enables rapid extraction of video content for further processing.
