> 🐍 🏠 🍎 🐧 - Strategic task prioritization and agent orchestration for multi-project operators. 22 MCP tools with 5-factor scoring engine, advisory document analysis, agent dispatch with autonomy levels, HMAC webhooks, time-aware planning, and CI/CD integration. Standalone CLI + MCP server.

Quarterback is a tool for strategic task prioritization and agent orchestration, designed for operators managing multiple projects. It provides 22 MCP tools with a 5-factor scoring engine, advisory document analysis, and agent dispatch with configurable autonomy levels. The system includes HMAC webhooks, time-aware planning, and CI/CD integration, and can run as a standalone CLI or as an MCP server. It aims to help users focus on high-impact tasks and automate complex workflows.
