> 📇 🏠 - Full Figma control: create shapes, text, components, set styles, auto-layout, variables, export. 80+ tools.

Figma-use is a server implementation that provides over 80 tools for controlling Figma through a MCP (Model Context Protocol) interface. It enables programmatic creation of shapes, text, components, and customization of styles, auto-layout, variables, and exports. This allows developers and designers to automate design workflows directly from AI assistants or other tools. It is listed under Developer Tools and is designed for integration with embodied-intelligence or AI-agent systems.
