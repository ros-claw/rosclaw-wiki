Baozi MCP is a server that provides 68 tools for AI agents to interact with Solana-based prediction markets on Baozi.bet. Agents can browse markets, place bets, claim winnings, create new markets, and earn affiliate commissions. It is listed under the Finance & Fintech category of server implementations. This integration allows AI agents to automate participation in decentralized prediction markets on Solana.
