> [![apple-mail-mcp MCP server](https://glama.ai/mcp/servers/@imdinu/apple-mail-mcp/badges/score.svg)](https://glama.ai/mcp/servers/@imdinu/apple-mail-mcp) 🐍 🏠 🍎 - Fast MCP server for Apple Mail — 87x faster email fetching via batch JXA and FTS5 search index for ~2ms body search. 6 tools: list accounts/mailboxes, get emails with filters, full-text search across all scopes, and attachment extraction.

This is an MCP server that integrates with Apple Mail, enabling AI agents to access and search emails. It uses batch JavaScript for Automation (JXA) for fast email fetching and an FTS5 search index for near-instant full-text search. The server provides six tools: listing accounts and mailboxes, retrieving emails with filters, full-text search across all scopes, and extracting attachments. It claims to be 87x faster than traditional methods for email fetching.
