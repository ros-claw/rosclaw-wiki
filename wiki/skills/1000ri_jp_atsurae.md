> 🐍 ☁️ 🍎 🪟 🐧 - AI-powered video editing MCP server with 10 tools for timeline editing, 5-layer compositing, semantic operations, and FFmpeg rendering (1920x1080, 30fps H.264+AAC).

Atsurae is an AI-powered video editing server that implements the Model Context Protocol (MCP). It provides 10 tools for timeline editing, supports 5-layer compositing, and enables semantic operations on video content. The server renders output using FFmpeg at 1920x1080 resolution, 30fps with H.264 video and AAC audio. It is designed to integrate with AI agents for automated video production workflows.
