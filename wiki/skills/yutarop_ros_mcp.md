> 🐍 🏠 🐧 - MCP server that supports ROS2 topics, services, and actions communication, and controls robots using natural language.

This project provides an MCP (Model Context Protocol) server for ROS2, enabling communication with ROS2 topics, services, and actions. It allows developers and AI agents to control robots using natural language commands. The server is built with Python and is compatible with Linux environments. It serves as a bridge between natural language interfaces and the ROS2 ecosystem.
