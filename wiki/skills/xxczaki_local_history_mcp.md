> 📇 🏠 🍎 🪟 🐧  - MCP server for accessing VS Code/Cursor Local History

This MCP server provides access to the local history feature of VS Code and Cursor editors. It allows other tools to read and interact with saved file versions. The server is cross-platform, supporting various operating systems. It is categorized under file systems in the MCP server implementations list.
