> One-step Safe rebalancer using on-chain 31Third policies.

This project provides a one-step rebalancer for Safe multisig wallets using on-chain policies from 31Third. It simplifies the process of adjusting asset allocations within a Safe by leveraging predefined rules. The tool is likely used by DeFi users or DAOs to automate portfolio management while maintaining security via Safe contracts. It reduces gas costs and complexity compared to manual rebalancing.
