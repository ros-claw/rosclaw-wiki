MCP + HTTP REST API.

This MCP server provides a programmatic interface to Google NotebookLM, enabling automated Q&A with citations, creation of audio podcasts, video content, and source management. It exposes both MCP and HTTP REST APIs, allowing AI agents to interact with NotebookLM's note-taking and research capabilities. This integration enhances knowledge management and retrieval for AI systems, supporting full automation of NotebookLM features.
