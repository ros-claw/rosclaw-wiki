This MCP server provides 25 tools for interacting with the Solana blockchain. It enables wallet management, SOL and SPL token transfers, SPL token creation and minting, account operations, and network switching between mainnet, devnet, and testnet. Designed for finance and fintech applications, it simplifies building Solana-based agents.
