> OpenAI documentation on grading agent traces directly, which is especially helpful for long multi-step tasks.

Trace grading is an approach from OpenAI for evaluating agent behavior by directly grading the traces of actions. This method is particularly useful for assessing long, multi-step tasks where intermediate steps matter. It is categorized under Evals & Observability, focusing on understanding agent performance through detailed trace analysis.
