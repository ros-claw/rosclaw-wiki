> Generate comprehensive documentation from code. READMEs, API docs, and guides.

This plugin automatically generates comprehensive documentation from source code, including README files, API documentation, and user guides. It parses code comments, function signatures, and module structures to produce human-readable docs. The tool aims to reduce manual documentation effort and keep docs in sync with code changes. It supports multiple programming languages and documentation formats.
