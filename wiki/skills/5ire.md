> | [GitHub 仓库](https://github.com/nanbingxyz/5ire)

5ire 是一个基于 MCP (Model Context Protocol) 的客户端工具，旨在为开发者提供便捷的 AI 模型交互接口。它支持多种后端模型，并允许用户通过图形界面管理对话上下文。该项目开源在 GitHub 上，类似于 Claude Desktop 的第三方替代方案，但更加轻量和可定制。目前适合作为本地 AI 助手使用。
