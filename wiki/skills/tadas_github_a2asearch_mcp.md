Install: `npx -y a2asearch-mcp`. Ask Claude: "Find MCP servers for database access". Free, no auth required.

a2asearch-mcp is an MCP server that aggregates and indexes over 4,800 tools including MCP servers, AI agents, CLI tools, and agent skills. It allows users to search this extensive catalog to find relevant tools, such as database access MCP servers. The service is free, requires no authentication, and can be used with AI assistants like Claude. Installation is done via npx, and search results are returned directly from the MCP server.
