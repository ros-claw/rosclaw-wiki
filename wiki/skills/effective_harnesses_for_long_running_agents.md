This project describes Anthropic's foundational article on harnesses for long-running agents. It covers key components such as initializer agents, feature lists, an init.sh script, self-verification mechanisms, and handoff artifacts. These elements are designed to manage agent execution across many context windows, ensuring reliability and continuity. The article provides practical guidance for building effective, long-running agent systems.
