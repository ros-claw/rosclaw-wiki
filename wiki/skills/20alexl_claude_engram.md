An MCP server that provides persistent memory and session intelligence for Claude Code. It automatically tracks mistakes, decisions, and context via hooks, and mines session history for patterns and cross-session search. Includes loop detection, pre-edit warnings, and context compaction survival. Runs locally using Ollama.
