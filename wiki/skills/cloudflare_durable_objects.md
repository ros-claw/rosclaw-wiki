Cloudflare Durable Objects is a serverless computing service that provides strongly consistent, low-latency storage and coordination for Cloudflare Workers. It allows developers to define single-threaded objects accessible globally with strict consistency guarantees, making it ideal for real-time multiplayer apps, collaborative tools, and shared state across distributed edge locations. The service integrates directly with Cloudflare Workers and is billed based on compute and storage usage.
