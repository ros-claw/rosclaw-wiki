Hosted MCP at `https://app.maiat.io/api/mcp`.

Maiat Protocol is a trust infrastructure for the agent economy, providing a hosted MCP server with tools for agent trust scores (indexing over 18K agents), token rug pull forensics, outcome reporting for oracle feedback loops, and Scarab reputation points. It enables agents to verify each other's trustworthiness and detect fraudulent tokens. The protocol is listed under finance and fintech, aiming to build decentralized trust mechanisms for autonomous agents.
