> Safe Python interpreter based on HF Smolagents `LocalPythonExecutor`

This project provides an MCP server that implements a safe Python interpreter based on Hugging Face Smolagents' LocalPythonExecutor. It allows LLMs and coding agents to execute Python code in a sandboxed environment, preventing harmful operations. The server integrates with the Model Context Protocol to offer secure code execution capabilities. It is listed under Coding Agents server implementations.
