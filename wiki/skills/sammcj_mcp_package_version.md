> 📇 🏠 - An MCP Server to help LLMs suggest the latest stable package versions when writing code.

This MCP server provides LLMs with the latest stable versions of software packages from popular registries. It helps AI coding assistants suggest accurate package versions when writing code, reducing errors from stale or incorrect version references. The server supports multiple package managers like npm, PyPI, and others. By integrating via the Model Context Protocol, it enables real-time version lookups during development conversations.
