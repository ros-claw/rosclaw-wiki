> 📇 🏠 - Local MCP server for searching 300,000+ foods, nutrition facts, and barcodes from the OpenNutrition database.

This is a local MCP server that enables searching over 300,000 food items, nutrition facts, and barcodes from the OpenNutrition database. It implements the Model Context Protocol, allowing MCP clients to query food data locally. The server is categorized under search and data extraction tools in the MCP ecosystem.
