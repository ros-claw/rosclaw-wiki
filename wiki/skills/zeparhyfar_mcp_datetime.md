> MCP server providing date and time functions in various formats

This is an MCP (Model Context Protocol) server that offers date and time utility functions. It enables conversion between various date and time formats, such as ISO 8601, Unix timestamps, and human-readable strings. The server can be used within MCP-based systems for scheduling, logging, or timezone calculations. It provides a standardized interface for obtaining current date/time in different representations.
