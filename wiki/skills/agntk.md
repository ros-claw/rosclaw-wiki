> Zero-config AI agent CLI with persistent named agents, 20+ built-in tools, and hardware-aware local model selection.

agntk is a zero-configuration CLI tool for managing AI agents. It allows users to create persistent named agents with built-in tools, and automatically selects local models based on hardware capabilities. The tool aims to simplify developer workflows by providing over 20 integrated tools and seamless local AI execution without complex setup.
