> 🔥 ⛅️ - Firebase services including Auth, Firestore and Storage.

This is an MCP (Model Context Protocol) server implementation that provides integration with Firebase services. It supports authentication via Firebase Auth, document storage and retrieval using Firestore, and file storage through Firebase Storage. This server enables AI agents to interact with Firebase backends as part of their tooling and context.
