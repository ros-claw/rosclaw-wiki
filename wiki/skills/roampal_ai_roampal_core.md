Memories that help get promoted, memories that mislead get demoted. Works with Claude Code and OpenCode via hooks + MCP.

roampal-core is an MCP server that provides outcome-based persistent memory for AI coding tools. It promotes memories that help achieve desired outcomes and demotes those that are misleading. The tool integrates with Claude Code and OpenCode using hooks and the Model Context Protocol. This allows AI agents to learn from past actions and improve their performance over time.
