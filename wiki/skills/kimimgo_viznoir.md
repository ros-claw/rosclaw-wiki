Headless EGL/OSMesa.

Viznoir is a Model Context Protocol (MCP) server that provides cinema-quality scientific visualization capabilities for computational data. It offers 22 tools for rendering, slicing, contouring, volume rendering, and animating data from CFD, FEA, and SPH simulations. The server supports common formats like OpenFOAM, VTK, and CGNS, and runs headlessly using EGL or OSMesa for offscreen rendering. It is designed to be integrated with AI agents to enable automated visualization workflows within the MCP ecosystem.
