> Browser automation for AI agents via inference.sh.

Agentic-browser-0-1-2 is a tool that enables AI agents to control web browsers for automation tasks. It leverages the inference.sh platform to run agentic workflows, allowing agents to interact with web pages programmatically. The project aims to bridge large language models with real-world browser actions, enabling autonomous web navigation and data extraction. This facilitates complex multi-step tasks such as form filling, scraping, and testing through natural language instructions.
