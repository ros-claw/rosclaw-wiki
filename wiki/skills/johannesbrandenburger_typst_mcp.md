> 🐍 🏠 - MCP server for Typst, a markup-based typesetting system. It provides tools for converting between LaTeX and Typst, validating Typst syntax, and generating images from Typst code.

This project is an MCP (Model Context Protocol) server that integrates with Typst, a modern markup-based typesetting system. It provides tools for converting documents between LaTeX and Typst formats, validating Typst syntax, and rendering Typst code into images. Designed to be used with AI agents or other tools that support the MCP protocol, it enables automated typesetting and conversion workflows.
