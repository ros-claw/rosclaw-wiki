> 📇 🏠 - A MCP server for interacting with [Bruno API Client](https://www.usebruno.com/).

This project is an MCP server that enables AI agents to interact with the Bruno API Client. It allows agents to manage API collections, run requests, and integrate Bruno's capabilities into MCP-compatible workflows. The server acts as a bridge between Bruno's API testing features and AI-driven tools, enhancing automation and development efficiency.
