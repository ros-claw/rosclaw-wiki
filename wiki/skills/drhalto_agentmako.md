Agentmako is a local-first codebase intelligence engine that gives coding agents structured context packets, indexed code/schema facts, and diagnostics over the Model Context Protocol (MCP). It stores its data in a local SQLite database, reducing the need for agents to repeatedly scan the repository with grep. The tool also offers optional integration with Postgres and Supabase, and includes a bundled plugin for Claude Code. This helps agents understand the codebase more efficiently and contextually.
