> Analisa projetos no SonarQube self-hosted, obtém issues e sugere soluções automatizadas.

This tool analyzes projects hosted on a self-hosted SonarQube instance. It retrieves code quality issues from SonarQube and suggests automated solutions for them. The integration helps teams manage and improve code quality efficiently. It aims to streamline the process of identifying and fixing issues without manual intervention.
