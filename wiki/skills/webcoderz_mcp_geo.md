> 🐍 🏠 - Geocoding MCP server for nominatim, ArcGIS, Bing

This is an MCP (Model Context Protocol) server for geocoding, providing a unified interface to multiple geocoding services including Nominatim (OpenStreetMap), ArcGIS, and Bing Maps. It allows AI agents to convert addresses to geographic coordinates and vice versa using these providers. The server is written in Python and can be integrated with any MCP-compatible client. It simplifies location-based tasks for AI agents by abstracting away the different APIs of each geocoding service.
