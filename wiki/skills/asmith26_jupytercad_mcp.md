> 🐍 🏠 🍎 🪟 🐧 - An MCP server for [JupyterCAD](https://github.com/jupytercad/JupyterCAD) that allows you to control it using LLMs/natural language.

JupyterCAD-MCP is a server implementation that connects the Model Context Protocol (MCP) to JupyterCAD, a CAD tool within the Jupyter ecosystem. It enables users to control JupyterCAD using natural language commands via large language models (LLMs). This integration allows for AI-assisted 3D modeling and design directly from a Jupyter environment. The project supports multiple platforms including macOS, Windows, and Linux.
