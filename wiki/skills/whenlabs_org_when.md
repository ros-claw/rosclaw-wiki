WhenLabs-org/when is a command-line MCP server that provides seven developer tools for improving code quality and workflow. It automatically detects your tech stack and generates AI context files, catches port conflicts before they cause issues, validates your .env schema against expected variables, spots documentation drift, audits dependency licenses for compliance, and times coding tasks. These tools integrate into any MCP-compatible client, making it a versatile all-in-one assistant for developers.
