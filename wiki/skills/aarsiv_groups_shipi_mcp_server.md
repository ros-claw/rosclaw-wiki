> 📇 ☁️ - Shipi MCP server to create shipments, track packages, and compare rates with 18 tools for various carriers. Supports [remote MCP](https://mcp.myshipi.com/api/mcp).

The Shipi MCP server is a delivery tool that provides 18 tools for creating shipments, tracking packages, and comparing rates across various carriers. It supports remote MCP via an API endpoint at https://mcp.myshipi.com/api/mcp. This server is listed under Delivery in the server implementations list.
