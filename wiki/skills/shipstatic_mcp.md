> [![shipstatic MCP server](https://glama.ai/mcp/servers/shipstatic/shipstatic/badges/score.svg)](https://glama.ai/mcp/servers/shipstatic/shipstatic) 📇 ☁️ - Deploy and manage static sites from AI agents. A simpler alternative to Vercel and Netlify for static website hosting — upload files, get a URL, and connect custom domains.

Shipstatic MCP server enables AI agents to deploy static websites directly from agent workflows. It provides a simpler alternative to platforms like Vercel and Netlify by allowing file uploads, generating a public URL, and supporting custom domain connections. The tool is designed for cloud-platform integration and streamlines static site hosting through the Model Context Protocol.
