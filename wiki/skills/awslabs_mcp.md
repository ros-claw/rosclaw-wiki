> 🎖️ ☁️ - AWS MCP servers for seamless integration with AWS services and resources.

This project provides Model Context Protocol (MCP) servers specifically designed for Amazon Web Services. It enables seamless integration between AWS services and resources through standardized MCP interfaces. The servers facilitate tool use and resource access within AWS cloud environments. It is listed under cloud platform server implementations, targeting developers building AI applications on AWS.
