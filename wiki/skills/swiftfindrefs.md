> Use swiftfindrefs (IndexStoreDB) to list every Swift source.

swiftfindrefs is a command-line tool that uses Apple's IndexStoreDB to enumerate all Swift source files in a project. It can list every Swift source file, potentially useful for indexing or searching references. The tool is designed for Swift developers who need to perform code analysis. It integrates with the IndexStoreDB library to access the index store built by the compiler.
