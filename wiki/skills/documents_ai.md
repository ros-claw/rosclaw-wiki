> Real-time OCR and data extraction API by Veryfi.

documents-ai is a real-time OCR and data extraction API developed by Veryfi. It allows developers to integrate document processing capabilities such as scanning receipts, invoices, and other documents to extract structured data. The API supports various document types and provides fast, accurate data extraction for use in automation, accounting, and expense management applications.
