Single Go binary, 10 tools, async generation with polling.

Trident-MCP is a Model Context Protocol server that provides AI-powered 3D model generation and post-processing. It can generate 3D models from text, images, or multiview inputs via the Tripo API, and offers tools for retopology, format conversion (GLB, FBX, OBJ, STL, USDZ), and stylization. The single Go binary includes 10 tools and supports asynchronous generation with polling. It is designed for multimedia processing workflows in AI agent environments.
