> Complete Kaggle integration — account setup, competition reports, dataset/model downloads, notebook execution, submissions, and badge collection.

kaggle-skill is a plugin that provides complete integration with Kaggle for an AI agent. It enables account setup, competition reports, dataset and model downloads, notebook execution, submissions, and badge collection. This allows the agent to interact with Kaggle's platform programmatically, accessing data science resources and participating in competitions.
