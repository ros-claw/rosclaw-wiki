Knowledge Graph that learns across executions.

Agentled/mcp-server is an AI-native workflow orchestration tool that integrates with over 100 services via MCP tools. It provides long-term memory through a knowledge graph that learns across executions. The platform offers 32 MCP tools for business workflows like lead enrichment, content publishing, company research, and media production. It uses a unified credits system and is listed under workplace and productivity server implementations.
