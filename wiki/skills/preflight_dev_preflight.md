> 📇 🏠 🍎 🪟 🐧 - 24-tool MCP server for Claude Code that catches vague prompts before they waste tokens. Includes 12-category prompt scorecards, session history search with LanceDB vectors, cross-service contract awareness, correction pattern learning, and cost estimation.

This project provides an MCP (Model Context Protocol) server specifically designed for Claude Code to detect and prevent vague prompts, saving tokens and improving efficiency. It includes 12-category prompt scorecards, session history search using LanceDB vectors, cross-service contract awareness, correction pattern learning, and cost estimation. The tool integrates with Claude Code to catch unclear instructions before they generate unnecessary cost or wasted effort, helping developers maintain high-quality interactions with AI coding agents.
