> 📇 ☁️ - Fast domain availability aggregator with pricing. Checks Porkbun, Namecheap, GoDaddy, RDAP & WHOIS. Includes bulk search, registrar comparison, AI-powered suggestions, and social media handle checking.

This project provides a Model Context Protocol (MCP) server for fast domain availability checking and pricing. It aggregates data from multiple registrars including Porkbun, Namecheap, GoDaddy, RDAP, and WHOIS. Features include bulk search, registrar comparison, AI-powered domain suggestions, and social media handle checking. It is designed for developers integrating domain search into AI-assisted tools.
