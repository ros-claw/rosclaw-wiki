Local JSON, zero config, no server required.

Rememb is a Model Context Protocol (MCP) server that gives AI agents persistent memory with sectioned entries like project, user, and context. It supports semantic search, a CLI interface, and per-project scoping. Storage uses local JSON files with zero configuration and no external server needed. The tool is cross-platform (Mac, Windows, Linux) and designed for easy integration into AI workflows.
