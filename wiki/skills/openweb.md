> Agent-native way to access any website. Calls the same APIs the website calls (JSON in, JSON out) with auth (cookies, JWT, CSRF, signing) auto-resolved per request. 90+ sites built in.

OpenWeb is a tool designed for AI agents to access websites natively by calling their underlying APIs directly. It handles authentication automatically, including cookies, JWT, CSRF tokens, and signing, on a per-request basis. The tool supports over 90 predefined sites and returns data in JSON format. This allows agents to interact with web services without needing to parse HTML or manage complex authentication flows.
