> 📇 ☁️ - Access Dutch Railways (NS) travel information, schedules, and real-time updates

This tool provides access to Dutch Railways (NS) travel information, schedules, and real-time updates via an MCP server. It allows users to query train schedules, check disruptions, and access departure times. The server integrates with the NS API to deliver accurate and up-to-date data. It is designed for developers building travel-related applications.
