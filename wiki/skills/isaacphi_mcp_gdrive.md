> 📇 ☁️ - Model Context Protocol (MCP) Server for reading from Google Drive and editing Google Sheets.

This project provides a Model Context Protocol (MCP) server that enables AI agents to read files from Google Drive and edit Google Sheets. It is listed under File Systems in the MCP server implementations and allows seamless integration of Google Drive data into agent workflows. The server handles authentication and API interactions, making it easy for developers to add Google Drive and Sheets capabilities to their MCP-based tools.
