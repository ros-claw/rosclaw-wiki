> 📇 🏠 - Static server that provides persistent tool-specific context and rules for AI models

The MCP-Context-Provider is a static server designed to supply persistent, tool-specific context and rules to AI models. It helps maintain consistent behavior across interactions by storing relevant information that AI agents can reference. This tool is part of the Model Context Protocol (MCP) ecosystem, focusing on knowledge and memory management for embodied AI systems.
