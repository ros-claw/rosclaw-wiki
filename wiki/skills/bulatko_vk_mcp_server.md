> [![vk-mcp-server MCP server](https://glama.ai/mcp/servers/bulatko/vk-mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/bulatko/vk-mcp-server) 📇 ☁️ - MCP server for VK (VKontakte) social network API. Access users, walls, groups, friends, newsfeed, photos, and community stats.

This is a Model Context Protocol (MCP) server that provides access to the VKontakte (VK) social network API. It enables AI agents to interact with VK features such as user profiles, walls, groups, friends, newsfeeds, photos, and community statistics. The server is listed under social media implementations on the MCP server registry. It simplifies connecting AI tools to a major Russian social media platform.
