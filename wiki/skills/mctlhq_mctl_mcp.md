mctlhq/mctl-mcp is an MCP server that provides an AI-native platform for managing Kubernetes clusters and automating GitOps workflows. It offers over 30 tools for interacting with Kubernetes resources, enabling AI agents to perform operations like deployments, scaling, monitoring, and rollbacks. The platform integrates GitOps principles to synchronize cluster state with Git repositories. This allows AI assistants to manage cloud-native infrastructure using natural language or structured commands.
