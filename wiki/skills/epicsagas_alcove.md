Alcove is an MCP server that gives AI coding agents on-demand access to private project documentation using BM25 ranked search. It works with tools like Claude Code, Cursor, Codex, and Gemini CLI, keeping docs private and out of public repositories. Setup is done once, and the server can be used across multiple coding agents.
