> 🐍 ☁️ - An MCP server for tracking and managing cryptocurrency portfolio allocations.

This project is an MCP server designed for tracking and managing cryptocurrency portfolio allocations. It enables AI agents to interact with cryptocurrency portfolio data, such as checking balances and performing rebalancing actions. Built on the Model Context Protocol, it integrates with external APIs (e.g., CoinGecko) to provide real-time portfolio insights. The server exposes tools that can be called by AI assistants to help users optimize their crypto holdings.
