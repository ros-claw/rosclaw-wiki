> 🐍 ☁️ - MCP server for Atlassian products (Confluence and Jira). Supports Confluence Cloud, Jira Cloud, and Jira Server/Data Center. Provides comprehensive tools for searching, reading, creating, and managing content across Atlassian workspaces.

This MCP server provides integration with Atlassian products, specifically Confluence and Jira. It supports both cloud-based and on-premises versions, including Jira Server and Data Center. The server offers comprehensive tools for searching, reading, creating, and managing content across Atlassian workspaces. It enables AI agents to interact with these services through the Model Context Protocol.
