A stateful Model Context Protocol (MCP) server that wraps real language servers, offering 50 tools and supporting 30 languages. It maintains persistent sessions to keep indexes warm across files and projects. Features speculative execution to simulate edits in memory before writing to disk, enabling agent workflows. Designed for developer tools and CI-verified languages.
