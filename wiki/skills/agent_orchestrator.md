> Meta-agent skill for orchestrating complex tasks.

Agent Orchestrator is a meta-agent skill designed to coordinate and manage the execution of complex, multi-step tasks. It allows an AI agent to break down high-level objectives into subtasks, assign them to specialized agents or tools, and monitor progress. This enables more sophisticated problem-solving by leveraging hierarchical planning and execution. The project likely provides a framework for building agent systems that can handle intricate workflows.
