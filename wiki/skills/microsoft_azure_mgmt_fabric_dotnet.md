This is the Azure Fabric management library for .NET, providing client libraries to manage and interact with Azure Fabric resources. It is part of the Azure SDK for .NET and supports operations like creating, updating, and deleting fabric clusters or analytics components. The library is maintained by Microsoft and is listed under the .NET Skills category in the project index.
