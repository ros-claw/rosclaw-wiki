> 🏎️ ☁️ - Remote Storage Access: SFTP, S3, FTP, SMB, NFS, WebDAV, GIT, FTPS, gcloud, azure blob, sharepoint, etc.

Filestash is an open-source, self-hosted web application that provides a unified interface for accessing a wide range of remote storage protocols. It supports protocols such as SFTP, S3, FTP, SMB, NFS, WebDAV, Git, FTPS, Google Cloud Storage, Azure Blob, and SharePoint. Users can manage files across different backends through a single web dashboard, making it useful for teams and individuals who need centralized remote file management. The project is designed to be extensible and customizable with plugins.
