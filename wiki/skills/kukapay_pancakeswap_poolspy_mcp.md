> 🐍 ☁️ -  An MCP server that tracks newly created pools on Pancake Swap.

This MCP server, called PoolSpy, monitors and tracks newly created liquidity pools on PancakeSwap, a decentralized exchange on the BNB Chain. It provides tools for AI agents to receive real-time notifications about new pool listings. Built using the Model Context Protocol (MCP), it enables easy integration with AI assistants for monitoring DeFi activities.
