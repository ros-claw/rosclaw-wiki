This is the Azure management SDK for Microsoft Fabric, written in Python. It provides Python classes for managing Fabric capacities using Azure Resource Manager. Developers can use this package to create, update, and delete Fabric resources programmatically. It is part of the Azure Python SDK ecosystem, commonly used in infrastructure-as-code and automation scripts.
