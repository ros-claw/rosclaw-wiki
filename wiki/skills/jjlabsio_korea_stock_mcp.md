> 📇 ☁️ - An MCP Server for Korean stock analysis using OPEN DART API and KRX API

This project is an MCP (Model Context Protocol) server designed for Korean stock market analysis. It leverages two official Korean financial data sources: the OPEN DART API (for corporate disclosures) and the KRX API (for stock exchange data). The server enables AI agents or clients to query and retrieve structured stock information, making it useful for financial analysis tools and chatbots. By integrating these APIs into a standardized MCP interface, it simplifies access to Korean equity data for automated trading and research applications.
