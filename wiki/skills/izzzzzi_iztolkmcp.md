Compile, syntax-check, and generate deployment deeplinks for TON contracts directly from AI assistants.

This MCP server provides AI assistants with access to the Tolk smart contract compiler for the TON blockchain. It supports compiling contracts, checking syntax, and generating deployment deeplinks. The server allows developers to interact with TON contract development workflows directly through natural language or tool-based AI interfaces. It simplifies blockchain development by integrating compiler and deployment tooling into the Model Context Protocol.
