> ☕ ☁️/🏠 - A Spring AI MCP-based service for retrieving ONES Waiki content and converting it to AI-friendly text format.

This MCP server, built with Spring AI, retrieves content from ONES Waiki and converts it into a text format suitable for AI processing. It can be deployed in the cloud or on-premises, enabling AI agents to access wiki information seamlessly. The service implements the Model Context Protocol, allowing integration with various AI tools. It serves as a bridge between ONES Waiki and AI applications.
