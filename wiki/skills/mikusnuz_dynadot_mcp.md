An MCP server that integrates with the Dynadot domain registrar API, providing 60 tools for domain search, registration, DNS management, contact handling, transfers, and marketplace operations. It enables AI agents to perform domain-related tasks through the Model Context Protocol. The server is listed under Cloud Platforms in the MCP server directory.
