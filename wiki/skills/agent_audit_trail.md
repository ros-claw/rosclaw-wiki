> Tamper-evident, hash-chained audit logging for AI agents.

This project implements tamper-evident audit logging for AI agents using hash chaining. Each log entry's cryptographic hash is linked to the previous one, forming an immutable chain that detects any tampering. It is designed for accountability and transparency in autonomous agent systems. The tool helps verify the integrity of agent actions and decisions over time.
