Auth0 Next.js SDK provides authentication and authorization for Next.js applications using Auth0. It handles login, logout, session management, and user data. Built for TypeScript, it integrates with Next.js App Router and Pages Router. It offers helpers for API routes and middleware to protect pages. This package simplifies adding Auth0 to any Next.js project.
