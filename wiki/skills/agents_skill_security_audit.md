> Minimal helper to audit skill.md-style instructions for supply-chain risks.

This is a minimal tool that audits 'skill.md'-style instruction files for supply-chain risks. It helps developers identify potential security issues in instructions used by AI agents. The audit focuses on dependencies and instructions sourced from third parties. It is designed to be lightweight and easy to integrate into agent development workflows.
