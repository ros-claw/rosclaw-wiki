AgentBase1/mcp-server is an open registry of AI agent instruction files, accessible via MCP tools. It allows searching and retrieving system prompts, skills, workflows, domain packs, and safety filters. The registry contains 44 CC0-licensed files and is free to use. It serves as a knowledge and memory resource for AI agents, enabling them to find structured instructions.
