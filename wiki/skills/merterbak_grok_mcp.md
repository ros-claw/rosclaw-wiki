> 🐍 ☁️ 🍎 🪟 🐧 - MCP server for xAI's [Grok API](https://docs.x.ai/docs/overview) with agentic tool calling, image generation, vision, and file support.

This project provides an MCP server that acts as an aggregator for xAI's Grok API, offering a standardized interface for agentic tool calling, image generation, vision capabilities, and file support. It runs on Python and supports multiple platforms including cloud, macOS, Windows, and Linux. The server simplifies integration of Grok's models into MCP-compatible applications, enabling developers to build AI agents with advanced features. By leveraging the Grok API, it extends the Model Context Protocol ecosystem with powerful generative AI capabilities.
