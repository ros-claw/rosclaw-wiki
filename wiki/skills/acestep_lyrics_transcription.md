> Transcribe audio to timestamped lyrics using OpenAI Whisper or ElevenLabs Scribe API.

This tool transcribes audio files into timestamped lyrics, enabling applications like karaoke and subtitle generation. It uses either OpenAI Whisper or ElevenLabs Scribe API for accurate speech recognition. The output includes precise timing for each lyric segment, making it useful for music analysis and synchronization.
