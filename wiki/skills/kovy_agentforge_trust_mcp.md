AgentForge Trust MCP is a server that evaluates the trustworthiness of other MCP servers by assigning a score from 0 to 100 across five dimensions: security, code health, behavioral audit, community trust, and EU compliance. It provides tools such as check_trust, evaluate_policy, list_trusted, and recommend, enabling users to assess servers before connecting. With over 3,600 servers audited and a free public API, it helps enhance safety in the MCP ecosystem. The project is categorized under security-focused server implementations.
