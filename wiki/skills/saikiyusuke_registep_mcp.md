> 📇 ☁️ - AI-powered POS & sales analytics MCP server with 67 tools for Airレジ, スマレジ, and BASE EC integration. Provides store management, sales data querying, AI chat analysis, and weather correlation features.

This project is an MCP server that integrates with Japanese POS and e-commerce platforms like Airレジ, スマレジ, and BASE EC. It provides 67 tools for store management, sales data querying, AI-powered chat analysis, and weather correlation features. The server enables users to analyze sales data and get insights through natural language queries. It is designed to be a comprehensive analytics tool for retail and e-commerce businesses using those platforms.
