> 🐍 ☁️ 🏠 - TIBET provenance tracking for AI decisions. Cryptographic audit trails with ERIN/ERAAN/EROMHEEN/ERACHTER intent logging for compliance.

This MCP server implements TIBET provenance tracking for AI decision-making, providing cryptographic audit trails. It uses a four-tag system (ERIN, ERAAN, EROMHEEN, ERACHTER) for intent logging to ensure compliance. The tool helps developers maintain transparent and verifiable records of AI actions. It is listed under Developer Tools for server implementations.
