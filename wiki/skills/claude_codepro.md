> Professional development environment for Claude Code with spec-driven workflow, TDD enforcement, cross-session memory, semantic search, quality hooks, and modular rules integration. A bit "heavyweight" but feature-packed and has wide coverage.

Claude CodePro is a professional development environment that enhances Claude Code by enforcing a spec-driven workflow and TDD practices. It includes cross-session memory, semantic search, quality hooks, and modular rules integration. Though considered heavyweight, it offers a comprehensive set of features for improving development workflows.
