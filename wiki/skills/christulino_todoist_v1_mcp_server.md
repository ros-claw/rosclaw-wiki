This is an MCP server that integrates with Todoist, a popular task management application. It uses the unified API v1 and provides 20 tools for managing tasks, projects, sections, and labels. The server operates via stdio transport, which eliminates daily reconnection issues. This allows AI agents to interact with Todoist data and perform actions seamlessly.
