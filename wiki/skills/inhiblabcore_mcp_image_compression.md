> 🐍 🏠 - MCP server for local compression of various image formats.

This is an MCP server that provides local compression for various image formats. It operates entirely on the user's machine, preserving privacy and reducing latency. Listed under Developer Tools, it integrates with the Model Context Protocol ecosystem to enable automated image optimization workflows.
