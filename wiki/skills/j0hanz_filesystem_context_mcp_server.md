> 📇 🏠 - Read-only MCP server for secure filesystem exploration, searching, and analysis with symlink protection.

This is a read-only MCP server for filesystem context. It allows secure exploration and searching of the file system while protecting against symlink attacks. AI agents can safely analyze files without modification risks. The server is part of the Model Context Protocol ecosystem for agent tooling.
