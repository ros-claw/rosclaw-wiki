This is a Model Context Protocol (MCP) server that integrates with the Trading 212 API, offering 28 tools for managing portfolios, executing trades (market, limit, stop orders), handling pies and dividends, fetching market data, and performing analytics. It includes built-in rate limiting to ensure stable API usage. Designed for developers building AI assistants or automated systems for stock trading and investment management on the Trading 212 platform.
