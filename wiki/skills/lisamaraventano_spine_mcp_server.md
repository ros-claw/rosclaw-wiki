This is an MCP server from The Underground Cultural District that provides 23 tools for AI agents, including 13 free developer utilities such as UUID generation, JSON formatting, Base64 encoding, hashing, JWT decoding, regex testing, cron scheduling, and ETH conversion. It also offers 7 paid creative tools and a browsable marketplace with over 218 digital goods across 22 shops. The server can be installed via npm as '@underground-cultural-district/mcp-server' and is listed under Developer Tools in the MCP server directory.
