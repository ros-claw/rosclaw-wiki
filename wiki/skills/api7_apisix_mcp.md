> 🎖️ 📇 🏠 MCP Server that support for querying and managing all resource in [Apache APISIX](https://github.com/apache/apisix).

This project provides a Model Context Protocol (MCP) server that integrates with Apache APISIX, an open-source API gateway. It enables AI agents to query and manage APISIX resources such as routes, services, and plugins through natural language interactions. The server is designed for developers to streamline API management tasks within AI-driven development workflows. It is categorized as a developer tool in the MCP server ecosystem.
