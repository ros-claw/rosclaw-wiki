> 🦀 🏠 🚨 🍎 🪟 🐧 - A Rust-based MCP server bridging Wazuh SIEM with AI assistants, providing real-time security alerts and event data for enhanced contextual understanding.

This project is a Rust-based MCP server that connects Wazuh, a popular open-source SIEM (Security Information and Event Management) platform, to AI-powered assistants. It allows AI agents to access real-time security alerts and event data from Wazuh, enhancing their ability to provide contextual security insights. The server runs on major operating systems (macOS, Windows, Linux) and leverages Rust's performance and safety for efficient data handling. By bridging SIEM data with AI, it enables automated security analysis, incident response, and decision support within AI-driven workflows.
