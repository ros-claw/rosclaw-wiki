> 🐍 ☁️ - Google Ad Manager API integration for managing campaigns, orders, line items, creatives, and advertisers with bulk upload support.

This project provides an MCP server for interacting with Google Ad Manager, enabling management of advertising campaigns, orders, line items, creatives, and advertisers. It supports bulk upload functionality to handle large-scale operations efficiently. The server is categorized under marketing implementations, making it suitable for automated ad operations.
