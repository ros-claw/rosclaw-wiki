> 🐍 ☁️ - Universal MCP server for CalDAV protocol integration. Works with any CalDAV-compatible calendar server including Yandex Calendar, Google Calendar (via CalDAV), Nextcloud, ownCloud, Apple iCloud, and others. Supports creating events with recurrence, categories, priority, attendees, reminders, searching events, and retrieving events by UID.

This MCP server enables integration with any CalDAV-compatible calendar service, such as Yandex, Google, Nextcloud, ownCloud, and iCloud. It allows creating and managing calendar events with advanced features like recurrence, categories, priority, attendees, and reminders. Users can search events and retrieve them by unique ID. The server serves as a universal bridge between AI agents and various calendar systems via the Model Context Protocol.
