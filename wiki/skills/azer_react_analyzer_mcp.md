> 📇 🏠 - Analyze React code locally, generate docs / llm.txt for whole project at once

This tool is an MCP server that analyzes React codebases locally. It generates comprehensive documentation or an 'llm.txt' file for the entire project at once. This helps developers quickly understand and document their React code structure.
