Install: `npm install -g firma-app`.

Firma is a local-first CLI asset tracker designed for overseas stock investors, integrating with Claude Desktop via the Model Context Protocol (MCP). It provides 13 tools for portfolio tracking, net worth snapshots, cash flow analysis, and market research, including earnings, insider trades, and SEC filings through Finnhub. The tool is installed globally via npm and runs on macOS, Windows, and Linux.
