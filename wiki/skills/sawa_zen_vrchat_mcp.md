> 📇 🏠 This is an MCP server for interacting with the VRChat API. You can retrieve information about friends, worlds, avatars, and more in VRChat.

This MCP server enables AI assistants to interact with the VRChat API, providing tools to retrieve information about friends, worlds, avatars, and other game data. It serves as a bridge between VRchat and language models, enabling social and in-world queries. The project is listed under server implementations for communication, emphasizing its role in enabling AI-driven interactions within VRChat.
