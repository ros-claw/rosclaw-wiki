> 🍎 Build iOS Xcode workspace/project and feed back errors to llm.

xcodebuild is a developer tool that compiles iOS Xcode projects or workspaces. It captures build errors and feeds them to a large language model (LLM) for analysis or automated correction. This integration streamlines iOS debugging by combining traditional build processes with AI feedback. It is categorized under Server Implementations and Developer Tools within the AI-agent tooling ecosystem.
