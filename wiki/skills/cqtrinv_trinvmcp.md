> 📇 ☁️ - Explore French communes and cadastral parcels based on name and surface

This MCP server provides tools to explore French communes and cadastral parcels by name and surface area. It allows querying geographic data for administrative divisions and land parcels in France. Users can search for communes by name and retrieve parcel information. The server is designed for integration with AI assistants to access French location data.
