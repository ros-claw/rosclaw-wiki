> 📇 ☁️ MCP server to interact with Quran.com corpus via the official REST API v4.

This project is a Model Context Protocol (MCP) server that provides AI agents with access to the Quran.com corpus through its official REST API v4. It allows users to query verses, translations, commentaries, and other Islamic textual resources for contextual retrieval. The server bridges Islamic sacred texts with AI-powered applications, enabling cultural and religious exploration.
