> A mature research coding agent that makes the harness, prompt, tools, and environment design directly inspectable.

SWE-agent is a mature research tool for building coding agents. It emphasizes transparency by making the harness, prompts, tools, and environment design directly inspectable. This allows researchers to understand and modify the agent's components easily. It is listed under runtimes and reference implementations, indicating it is a concrete implementation for agent development.
