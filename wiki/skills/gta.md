> A benchmark that evaluates the tool-use capability of LLM-based agents using human-written queries, real deployed tools, and authentic multimodal inputs, exposing harness gaps between isolated testing and real deployment.

GTA is a benchmark designed to evaluate how well LLM-based agents can use tools. It uses human-written queries, real deployed tools, and authentic multimodal inputs to test agents. The benchmark reveals gaps between isolated testing and real-world deployment of these agents.
