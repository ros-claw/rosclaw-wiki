> 📇 ☁️ A Model-Context-Protocol (MCP) server for integrating with Yuque API, allowing AI models to manage documents, interact with knowledge bases, search content, and access analytics data from the Yuque platform.

A Model-Context-Protocol (MCP) server that connects AI models to the Yuque platform, enabling document management, knowledge base interaction, content search, and analytics access. It allows AI assistants to read, write, and manage documents within Yuque's cloud-based knowledge management system. This integration streamlines knowledge retrieval and collaboration for AI-powered workflows.
