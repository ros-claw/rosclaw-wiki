Recall Nest is a Model Context Protocol (MCP) server that provides persistent memory for AI coding agents such as Claude Code, Codex, and Gemini CLI. It uses hybrid retrieval combining vector search and BM25, along with cross-encoder reranking for accurate information recall. The system includes a knowledge graph with Personalized PageRank (PPR) traversal, session checkpoint and resume capabilities, and multi-scope isolation. It is local-first, built on LanceDB and SQLite, with no external dependencies.
