Self-hosted, open-source pipeline tool with multi-LLM support.

This project is an MCP (Model Context Protocol) server that transforms RocketRide AI pipelines into tools for use with AI assistants like Claude, Cursor, and Windsurf. It is self-hosted and open-source, allowing users to run custom AI workflows. The server supports multiple large language models (multi-LLM), making it flexible for various AI tasks. Essentially, it bridges the gap between AI pipelines and popular coding assistants.
