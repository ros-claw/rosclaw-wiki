> 🐍 🏠 🍎 🪟 🐧 - Structural codebase indexer exposing 17 query tools (functions, classes, imports, dependency graphs, change impact) via MCP. Zero dependencies.

This MCP server indexes codebases to provide structural information, exposing 17 query tools for functions, classes, imports, dependency graphs, and change impact analysis. It requires zero dependencies and works cross-platform (Windows, macOS, Linux) with support for Python (and potentially other languages via emojis). Developers can use it to understand code architecture and evaluate the impact of modifications. The tool integrates with the Model Context Protocol for AI-assisted code exploration.
