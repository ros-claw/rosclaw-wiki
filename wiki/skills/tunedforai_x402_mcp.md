Free via MCP ([`@tunedforai/x402-mcp`](https://www.npmjs.com/package/@tunedforai/x402-mcp) on npm) or pay-per-call in USDC on Base via x402 REST at [`x402.tunedfor.ai`](https://x402.tunedfor.ai) — no API key, no rate limits.

This project is an MCP server that provides real-time cryptocurrency market structure data for AI agents. It aggregates order flow from 20 exchanges across 24 tokens, offering nine tools including price, funding rates, open interest, cross-exchange cumulative volume delta with whale activity, 7-year OHLCV history, and on-chain address risk analysis. The server is free to use via MCP protocol or can be accessed through a pay-per-call REST API in USDC on Base without requiring an API key or rate limits. It is designed to give AI agents deep, institutional-grade market insights for trading and analysis.
