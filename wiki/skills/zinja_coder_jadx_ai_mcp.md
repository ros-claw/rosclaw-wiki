> ☕ 🏠 - JADX-AI-MCP is a plugin and MCP Server for the JADX decompiler that integrates directly with Model Context Protocol (MCP) to provide live reverse engineering support with LLMs like Claude.

JADX-AI-MCP is a plugin and MCP server for the JADX decompiler that integrates with the Model Context Protocol to enable live reverse engineering assistance using large language models like Claude. It allows developers to interact with decompiled code through an AI-powered interface, streamlining the analysis of Android applications. This tool combines decompilation with AI chat to provide contextual suggestions and explanations during reverse engineering tasks.
