EquiVault MCP is an official MCP server for AI-powered equity research, designed to be used with Claude. It provides 38 tools covering company fundamentals, financial statements, ratios, stock quotes, screening, peer comparison, investment narratives, guidance tracking, segments, capital allocation, insider transactions, earnings quality, signals intelligence, alerts, briefs, and portfolio analytics. The server is tier-aware, offering graceful upgrade prompts for premium features, and can be easily installed via `npx equivault-mcp`. This tool enables comprehensive financial analysis and decision support through natural language interaction.
