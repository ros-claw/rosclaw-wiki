This is an MCP server that provides real-time, on-chain calculated crypto indicators including EMA, RSI, Bollinger Bands, and Volatility for 22 different tokens. It aggregates 484 indicator feeds across four timeframes, leveraging Chainlink oracles for decentralized data. Users can explore the service via a free trial faucet, making it suitable for developers building AI-driven trading or analysis tools within the Model Context Protocol ecosystem.
