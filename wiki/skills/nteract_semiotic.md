nteract/semiotic is an MCP server built with React that provides data visualization capabilities to AI agents. It supports more than 30 chart types and exposes five tools: suggest charts for a dataset, render validated React configurations to SVG, diagnose configuration anti-patterns, get component schemas, and report issues. The server helps AI applications dynamically create and refine data visualizations.
