> 🐍 ☁️ 🏠 - An MCP server for searching and downloading royalty-free stock photography from Pexels and Unsplash. Features multi-provider search, rich metadata, pagination support, and async performance for AI assistants to find and access high-quality images.

This project is a server that implements the Model Context Protocol (MCP) to let AI assistants search for and download royalty-free stock photos. It supports two providers, Pexels and Unsplash, and combines their results into a single search. The server returns rich metadata for each image and supports pagination. It is designed for async performance to help AI tools quickly find and retrieve high-quality images.
