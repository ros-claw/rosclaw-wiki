> 🐍 ☁️ - MCP server for interacting with cloud deployments of Jetbrains Datalore platform. Fully incorporated Datalore API ( run, run interactively, get run data, fetch files )

This project is an MCP (Model Context Protocol) server that enables interaction with cloud deployments of the JetBrains Datalore platform. It fully incorporates the Datalore API, allowing users to run computations, run interactively, retrieve run data, and fetch files from the cloud environment. It is listed under Developer Tools within the Server Implementations category, making it a specialized tool for developers working with Datalore in cloud settings. The server acts as a bridge between MCP clients and Datalore, facilitating automated workflows and data science tasks.
