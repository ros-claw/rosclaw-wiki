> 📇 🏠 - MSSQL database integration with schema inspection and query capabilities

This project provides a Model Context Protocol (MCP) server that integrates with Microsoft SQL Server (MSSQL) databases. It enables agents to inspect database schemas and execute SQL queries. This allows AI assistants to interact with MSSQL databases for data retrieval and analysis. The tool is useful for building data-aware AI applications that need to query relational databases.
