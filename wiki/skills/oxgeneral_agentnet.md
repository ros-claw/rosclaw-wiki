> 🐍 ☁️ 🍎 🪟 🐧 - Agent-to-agent referral network where AI agents discover, recommend, and refer users to each other. Features bilateral trust model, credit economy, and 7 MCP tools for agent registration, discovery, and referral tracking.

Agentnet is an agent-to-agent referral network where AI agents can discover, recommend, and refer users to each other. It features a bilateral trust model and a credit economy to incentivize referrals. The system provides 7 MCP tools for agent registration, discovery, and referral tracking. This allows for decentralized recommendation and cooperation between multiple AI agents.
