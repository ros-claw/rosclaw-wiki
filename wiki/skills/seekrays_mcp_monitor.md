> 🏎️ 🏠 - A system monitoring tool that exposes system metrics via the Model Context Protocol (MCP). This tool allows LLMs to retrieve real-time system information through an MCP-compatible interface.（support CPU、Memory、Disk、Network、Host、Process）

seekrays/mcp-monitor is a system monitoring tool that integrates with the Model Context Protocol (MCP). It exposes real-time metrics such as CPU, memory, disk, network, host, and process information via an MCP-compatible interface. This allows large language models (LLMs) to query system status directly through the MCP. The tool is listed under Server Implementations in the MCP ecosystem, focusing on monitoring capabilities.
