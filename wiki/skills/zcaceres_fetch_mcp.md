> 📇 🏠 - An MCP server to flexibly fetch JSON, text, and HTML data

fetch-mcp is an MCP server that enables flexible fetching of JSON, text, and HTML data. It is designed for developers integrating external data into AI agent workflows. The server provides a simple interface to retrieve content from URLs or other sources. This tool fits within the Model Context Protocol ecosystem for agent tooling. It is categorized as a developer tool in the MCP server implementations.
