> 🐍 🏠 - MCP server to access and manage LLM application prompts created with [Langfuse]([https://langfuse.com/](https://langfuse.com/docs/prompts/get-started)) Prompt Management.

This MCP server enables AI agents to access and manage LLM prompts via Langfuse's Prompt Management system. It allows developers to retrieve, version, and collaborate on prompts using a standardized protocol. The server is written in Python and runs locally, integrating directly with Langfuse's prompt tooling. It streamlines prompt workflow automation for AI applications.
