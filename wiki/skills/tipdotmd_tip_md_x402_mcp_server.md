> 📇 ☁️ - MCP server for cryptocurrency tipping through AI interfaces using x402 payment protocol and CDP Wallet.

This MCP server enables cryptocurrency tipping through AI interfaces using the x402 payment protocol and CDP Wallet. It integrates with MCP-compatible clients to allow AI agents to send tips in cryptocurrency. The server handles payment processing via the x402 protocol, which is a micro-payment system, and uses Coinbase's CDP Wallet for wallet management. This facilitates seamless micro-transactions within AI agent interactions.
