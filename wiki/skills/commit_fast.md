> Automates git commit process by selecting the first suggested message, generating structured commits with consistent formatting while skipping manual confirmation and removing Claude co-Contributorship footer

/commit-fast is a slash command that automates the git commit process by selecting the first suggested commit message, generating structured commits with consistent formatting, skipping manual confirmation, and removing the Claude co-contributorship footer. It streamlines the workflow for faster, uniform commits.
