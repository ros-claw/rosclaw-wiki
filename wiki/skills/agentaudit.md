> Automatic security gate that checks packages against a vulnerability database before installation.

Agentaudit is a tool designed to automatically check packages for known vulnerabilities before they are installed. It acts as a security gate, integrating into workflows to prevent vulnerable packages from being added to a system. By consulting a vulnerability database, it helps maintain secure software supply chains. This tool is useful for developers and system administrators seeking to reduce security risks during package installation.
