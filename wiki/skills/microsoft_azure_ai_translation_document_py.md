This Python SDK enables integration with Azure AI Document Translation, allowing users to translate batches of documents while preserving structure and formatting. It handles submission of translation jobs, monitors progress, and retrieves results via Azure's cloud service. The library provides a high-level interface for automating document translation workflows in Python applications.
