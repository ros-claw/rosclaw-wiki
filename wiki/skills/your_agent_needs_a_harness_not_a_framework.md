> Inngest's case for treating state, retries, traces, and concurrency as first-class infrastructure.

This project argues that building AI agents with frameworks introduces unnecessary complexity and fragility. Instead, it proposes using a 'harness' that treats state management, retries, tracing, and concurrency as first-class infrastructure concerns. By offloading these operational responsibilities to the platform, developers can focus on agent logic without reinventing reliable execution. The approach aims to make agents more robust, observable, and scalable.
