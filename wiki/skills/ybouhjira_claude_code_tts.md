> 🏎️ ☁️ 🍎 🪟 🐧 - MCP server plugin for Claude Code that converts text to speech using OpenAI's TTS API. Features 6 voices, worker pool architecture, mutex-protected playback, and cross-platform support.

This is a plugin for Claude Code that adds text-to-speech functionality using OpenAI's TTS API. It allows you to have Claude's responses read aloud with a choice of six different voices. The plugin uses a worker pool for efficient processing and mutex-protected playback to prevent audio conflicts. It works on Windows, macOS, Linux, and cloud environments. By integrating as an MCP server, it provides a seamless voice interface within Claude Code.
