Published on npm.

This project is an MCP (Model Context Protocol) server that enables AI assistants to check the real-time operational status of over 114 cloud services and APIs, including major platforms like AWS, GitHub, Stripe, and OpenAI. It allows users to ask about the current status of these services directly within AI workflows. The server is published as an npm package and can be integrated with various MCP-compatible AI tools. It provides a convenient way to monitor service health without leaving the AI assistant environment.
