API-backed extraction with token counting, CSS selector support, and configurable caching via [StripFeed](https://www.stripfeed.dev).

This MCP server converts any URL into clean, token-efficient Markdown, optimized for AI agents. It uses an API backend (StripFeed) to extract content and supports features like token counting, CSS selector targeting, and configurable caching. The tool helps reduce token usage when feeding web content into language models or other AI pipelines.
