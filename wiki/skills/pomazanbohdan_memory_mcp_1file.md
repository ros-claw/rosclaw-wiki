> 🦀 🏠 🍎 🪟 🐧 - A self-contained Memory server with single-binary architecture (embedded DB & models, no dependencies). Provides persistent semantic and graph-based memory for AI agents.

This is a self-contained memory server for AI agents, implemented as a single binary with no external dependencies. It uses an embedded database and models to provide persistent storage for both semantic and graph-based memory. The server is cross-platform and designed for integration with the Model Context Protocol (MCP) ecosystem.
