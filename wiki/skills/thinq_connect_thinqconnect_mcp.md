> 🎖️ 🐍 ☁️ - Interact with LG ThinQ smart home devices and appliances through the ThinQ Connect MCP server.

This MCP server enables interaction with LG ThinQ smart home devices and appliances through the Model Context Protocol. It allows users to control and monitor LG smart home products programmatically. The server is implemented in Python and integrates with the LG ThinQ cloud API. It provides a standardized interface for AI agents to manage smart home functionalities.
