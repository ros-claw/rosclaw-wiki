> [![mrslbt/rippr MCP server](https://glama.ai/mcp/servers/mrslbt/rippr/badges/score.svg)](https://glama.ai/mcp/servers/mrslbt/rippr) 📇 🏠 - YouTube transcript extraction for AI agents. Clean text, timestamps, or structured JSON from any video. No API keys required. Install via `npx rippr-mcp`.

Rippr is an MCP server that extracts YouTube video transcripts, providing clean text, timestamps, or structured JSON output. It requires no API keys and works with any video, making it easy for AI agents to access video content. Installation is via a single npx command. This tool is categorized under search and data extraction, simplifying integration into AI workflows.
