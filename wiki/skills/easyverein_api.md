> Work with the easyVerein v2.0 REST API.

This project is a client library for the easyVerein v2.0 REST API, enabling developers to manage membership data programmatically. It provides functions for authentication, data retrieval, and manipulation of entities like members and events. The library simplifies integration of easyVerein's features into custom applications or workflows.
