> Analyzes code structure and purpose to create comprehensive documentation detailing inputs/outputs, behavior, user interaction flows, and edge cases with error handling.

This slash command analyzes code structure and purpose to automatically generate comprehensive documentation. It covers inputs/outputs, behavior details, user interaction flows, and edge cases with error handling. The tool helps developers quickly produce high-quality docs directly from source code.
