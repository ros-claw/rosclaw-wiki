> A Model Context Protocol (MCP) server that allows AI agents to generate secure smart contracts in multiples languages based on [OpenZeppelin Wizard templates](https://wizard.openzeppelin.com/).

This project implements a Model Context Protocol (MCP) server that enables AI agents to generate secure smart contracts. It leverages OpenZeppelin Wizard templates to support multiple programming languages. The server is designed for developer tools in the embodied-intelligence and AI-agent tooling ecosystem.
