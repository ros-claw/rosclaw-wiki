This MCP server integrates JetBrains TeamCity with MCP, providing 87 tools for managing builds, tests, agents, and CI/CD pipelines. It supports a dual-mode operation (development and full) and allows runtime mode switching. Designed for developers, it streamlines TeamCity automation and monitoring through a standardized interface.
