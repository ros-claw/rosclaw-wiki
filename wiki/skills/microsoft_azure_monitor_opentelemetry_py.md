This is a Python library by Microsoft that bridges OpenTelemetry with Azure Monitor. It enables developers to export telemetry data such as logs, metrics, and traces from Python applications directly to Azure Monitor. The library conforms to the OpenTelemetry standard, ensuring compatibility with other instrumentations. It supports both automatic and manual instrumentation for flexible monitoring. This tool is essential for observability in Azure-based Python applications.
