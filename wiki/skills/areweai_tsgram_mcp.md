> TSgram: Telegram + Claude with local workspace access on your phone in typescript. Read, write, and vibe code on the go!

TSgram is a TypeScript-based MCP server that integrates Telegram with Claude, enabling users to read, write, and code directly from their phone. It provides local workspace access through Telegram messages, allowing developers to interact with their codebase and AI assistant on the go. The server is designed for mobile use and leverages the Model Context Protocol for seamless communication between Telegram and Claude.
