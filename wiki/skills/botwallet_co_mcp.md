Earn via invoices, spend on other agents and paid APIs, manage USDC on Solana with human-set spending limits and FROST 2-of-2 threshold signing.

This MCP server implements a wallet for AI agents, allowing them to earn money via invoices, spend on other agents and paid APIs, and manage USDC on the Solana blockchain. It features human-set spending limits and FROST 2-of-2 threshold signing for security. This enables agents to autonomously conduct financial transactions within defined constraints.
