> [![mcp-teslamate-fleet](https://glama.ai/mcp/servers/lodordev/mcp-teslamate-fleet/badges/score.svg)](https://glama.ai/mcp/servers/lodordev/mcp-teslamate-fleet) 🐍 🏠 - Combined TeslaMate analytics + Fleet API commands — 29 tools for vehicle telemetry, driving history, energy analytics, and remote control (climate, charging, locks, sentry).

This MCP server integrates TeslaMate's local analytics with Tesla's Fleet API to provide a comprehensive interface for Tesla vehicle management. It offers 29 tools that cover vehicle telemetry, driving history, energy analytics, and remote control features such as climate settings, charging controls, locks, and sentry mode. Developers can use it to build applications that monitor and control Tesla vehicles through a standardized protocol.
