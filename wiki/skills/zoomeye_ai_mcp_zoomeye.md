> 📇 ☁️ - Querying network asset information by ZoomEye MCP Server

Zoomeye MCP Server is an implementation of the Model Context Protocol that allows querying network asset information through the ZoomEye search engine. It enables users to search for devices, services, and vulnerabilities using ZoomEye's extensive database. This tool is useful for cybersecurity research, network asset discovery, and open-source intelligence gathering.
