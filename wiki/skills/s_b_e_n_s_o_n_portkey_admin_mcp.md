This MCP server provides a comprehensive interface to the Portkey AI Gateway Admin API, offering 150 tools for managing prompts, configurations, analytics, API keys, guardrails, integrations, and more. It allows AI agents to perform administrative operations on the Portkey platform through the Model Context Protocol, simplifying AI gateway administration in cloud environments.
