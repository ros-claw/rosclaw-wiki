> 📇 🏠 - Bitcoin Lightning wallet integration powered by Nostr Wallet Connect

This MCP server integrates Bitcoin Lightning wallet functionality through Nostr Wallet Connect (NWC). It allows AI agents to interact with a Lightning wallet, enabling transactions and wallet queries. The server uses the Model Context Protocol (MCP) to expose wallet capabilities. It is designed for finance and fintech applications.
