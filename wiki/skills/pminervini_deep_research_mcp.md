> 🐍 ☁️ 🏠 - Deep research MCP server for OpenAI Responses API or Open Deep Research (smolagents), with web search and code interpreter support.

This is an MCP server that enables deep research capabilities using either OpenAI's Responses API or the Open Deep Research system from smolagents. It includes support for web search and a code interpreter to assist with research tasks. The server can be integrated into AI agent workflows to perform complex research queries.
