> [![tactual-dev/tactual MCP server](https://glama.ai/mcp/servers/tactual-dev/tactual/badges/score.svg)](https://glama.ai/mcp/servers/tactual-dev/tactual) 📇 🏠 🍎 🪟 🐧 - Screen-reader navigation cost analyzer. Models real AT user effort with per-profile scoring, graph-based pathfinding, and step-by-step navigation traces.

Tactual is an MCP server that analyzes the cost of navigating web interfaces using a screen reader. It models the effort required by real assistive technology users through per-profile scoring and graph-based pathfinding. The tool provides step-by-step navigation traces to help developers identify and reduce barriers to accessibility. It is designed for use in developer tools and can be integrated into automated testing workflows.
