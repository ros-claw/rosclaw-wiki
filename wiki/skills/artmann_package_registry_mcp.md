> 🏠 📇 🍎 🪟 🐧 - MCP server for searching and getting up-to-date information about NPM, Cargo, PyPi, and NuGet packages.

The Package Registry MCP server provides a unified interface to search and retrieve package information from multiple package registries including NPM, Cargo, PyPi, and NuGet. It is designed to integrate with the Model Context Protocol (MCP), allowing AI assistants and developer tools to access up-to-date package metadata. The server supports cross-platform operation on macOS, Windows, and Linux. It helps developers quickly find package details, versions, and dependencies without leaving their development environment.
