> 🐍 🏠 - MCP server for spatial transcriptomics analysis with 60+ integrated methods covering cell annotation, deconvolution, spatial statistics, and visualization.

ChatSpatial is a server implementation that provides a chat-based interface for spatial transcriptomics analysis. It integrates over 60 methods for cell annotation, deconvolution, spatial statistics, and visualization. This enables researchers to perform complex bioinformatics analyses through natural language interactions. The server is designed to streamline spatial data analysis workflows in biology and medicine.
