> 📇 ☁️ - Fetch YouTube subtitles

mcp-youtube is a server implementation that integrates with the Model Context Protocol to fetch subtitles from YouTube videos. It allows AI agents to access video transcript data directly. This tool is part of the MCP ecosystem and can be used to enhance AI understanding of video content. The server likely provides a simple API for retrieving subtitles given a video ID or URL.
