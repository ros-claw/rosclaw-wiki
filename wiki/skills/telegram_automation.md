> Automate Telegram: messages, chats, media, groups, and bots.

This skill enables AI agents to automate Telegram tasks such as sending messages, managing chats and groups, handling media, and controlling bots. It integrates with the Composio platform for seamless app automation, allowing users to build workflows for notifications, content distribution, and bot management. The automation reduces manual effort by letting agents interact with Telegram's API through pre-built actions.
