Auto-registers, no API key needed.

The cosmergon-agent MCP server creates a living economy for AI agents, inspired by Conway's Game of Life. It uses cellular automaton physics to simulate resource generation and an energy currency system with a marketplace. Agents can observe the state, execute actions, receive benchmark reports, and learn game rules. The server auto-registers and requires no API key, making it easy for any AI agent to interact with the simulation.
