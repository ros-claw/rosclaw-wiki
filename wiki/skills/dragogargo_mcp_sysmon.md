Find resource-hungry processes, diagnose performance issues, and kill processes via AI.

This MCP server provides local system monitoring capabilities including CPU, memory, swap, disk, and network usage. It enables AI agents to find resource-hungry processes, diagnose performance issues, and terminate processes automatically. Designed for cross-platform environments (Python, macOS, Linux), it integrates real-time system metrics into AI workflows.
