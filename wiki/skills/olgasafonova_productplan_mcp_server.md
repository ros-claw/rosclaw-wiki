> 🏎️ ☁️ - Query ProductPlan roadmaps. Access OKRs, ideas, launches, and timeline data.

This project provides an MCP (Model Context Protocol) server that allows querying ProductPlan roadmaps. It enables access to OKRs, ideas, launches, and timeline data from ProductPlan, making it easier to integrate with AI agents and tools. The server acts as a bridge between ProductPlan's API and MCP-compatible clients, enabling structured data retrieval.
