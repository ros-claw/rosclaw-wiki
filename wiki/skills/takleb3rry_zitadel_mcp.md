> 📇 ☁️ 🏠 - MCP server for Zitadel identity management — manage users, projects, OIDC apps, roles, and service accounts through natural language.

This project provides an MCP server for Zitadel identity management, enabling users to manage users, projects, OIDC applications, roles, and service accounts through natural language commands. It is listed under Security in the Server Implementations category of the MCP ecosystem. The tool simplifies identity and access management tasks by converting natural language into API calls against Zitadel.
