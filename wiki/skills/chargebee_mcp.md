> 🎖️ 📇 ☁️ - MCP Server that connects AI agents to [Chargebee platform](https://www.chargebee.com/).

This project is a server that implements the Model Context Protocol, enabling AI agents to interact with the Chargebee billing and subscription management platform. It allows AI agents to perform actions like managing subscriptions, invoices, and customer data through Chargebee's API. The server is listed under Finance and Fintech use cases, highlighting its role in automating financial operations. It simplifies integrating AI with subscription billing workflows.
