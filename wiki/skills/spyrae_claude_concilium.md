> 📇 🏠 🍎 🪟 🐧 - Multi-agent AI consultation framework for Claude Code. Three MCP servers wrapping CLI tools (Codex, Gemini, Qwen) for parallel code review and problem-solving with fallback chains and error detection. Includes ready-to-use Claude Code skill.

Claude Concilium is a multi-agent AI framework that runs three MCP servers wrapping CLI tools (Codex, Gemini, Qwen) to enable parallel code review and problem-solving. It supports fallback chains and error detection for robust consultation. The project includes a ready-to-use skill for Claude Code, allowing users to leverage multiple coding agents simultaneously. This setup improves code quality by combining diverse AI perspectives and handling failures gracefully.
