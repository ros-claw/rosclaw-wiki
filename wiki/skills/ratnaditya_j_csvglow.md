csvglow is an MCP server that transforms CSV and Excel files into fully self-contained HTML dashboards. It leverages the ECharts library to generate interactive charts and graphs, all themed with a dark gradient design. The dashboards also include sortable data tables for easy exploration. This tool is ideal for quickly visualizing tabular data without requiring any external dependencies or web servers.
