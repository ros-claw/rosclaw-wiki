JARVIS-Orb is an MCP server that provides persistent four-tier memory for AI agents, covering episodic, semantic, project, and procedural types. It includes features like temporal scoring to prioritize memories, contradiction detection to maintain consistency, and entity tracking across interactions. A real-time desktop visualization orb displays the memory state visually, making it easier to monitor and debug agent cognition.
