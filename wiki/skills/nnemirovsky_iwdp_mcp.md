> [![iwdp-mcp MCP server](https://glama.ai/mcp/servers/nnemirovsky/iwdp-mcp/badges/score.svg)](https://glama.ai/mcp/servers/nnemirovsky/iwdp-mcp) 🏎️ 🏠 🍎 🐧 - iOS Safari debugging via ios-webkit-debug-proxy — MCP server with full WebKit Inspector Protocol support (DOM, CSS, Network, Storage, Debugger, and more)

This MCP server enables debugging of iOS Safari browsers using the ios-webkit-debug-proxy. It provides full WebKit Inspector Protocol support, covering areas like DOM, CSS, Network, Storage, and Debugger interactions. The server integrates with the Model Context Protocol to allow AI agents to remotely control and inspect Safari on iOS devices. It is useful for automated testing, debugging, and browser automation tasks involving Apple devices.
