> 🐍 🏠 - Run Python code in a secure sandbox via MCP tool calls

pydantic/pydantic-ai/mcp-run-python is a server implementation that allows AI agents to run Python code in a secure sandbox via MCP tool calls. It ensures code execution is isolated and safe, preventing unauthorized access to the host system. This tool is part of the broader pydantic-ai ecosystem, which provides frameworks for building reliable AI agents with structured outputs and tool use.
