> 📇 🏠 - Run any command with `run_command` and `run_script` tools.

This MCP server allows running arbitrary commands and scripts on the host machine via `run_command` and `run_script` tools. It is designed for coding agents that need to execute shell commands as part of their workflows. The server provides a simple interface to run both one-off commands and full scripts, making it useful for automation and development tasks.
