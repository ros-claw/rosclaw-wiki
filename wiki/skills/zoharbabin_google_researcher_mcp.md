This project is a Model Context Protocol (MCP) server that provides comprehensive research capabilities. It integrates multiple search tools including Google Search (web, news, images), web scraping with JavaScript rendering, academic paper databases (arXiv, PubMed, IEEE), patent search, and YouTube transcript extraction. The server enables AI agents to perform in-depth research by combining these diverse data sources through a standardized interface.
