> Create, search, and manage Bear notes via grizzly.

This project provides a command-line tool to create, search, and manage notes in the Bear note-taking app using the grizzly library. It enables users to automate note-taking tasks directly from the terminal, integrating with Bear's underlying data structures or URL scheme. The tool simplifies note management for developers and power users who prefer command-line workflows over the Bear app's graphical interface.
