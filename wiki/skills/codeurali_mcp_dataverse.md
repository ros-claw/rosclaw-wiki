> [![mcp-dataverse MCP server](https://glama.ai/mcp/servers/@codeurali/mcp-dataverse/badges/score.svg)](https://glama.ai/mcp/servers/@codeurali/mcp-dataverse) 📇 🏠 ☁️ - Microsoft Dataverse MCP server with 63 tools for entity CRUD, FetchXML/OData queries, metadata inspection, workflow execution, audit logs, and Power Platform integration. Zero-config device code authentication.

This is a Model Context Protocol (MCP) server that provides 63 tools for interacting with Microsoft Dataverse. It supports entity CRUD operations, FetchXML and OData queries, metadata inspection, workflow execution, audit log retrieval, and integration with the Power Platform. The server features zero-configuration device code authentication, making it easy to connect without manual setup. It is listed under the Databases category in the MCP server implementations directory.
