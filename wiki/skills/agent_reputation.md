> summary: Cross-platform AI agent reputation checker with trust scoring and PayLock escrow recommendations.

Agent-reputation is a cross-platform tool that checks the reputation of AI agents. It assigns trust scores to agents and provides recommendations for using PayLock escrow services. This helps users evaluate the reliability of AI agents before engaging with them. The tool aims to build a trust layer in multi-agent systems by aggregating reputation data across platforms.
