> 🐍 🏠 - Access live and historical NBA statistics including player stats, game scores, team data, and advanced analytics via Model Context Protocol

This MCP server provides AI assistants with access to live and historical NBA data, including player stats, game scores, team information, and advanced analytics. It is built in Python and integrates with the Model Context Protocol to enable real-time sports queries. Developers can use it to enhance AI tools with basketball-related information.
