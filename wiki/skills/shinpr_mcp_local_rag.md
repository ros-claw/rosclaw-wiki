> 📇 🏠 - Privacy-first document search server running entirely locally. Supports semantic search over PDFs, DOCX, TXT, and Markdown files with LanceDB vector storage and local embeddings - no API keys or cloud services required.

This project is a local document search server designed for privacy. It provides semantic search over PDFs, DOCX, TXT, and Markdown files. The server uses LanceDB for vector storage and local embeddings for processing. It requires no API keys or cloud services, making it fully offline and private. It is implemented as an MCP server for integration with AI assistants.
