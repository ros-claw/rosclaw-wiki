This MCP server exposes 22 distinct Mistral AI capabilities through a unified interface, including chat, OCR, audio processing, vision, agents, embeddings, moderation, classification, file handling, and batch operations. It supports dual transport modes: standard stdio and Streamable HTTP, with structured outputs on every tool and six curated prompts (in French and English) that feature argument completion. A vendor API key from Mistral AI is required to use this server. It is designed for integration with MCP-compatible clients, offering a wide range of AI functionalities.
