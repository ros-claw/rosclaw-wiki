> Full-text search your Claude Code sessions. Run `recall` in terminal, type to search, Enter to resume. Alternative to `claude --resume`.

recall is a command-line tool that enables full-text search through your Claude Code sessions. You run `recall` in the terminal, type a search query, and press Enter to resume a matching session. It provides a more efficient alternative to `claude --resume` for navigating past conversations. The tool is designed to improve discovery and reuse of previous interactions with Claude Code.
