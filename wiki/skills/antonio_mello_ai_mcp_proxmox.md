This project provides an MCP server that lets AI assistants manage Proxmox VE clusters, including VMs, containers, snapshots, templates, cloud-init, firewall, and migrations. It offers 29 tools with a two-step confirmation mechanism for destructive operations to prevent accidents. This integration enables natural language control of Proxmox infrastructure through compatible AI agents.
