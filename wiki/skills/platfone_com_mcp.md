> [![platfone-com/mcp MCP server](https://glama.ai/mcp/servers/platfone-com/mcp/badges/score.svg)](https://glama.ai/mcp/servers/platfone-com/mcp) 📇 ☁️ 🏠 - Virtual phone number platform for AI agents — rent numbers across 200+ countries, receive SMS, and manage the full activation lifecycle. Supports stdio and HTTP transport.

This MCP server integrates a virtual phone number platform into AI agents, enabling them to rent phone numbers from over 200 countries, receive SMS messages, and manage the full activation lifecycle. It supports both stdio and HTTP transport protocols, making it easy to connect AI agents to real-world communication channels. The platform allows agents to autonomously handle number operations such as activation, deactivation, and message retrieval.
