> 🎖️ ☁️ - Serverless MariaDB Cloud DB MCP server. Tools to launch, delete, execute SQL and work with DB level AI agents for accurate text-2-sql and conversations.

SkySQL's MCP server integrates MariaDB Cloud with AI agents for natural language to SQL conversion. It provides tools to launch, delete, and execute SQL queries on serverless databases. The server enables conversational interactions and automated database management through the Model Context Protocol. This facilitates accurate text-to-SQL capabilities without manual query writing.
