TradeRouter MCP server provides a non-custodial Solana swap and limit order engine for AI agents. It offers 21 tools including swap, limit, trailing stop, TWAP, DCA, and combo orders across major DEXs like Raydium, PumpSwap, Orca, and Meteora. Execution is protected by Jito MEV protection and uses Ed25519 server verification to ensure private keys never leave the process. The project is open-source under MIT and can be run via npx.
