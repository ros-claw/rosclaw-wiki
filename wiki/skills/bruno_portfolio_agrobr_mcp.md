> 🐍 ☁️ - Brazilian agricultural data for LLMs — prices, crop estimates, climate, deforestation from 19 public sources via CEPEA, CONAB, IBGE, INPE and B3.

This server aggregates Brazilian agricultural data from 19 public sources, covering prices, crop estimates, climate, and deforestation. It exposes these datasets to LLMs through APIs such as CEPEA, CONAB, IBGE, INPE, and B3. The project aims to supply structured, up-to-date agricultural information for AI applications in Brazil.
