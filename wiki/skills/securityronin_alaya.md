Alaya is a neuroscience-inspired memory engine for AI agents, designed to store episodes and consolidate knowledge through a lifecycle of strengthening, transformation, and forgetting. It builds a personal knowledge graph with emergent categories, preferences, and semantic recall. The system runs locally with SQLite, requires zero configuration, and provides 10 MCP tools for integration. Installation is done via npx alaya-mcp. It aims to give AI agents a long-term memory capability similar to human cognition.
