> 🐍 ☁️ - A VMware ESXi/vCenter management server based on MCP (Model Control Protocol), providing simple REST API interfaces for virtual machine management.

This project is an MCP (Model Control Protocol) server that provides a REST API for managing VMware ESXi and vCenter environments. It allows users to perform virtual machine operations such as creation, deletion, and configuration through simple API calls. The server acts as a bridge between AI agents or tools and VMware infrastructure, enabling automated VM management. It is listed under cloud platform server implementations.
