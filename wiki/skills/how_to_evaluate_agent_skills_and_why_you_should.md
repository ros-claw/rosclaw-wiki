> OpenHands' hands-on playbook for measuring whether a skill actually helps using bounded tasks, deterministic verifiers, no-skill baselines, and trace review.

This project provides a practical guide for evaluating agent skills using a systematic methodology. It emphasizes the use of bounded tasks, deterministic verifiers, and no-skill baselines to measure whether a skill actually improves performance. The playbook also incorporates trace review to ensure thorough analysis. It is designed for developers and researchers working on embodied intelligence and AI agents.
