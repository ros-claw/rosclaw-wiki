Playwright + FastAPI, Docker-based isolated sessions, stdio bridge for Claude Desktop and Cursor.

Auto-browser is an open-source MCP server for browser automation that includes a human takeover feature through noVNC. It supports reusable authentication profiles and built-in approval and audit rails for safe operation. The implementation uses Playwright and FastAPI, runs isolated sessions in Docker containers, and provides a stdio bridge compatible with Claude Desktop and Cursor.
