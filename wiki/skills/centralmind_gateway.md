> 🏎️ 🏠 🍎 🪟 - MCP and MCP SSE Server that automatically generate API based on database schema and data. Supports PostgreSQL, Clickhouse, MySQL, Snowflake, BigQuery, Supabase

Centralmind Gateway is a server implementation that automatically generates APIs based on database schemas and data, supporting both MCP and MCP over SSE protocols. It connects to multiple databases including PostgreSQL, Clickhouse, MySQL, Snowflake, BigQuery, and Supabase. This tool allows AI agents and applications to interact with databases through standardized interfaces without manual API development.
