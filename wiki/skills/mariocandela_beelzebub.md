> ☁️ - Beelzebub is a honeypot framework that lets you build honeypot tools using MCP. Its purpose is to detect prompt injection or malicious agent behavior. The underlying idea is to provide the agent with tools it would never use in its normal work.

Beelzebub is a honeypot framework built on the Model Context Protocol (MCP) that creates deceptive tools to detect prompt injection or malicious agent behavior. It provides AI agents with tools they would never use in their normal work, effectively trapping attackers in a controlled environment. This allows security researchers to monitor and analyze adversarial actions against AI systems.
