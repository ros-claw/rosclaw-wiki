> 🐍 🦀 🏠 - The Semantic Engine for Model Context Protocol(MCP) Clients and AI Agents

Wren-engine is a semantic engine that implements the Model Context Protocol (MCP) for AI agents and clients. It provides a database abstraction layer enabling semantic queries and context management. The project is written in Python and Rust, offering performance and flexibility. It serves as a server implementation for connecting AI agents to various data sources.
