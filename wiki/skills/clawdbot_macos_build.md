> Build the Clawdbot macOS menu bar app.

This project provides the build configuration and scripts to compile Clawdbot, a macOS menu bar application. It includes Xcode project files and build instructions for developers. The app sits in the menu bar for quick access and is built using native macOS technologies. The goal is to create a seamless user experience on macOS.
