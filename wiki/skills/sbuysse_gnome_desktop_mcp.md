Works on any GNOME 45–49 Linux desktop.

This MCP server enables AI agents to automate the GNOME desktop environment on Linux. It provides 30 tools via the D-Bus interface, covering screenshots, window management, mouse and keyboard injection, clipboard control, workspace handling, and system notifications. Designed for GNOME versions 45 through 49, it is listed under OS Automation in the MCP server ecosystem.
