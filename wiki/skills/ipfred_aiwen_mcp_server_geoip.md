> 🐍 📇 ☁️ – MCP Server for the Aiwen IP Location, Get user network IP location, get IP details (country, province, city, lat, lon, ISP, owner, etc.)

This is an MCP server that provides IP geolocation services using the Aiwen IP Location API. It can retrieve a user's network IP location and detailed information such as country, province, city, latitude/longitude, ISP, and owner. It is designed for integration into AI agent tooling environments, allowing agents to access location data based on IP addresses.
