> 🐍 🏠 🪟 🐧 - A local MCP server that generates animations using Manim.

This project provides a local MCP (Model Context Protocol) server that uses Manim, a mathematical animation engine, to generate animations. It is designed to integrate with AI agents or tools that can send requests to create animated content. The server is listed under Art & Culture, indicating its focus on generating animations for artistic or educational purposes. By running locally, it allows users to produce custom animations from prompts without relying on external services.
