Hot-reloadable capabilities, OpenAPI auto-import, 42 starter capabilities (25 zero-config).

MCP-Gateway is a universal gateway for MCP (Model Context Protocol) servers that consolidates multiple tools into four meta-tools, drastically reducing context window usage by up to 95%. It supports single-port multiplexing, hot-reloadable capabilities, and automatic import from OpenAPI specifications. The server includes 42 starter capabilities, with 25 being zero-configuration, streamlining management of hundreds of tool registrations.
