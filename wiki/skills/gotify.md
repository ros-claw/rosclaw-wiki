> Send push notifications via Gotify when long-running tasks complete.

This project integrates with the Gotify notification server to send push notifications when long-running tasks complete. It allows users to receive real-time alerts without manual checking. The tool simplifies the process by providing a lightweight wrapper around the Gotify API.
