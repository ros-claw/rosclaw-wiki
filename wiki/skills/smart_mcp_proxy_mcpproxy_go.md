> [![smart-mcp-proxy/mcpproxy-go MCP server](https://glama.ai/mcp/servers/smart-mcp-proxy/mcpproxy-go/badges/score.svg)](https://glama.ai/mcp/servers/smart-mcp-proxy/mcpproxy-go) 🏎️ 🏠 🍎 🪟 🐧 - Local MCP proxy with BM25 tool filtering, quarantine security, activity logging, and web UI. Routes multiple servers through a single endpoint.

This is a local MCP proxy that routes requests from multiple MCP servers through a single endpoint, simplifying client integration. It uses BM25 algorithm to filter and rank tools dynamically, enhancing relevance and efficiency. A quarantine security mechanism isolates tools to prevent unauthorized access, while comprehensive activity logging tracks all interactions. The proxy includes a web UI for monitoring and configuration, supporting macOS, Windows, and Linux platforms.
