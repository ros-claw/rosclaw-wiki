> 🐍 ☁️ MCP to search through PapersWithCode API

This project provides an MCP server that interfaces with the PapersWithCode API to enable searching for academic papers with associated code implementations. It allows users to query for papers by keywords, filter by tasks, datasets, or methods, and retrieve results with links to code repositories. The server is designed to be used with MCP-compatible clients for research and discovery. It simplifies access to the PapersWithCode database through a standardized tool interface.
