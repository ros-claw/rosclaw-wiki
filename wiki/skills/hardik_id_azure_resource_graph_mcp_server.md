> 📇 ☁️/🏠 - A Model Context Protocol server for querying and analyzing Azure resources at scale using Azure Resource Graph, enabling AI assistants to explore and monitor Azure infrastructure.

This server implements the Model Context Protocol (MCP) to allow AI assistants to query Azure resources at scale using Azure Resource Graph. It enables scalable exploration and monitoring of Azure infrastructure, providing a standardized interface for cloud management. The server is listed under Cloud Platforms in the MCP server implementations, integrating with AI tools to assist in resource analysis.
