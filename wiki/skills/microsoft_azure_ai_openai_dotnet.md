The microsoft/azure-ai-openai-dotnet library is a .NET client SDK for Azure OpenAI Service. It enables C# developers to integrate large language models like GPT-4 into their applications. The package handles authentication, request formatting, and response parsing for chat completions, embeddings, and other OpenAI endpoints. This SDK simplifies building AI-powered features in .NET projects while leveraging Azure's enterprise security and scalability.
