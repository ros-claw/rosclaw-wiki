> 🐍 ☁️ 🏠 - DICOM integration to query, read, and move medical images and reports from PACS and other DICOM compliant systems.

This project implements an MCP server for DICOM integration, allowing querying, reading, and moving medical images and reports from PACS and other DICOM-compliant systems. It is designed to bridge MCP with medical imaging databases, supporting both cloud and local deployments. The server is built with Python and listed under server implementations for databases, making it useful for healthcare AI applications.
