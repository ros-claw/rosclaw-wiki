Findata-mcp is an MCP server that provides real-time stock data, company fundamentals, economic indicators from the FRED database (800,000+ series), SEC filings, and cryptocurrency prices. It offers five tools and uses x402 micropayments on the Base mainnet, charging $0.01 per call with no signup required. This enables lightweight, pay-per-use access to financial data for AI agents and applications.
