> A really stacked status line that exposes just about everything you might need - context usage, tools, agents, todos, etc. Highly configurable and actively maintained at the time of writing - code quality is strong.

Claude HUD is a highly configurable status line for Claude AI that displays detailed information like context usage, tool usage, agents, and todos. It aims to expose everything you might need in a stacked layout. The project is actively maintained with strong code quality, making it a reliable tool for users who want full visibility into Claude's operations.
