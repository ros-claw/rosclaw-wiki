LeonTing1010/tap is an MCP server that translates AI-driven browser automation commands into deterministic `.tap.json` plans using a closed set of 25 operations, eliminating the need for runtime LLM calls. It operates on your existing logged-in Chrome browser and detects changes in web page structure via semantic fingerprint diffs, ensuring plans remain valid as sites evolve. The project includes a growing library of 65+ community-contributed taps covering over 40 websites, making it a practical tool for reliable and maintainable browser automation.
