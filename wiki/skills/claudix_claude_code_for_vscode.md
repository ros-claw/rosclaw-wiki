> A VSCode extension that brings Claude Code directly into your editor with interactive chat interface, session management, intelligent file operations, terminal execution, and real-time streaming responses. Built with Vue 3, TypeScript.

Claudix is a VSCode extension that integrates Claude Code with an interactive chat interface, session management, and file operations. It allows real-time streaming responses and terminal execution within the editor. Built with Vue 3 and TypeScript, it enhances AI-assisted coding workflows.
