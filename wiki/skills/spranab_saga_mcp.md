SQLite-backed, 31 tools.

The saga-mcp server is a project tracking tool designed for AI agents, featuring a Jira-like hierarchy of projects, epics, tasks, and subtasks. It includes task dependencies with automatic blocking and unblocking, threaded comments, reusable templates, and activity logging. It also offers a natural language dashboard and is backed by SQLite. With 31 tools, it provides comprehensive functionality for managing projects and tasks through the Model Context Protocol (MCP). This makes it suitable for AI agents to organize and track work autonomously.
