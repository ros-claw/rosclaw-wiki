AgentShield-MCP is a Model Context Protocol (MCP) server that provides DeFi tools for AI agents, specifically on the Base network. It includes live Uniswap V3 price data (slot0), on-chain agent scoring, and a DeFi knowledge base. The service uses x402 micropayments in USDC on a pay-per-query basis, allowing AI agents to access financial data economically.
