> [![mcp-telegram MCP server](https://glama.ai/mcp/servers/overpod/mcp-telegram/badges/score.svg)](https://glama.ai/mcp/servers/overpod/mcp-telegram) 📇 🏠 🍎 🪟 🐧 - Telegram MCP server via MTProto/GramJS — 20 tools for reading chats, searching messages, downloading media, managing contacts. QR code login, npx zero-install. Hosted version at mcp-telegram.com.

This project provides a Telegram MCP server that uses MTProto via GramJS to offer 20 tools for interacting with Telegram. It supports reading chats, searching messages, downloading media, and managing contacts. Authentication is done via QR code login, and the server can be run with npx zero-install. A hosted version is also available at mcp-telegram.com.
