unphurl-mcp is an MCP server that provides 13 tools for analyzing URLs, aimed at enhancing security and data quality for AI agents. It checks for redirect behavior, brand impersonation, domain age, SSL validation, parked domains, URL structure, and DNS enrichment. This allows AI agents to assess the trustworthiness of URLs before taking actions, reducing exposure to phishing and malicious sites.
