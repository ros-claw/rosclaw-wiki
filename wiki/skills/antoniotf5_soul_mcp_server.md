SOUL.md is the open format for persistent AI agent identity — personality, voice, values, and behavioral constraints in a machine-readable YAML file.

soul-mcp-server is an MCP (Model Context Protocol) server that allows Claude Desktop to generate and validate SOUL.md files. These files are written in YAML and define an AI agent's persistent identity, including personality, voice, values, and behavioral constraints. The server is categorized under Knowledge & Memory, helping maintain consistent agent persona across sessions. It enables users to create and validate identity files programmatically through the MCP interface.
