> Query Find My locations and battery status for family devices.

This tool allows users to query Apple's Find My network to retrieve the current locations and battery statuses of devices belonging to family members. It likely provides a command-line interface or API to access this information from iCloud. It is useful for tracking shared family devices such as iPhones, iPads, or AirTags. The tool leverages Apple's family sharing feature to access location data authorized by family members.
