Each entry follows a consistent pattern-language format with Context, Problem, Forces, Solution, Consequences, and Related Patterns. Opinionated and erudiate, which is actually good for an "encyclopedia" in some ways.

This encyclopedia is a free reference that documents over 190 patterns for building software with AI assistance, ranging from foundational ideas to advanced agentic workflows. Each pattern follows a structured format including context, problem, forces, solution, consequences, and related patterns. It covers not only coding patterns but also governance, testing, and socio-technical aspects of AI-assisted development. The resource is opinionated yet comprehensive, making it a useful guide for developers working with AI tools.
