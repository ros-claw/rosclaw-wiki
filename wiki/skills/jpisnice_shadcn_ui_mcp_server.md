> 📇 🏠 - MCP server that gives AI assistants seamless access to shadcn/ui v4 components, blocks, demos, and metadata.

This project is an MCP server that allows AI assistants to interact with shadcn/ui v4 components, blocks, demos, and metadata. It provides a standardized interface for querying UI elements, enabling AI tools to fetch component information or generate UI code. The server leverages the Model Context Protocol to integrate with AI assistants and developer workflows. It is categorized as a developer tool, helping to streamline the use of shadcn/ui in AI-assisted development.
