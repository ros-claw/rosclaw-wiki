This MCP server provides AI agents with historical stock chart pattern intelligence using pre-computed embeddings. It covers 15,000 stocks and 10 years of data, allowing agents to search for similar chart patterns by ticker and date or by uploading a screenshot. The server includes 19 tools for tasks such as pattern search, forward returns analysis, regime analysis, and trade simulation. It is designed for finance and fintech applications and offers a free tier of 200 calls per day.
