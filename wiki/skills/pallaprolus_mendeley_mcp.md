> 🐍 ☁️ - MCP server for Mendeley reference manager. Search your library, browse folders, get document metadata, search the global catalog, and add papers to your collection.

This project implements a Model Context Protocol (MCP) server that connects AI agents to the Mendeley reference manager. It allows agents to search a user's personal library, browse folders, retrieve document metadata, and search the global Mendeley catalog. Users can also add new papers to their collection directly through the server. Built in Python, it provides a cloud-based interface for AI tools to interact with academic reference data.
