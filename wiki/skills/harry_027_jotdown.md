> 🦀 🏠 - An MCP server to create/update pages in Notion app & auto generate mdBooks from structured content.

JotDown is an MCP server implemented in Rust that enables AI agents to create and update pages in the Notion application. It also automatically generates mdBooks from structured content, allowing for easy documentation publishing. The tool integrates with Notion's API to manage pages programmatically via the Model Context Protocol.
