Zero API keys needed.

The wc26-mcp project is a Model Context Protocol (MCP) server that provides 18 tools for accessing FIFA World Cup 2026 data, including matches, teams, venues, city guides, fan zones, visa requirements, injuries, odds, and standings. It requires no API keys and is designed to be easy to use for AI agents. The server is listed under Sports in server implementations. It supports zero-configuration access to real-time and static World Cup information.
