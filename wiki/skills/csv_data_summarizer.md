> Automatically analyzes CSV files and generates comprehensive insights with visualizations without requiring user prompts.

CSV Data Summarizer automatically analyzes CSV files to generate comprehensive insights and visualizations without requiring any user prompts. It streamlines the data exploration process by detecting patterns, statistics, and trends in tabular data. The tool produces visual representations such as charts or graphs to highlight key findings, making raw data more accessible. This skill is aimed at users who need quick, automated data analysis without manual configuration.
