Works in Claude Desktop, Claude Code, Hermes Agent, OpenClaw, and any MCP client.

geolabel-mcp is a server that converts GPS coordinates into location information such as place names, business categories, and opening hours, using data from OpenStreetMap. It is designed for use with AI agent tools like Claude Desktop, Claude Code, and others that support the Model Context Protocol (MCP). This tool helps AI systems understand physical locations by providing structured, real-world context. It falls under the Location Services category of MCP server implementations.
