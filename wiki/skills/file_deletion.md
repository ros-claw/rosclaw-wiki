> Secure file deletion and data sanitization methods.

This project provides tools for secure file deletion to prevent data recovery. It implements various overwriting algorithms that ensure data cannot be reconstructed from storage media. The methods include multiple passes and random data overwrites. It is useful for sanitizing drives before disposal or reuse. Overall, it helps maintain data privacy and security.
