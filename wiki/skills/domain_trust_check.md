> Check any URL for phishing, malware, brand abuse, and scams before visiting. Powered by the Outtake Trust API.

domain-trust-check is a command-line tool that verifies the safety of any URL before visiting. It leverages the Outtake Trust API to detect phishing, malware, brand abuse, and scams. The tool provides a quick assessment to help users avoid malicious websites. It is useful for security researchers and everyday internet users to preemptively evaluate URL trustworthiness.
