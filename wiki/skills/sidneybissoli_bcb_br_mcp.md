This project is a Model Context Protocol (MCP) server that provides access to over 18,000 economic time series from the Brazilian Central Bank (BCB). It includes key indicators such as the Selic interest rate, IPCA inflation index, exchange rates, and GDP data, all sourced from the BCB's SGS public API. The server offers 150+ curated indicators, making it easy for AI agents to retrieve Brazilian economic data in a structured way. It is designed for integration with AI assistants and tools that support the MCP standard.
