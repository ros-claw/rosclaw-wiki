> 🐍 ☁️ - An MCP server that provides real-time whale alerts on Hyperliquid, flagging positions with a notional value exceeding $1 million.

This MCP server monitors Hyperliquid for large cryptocurrency positions exceeding $1 million in notional value, generating real-time whale alerts. It helps traders and analysts detect significant market movements on the Hyperliquid decentralized exchange. The server integrates with MCP clients to deliver timely notifications for large trades. It is designed for use in finance and fintech applications requiring market surveillance.
