Preserves file encoding (UTF-8, EUC-KR, Shift_JIS, etc.) and respects .editorconfig settings.

This project provides an MCP server that offers over 20 file manipulation tools specifically designed for AI coding agents. It features automatic encoding detection and smart indentation conversion, preserving file encodings like UTF-8, EUC-KR, and Shift_JIS. The tools include read/edit capabilities, SSH and SFTP support, process management, and system utilities. It respects .editorconfig settings to maintain consistent coding styles.
