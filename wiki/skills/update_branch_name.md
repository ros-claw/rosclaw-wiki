> Updates branch names with proper prefixes and formats, enforcing naming conventions, supporting semantic prefixes, and managing remote branch updates.

This slash command updates Git branch names to adhere to defined naming conventions. It enforces proper prefixes, supports semantic prefix types (e.g., feature, bugfix, release), and handles updates to both local and remote branches. This ensures consistent branch naming across projects and teams, improving collaboration and automation.
