neondatabase/agent-skills is a repository that provides a collection of reusable skills for AI agents, enabling them to interact with databases and perform data operations efficiently. It focuses on enhancing agent capabilities in data retrieval, manipulation, and analysis within a Neon environment. The skills are designed to be modular and easily integrated into agent workflows, promoting automation and intelligent data handling.
