> 🏎️ ☁️ Tools to the query and execute of Dify workflows

This project offers Go-based tools for querying and executing workflows on the Dify platform, an open-source LLM app development framework. It allows developers to programmatically interact with Dify's workflow APIs directly from Go applications. Users can manage workflow execution, retrieve outputs, and integrate Dify workflows into larger systems. The toolkit includes functions for listing, triggering, and monitoring workflows, simplifying automation and integration tasks.
