> A library of slash commands intended specifically to facilitate common and advanced operations on Linux desktop environments (although many would also be useful on Linux servers). Command groups include hardware benchmarking, filesystem organisation, and security posture validation.

This project provides a library of slash commands tailored for Linux desktop environments, though many commands also work on Linux servers. It includes command groups for hardware benchmarking, filesystem organization, and security posture validation. The commands aim to facilitate common and advanced operations directly from the command line.
