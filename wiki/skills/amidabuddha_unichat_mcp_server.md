> 🐍/📇 ☁️ - Send requests to OpenAI, MistralAI, Anthropic, xAI, Google AI or DeepSeek using MCP protocol via tool or predefined prompts. Vendor API key required

This is an MCP server that provides a unified interface to send requests to multiple AI model providers including OpenAI, MistralAI, Anthropic, xAI, Google AI, and DeepSeek. It uses the Model Context Protocol (MCP) to expose these capabilities as tools or through predefined prompts. Users must provide their own vendor API keys. The server acts as a middleware to centralize and simplify access to various large language models.
