> ☕ 🏠 - 56 semantic Java analysis tools via Eclipse JDT. Compiler-accurate navigation, refactoring, find references, call hierarchy, and code metrics for AI agents.

JavaLens MCP is an MCP server that provides 56 semantic Java analysis tools powered by Eclipse JDT. It offers compiler-accurate navigation, refactoring, find references, call hierarchy, and code metrics. The tool is designed for AI agents to interact with Java codebases. It enables automated code understanding and manipulation. Developers can integrate it into their workflows for sophisticated Java program analysis.
