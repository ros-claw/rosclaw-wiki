> 📇 🏠 - A proxy tool for composing multiple MCP servers into one unified endpoint. Scale your AI tools by load balancing requests across multiple MCP servers, similar to how Nginx works for web servers.

mcgravity is a proxy tool that combines multiple MCP (Model Context Protocol) servers into a single unified endpoint. It works similarly to Nginx but for AI tooling, enabling load balancing across different MCP servers. This allows scaling AI tools by distributing requests efficiently. The tool simplifies managing multiple MCP servers by providing a single access point. It is categorized as an aggregator in the MCP ecosystem.
