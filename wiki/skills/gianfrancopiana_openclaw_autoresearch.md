> ![GitHub stars](https://img.shields.io/github/stars/gianfrancopiana/openclaw-autoresearch?style=social) - OpenClaw port of pi-autoresearch; autonomous experiment loop for any optimization target with statistical confidence scoring.

This project ports the pi-autoresearch system to the OpenClaw hardware platform, enabling an autonomous experiment loop that optimizes any target variable. The loop uses statistical confidence scoring to evaluate and iterate on experimental results. It automates parameter tuning and optimization specifically for OpenClaw-based systems. The project is listed under platform ports and hardware forks, indicating direct hardware integration.
