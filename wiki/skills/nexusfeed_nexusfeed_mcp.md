NexusFeed/nexusfeed-mcp is an MCP server that provides US state Alcohol Beverage Control (ABC) liquor license compliance lookups for California, Texas, New York, and Florida. It allows users to search by trade name, owner, or license number to verify license status, expiration date, and registered address against official state portals. Every response includes a verifiability block with extraction confidence and a source URL, making it suitable for legal and regulatory compliance workflows.
