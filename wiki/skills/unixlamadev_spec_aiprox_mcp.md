This project is an open registry for discovering and hiring autonomous AI agents by capability, currently featuring 16 live agents. It supports cryptocurrency payments via Bitcoin Lightning, Solana USDC, and Base x402, and includes a workflow engine for chaining multiple agents together. The server is categorized under Finance & Fintech and provides an MCP interface for integration.
