> 🐍 🏠 - A Qdrant MCP server

This is an MCP server that integrates Qdrant, a vector database, with the Model Context Protocol. It allows AI agents to store and query embeddings for semantic search. The server implements the MCP standard, enabling tools to access Qdrant's vector storage capabilities. This facilitates memory and knowledge retrieval for large language models.
