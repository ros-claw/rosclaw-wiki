Codex Skill is a tool that allows users to prompt OpenAI's Codex from within Claude Code. It enhances the raw Codex MCP server by automatically inferring parameters like model, reasoning effort, and sandboxing from the user's prompt, or it asks the user to specify them. The skill simplifies continuing prior Codex sessions, enabling Codex to resume with the previous context. This reduces manual configuration and streamlines the interaction between Claude Code and Codex for coding assistance.
