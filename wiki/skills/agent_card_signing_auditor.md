> Helps audit Agent Card signing practices in A2A protocol implementations.

This tool helps audit how Agent Cards are signed in implementations of the A2A protocol. It checks that signatures are correctly applied and validated. This ensures the integrity and authenticity of agent identity and claims. The tool is useful for developers and auditors working with A2A systems.
