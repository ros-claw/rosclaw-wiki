> 🐧 🪟 🍎 - An MCP server (and command-line tool) to provide a dynamic map of chat-related files from the repository with their function prototypes and related files in order of relevance. Based on the "Repo Map" functionality in Aider.chat

RepoMapper is a tool that generates a dynamic map of files in a repository that are relevant to chat-based coding assistants, listing function prototypes and related files in order of relevance. It is inspired by the 'Repo Map' feature from Aider.chat and can function as both an MCP server and a command-line interface. This helps AI agents quickly understand a codebase's structure and context without manual scanning.
