This MCP server provides access to the AutoEQ database of over 8,800 headphone and IEM models for equalization. Users can search by model name or sound signature, retrieve parametric EQ settings, compare headphones band-by-band, and browse rankings based on Harman preference scores. It includes automatic sound signature classification into categories like Neutral, Warm, Bright, Dark, and V-shaped. The server is designed to help audio enthusiasts and professionals optimize their listening experience with data-driven EQ adjustments.
