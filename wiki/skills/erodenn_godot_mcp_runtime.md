> [![godot-runtime-mcp MCP server](https://glama.ai/mcp/servers/@Erodenn/godot-runtime-mcp/badges/score.svg)](https://glama.ai/mcp/servers/@Erodenn/godot-runtime-mcp) 📇 🏠 🍎 🪟 🐧 - MCP server for Godot 4.x with runtime control via injected UDP bridge: input simulation, screenshots, UI discovery, and live GDScript execution while the game is running.

This project is an MCP server for Godot 4.x that enables runtime control of games through a UDP bridge. It allows AI agents to simulate inputs, take screenshots, discover UI elements, and execute live GDScript code. This tool bridges the Model Context Protocol with the Godot engine, enabling embodied intelligence and agentic interactions with game environments. It's particularly useful for automated testing, game debugging, and AI-driven gameplay.
