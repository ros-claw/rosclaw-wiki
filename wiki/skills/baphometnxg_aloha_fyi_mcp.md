Results ship with affiliate booking links. Hosted Streamable HTTP endpoint — no install required. Powered by [aloha.fyi](https://aloha.fyi).

This project is a Model Context Protocol (MCP) server focused on Hawaii tourism, providing access to over 2,500 bookable tours from major platforms like Viator, GetYourGuide, Klook, and Groupon, along with 579 events across multiple Hawaiian islands. It includes affiliate booking links for monetization and is hosted as a Streamable HTTP endpoint that requires no installation. The server is powered by the aloha.fyi service and aims to offer a convenient way to discover and book Hawaii activities through AI agents.
