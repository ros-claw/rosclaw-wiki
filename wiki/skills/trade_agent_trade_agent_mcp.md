Trade-Agent/trade-agent-mcp is a server implementation under the Model Context Protocol (MCP) that allows AI agents to trade stocks and cryptocurrencies through brokerages like Robinhood. It automates financial trading by connecting language models with real-world brokerage APIs. This enables autonomous or assisted trading decisions in finance and fintech applications.
