Create hosted checkout links, verify on-chain payments, generate MPP/x402/AP2 agent-commerce challenges. Supports USDC + native tokens (ALGO/VOI/HBAR/XLM) on Algorand, VOI, Hedera, and Stellar — mainnet + testnet. Routes through AlgoVoi Cloud for managed payouts. Install: `npx @algovoi/mcp-server` or `uvx algovoi-mcp`.

This MCP server implements a crypto payment gateway for agent-to-agent commerce. It enables creating hosted checkout links and verifying on-chain payments across multiple blockchains including Algorand, Hedera, and Stellar. The tool supports USDC and native tokens on both mainnet and testnet, routing through AlgoVoi Cloud for managed payouts. Developers can install it via npx or uvx.
