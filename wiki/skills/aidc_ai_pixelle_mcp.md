> 🐍 📇 🏠 🎥 🔊 🖼️ - An omnimodal AIGC framework that seamlessly converts ComfyUI workflows into MCP tools with zero code, enabling full-modal support for Text, Image, Sound, and Video generation with Chainlit-based web interface.

Pixelle-MCP is an omnimodal AIGC framework that converts ComfyUI workflows into MCP (Model Context Protocol) tools without requiring any code. It supports full-modal generation including text, image, sound, and video. The tool provides a Chainlit-based web interface for ease of use.
