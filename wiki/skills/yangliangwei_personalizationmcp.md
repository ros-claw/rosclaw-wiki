> 🐍 ☁️ 🏠 🍎 🪟 🐧 - Comprehensive personal data aggregation MCP server with Steam, YouTube, Bilibili, Spotify, Reddit and other platforms integrations. Features OAuth2 authentication, automatic token management, and 90+ tools for gaming, music, video, and social platform data access.

This MCP server aggregates personal data from multiple platforms including Steam, YouTube, Bilibili, Spotify, and Reddit. It provides OAuth2 authentication and automatic token management. With over 90 tools, it enables access to gaming, music, video, and social media data. The server simplifies integrating diverse personal data sources into AI applications.
