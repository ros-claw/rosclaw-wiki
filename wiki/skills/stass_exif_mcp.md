> 📇 🏠 🐧 🍎 🪟 - A MCP server that allows one to examine image metadata like EXIF, XMP, JFIF and GPS.  This provides foundation for LLM-powered search and analysis of photo librares and image collections.

This project is a Model Context Protocol (MCP) server that enables examination of image metadata such as EXIF, XMP, JFIF, and GPS. It is cross-platform, running on Linux, macOS, and Windows. The tool provides a foundation for LLM-powered search and analysis of photo libraries and image collections. It allows AI agents to access and reason about image metadata for automated organization and retrieval.
