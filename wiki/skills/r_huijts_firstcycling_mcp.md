> 📇 ☁️ - Access cycling race data, results, and statistics through natural language. Features include retrieving start lists, race results, and rider information from firstcycling.com.

This MCP server enables natural language access to cycling race data from firstcycling.com. It supports retrieving start lists, race results, rider information, and statistics. The tool simplifies querying sports data through conversational interfaces, making it useful for cycling enthusiasts and analysts.
