> Comprehensive security audit for an agent's full skill stack.

This project provides a comprehensive security audit framework for an AI agent's entire skill stack. It systematically reviews each component of the agent's capabilities to identify vulnerabilities. The audit covers tool integrations, APIs, and execution environments. It aims to ensure robust security practices are followed during agent development and deployment. This tool is essential for maintaining trusted and safe embodied intelligence systems.
