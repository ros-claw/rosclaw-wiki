The flowzap-xyz/flowzap-mcp server creates workflow, sequence, and architecture diagrams using the FlowZap Code DSL. It provides seven tools including validation, playground URL generation, syntax documentation, graph export, artifact parsing, diffing, and patching. No API key is required, and it can be installed via npm. It is listed under Server Implementations for Architecture & Design.
