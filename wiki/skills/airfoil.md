> Control AirPlay speakers via Airfoil from the command line.

airfoil is a command-line tool that allows users to control AirPlay speakers through the Airfoil application. It provides a way to manage audio streaming to AirPlay-compatible devices from the terminal. Users can perform actions like selecting speakers, adjusting volume, and streaming audio without a GUI. This is useful for automation, scripting, and headless setups.
