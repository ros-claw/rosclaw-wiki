> 🏎️ 🏠 - Control AVM FRITZ!Box routers - manage devices, WiFi, network settings, parental controls, and schedule time-delayed actions

This project provides a Model Context Protocol (MCP) server for controlling AVM FRITZ!Box routers. It enables managing connected devices, WiFi settings, network configurations, parental controls, and scheduling time-delayed actions. The server offers a standardized interface for AI agents to interact with home network infrastructure. It is listed under home automation server implementations.
