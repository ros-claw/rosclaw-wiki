Wopee MCP is an MCP server that enables autonomous testing of web applications using AI agents. It can launch real browsers, execute test cases, and report pass/fail results along with screenshots. The server also generates user stories, test cases, and Playwright code from application context. It provides eight tools for end-to-end test automation.
