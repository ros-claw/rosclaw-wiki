The asqav-mcp MCP server enforces governance policies for AI agents, ensuring actions comply with defined rules. It provides quantum-safe audit trails using ML-DSA digital signatures, supports multi-party authorization, and generates compliance reports. Through MCP tools, agents can check policies, sign actions, and verify signatures to maintain security and accountability.
