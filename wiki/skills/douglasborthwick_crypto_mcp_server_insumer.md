This MCP server enables cross-chain attestation across 31 blockchains, providing tools for ECDSA-signed verification, wallet trust profiles, compliance templates, and merchant onboarding. It supports ACP/UCP commerce protocols, making it suitable for decentralized finance (DeFi) and fintech applications. By integrating with MCP clients, it allows AI agents to verify on-chain data and enforce trust profiles. The server is designed for compliance and merchant use cases in blockchain ecosystems.
