OpenTTT-MCP is a server that provides Proof-of-Time temporal attestation for AI agents. It gathers temporal proofs from four HTTPS sources and maintains a database of over 54,000 proofs. Compatible with Claude Desktop, it enables verifiable timestamps for agent actions, particularly useful in finance and fintech applications.
