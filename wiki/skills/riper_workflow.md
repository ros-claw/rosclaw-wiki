> Structured development workflow enforcing separation between Research, Innovate, Plan, Execute, and Review phases. Features consolidated subagents for context-efficiency, branch-aware memory bank, and strict mode enforcement for guided development.

The RIPER Workflow provides a structured development methodology that separates work into five distinct phases: Research, Innovate, Plan, Execute, and Review. It features consolidated subagents to maintain context efficiency, a branch-aware memory bank for tracking state across different development branches, and a strict mode that enforces guided development. This approach aims to offer clear guardrails for developers, ensuring systematic progress and reduced context-switching overhead.
