> An MCP server to interact with Google Search Console and Bing Webmasters.

This MCP server integrates with Google Search Console and Bing Webmasters, allowing AI agents to query search analytics, sitemaps, and other SEO data. It provides tools to fetch performance reports, manage sitemaps, and inspect URLs. The server is designed for use in customer data platforms and SEO automation workflows. It enables natural language interactions with search engine data through the Model Context Protocol.
