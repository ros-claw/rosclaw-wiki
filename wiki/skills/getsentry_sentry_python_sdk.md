Sentry Python SDK is the official Python client for Sentry, an error tracking and performance monitoring platform. It enables developers to capture and aggregate errors, exceptions, and performance data from Python applications. The SDK supports automatic instrumentation for popular frameworks like Django, Flask, and FastAPI, and provides manual APIs for custom logging and tracing. It helps teams identify, diagnose, and fix issues in production systems efficiently.
