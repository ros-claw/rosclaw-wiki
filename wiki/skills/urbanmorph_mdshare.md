> 📇 ☁️ - Markdown collaboration for AI workflows. Share markdown instantly via public links with four permission levels (admin, edit, comment, view), inline comments anchored to text, real-time WebSocket sync, and version history. Free, no login. `npx mdshare-mcp` lets AI agents read docs, review comments, incorporate feedback, and resolve threads — the full review loop without copy-pasting between tools.

mdshare is a free, no-login markdown collaboration tool designed for AI workflows. It allows users to share markdown documents via public links with four permission levels and features inline comments, real-time synchronization via WebSocket, and version history. AI agents can use the MCP interface to read documents, review comments, incorporate feedback, and resolve threads, enabling a full review loop without copy-pasting.
