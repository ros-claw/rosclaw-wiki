Attestations, disputes, sybil detection, IPFS audit anchoring.

This project provides a software development kit (SDK) for establishing trust, identity, and reputation for AI agents. It uses W3C Decentralized Identifiers (DIDs) for identity and implements the EigenTrust algorithm for reputation scoring. The SDK also supports attestations, dispute resolution, sybil attack detection, and anchors audit trails to the InterPlanetary File System (IPFS). Its goal is to enable a secure and transparent trust framework for autonomous agent interactions.
