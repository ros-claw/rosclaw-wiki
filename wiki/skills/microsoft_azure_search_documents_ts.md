The azure-search-documents-ts package is the official TypeScript client library for Azure Cognitive Search. It allows developers to integrate search capabilities into applications using TypeScript. The library provides operations for managing search indexes, documents, and queries. It is part of the Azure SDK for JavaScript/TypeScript ecosystem.
