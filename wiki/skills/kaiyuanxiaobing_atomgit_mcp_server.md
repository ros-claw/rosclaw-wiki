> 📇 ☁️ - Official AtomGit server for integration with repository management, PRs, issues, branches, labels, and more.

This is the official MCP server for AtomGit, a Git repository hosting platform. It enables AI agents to integrate with version control features such as repository management, pull requests, issues, branches, and labels. The server provides a standardized interface via the Model Context Protocol for interacting with AtomGit's API.
