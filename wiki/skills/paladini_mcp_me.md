paladini/mcp-me is a digital identity layer for AI tools, providing a unified profile with bio, career, skills, interests, and projects. It automatically generates this profile from over 342 public APIs (e.g., GitHub, Medium, Strava) and includes 13 real-time plugins for services like Spotify and Steam. Profiles are stored locally in YAML format, prioritizing privacy, and work with multiple MCP clients including Claude Desktop and Cursor. This server helps AI assistants access a user's persistent identity across sessions, enhancing context and personalization.
