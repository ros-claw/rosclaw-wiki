> 📇 ☁️ -  An MCP server that tracks newly created liquidity pools on Uniswap across multiple blockchains.

This MCP server monitors newly created liquidity pools on Uniswap across multiple blockchains. It provides real-time notifications of new pools, enabling users to track emerging trading pairs and liquidity events. The server helps developers and traders stay updated on Uniswap pool creation for market analysis or automated strategies.
