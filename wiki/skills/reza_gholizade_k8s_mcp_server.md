> 🏎️ ☁️/🏠 - A Kubernetes Model Context Protocol (MCP) server that provides tools for interacting with Kubernetes clusters through a standardized interface, including API resource discovery, resource management, pod logs, metrics, and events.

This is a Model Context Protocol (MCP) server designed for interacting with Kubernetes clusters. It provides a standardized interface for API resource discovery, resource management, pod logs, metrics, and events. The server can be hosted in cloud or on-premises environments, making it suitable for various Kubernetes deployments. It aims to simplify cluster management by exposing tools through the MCP protocol.
