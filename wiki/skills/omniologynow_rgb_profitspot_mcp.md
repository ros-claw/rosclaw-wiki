This MCP server equips AI agents with cross-chain DeFi intelligence, covering 86 blockchains and over 6,500 liquidity pools. It provides seven tools for yield discovery, pool analysis, profit simulation, risk scoring, whale tracking, impermanent loss calculation, and a DeFi overview. Designed for easy integration, it can be installed via pip and enables AI agents to query and analyze decentralized finance data across multiple chains.
