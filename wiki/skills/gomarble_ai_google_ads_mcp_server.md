> 🐍 ☁️ - MCP server acting as an interface to the Google Ads, enabling programmatic access to Google Ads data and management features.

This MCP server provides a programmatic interface to Google Ads, allowing AI agents to access campaign data, manage accounts, and automate marketing tasks. Built with Python and cloud infrastructure, it leverages the Model Context Protocol for seamless integration. The server enables retrieval of performance metrics, keyword management, and other advertising operations.
