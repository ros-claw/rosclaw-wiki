Agentwallet-mcp is a permissionless wallet infrastructure designed for AI agents, offering 29 tools for wallet creation, transaction signing, token transfers, and x402 payments. It operates across all EVM chains and Solana without requiring KYC or API keys, and agents pay transaction fees in USDC. This server enables autonomous agents to manage financial operations seamlessly within the Model Context Protocol ecosystem.
