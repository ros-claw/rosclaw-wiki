> Apple Photos.app integration for macOS.

This project provides a Python-based integration for Apple's Photos.app on macOS, allowing programmatic access to photo libraries, albums, and metadata. It enables users to query, export, and manipulate photos and albums using a simple API. The tool is useful for automating photo management tasks, such as backing up or organizing large photo collections. It leverages macOS-specific frameworks to interact with the Photos library directly.
