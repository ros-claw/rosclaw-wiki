> 🐍 🏠 - Local-first AWS security analyzer that discovers attack paths and generates remediations using graph theory.

CyntriSec CLI is a local-first security tool for AWS that uses graph theory to identify attack paths and generate remediation steps. It runs offline, ensuring data privacy while analyzing cloud infrastructure for vulnerabilities. The tool helps security teams prioritize fixes by mapping complex attack chains.
