> 🏎️ ☁️ 🏠 🍎 🪟 🐧 - Connect to any MediaWiki wiki (Wikipedia, Fandom, corporate wikis). 33+ tools for search, read, edit, link analysis, revision history, and Markdown conversion. Supports stdio and HTTP transport.

This project implements a Model Context Protocol (MCP) server that connects to any MediaWiki-based wiki, including Wikipedia, Fandom, and corporate wikis. It provides over 30 tools for searching, reading, editing, analyzing links, browsing revision history, and converting pages to Markdown. The server supports both standard I/O and HTTP transport methods, making it flexible for integration with AI agents and other tools.
