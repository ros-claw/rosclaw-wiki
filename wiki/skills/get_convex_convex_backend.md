> 📇 ☁️ - Convex database integration to introspect tables, functions, and run oneoff queries ([Source](https://github.com/get-convex/convex-backend/blob/main/npm-packages/convex/src/cli/mcp.ts))

This project implements an MCP server for Convex databases, allowing AI agents to introspect tables and functions, and run one-off queries. It is part of the Convex backend and is implemented as a CLI MCP tool in the convex npm package. The integration enables natural language interaction with Convex's real-time database and serverless functions.
