> 🐍 ☁️ - An MCP server that aggregates real-time cryptocurrency news from multiple RSS feeds.

This MCP server aggregates real-time cryptocurrency news from multiple RSS feeds, providing a unified stream of crypto-related updates. It is built with Python and designed for integration with AI agents via the Model Context Protocol (MCP). Users can access filtered or categorized crypto news to inform trading or analysis. The server simplifies staying up-to-date with fast-moving crypto markets.
