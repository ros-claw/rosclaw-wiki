> 📇 ☁️ - An MCP server that provides real-time prediction market data from multiple platforms including Polymarket, PredictIt, and Kalshi. Enables AI assistants to query current odds, prices, and market information through a unified interface.

This project implements an MCP server that aggregates real-time prediction market data from multiple platforms. It provides a unified interface for AI assistants to query current odds and prices from Polymarket, PredictIt, and Kalshi. The server enables integration with AI tools to fetch market information without separate API handling. It falls under the Finance & Fintech category in the MCP server list.
