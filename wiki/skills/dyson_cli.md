> Control Dyson air purifiers, fans, and heaters via local MQTT.

dyson-cli is a command-line tool that allows users to control Dyson air purifiers, fans, and heaters over a local network using MQTT. It provides a way to send commands and read status without relying on the cloud. The tool is useful for integrating Dyson devices into home automation systems. It likely requires a local MQTT broker and network access to the Dyson devices.
