> 📇 ☁️ - A MCP server for Stadia Maps' Location APIs - Lookup addresses, places with geocoding, find time zones, create routes and static maps

This project is an MCP server that provides access to Stadia Maps' Location APIs. It enables address lookups, place searches through geocoding, time zone retrieval, route creation, and static map generation. It integrates location services into the Model Context Protocol ecosystem.
