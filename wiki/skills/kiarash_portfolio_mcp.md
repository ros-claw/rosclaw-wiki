> – WebMCP-enabled portfolio with Ed25519 signed discovery. AI agents can query projects, skills, and execute terminal commands. Built on Cloudflare Pages Functions.

Kiarash Portfolio MCP is a web-enabled portfolio that integrates with AI agents using the Model Context Protocol (MCP). It features Ed25519 cryptographic signing for discovery and allows AI agents to query projects, skills, and execute terminal commands. The portfolio is built on Cloudflare Pages Functions, making it serverless and scalable. This enables AI assistants to interact with and retrieve information from the portfolio in a secure and verifiable manner.
