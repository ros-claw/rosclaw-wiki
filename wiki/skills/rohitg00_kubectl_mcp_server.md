> 🐍 ☁️/🏠 - A Model Context Protocol (MCP) server for Kubernetes that enables AI assistants like Claude, Cursor, and others to interact with Kubernetes clusters through natural language.

A Model Context Protocol (MCP) server that connects AI assistants to Kubernetes clusters, allowing natural language commands for cluster management. It supports popular AI tools like Claude and Cursor. This enables users to interact with Kubernetes resources without needing to remember kubectl commands. The server acts as a bridge between AI agents and cloud infrastructure.
