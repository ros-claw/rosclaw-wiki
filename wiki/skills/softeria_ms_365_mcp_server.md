> 📇 ☁️ - MCP server that connects to Microsoft Office and the whole Microsoft 365 suite using Graph API (including Outlook, mail, files, Excel, calendar)

This is a Model Context Protocol (MCP) server that integrates AI agents with Microsoft 365 services via the Microsoft Graph API. It supports core productivity tools like Outlook, mail, files, Excel, and calendar, enabling actions such as sending emails, managing events, or querying documents. Designed for MCP-based systems, it expands agent capabilities into Microsoft's collaboration suite.
