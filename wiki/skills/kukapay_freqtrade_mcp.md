> 🐍 ☁️ - An MCP server that integrates with the Freqtrade cryptocurrency trading bot.

This project provides a Model Context Protocol (MCP) server that connects to Freqtrade, an open-source cryptocurrency trading bot. It allows AI assistants to interact with Freqtrade through standardized tools and resources, enabling tasks like fetching trade history, checking open positions, and adjusting strategy parameters. The integration makes it possible for AI agents to monitor and manage automated crypto trading operations. By using MCP, it ensures secure and structured communication between large language models and the trading bot.
