> 🐍 ☁️ - Unofficial GitHub MCP server that provides access to GitHub's GraphQL API, enabling more powerful and flexible queries for repository data, issues, pull requests, and other GitHub resources.

This is an unofficial MCP server for GitHub that uses the GraphQL API instead of the traditional REST API. It allows more powerful and flexible queries for repository data, issues, pull requests, and other GitHub resources. The server is implemented in Python and designed to integrate with MCP-compatible tools. It provides a single resource endpoint and several tools for interacting with GitHub data.
