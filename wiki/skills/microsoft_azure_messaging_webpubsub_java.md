This is the official Java SDK for Azure Web PubSub service, enabling real-time messaging and pub/sub patterns. It provides client and management libraries for interacting with Azure Web PubSub from Java applications. The SDK supports WebSocket connections, event handlers, and message broadcasting. It is part of Microsoft's cloud messaging services under the Azure ecosystem.
