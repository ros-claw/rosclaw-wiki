> [![mikusnuz/meta-ads-mcp MCP server](https://glama.ai/mcp/servers/mikusnuz/meta-ads-mcp/badges/score.svg)](https://glama.ai/mcp/servers/mikusnuz/meta-ads-mcp) 📇 ☁️ - MCP server for Meta Marketing API v25.0 — 123 tools for Facebook & Instagram ad campaigns, audiences, creatives, insights, catalogs, and automated rules.

This project provides an MCP server that connects to Meta's Marketing API version 25.0. It exposes over 120 tools for managing Facebook and Instagram ad campaigns, audiences, creatives, and insights. Users can programmatically control ad catalogs and set up automated rules through the server. The server is listed under the Marketing category in the MCP server registry.
