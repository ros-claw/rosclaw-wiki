> 📇 🏠 - MCP server for secure database access (PostgreSQL, MySQL, SQLite) with parameterized queries and schema inspection

This MCP server enables large language models to securely access and interact with databases. It supports PostgreSQL, MySQL, and SQLite, using parameterized queries to prevent SQL injection and providing schema inspection for understanding database structure. Ideal for AI agents that need to query data or retrieve metadata from relational databases.
