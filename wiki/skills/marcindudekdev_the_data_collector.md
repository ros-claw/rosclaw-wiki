> [![crypto-signals-mcp MCP server](https://glama.ai/mcp/servers/MarcinDudekDev/crypto-signals-mcp/badges/score.svg)](https://glama.ai/mcp/servers/MarcinDudekDev/crypto-signals-mcp) 🐍 ☁️ - MCP server for scraping Hacker News, Bluesky, and Substack with x402 micropayment support. Tools: hn_search, bluesky_search, substack_search. $0.05/call via USDC on Base.

This MCP server enables AI agents to search Hacker News, Bluesky, and Substack through three dedicated tools: hn_search, bluesky_search, and substack_search. Each API call costs $0.05, paid via USDC on the Base blockchain using x402 micropayments. It is designed for real-time data extraction from social and news platforms, supporting both serendipitous discovery and structured retrieval. The server is listed under Search & Data Extraction in the MCP server ecosystem.
