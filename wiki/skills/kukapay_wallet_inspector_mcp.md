> 🐍 ☁️ -  An MCP server that empowers AI agents to inspect any wallet’s balance and onchain activity across major EVM chains and Solana chain.

This project implements an MCP (Model Context Protocol) server that enables AI agents to query wallet balances and onchain activity across multiple EVM-compatible blockchains and the Solana network. It provides a standardized interface for agents to inspect financial data directly from blockchain sources. The tool is listed under Finance & Fintech, indicating its application in financial analysis and automation. It simplifies agent access to real-time wallet information without requiring custom blockchain integrations.
