> Interact with Akaunting open-source accounting software via REST API.

This project is a PHP client library that enables interaction with the Akaunting open-source accounting software via its REST API. It provides developers with tools to manage invoices, expenses, customers, and other accounting data programmatically. The library simplifies integration of accounting features into custom applications and automates data exchange with Akaunting instances.
