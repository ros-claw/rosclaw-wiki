> 🐍 🏠 🪟 - A Model Context Protocol (MCP) server designed to connect to a CCTV recording program (VMS) to retrieve recorded and live video streams. It also provides tools to control the VMS software, such as showing live or playback dialogs for specific channels at specified times.

This project is an MCP server that connects to a CCTV recording program (VMS) to retrieve both recorded and live video streams. It also provides tools to control the VMS software, such as displaying live or playback dialogs for specific channels at specified times. This enables AI agents to interact with video surveillance systems through the Model Context Protocol.
