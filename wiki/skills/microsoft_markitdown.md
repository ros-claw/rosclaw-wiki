> 🎖️ 🐍 🏠 - MCP tool access to MarkItDown -- a library that converts many file formats (local or remote) to Markdown for LLM consumption.

Microsoft's MarkItDown is a library that converts various file formats (like PDF, Word, Excel, images, etc.) into Markdown, making them suitable for use with large language models. This project provides a server implementation for the Model Context Protocol (MCP), which allows MCP tools to access MarkItDown's conversion capabilities locally or remotely. It simplifies integrating file-to-markdown conversion into AI agent workflows, enabling agents to process diverse document types.
