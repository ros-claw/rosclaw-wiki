> 🐍 🏠 ☁️ - MCP server providing a powerful bioinformatics toolkit for genomics queries and analysis, wrapping the popular `gget` library.

The gget-mcp server converts the popular gget Python library into an MCP server for bioinformatics. It lets AI agents perform genomic queries such as retrieving gene sequences, finding orthologs, and analyzing protein structures. This integration makes genomic analysis accessible within AI workflows via the Model Context Protocol. It is designed for researchers and developers building AI-powered biology tools.
