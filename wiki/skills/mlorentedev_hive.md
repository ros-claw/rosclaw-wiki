Hive is an MCP server that provides on-demand access to an Obsidian vault. It features adaptive context loading that saves 67-82% of tokens, along with full-text and ranked search, health checks, automatic Git commits, and worker delegation. The server includes 10 tools and is compatible with any MCP client.
