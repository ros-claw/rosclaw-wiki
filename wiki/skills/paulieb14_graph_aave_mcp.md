This MCP server provides access to AAVE V2 and V3 lending protocol data across seven blockchain networks using The Graph's subgraphs. It enables queries for reserves, user positions, health factors, liquidations, flash loans, and governance data. Users can retrieve real-time on-chain information to monitor lending markets and assess risk. The server is part of the Finance & Fintech category of MCP implementations.
