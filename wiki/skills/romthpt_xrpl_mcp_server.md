> 📇 ☁️ - MCP server for the XRP Ledger that provides access to account information, transaction history, and network data. Allows querying ledger objects, submitting transactions, and monitoring the XRPL network.

This project is an MCP server that provides access to the XRP Ledger (XRPL), allowing users to query account information, transaction history, and network data. It enables submitting transactions, querying ledger objects, and monitoring the XRPL network. Designed for fintech applications, it simplifies interaction with the XRP Ledger through the Model Context Protocol.
