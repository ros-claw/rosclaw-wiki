> 🎖️ 📇 ☁️ 🏠 - Use natural language to explore LLM observability, traces, and monitoring data captured by Opik.

This project, Comet-ML/Opik-MCP, provides a server implementation that lets you use natural language to explore LLM observability data. It integrates with Opik, a platform for tracking and monitoring large language model traces. By connecting through the Model Context Protocol (MCP), users can query logs, metrics, and other observability data conversationally. This simplifies debugging and analysis of LLM behavior without needing complex query languages.
