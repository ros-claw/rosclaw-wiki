This MCP server provides access to German public procurement data using the Open Contracting Data Standard (OCDS). It enables semantic search and tender matching with company profiles to identify relevant business opportunities. Users can apply structured filtering to narrow down results by various criteria. The project is built in Rust and supports multiple platforms including Windows, macOS, and Linux.
