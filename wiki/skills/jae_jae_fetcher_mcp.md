> 📇 🏠 - MCP server for fetching web page content using Playwright headless browser, supporting Javascript rendering and intelligent content extraction, and outputting Markdown or HTML format.

This project is an MCP server that allows fetching web page content with a Playwright headless browser. It can render JavaScript and intelligently extract the main content. The output can be in Markdown or HTML format. It is particularly useful for search and data extraction tasks in the MCP ecosystem.
