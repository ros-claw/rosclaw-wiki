This MCP server provides a suite of 26 video editing tools for AI agents to perform tasks like trimming, merging, text overlays, audio sync, filters, color grading, and picture-in-picture. It is built with Python, has 380 tests, and supports progress callbacks. The server works with MCP-compatible clients such as Claude Code and Cursor, and handles batch processing and format conversion.
