> 🏎️ 🏠 A – user-friendly read-only mysql mcp server for cursor and n8n...

This project provides a user-friendly, read-only MySQL server that implements the Model Context Protocol (MCP). It is designed to integrate with AI coding assistants like Cursor and workflow automation tools like n8n. The server allows safe, query-only access to MySQL databases, preventing any write operations. It aims to simplify database interaction for AI agents by offering a straightforward setup.
