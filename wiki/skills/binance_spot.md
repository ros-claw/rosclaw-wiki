The binance/spot project is a TypeScript SDK for interacting with Binance's spot trading API. It provides a comprehensive set of methods to manage orders, account information, market data, and websocket streams. Designed for easy integration, it supports both REST and WebSocket endpoints. This library is widely used by developers building automated trading bots and applications on Binance exchange.
