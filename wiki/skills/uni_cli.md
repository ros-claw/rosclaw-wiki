Ships an 8-phase Karpathy-style self-repair loop, eval harness with a starter catalog, per-call cost ledger, hardcoded sensitive-path deny list, and `unicli mcp serve` that auto-registers one MCP tool per adapter. ~80 tokens per invocation.

Uni-CLI is a universal command-line interface that serves as a hub for connecting AI agents to 134 websites and desktop applications through 711 declarative YAML pipelines. It features an 8-phase self-repair loop inspired by Karpathy, an evaluation harness with a starter catalog, per-call cost tracking, and a hardcoded deny list for sensitive file paths. The tool also includes a 'unicli mcp serve' command that automatically registers each adapter as a Model Context Protocol (MCP) tool, with an average token cost of around 80 per invocation.
