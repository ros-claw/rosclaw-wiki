> 提取抖音无水印视频链接，视频文案

This project implements an MCP server that enables AI agents to extract Douyin (Chinese TikTok) video links without watermarks and retrieve the associated video captions. It integrates with the Model Context Protocol to provide a tool for social media content extraction, allowing agents to obtain clean video URLs and textual descriptions. The server is useful for analyzing or repurposing Douyin content within AI-driven workflows.
