> 🦀 ☁️ - Fetch real-time stock prices from Stooq without API keys. Supports global markets (US, Japan, UK, Germany).

Stooq MCP is a server implementation for the Model Context Protocol that provides real-time stock price data from Stooq, a free financial data provider. It does not require any API keys, making it easy to integrate into AI agents for financial queries. The server supports global markets including the US, Japan, UK, and Germany, and is written in Rust with cloud deployment capabilities. This tool enables AI agents to fetch current stock prices without authentication overhead.
