> 🐍 🏠 🍎 🪟 🐧 - AI image generation using Google Gemini's nano banana model.

This MCP server integrates Google Gemini's nano banana model for AI image generation. It is a cross-platform tool supporting Python, macOS, Windows, and Linux. The server uses the Model Context Protocol (MCP) to allow clients to generate images through Gemini. It provides a simple API for image creation, enabling developers to add image generation capabilities to their applications.
