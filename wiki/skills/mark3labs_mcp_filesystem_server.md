> 🏎️ 🏠 - Golang implementation for local file system access.

mcp-filesystem-server is an open-source server implementation written in Go that provides local file system access through the Model Context Protocol (MCP). It enables AI agents and applications to read, write, and manage files on the host machine securely. This tool is ideal for integrating file operations into MCP-compatible workflows, especially for Go-based environments. The project is listed under file system server implementations in the MCP ecosystem.
