> The PlanetScale CLI includes an MCP server that provides AI tools direct access to your PlanetScale databases.

The PlanetScale CLI includes an MCP (Model Context Protocol) server that gives AI tools direct access to PlanetScale databases. This integration allows AI assistants to query and manage serverless MySQL databases using natural language. It streamlines database interactions for AI-driven workflows and development tasks.
