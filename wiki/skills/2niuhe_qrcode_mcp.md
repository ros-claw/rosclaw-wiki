> 🐍 🏠 🍎 🪟 🐧 - A QR code generation MCP server that converts any text (including Chinese characters) to QR codes with customizable colors and base64 encoding output.

This MCP server generates QR codes from text input, including support for Chinese characters. Users can customize the QR code colors and receive the output as a base64-encoded image. It is designed to be integrated with AI assistants via the Model Context Protocol, enabling QR code creation as a tool for chatbots or other AI applications.
