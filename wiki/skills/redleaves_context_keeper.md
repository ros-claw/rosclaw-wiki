> 🏎️ 🏠 ☁️ 🍎 🪟 🐧 - LLM-driven context and memory management with wide-recall + precise-reranking RAG architecture. Features multi-dimensional retrieval (vector/timeline/knowledge graph), short/long-term memory, and complete MCP support (HTTP/WebSocket/SSE).

Context-keeper is an LLM-driven tool for managing context and memory using a RAG architecture with wide recall and precise reranking. It supports multi-dimensional retrieval including vector, timeline, and knowledge graph searches. The system features both short-term and long-term memory, and provides complete MCP support via HTTP, WebSocket, and SSE protocols. This project is designed for AI agents needing persistent, structured memory and context across sessions.
