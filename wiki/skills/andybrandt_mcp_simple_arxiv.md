> 🐍 ☁️  MCP for LLM to search and read papers from arXiv

This project provides a Model Context Protocol (MCP) server that allows large language models to search for and retrieve academic papers from the arXiv repository. It enables LLMs to interact with arXiv's database through a simple interface, making it easier to incorporate scholarly research into AI-driven workflows. The tool supports searching by keywords, authors, or categories and can fetch paper details, abstracts, and metadata. It is listed under Search & Data Extraction server implementations.
