Roslyn CodeLens MCP is a Model Context Protocol server for .NET code intelligence. It provides 22 semantic tools like type hierarchies, call graphs, dependency injection registration analysis, diagnostics, code fixes, and complexity metrics. The server uses pre-built indexes to enable sub-millisecond lookups. It's designed for developer tooling integration, especially with AI agents that need deep code understanding.
