Real-time world state (exchange status, VIX/VVIX/SKEW, economic events) in one call, plus independent quality ratings (0-100) for financial data APIs. 8 MCP tools.

The Oath Score MCP server provides a trust layer for AI trading agents by offering real-time world state information including exchange status, market volatility indices (VIX, VVIX, SKEW), and economic events in a single API call. It also provides independent quality ratings (0-100) for financial data APIs. The tool exposes 8 MCP tools for agents to use. Its goal is to enhance reliability and transparency in automated trading systems.
