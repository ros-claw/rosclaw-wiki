> [![mikusnuz/umami-mcp MCP server](https://glama.ai/mcp/servers/mikusnuz/umami-mcp/badges/score.svg)](https://glama.ai/mcp/servers/mikusnuz/umami-mcp) 📇 ☁️ - Full-coverage MCP server for Umami Analytics API v2 — 66 tools for websites, stats, sessions, events, reports, users, teams, and realtime monitoring.

This MCP server provides full coverage of the Umami Analytics API v2, offering 66 tools for managing websites, stats, sessions, events, reports, users, teams, and realtime monitoring. It allows AI agents to interact with Umami analytics data through the Model Context Protocol. The server is designed for easy integration into AI workflows, enabling automated analytics queries and configuration. It is listed under Server Implementations > Monitoring on a registry. Hosted on GitHub by mikusnuz, it is a specialized tool for accessing Umami's analytics platform.
