> #️⃣ 🏠 🍎 🪟 🐧 - Provides AI agents with detailed type information from .NET projects including assembly exploration, namespace discovery, type reflection, and NuGet integration

This project is a Model Context Protocol (MCP) server that provides AI agents with detailed type information from .NET projects. It enables exploration of assemblies, namespaces, types, and reflection, and integrates with NuGet package management. The server allows AI agents to understand the structure and metadata of .NET codebases, facilitating code analysis and development tasks.
