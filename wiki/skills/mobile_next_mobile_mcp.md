> 📇 🏠 🐧 🍎 - MCP Server for Android/iOS application and device automation, development and app scraping. Simulator/Emulator/Physical devices like iPhone, Google Pixel, Samsung supported.

This project is an MCP (Model Context Protocol) server designed for automating Android and iOS devices, including simulators, emulators, and physical devices like iPhones, Google Pixels, and Samsungs. It supports tasks such as device automation, app development, and app scraping. The server provides developers with a unified interface to control mobile devices for testing and development workflows.
