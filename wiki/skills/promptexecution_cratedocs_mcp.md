> 🦀 🏠 - Outputs short-form Rust crate derived traits,interfaces, etc. from AST (uses same api as rust-analyzer), output limits (token estimation) & crate docs w/regex stripping.

This MCP server extracts short-form Rust crate information including derived traits and interfaces from the abstract syntax tree (AST), using the same API as rust-analyzer. It provides token estimation for output limits and strips regex patterns from crate documentation. The tool is designed to help AI agents and developer tools quickly understand Rust crate structures.
