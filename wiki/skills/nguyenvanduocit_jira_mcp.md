> 🏎️ ☁️ - A Go-based MCP connector for Jira that enables AI assistants like Claude to interact with Atlassian Jira. This tool provides a seamless interface for AI models to perform common Jira operations including issue management, sprint planning, and workflow transitions.

The Jira MCP connector is a Go-based tool that enables AI assistants like Claude to interact with Atlassian Jira through the Model Context Protocol. It allows AI models to perform common Jira operations such as issue management, sprint planning, and workflow transitions. The project is listed under Support and Service Management in the MCP server ecosystem.
