> 📇 ☁️ -  Model Context Protocol server for monitoring Operational Status of major digital platforms in Claude Desktop.

This project provides a Model Context Protocol (MCP) server that allows Claude Desktop users to monitor the operational status of major digital platforms. It enables real-time queries about platform uptime and incidents directly within a conversation. The server acts as a bridge between Claude and status monitoring APIs, giving immediate visibility into service health. This helps users quickly determine if external platforms are experiencing outages without switching contexts.
