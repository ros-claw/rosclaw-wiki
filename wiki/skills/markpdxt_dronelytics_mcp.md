This server provides drone airspace intelligence and mission planning capabilities. It offers 24 tools to check airspace restrictions across 11 FAA data layers, plan grid/orbit/corridor surveys, validate Part 107 compliance, and generate pre-flight briefings. Additionally, it supports exporting mission plans to formats like KML, GPX, QGC, Litchi, and WPML. It is available via npx command.
