This MCP server allows AI assistants to manage pfSense firewalls using 17 tools. It supports operations like firewall rules, DHCP leases and reservations, DNS overrides, gateway monitoring, ARP table, and service management. Destructive actions require a two-step confirmation for safety. It integrates AI tools with pfSense network management.
