> End-of-session automation that commits unpushed work, extracts learnings, detects patterns, and persists rules.

This tool automates end-of-session tasks by committing any unpushed changes to version control. It then extracts key learnings from the session, identifies recurring patterns, and saves actionable rules for future sessions. It helps developers maintain consistent workflow and capture insights automatically.
