> 📇 🏠 🍎 🪟 🐧 - Wenyan MCP Server, which lets AI automatically format Markdown articles and publish them to WeChat GZH.

This project provides a Wenyan MCP Server that enables AI agents to automatically format Markdown articles and publish them to WeChat Official Accounts (GZH). It acts as an integration between the Model Context Protocol (MCP) and the WeChat publishing platform. The server streamlines the process of turning AI-generated Markdown content into formatted posts for distribution on WeChat.
