This is a production-grade MCP server designed for secure access to local development environments. It provides capabilities for filesystem operations, database interactions, process management, and OpenAPI integration. Key security features include scope enforcement, a command allowlist, and a read-only database mode to prevent accidental modifications. It is listed under Developer Tools in the MCP server registry and is ideal for developers needing controlled access to their local dev stacks.
