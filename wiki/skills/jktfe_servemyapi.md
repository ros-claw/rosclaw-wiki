> 📇 🏠 🍎 - A personal MCP (Model Context Protocol) server for securely storing and accessing API keys across projects using the macOS Keychain.

This project is a personal MCP (Model Context Protocol) server designed to securely store and retrieve API keys across multiple projects. It leverages the macOS Keychain for encrypted storage, ensuring credentials are not exposed in plain text. Developers can integrate it with AI assistants or tools that support MCP to access API keys on demand. The tool simplifies managing sensitive keys while maintaining security and convenience.
