Agent-bom is an AI supply chain security scanner implemented as an MCP server. It provides 18 tools to auto-discover MCP clients, scan dependencies for CVEs (using OSV, NVD, EPSS, CISA KEV), map vulnerability blast radius to exposed credentials and tools, run CIS benchmarks, and generate CycloneDX/SPDX SBOMs. It also enforces compliance with frameworks like OWASP LLM Top 10, MITRE ATLAS, NIST AI RMF, and the EU AI Act. The tool runs on multiple platforms (macOS, Windows, Linux, cloud) and is designed to secure AI agent workflows.
