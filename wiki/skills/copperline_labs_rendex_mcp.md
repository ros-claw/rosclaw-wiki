Rendex-MCP is a Model Context Protocol (MCP) server that provides screenshot, PDF, and HTML rendering capabilities for AI agents. It can capture any URL or raw HTML as PNG, JPEG, WebP, or PDF, with support for batch processing and geo-targeting. The tool offers asynchronous webhooks and integrates natively with MCP, making it easy for AI agents to use. A free tier is included, allowing developers to test and experiment with the service.
