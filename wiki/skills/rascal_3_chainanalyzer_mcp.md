ChainAnalyzer-MCP is a Model Context Protocol server that provides multi-chain AML risk scoring and sanctions screening for AI agents. It employs 76+ detection rules, machine learning anomaly scoring, and Neo4j graph analysis across five blockchains: Bitcoin, Ethereum, Polygon, Avalanche, and Solana. The service operates on a pay-per-request model using x402 USDC on Base or Solana, with costs ranging from $0.003 to $0.05 per request. It aims to help AI agents assess blockchain transaction risks and comply with anti-money laundering regulations.
