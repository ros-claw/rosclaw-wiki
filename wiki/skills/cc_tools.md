> High-performance Go implementation of Claude Code hooks and utilities. Provides smart linting, testing, and statusline generation with minimal overhead.

cc-tools is a high-performance Go library that implements hooks and utilities for Claude Code. It provides smart linting, testing, and statusline generation with minimal overhead. This toolkit is designed to enhance Claude Code workflows by offering efficient tooling integration. It leverages Go's performance characteristics to deliver fast execution.
