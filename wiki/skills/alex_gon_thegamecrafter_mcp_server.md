Browse catalogs, create projects, upload artwork, get pricing.

This MCP server integrates with The Game Crafter platform to allow AI agents to design, manage, and price tabletop games. Users can browse catalogs of components, create new game projects, upload artwork, and retrieve pricing information. It essentially provides an API wrapper via MCP for automating game creation workflows on The Game Crafter.
