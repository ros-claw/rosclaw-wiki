> 🎖️ 📇 ☁️ 🏠 - Connect any bitcoin lightning wallet to your agent to send and receive instant payments globally.

This MCP server enables AI agents to send and receive instant Bitcoin Lightning payments by connecting to any Lightning wallet. It provides tools for payment creation, invoice handling, and balance queries. Designed for global, real-time transactions, it integrates financial capabilities into agent workflows. Useful for tipping, microtransactions, and automated payment systems.
