StatelessAgent is a Model Context Protocol (MCP) server that provides memory with provenance tracking, recording where agent knowledge originated and detecting when sources change. It includes 17 MCP tools for session handoffs, decisions, semantic search, and knowledge graph capabilities. The server works across multiple AI coding assistants like Claude Code, Cursor, Windsurf, Codex CLI, and Gemini CLI. It runs as a single Go binary using SQLite and vector search, fully local and private.
