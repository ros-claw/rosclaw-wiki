> 📇 ☁️/🏠 - Typescript implementation of Kubernetes cluster operations for pods, deployments, services.

This project implements a Model Context Protocol (MCP) server in TypeScript for managing Kubernetes clusters. It supports operations on pods, deployments, and services, allowing AI agents to interact with cluster resources. The server is designed for both cloud and local environments and is listed under cloud platform server implementations. It simplifies Kubernetes management through standardized agent tooling.
