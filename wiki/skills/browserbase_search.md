browserbase/search is a TypeScript library for performing web searches and extracting structured data from search engine results. It integrates with the Browserbase platform to provide reliable browser-based search capabilities. The tool is designed for AI agents and automation workflows that need to query the web. It simplifies the process of collecting search results, handling pagination, and avoiding detection.
