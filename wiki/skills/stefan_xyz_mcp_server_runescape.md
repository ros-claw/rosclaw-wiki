> 📇 - An MCP server with tools for interacting with RuneScape (RS) and Old School RuneScape (OSRS) data, including item prices, player hiscores, and more.

This MCP server provides tools for querying RuneScape and Old School RuneScape data, such as item prices and player hiscores. It is designed for integration with AI agents via the Model Context Protocol, enabling automated access to game statistics. The server is listed under gaming tools and offers a structured way to retrieve real-time game information.
