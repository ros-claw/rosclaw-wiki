> 📇 🏠 - A MCP server for interacting with the Godot game engine, providing tools for editing, running, debugging, and managing scenes in Godot projects.

This MCP server provides AI agents with the ability to interact with the Godot game engine. It offers tools for editing scenes, running projects, debugging, and managing assets within Godot. Designed for gaming, it enables automated game development workflows. The server simplifies AI-driven scene management and project control.
