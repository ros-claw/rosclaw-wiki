> 📇 ☁️ 🍎 🪟 🐧 - AI image enhancement (upscaling, denoising, sharpening) via Topaz Labs API. Supports 8 models including Standard V2, Wonder 2, Bloom, and Recover 3.

This MCP server integrates with Topaz Labs API to provide AI-powered image enhancement including upscaling, denoising, and sharpening. It supports multiple models such as Standard V2, Wonder 2, Bloom, and Recover 3. The server enables AI agents and applications to process images through a standardized MCP interface. It falls under the Multimedia Process category of server implementations.
