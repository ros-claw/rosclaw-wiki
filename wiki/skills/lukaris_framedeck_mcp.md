This MCP server integrates with Framedeck, a Kanban-style content production manager designed for YouTube, Instagram, TikTok, and podcast creators. It provides 32 tools to manage entire production workflows, including stages, frames (cards), checklists, comments, and labels. Ideas start in an Idea Pool and progress through stages like Idea, Scripting, Filming, Editing, and Published. All tools include MCP safety annotations for secure use.
