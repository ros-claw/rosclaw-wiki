> [Glama](https://glama.ai/mcp/servers/mnemox-ai/tradememory-protocol) 🐍 🏠 - Structured 3-layer memory system (trades → patterns → strategy) for AI trading agents. Supports MT5, Binance, and Alpaca.

This project provides a structured 3-layer memory system (trades → patterns → strategy) for AI trading agents. It enables these agents to retain and learn from trading experiences across multiple platforms, including MT5, Binance, and Alpaca, supporting both short-term and long-term memory. The protocol helps improve decision-making by linking individual trade data to broader patterns and strategic insights. It is designed as a server implementation for the Model Context Protocol (MCP) in the finance and fintech domain.
