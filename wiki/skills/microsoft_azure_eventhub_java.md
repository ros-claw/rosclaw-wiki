This project provides a Java client library for Azure Event Hubs, a scalable event ingestion service. It enables applications to efficiently publish and subscribe to high-volume event streams. The library supports key features like event sending, receiving, checkpointing, and partition management. It integrates seamlessly with the Azure ecosystem and is the recommended Java SDK for Event Hubs.
