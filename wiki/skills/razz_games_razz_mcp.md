This MCP server lets AI agents play various games like dice, flip, crash, plinko, limbo, mines, tower, and HexWar with real SOL wagers. The games are provably fair, ensuring verifiable outcomes. It integrates with the Solana blockchain for wagering, enabling AI agents to engage in gambling-like activities using real cryptocurrency.
