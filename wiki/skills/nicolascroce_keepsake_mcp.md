> 📇 ☁️ - Personal CRM — manage contacts, interactions, tasks, notes, daily journal, and tags through 42 MCP tools

Keepsake MCP is a personal CRM tool that provides 42 MCP tools for managing contacts, interactions, tasks, notes, daily journals, and tags. It is designed to help users maintain relationships and track personal productivity through a unified interface. The project is listed under Workplace & Productivity server implementations, indicating its focus on enhancing professional and personal organization. By leveraging the Model Context Protocol, it integrates with AI agents to enable automated contact and task management.
