This MCP server integrates with the OpenGraph.io API to extract Open Graph metadata from web pages. It also enables taking screenshots, scraping web content, and querying sites with AI. Additionally, it can generate branded images like illustrations, diagrams, social cards, icons, and QR codes with iterative refinement capabilities. It is listed under Search & Data Extraction server implementations.
