> A wrapper around the Azure CLI command line that allows you to talk directly to Azure

The azure-cli-mcp project provides a wrapper for the Azure CLI that enables direct interaction with Azure through the Model Context Protocol (MCP). It allows users to manage Azure resources using natural language commands via MCP-compatible clients. This server simplifies Azure operations by bridging CLI functionality with conversational AI interfaces. It is designed for cloud platform management and infrastructure automation.
