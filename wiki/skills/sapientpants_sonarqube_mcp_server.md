> 🦀 ☁️ 🏠 - A Model Context Protocol (MCP) server that integrates with SonarQube to provide AI assistants with access to code quality metrics, issues, and quality gate statuses

This MCP server connects AI assistants to SonarQube, providing real-time access to code quality data. It enables AI tools to query metrics, issues, and quality gate statuses from SonarQube projects. This facilitates automated code review and quality monitoring within AI-driven development workflows.
