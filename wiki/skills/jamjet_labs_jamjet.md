Rust core for performance, Python authoring for ergonomics. Features graph-based workflows, durable execution, and multi-agent coordination.

Jamjet is a durable, agent-native AI runtime designed for building reliable and performant AI agents. It uses a Rust core for speed and Python for ease of authoring, and supports the Model Context Protocol (MCP) both as a client and server, as well as Agent-to-Agent (A2A) communication. The runtime features graph-based workflows for complex agent orchestration, durable execution to handle failures, and multi-agent coordination. It is aimed at developers needing robust, long-running AI agent systems.
