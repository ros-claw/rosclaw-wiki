> 🐍 ☁️ 🍎 🪟 🐧 - MCP server for RAGStack serverless knowledge bases. Search, chat with AI-generated answers, upload documents/media, scrape websites, and analyze metadata through an AWS-powered RAG pipeline (Lambda, Bedrock, S3, DynamoDB).

This project implements an MCP server that interfaces with RAGStack serverless knowledge bases, enabling AI-powered search, chat, document upload, website scraping, and metadata analysis. It leverages AWS serverless components including Lambda, Bedrock, S3, and DynamoDB for a scalable RAG pipeline. The server allows users to query knowledge bases with AI-generated answers and manage knowledge content through various operations.
