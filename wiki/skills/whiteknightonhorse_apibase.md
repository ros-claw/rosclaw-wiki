> [![APIbase MCP server](https://glama.ai/mcp/servers/whiteknightonhorse/APIbase/badges/score.svg)](https://glama.ai/mcp/servers/whiteknightonhorse/APIbase) 📇 ☁️ - Unified API hub for AI agents with 56+ tools across travel (Amadeus, Sabre), prediction markets (Polymarket), crypto, and weather. Pay-per-call via x402 micropayments in USDC.

APIbase is an MCP server that aggregates over 56 APIs for AI agents, covering travel (Amadeus, Sabre), prediction markets (Polymarket), crypto, and weather. It uses the x402 micropayment protocol to charge per call in USDC, enabling cost-efficient tool access. Built on the Model Context Protocol, it provides a unified interface for AI assistants to query diverse data sources. This reduces integration complexity for agents needing multiple external services.
