> MCP server for Volatility 3.x, allowing you to perform memory forensics analysis with AI assistant. Experience memory forensics without barriers as plugins like pslist and netscan become accessible through clean REST APIs and LLMs.

This project implements a Model Context Protocol (MCP) server that integrates with Volatility 3, a popular memory forensics tool. It exposes Volatility's plugin system (e.g., pslist, netscan) through clean REST APIs, enabling AI assistants like LLMs to perform memory analysis without manual command-line expertise. The server abstracts the complexity of memory forensics, allowing users to run investigations via natural language interactions with an AI. This lowers barriers to entry for security analysts and developers working with memory dumps.
