> 📇 ☁️ - TS version of yahoo finance mcp.

This project is a TypeScript implementation of a Model Context Protocol (MCP) server for Yahoo Finance. It allows AI agents to access financial data such as stock prices, quotes, and other market information through standard MCP interfaces. The server is listed under Finance & Fintech in the MCP server ecosystem. It provides a easy way for developers to integrate Yahoo Finance data into AI applications.
