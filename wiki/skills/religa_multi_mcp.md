> 🐍 🍎 🪟 🐧 - Parallel multi-model code review, security analysis, and AI debate with ChatGPT, Claude, and Gemini. Orchestrates multiple LLMs for compare, consensus, and OWASP Top 10 security checks.

Multi-MCP is a server-side tool that orchestrates multiple large language models (LLMs) like ChatGPT, Claude, and Gemini for parallel code review, security analysis, and AI debate. It compares outputs from different models to reach consensus and performs security checks based on the OWASP Top 10. The system is designed to enhance code quality and identify vulnerabilities by leveraging diverse AI perspectives. Written in Python, it supports multiple operating systems including macOS, Windows, and Linux.
