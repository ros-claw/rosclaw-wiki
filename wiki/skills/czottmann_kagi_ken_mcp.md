> 📇 ☁️ - Work with Kagi

This MCP server enables AI agents to perform searches and retrieve data from the Kagi search engine via the Model Context Protocol. It provides tools to query Kagi and access search results directly within agent workflows. The server acts as a bridge between AI assistants and Kagi's API for web search and data extraction. It is listed under Search & Data Extraction in the MCP server ecosystem.
