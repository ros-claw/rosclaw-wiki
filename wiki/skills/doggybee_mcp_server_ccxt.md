> 📇 ☁️ - An MCP server for accessing real-time crypto market data and trading via 20+ exchanges using the CCXT library. Supports spot, futures, OHLCV, balances, orders, and more.

This MCP server integrates with over 20 cryptocurrency exchanges via the CCXT library to provide real-time market data and trading capabilities. It supports various data types including OHLCV (candlestick charts), spot and futures markets, account balances, and order management. The server exposes these financial operations through the Model Context Protocol, enabling AI agents to access exchange features programmatically.
