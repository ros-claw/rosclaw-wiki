> 📇 ☁️ - MCP server enabling automated access to

This project implements a Model Context Protocol (MCP) server for interacting with LeetCode. It enables automated access to LeetCode problems, user data, and submissions through standardized MCP interfaces. The server is designed for integration with AI coding agents, allowing them to fetch problems, submit solutions, and retrieve results programmatically. It simplifies the process of using LeetCode within agentic workflows.
