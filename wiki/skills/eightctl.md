> Control Eight Sleep pods (status, temperature, alarms, schedules).

A command-line interface tool for controlling Eight Sleep smart mattress pods. It allows users to check pod status, adjust temperature settings, set alarms, and configure sleep schedules. This tool provides a programmatic way to interact with the Eight Sleep ecosystem without using the official app. It is useful for automating bedtime routines or integrating with other smart home systems.
