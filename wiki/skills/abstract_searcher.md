> Add abstracts to .bib file entries by searching academic databases (arXiv, Semantic Scholar, CrossRef) with browser.

abstract-searcher is a tool that automatically enriches BibTeX (.bib) files by adding missing abstracts from academic databases. It searches arXiv, Semantic Scholar, and CrossRef, and can be used directly from a browser. This helps researchers quickly update bibliography entries without manual lookup. The tool simplifies maintaining complete references for academic writing and citation management.
