> ☁️ - Curated directory of x402 payment protocol resources, MCP servers, and tools for HTTP 402-based USDC payments on Base, Arbitrum, and other EVM chains.

This is a curated directory of resources for the x402 payment protocol, which enables HTTP 402-based USDC payments on EVM chains like Base and Arbitrum. It includes MCP servers and tools for integrating USDC payments using this protocol. The project aims to serve as a central hub for developers and financiers interested in the x402 ecosystem.
