Twilize is an MCP server for programmatic generation of Tableau workbooks (twb/twbx). It provides 47 MCP tools to create charts, dashboards, calculated fields, dashboard actions, perform workbook migration, and build CSV-to-dashboard pipelines. The server can be installed via uvx twilize and supports multiple platforms. It is designed to automate Tableau workbook creation within the MCP ecosystem.
