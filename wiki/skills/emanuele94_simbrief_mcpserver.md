SimBrief-MCPServer is a Model Context Protocol (MCP) server that lets AI assistants access SimBrief flight plans. It provides 14 tools for retrieving flight summaries, weather data (METAR, TAF, ATIS), fuel plans, weights, times, ATC flight plans, navlogs, NOTAMs, alternate airport information, crew details, and performance sensitivity analysis. This server is designed for flight simulation enthusiasts who use SimBrief for flight planning and want to integrate AI capabilities. It supports multiple platforms including macOS, Windows, and Linux. The project is listed under Travel & Transportation within the MCP server ecosystem.
