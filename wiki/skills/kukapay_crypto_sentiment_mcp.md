> 🐍 ☁️ - An MCP server that delivers cryptocurrency sentiment analysis to AI agents.

This project is a Model Context Protocol (MCP) server that delivers cryptocurrency sentiment analysis to AI agents. It processes data from external sources to provide market sentiment, enabling AI-driven trading or analysis applications. The server integrates with AI agents via the MCP standard, making it easy to add sentiment data to any compatible system.
