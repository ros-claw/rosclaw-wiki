> 🐍 ☁️ - A Model Context Protocol server for TikTok Ads API integration, enabling AI assistants to manage campaigns, analyze performance metrics, handle audiences and creatives with OAuth authentication flow.

This project implements a Model Context Protocol (MCP) server that integrates with the TikTok Ads API. It allows AI assistants to manage advertising campaigns, analyze performance metrics, handle audience targeting, and manage creatives. The server uses OAuth for secure authentication. It simplifies the automation of TikTok ad operations through natural language or AI-driven tools.
