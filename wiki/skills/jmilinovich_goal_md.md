> ![GitHub stars](https://img.shields.io/github/stars/jmilinovich/goal-md?style=social) - Generalizes autoresearch into a `GOAL.md` pattern for repos where the agent must first construct a measurable fitness function before it can optimize.

This project introduces a GOAL.md pattern for AI agent repositories, generalizing the concept of autoresearch. The agent must first define a measurable fitness function in the GOAL.md file before it can optimize towards that goal. This approach ensures that the agent has a clear, quantifiable objective to guide its search and optimization processes. The pattern is intended to be general-purpose, applicable across different agent architectures and domains.
