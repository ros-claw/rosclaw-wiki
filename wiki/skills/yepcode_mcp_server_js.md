> 🎖️ 📇 ☁️ - Execute any LLM-generated code in a secure and scalable sandbox environment and create your own MCP tools using JavaScript or Python, with full support for NPM and PyPI packages

This project provides a secure sandbox environment for executing code generated by large language models (LLMs). It supports both JavaScript and Python, with full integration for NPM and PyPI packages. Users can create custom MCP (Model Context Protocol) tools that run inside this sandbox, ensuring safety and scalability. The server is designed to be used as an MCP server for code execution tasks.
