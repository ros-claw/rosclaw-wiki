> Local-first TUI/CLI for auditing AI coding-agent session traces, health gates, cost spikes, tool failures, latency gaps, and attempt-to-attempt diffs.

Agenttrace is a local-first tool with a terminal user interface (TUI) and command-line interface (CLI) for auditing AI coding agents. It analyzes session traces to monitor health gates, cost spikes, tool failures, and latency gaps. The tool also provides attempt-to-attempt diffs to compare different runs. It is categorized under evals and observability.
