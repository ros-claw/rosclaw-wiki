> 🐍 ☁️ - Comprehensive async Python SDK for [TickTick](https://ticktick.com/) with MCP server support. Features 45 tools for tasks, projects, tags, habits, focus/pomodoro sessions, and user analytics.

This project provides a comprehensive asynchronous Python SDK for the TickTick task management platform. It includes support for the Model Context Protocol (MCP) server, enabling seamless integration with AI agents and tools. The SDK offers 45 tools covering tasks, projects, tags, habits, focus/pomodoro sessions, and user analytics. It is designed for developers building automated workflows or AI-driven productivity solutions interacting with TickTick.
