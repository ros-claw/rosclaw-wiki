> 🏎️ 🏠 - MCP server proxy that offers a Web UI to the full message flow

The MCP Log Proxy is a proxy server for the Model Context Protocol that intercepts and logs all message traffic between clients and servers. It provides a web-based user interface that visualizes the full message flow, enabling developers to debug and monitor MCP interactions easily. This tool is useful for inspecting communication details during development or integration of MCP-based systems.
