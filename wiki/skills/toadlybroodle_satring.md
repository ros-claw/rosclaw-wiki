Satring is a curated directory of paid API services that use the L402 and x402 protocols for Lightning and USDC payments. It serves as an aggregator to help users discover and compare these APIs across various platforms. The project is listed under server implementations for aggregators in the MCP ecosystem. It supports multiple operating systems including macOS, Windows, and Linux, and is built with Python.
