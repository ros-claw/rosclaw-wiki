> Run a two-pass, multidisciplinary code audit led by a tie-breaker lead, combining security, performance, UX, DX.

This project implements a two-pass code audit process that evaluates code across multiple disciplines such as security, performance, user experience, and developer experience. A designated lead acts as a tie-breaker to resolve conflicting findings between passes, ensuring a balanced and comprehensive review. The framework is designed to guide AI agents in conducting systematic, multi-faceted code audits for improved code quality and robustness.
