> 📇 🏠 - Generate visual charts using [Apache ECharts](https://echarts.apache.org) with AI MCP dynamically.

This project implements a Model Context Protocol (MCP) server that enables AI agents to dynamically generate interactive charts and visualizations using Apache ECharts. It is listed under Customer Data Platforms, suggesting it can be used to visualize customer data or other datasets through AI-driven requests. The tool allows for flexible creation of various chart types without manual coding, making data exploration more accessible. By bridging MCP and ECharts, it empowers AI assistants to present data insights visually.
