> 🐍 ☁️ - An MCP server for accessing professional financial data, supporting multiple data providers such as Tushare.

finData-mcp-server is an MCP server for accessing professional financial data. It supports multiple data providers, including Tushare, a popular Chinese financial data API. This server enables AI agents to fetch financial datasets through the Model Context Protocol. It is designed for integration into finance and fintech applications.
