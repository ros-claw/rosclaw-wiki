> Generate interactive SVG architecture diagrams for AI agent systems.

Agent-topology-visualizer is a tool for generating interactive SVG diagrams that map the architecture of AI agent systems. It allows developers and researchers to visually represent the connections and hierarchies between multiple agents in a system. The generated diagrams are interactive, enabling users to explore the topology by zooming, panning, or clicking on elements. This aids in understanding complex multi-agent setups and communicating design decisions.
