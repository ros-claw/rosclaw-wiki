> Security-focused code review for hardcoded secrets, dangerous calls, and common vulnerabilities.

This tool performs security-focused code reviews to detect hardcoded secrets, dangerous function calls, and common vulnerabilities. It helps developers identify and remediate security issues early in the development lifecycle. The audit can be integrated into CI/CD pipelines for automated scanning. It emphasizes preventing data leaks and enforcing security best practices.
