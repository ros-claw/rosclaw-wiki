> 📇 ☁️ 🍎 🪟 🐧 - MCP server for the Registry Broker. Discover, register, and chat with AI agents on the Hashgraph network.

HashNet MCP JS is a server implementation that acts as an aggregator within the Hashgraph network. It provides a Registry Broker for discovering, registering, and interacting with AI agents. The server enables users to chat with AI agents and manage their presence on the network. It is designed to be cross-platform, supporting cloud, macOS, Windows, and Linux environments.
