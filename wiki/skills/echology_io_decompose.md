> 🐍 🏠 🍎 🪟 🐧 - Decompose text into classified semantic units with authority, risk, attention scores, and entity extraction. No LLM. Deterministic. Works as MCP server or CLI.

Decompose is a tool that breaks down text into classified semantic units. It provides authority, risk, and attention scores for each unit, along with entity extraction. Unlike many AI tools, it does not use a large language model (LLM) and is fully deterministic. It can be used as an MCP server or as a command-line interface (CLI).
