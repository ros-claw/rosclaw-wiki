> 📇 ☁️ - x402-native API gateway with 20+ capabilities (web-extract, web-search, translate, image-generate, screenshot, PDF, OCR, and more) payable with USDC on Base. No API keys — agents pay per call via HTTP 402.

Pylon MCP is an API gateway designed for AI agents, offering over 20 capabilities such as web extraction, web search, translation, image generation, screenshot, PDF processing, and OCR. It uses a unique payment model where agents pay per API call using USDC on the Base blockchain, eliminating the need for API keys. The gateway triggers payment via HTTP 402 status codes, making it x402-native and enabling agents to access diverse tools without traditional authentication overhead.
