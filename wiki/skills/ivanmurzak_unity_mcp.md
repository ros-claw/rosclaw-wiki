> #️⃣ 🏠 🍎 🪟 🐧 - MCP Server for Unity Editor and for a game made with Unity

This project provides an MCP (Model Context Protocol) server that connects AI agents with the Unity Editor and games built with Unity. It enables real-time interaction between AI models and Unity environments, supporting tasks like scene manipulation, asset management, and game state queries. The server runs on Windows, macOS, and Linux platforms. It is listed under gaming server implementations in the MCP ecosystem.
