> 📇 ☁️ - MCP server for RAD Security, providing AI-powered security insights for Kubernetes and cloud environments. This server provides tools for querying the Rad Security API and retrieving security findings, reports, runtime data and many more.

This MCP server integrates with RAD Security to provide AI-powered security insights for Kubernetes and cloud environments. It offers tools for querying the RAD Security API to retrieve security findings, reports, and runtime data. Developers and security teams can use this server to gain visibility into cloud-native security threats and vulnerabilities.
