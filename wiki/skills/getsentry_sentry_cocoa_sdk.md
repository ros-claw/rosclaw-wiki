The sentry-cocoa-sdk is a software development kit that integrates Sentry's error tracking and performance monitoring into Apple's Cocoa frameworks for iOS, macOS, tvOS, and watchOS. It captures crashes, exceptions, and performance data, sending them to the Sentry backend for analysis. Developers use it to gain insights into app stability and user experience. The SDK offers features like automatic breadcrumb tracking, user feedback, and distributed tracing.
