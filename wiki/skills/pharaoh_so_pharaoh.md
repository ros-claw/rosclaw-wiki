Pharaoh is a hosted MCP server that transforms TypeScript and Python codebases into Neo4j knowledge graphs. It supports blast radius analysis, dead code detection, dependency tracing, and architectural context. By representing code structure as a graph, it enables developers to understand the impact of changes and identify unused code.
