This MCP server allows AI agents to create professional Excalidraw architecture diagrams using natural language. It features auto-layout, architecture-aware component styling, and stateful editing for iterative improvements. The server includes mappings for over 50 technologies such as databases, message queues, and caches. No API keys are required, making it easy to integrate into any AI workflow. The tool is ideal for generating clear, visual architectural documentation from conversational prompts.
