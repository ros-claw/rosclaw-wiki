> 📇 🏠 - A FastMCP-based tool that fetches Bilibili's trending videos and exposes them via a standard MCP interface.

Bilibili-MCP is a FastMCP-based tool that fetches trending videos from Bilibili and exposes them through a standard Model Context Protocol (MCP) interface. It is designed for browser automation and AI agent tooling, allowing easy integration of Bilibili trending video data into MCP-compatible systems. The tool simplifies access to real-time trending content for applications like content curation or automated browsing.
