PromptSpeak MCP Server is a security-focused tool that adds a pre-execution governance layer for AI agents. It intercepts every tool call from an agent and runs it through an 8-stage pipeline that includes risk classification, behavioral drift detection, and a hold queue for dangerous operations. The system provides a complete audit trail to monitor and review all agent actions. With 45 tools and 658 tests, it is designed to enforce safe and predictable behavior from autonomous AI agents.
