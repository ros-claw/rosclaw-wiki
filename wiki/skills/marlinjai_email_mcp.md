> 📇 ☁️ 🏠 - Unified MCP server for email across Gmail (REST API), Outlook (Microsoft Graph), iCloud, and generic IMAP/SMTP. 24 tools for search, send, organize, and batch-manage emails with built-in OAuth2 and encrypted credential storage.

This project is a unified MCP (Model Context Protocol) server for managing emails across multiple services like Gmail, Outlook, iCloud, and generic IMAP/SMTP. It provides 24 tools for searching, sending, organizing, and batch-managing emails. The server includes built-in OAuth2 authentication and encrypted credential storage for secure access. It enables AI agents to interact with various email systems through a standardized protocol.
