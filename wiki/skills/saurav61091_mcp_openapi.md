This MCP server allows any OpenAPI 3.x specification to be turned into callable tools for Claude via the Model Context Protocol. Users can point to any OpenAPI spec URL or file, and Claude can call every endpoint through natural language. It supports multiple authentication methods including Bearer, API key, and Basic auth. This enables seamless integration of any REST API into Claude's tool-use capabilities.
