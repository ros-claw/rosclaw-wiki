> 🐍 🏠 - An OpenStreetMap MCP server with location-based services and geospatial data.

This project is an MCP server that provides location-based services and geospatial data using OpenStreetMap. It enables AI agents to perform tasks such as geocoding, reverse geocoding, and querying map data. The server is implemented in Python and follows the Model Context Protocol, allowing integration with AI assistants. It serves as a bridge between AI systems and real-world geographic information.
