> #️⃣ 🏠 🪟 - Full-featured Excel MCP server. 173 operations: Power Query, DAX, VBA, PivotTables, Tables, Charts, ranges, formatting. 100% Excel compatibility - uses Excel app instead of creating .xlsx files. Windows only.

This MCP server enables AI agents to interact directly with Microsoft Excel through the Model Context Protocol (MCP). It supports 173 operations including Power Query, DAX, VBA, PivotTables, Charts, ranges, and formatting, offering full Excel compatibility by using the actual Excel application rather than generating .xlsx files. The server is designed for Windows environments only and falls under the Developer Tools category.
