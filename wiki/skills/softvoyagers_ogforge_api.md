> 📇 ☁️ - Free Open Graph image generator API with themes, Lucide icons, and custom layouts. No API key required.

This project provides a free API for generating Open Graph (OG) images without requiring an API key. It supports customizable themes, Lucide icons, and custom layouts, making it easy to create social media preview images. It is listed under developer tools and server implementations, suitable for developers needing dynamic OG images.
