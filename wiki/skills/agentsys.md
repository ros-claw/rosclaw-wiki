Automates task-to-production workflows, PR management, code cleanup, performance investigation, drift detection, and multi-agent code review. AgentSys is a workflow automation system designed for Claude, featuring a collection of plugins, agents, and skills. It automates tasks such as code cleanup, PR management, performance investigation, drift detection, and multi-agent code review. The system uses deterministic methods like regex and AST analysis combined with LLM judgment for efficiency. It includes a tool called agnix for linting agent configurations. AgentSys has been deployed in production environments and is built on a large codebase with extensive testing.
