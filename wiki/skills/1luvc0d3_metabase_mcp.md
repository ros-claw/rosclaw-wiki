Features SQL guardrails, rate limiting, and audit logging.

This project provides a Model Context Protocol (MCP) server that connects Claude AI to Metabase, a business intelligence platform. It includes 28 tools enabling natural language data analysis, dashboard management, SQL querying, and automated insights generation. The server incorporates safety features like SQL guardrails, rate limiting, and audit logging to prevent malicious queries. It allows users to interact with Metabase data using plain English requests through Claude.
