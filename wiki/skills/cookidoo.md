> Access Cookidoo (Thermomix) recipes, shopping lists, and meal planning.

Cookidoo is a tool that provides programmatic access to the Cookidoo platform used by Thermomix, allowing users to retrieve recipes, manage shopping lists, and plan meals. It likely serves as an API wrapper or client library for integrating these features into custom applications. This enables automation of recipe-based shopping and meal scheduling.
