clamp-sh/mcp is an MCP server that provides AI-native web analytics capabilities. It allows querying pageviews, top pages, referrers, countries, devices, and custom events. The tool also supports creating conversion funnels and alerts for monitoring website performance. It is designed to integrate with AI agents for automated analysis and reporting.
