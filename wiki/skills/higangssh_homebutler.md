Homebutler is an all-in-one MCP server designed for homelab management. It can monitor system resources, manage Docker containers, perform Wake-on-LAN, scan networks, check open ports, and run alerts across multiple servers via SSH. The server is delivered as a single 10MB binary with zero dependencies, making it easy to deploy. It integrates with the Model Context Protocol to provide these capabilities to AI assistants.
