Agent-mq is a message queue system designed for AI coding assistants. It allows AI agents such as Claude Code, Cursor, and Codex to communicate by sending messages across different sessions and machines. The system uses UUID-based authentication for security and is self-hostable, giving users full control over their deployment. It is listed under server implementations for the Model Context Protocol (MCP) communication category.
