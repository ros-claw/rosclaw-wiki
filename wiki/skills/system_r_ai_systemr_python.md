System-R-AI/systemr-python is an MCP server that functions as a trading operating system for AI agents, offering 48 tools for pre-trade risk gates, position sizing, portfolio analytics, regime detection, and compliance scoring. It features remote SSE and Streamable HTTP transport, along with x402 USDC micropayments for financial transactions. This server is designed for finance and fintech applications, enabling AI agents to execute trading strategies with integrated risk and compliance checks.
