> ![GitHub stars](https://img.shields.io/github/stars/openai/mle-bench?style=social) - OpenAI's benchmark for measuring how well AI agents perform at ML engineering.

MLE-bench is a benchmark developed by OpenAI to evaluate the performance of AI agents on machine learning engineering tasks. It provides a standardized set of challenges that test an agent's ability to perform end-to-end ML workflows, including data preprocessing, model training, and evaluation. The benchmark aims to measure how well AI systems can automate complex engineering tasks typically done by human ML engineers. This tool helps researchers compare the capabilities of different AI agents in realistic ML engineering scenarios.
