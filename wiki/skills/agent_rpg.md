> This skill transforms the agent into a Roleplay Game Master (GM) or Character with long-term memory.

Agent-rpg is a skill that transforms an AI agent into a Roleplay Game Master or character with long-term memory. It allows the agent to run and participate in role-playing games by remembering past interactions and story elements. This enhances the immersive experience by providing consistent narrative context.
