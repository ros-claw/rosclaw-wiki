> 🏎 🏠 - Define tools using regular GraphQL queries/mutations and gqai automatically generates an MCP server for you.

gqai is a tool that allows developers to define tools using standard GraphQL queries and mutations. It automatically generates a Model Context Protocol (MCP) server from those definitions. This enables AI agents to interact with GraphQL APIs as tools through the MCP interface. The project simplifies connecting AI systems to existing GraphQL backends.
