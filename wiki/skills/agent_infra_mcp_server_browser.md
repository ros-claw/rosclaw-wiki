> 📇 🏠 - Browser automation capabilities using Puppeteer, both support local and remote browser connection.

This is a server implementation for the Model Context Protocol (MCP) that provides browser automation capabilities using Puppeteer. It supports both local and remote browser connections, allowing AI agents to interact with web pages programmatically. The server enables tasks such as navigation, form filling, and data extraction through a standardized interface.
