> 🐍 🏠 🪟 🐧 🍎 -  A Model Context Protocol (MCP) server that provides a set of tools for retrieving information about SonarQube projects like metrics (actual and historical), issues, health status.

This project is a Model Context Protocol (MCP) server that allows users to retrieve various metrics, issues, and health data from SonarQube projects. It is designed for developers who want to integrate SonarQube analysis into their tools via the MCP standard. The server provides tools for both current and historical metrics, making it useful for tracking code quality over time.
