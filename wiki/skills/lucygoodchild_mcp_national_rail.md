> 📇 ☁️ - An MCP server for UK National Rail trains service, providing train schedules and live travel information, intergrating the Realtime Trains API

This MCP server integrates with the UK National Rail system via the Realtime Trains API to provide train schedules and live travel information. It is designed for AI agents to query real-time train data using natural language. The server offers endpoints for departure boards, journey details, and service disruptions. It is part of the Model Context Protocol ecosystem for tool-using AI assistants.
