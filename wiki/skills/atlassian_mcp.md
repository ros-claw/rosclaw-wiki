> Run the Model Context Protocol (MCP) Atlassian server.

The atlassian-mcp project provides a server implementation for the Model Context Protocol (MCP) tailored for Atlassian products. It allows AI agents to interact with Atlassian tools like Jira and Confluence through standardized communication. This server likely supports common operations such as creating tickets, querying projects, and retrieving documentation. By leveraging MCP, it enables seamless integration of Atlassian ecosystems with AI assistants.
