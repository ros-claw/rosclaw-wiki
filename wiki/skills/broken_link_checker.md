> verify external URLs (http/https) for availability (200-399 status code).

Broken-link-checker is a tool for verifying that external URLs (HTTP/HTTPS) are accessible and return a successful status code in the 200-399 range. It helps maintain link integrity by detecting broken or redirected links on websites. This utility is commonly used in web development and quality assurance to ensure a good user experience.
