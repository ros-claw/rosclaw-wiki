This project provides a Java client library for Azure AI Anomaly Detector, a cloud service that identifies unusual patterns in time series data. It enables developers to integrate anomaly detection into Java applications, supporting both univariate and multivariate scenarios. The library follows standard Azure SDK conventions and is part of Microsoft's cognitive services ecosystem.
