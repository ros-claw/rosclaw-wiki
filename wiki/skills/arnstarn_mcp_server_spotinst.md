This MCP server provides an interface to the Spot.io (Spotinst) API for managing cloud infrastructure. It includes 23 tools for tasks such as creating and managing Ocean clusters, virtual node groups (VNGs), and Elastigroups. The server also handles cost analysis, right-sizing recommendations, and log retrieval. It supports both AWS and Azure clouds and allows for multi-account management.
