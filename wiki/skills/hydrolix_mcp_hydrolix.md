> 🎖️ 🐍 ☁️ - Hydrolix time-series datalake integration providing schema exploration and query capabilities to LLM-based workflows.

This MCP server integrates Hydrolix, a cloud-native time-series datalake, with LLM workflows. It provides tools for schema exploration and querying time-series data. This enables AI agents to interact with Hydrolix databases to retrieve and analyze historical data. The server is listed under Database server implementations for the Model Context Protocol, and is written in Python.
