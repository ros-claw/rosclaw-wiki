> 📇 🏠 - Dynamically load Claude Code skills into AI agents without copying files. Discover, read, and install skills on demand.

Agent-skill-loader enables AI agents to dynamically load skills from the Claude Code ecosystem on demand. It allows agents to discover, read, and install skills without manually copying files. This tool streamlines skill management for developer tooling by making skills accessible at runtime. It reduces friction for integrating new capabilities into AI agents, supporting a more flexible and extensible agent architecture.
