The x402-api-server is a pay-per-call DeFi data API designed for AI agents, leveraging x402 micropayments in USDC on the Base blockchain. It provides eight endpoints including price feeds, gas tracker, DEX quotes, whale tracker, yield scanner, funding rates, token scanner, and wallet profiler. No API keys are required, making it easy for AI agents to access financial data with granular payments.
