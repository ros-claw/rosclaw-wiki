> [![web-search](https://glama.ai/mcp/servers/robbyczgw-cla/web-search-plus-mcp/badges/score.svg)](https://glama.ai/mcp/servers/robbyczgw-cla/web-search-plus-mcp) 🐍 ☁️ 🏠 🍎 🪟 🐧 - Multi-provider web search with intelligent auto-routing (Serper, Tavily, Exa). Available via `uvx web-search-plus-mcp`.

This MCP server provides a unified interface for web searches, automatically routing queries to the most suitable provider (Serper, Tavily, or Exa) based on context. It is available via uvx and supports multiple operating systems. The intelligent auto-routing optimizes search results by leveraging each provider's strengths.
