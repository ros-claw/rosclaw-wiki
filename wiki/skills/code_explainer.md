Code-explainer is a tool that leverages Google's Gemma family of lightweight open models to provide human-readable explanations of code snippets. It helps developers and learners understand complex code by generating natural language descriptions and documentation. The skill is designed to run on edge devices, making it accessible for offline or low-latency code comprehension tasks.
