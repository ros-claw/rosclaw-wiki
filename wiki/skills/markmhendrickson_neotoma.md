Neotoma is a deterministic state layer for AI agents that stores versioned entities like contacts, tasks, transactions, and decisions. It provides immutable observations, full provenance tracking, and schema-first extraction. The system is local-first using SQLite and supports cross-client memory across AI tools such as Claude, Cursor, ChatGPT, and OpenClaw. This enables consistent and reliable memory across different AI agents and environments.
