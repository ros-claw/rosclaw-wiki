This MCP server provides AI assistants with sommelier-grade wine pairing recommendations using a proprietary Wine DNA algorithm. It offers seven tools for pairing wines with meals, ingredients, or recipe URLs. The server supports two payment methods: traditional API keys and x402 payments using USDC on the Base blockchain. This enables AI agents to access expert wine pairing intelligence in real time.
