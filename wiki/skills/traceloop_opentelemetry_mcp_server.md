> 🐍🏠 - An MCP server for connecting to any OpenTelemetry backend (Datadog, Grafana, Dynatrace, Traceloop, etc.).

This project provides a Model Context Protocol (MCP) server that enables AI agents to query and interact with OpenTelemetry backends. It supports popular observability platforms like Datadog, Grafana, Dynatrace, and Traceloop. The server acts as a bridge, allowing agents to retrieve telemetry data such as traces, metrics, and logs. It is designed for finance and fintech applications, where monitoring and observability are critical.
