> An add-on to the Bird skill that lets your agent check its X/Twitter DM.

This add-on extends the Bird skill to allow an AI agent to check direct messages on X/Twitter. It enables the agent to read and potentially respond to private messages from users. This integration is useful for building agents that can handle social media interactions. It likely relies on the Twitter API to access DMs.
