> OpenHands' overview of a layered verification stack using trajectory critics trained on production traces for reranking, early stopping, and review-time quality control.

This project presents a layered verification stack for AI-generated code. It uses trajectory critics trained on production traces to improve code quality. Techniques include reranking, early stopping, and review-time quality control. The stack is exemplified by OpenHands, an AI agent framework. The goal is to detect errors and enhance reliability of AI-generated code.
