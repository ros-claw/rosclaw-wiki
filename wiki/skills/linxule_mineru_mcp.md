> 📇 ☁️ - MCP server for MinerU document parsing API. Parse PDFs, images, DOCX, and PPTX with OCR (109 languages), batch processing (200 docs), page ranges, and local file upload. 73% token reduction with structured output.

This MCP server integrates with the MinerU document parsing API, enabling extraction of text and structured data from PDFs, images, DOCX, and PPTX files. It supports OCR in 109 languages, batch processing up to 200 documents, and allows specifying page ranges. Local file upload is supported. The structured output helps reduce token usage by 73% compared to raw text.
