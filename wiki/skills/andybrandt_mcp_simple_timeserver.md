> 🐍 🏠☁️ - An MCP server that allows checking local time on the client machine or current UTC time from an NTP server

This MCP server provides a simple way for clients to retrieve local time from their machine or the current UTC time from an NTP server. It is designed for use with the Model Context Protocol, allowing applications to access accurate time information without complex setup. The server is implemented in Python and can be run locally or integrated into MCP-based architectures. It offers a lightweight solution for time synchronization needs in AI agent tooling.
