This is a feature-rich MCP server that connects AI agents to an Obsidian vault, offering 23 tools and 3 resources for complete note management. It enables full-text search, CRUD operations on notes, frontmatter queries, tag manipulation, and backlink analysis. The server also supports graph traversal up to five hops, detection of orphan and broken links, and canvas-based workflows. It automatically detects the vault path, includes path traversal protection, and is released under the MIT license.
