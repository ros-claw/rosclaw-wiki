> [![propstack-mcp MCP server](https://glama.ai/mcp/servers/@ashev87/propstack-mcp/badges/score.svg)](https://glama.ai/mcp/servers/@ashev87/propstack-mcp) 📇 ☁️ 🍎 🪟 🐧 - Propstack CRM MCP: search contacts, manage properties, track deals, schedule viewings for real estate agents (Makler).

This MCP server connects to the Propstack CRM for real estate agents (Makler), enabling them to search contacts, manage properties, track deals, and schedule viewings directly through the MCP protocol. It provides a bridge between AI assistants and the Propstack platform, allowing automated interactions with real estate data. The tool is designed to streamline workflows for agents by offering structured access to CRM functions via a standardized interface.
