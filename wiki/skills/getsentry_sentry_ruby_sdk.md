The Sentry Ruby SDK is an open-source library that enables error tracking and performance monitoring in Ruby applications. It integrates with frameworks like Ruby on Rails to automatically capture exceptions, send crash reports, and collect performance data to Sentry's platform. The SDK supports breadcrumbs, context enrichment, and distributed tracing, helping developers debug production issues. It is maintained by Sentry and used widely in the Ruby ecosystem.
