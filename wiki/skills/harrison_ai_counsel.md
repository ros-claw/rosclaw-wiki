> 🐍 🏠 🍎 🪟 🐧 - Deliberative consensus engine enabling multi-round debate between AI models with structured voting, convergence detection, and persistent decision graph memory.

This project is a deliberative consensus engine that allows multiple AI models to debate a topic over several rounds. It features structured voting to aggregate opinions and convergence detection to know when the debate has reached a conclusion. The decisions and debate history are stored in a persistent decision graph memory for later reference and analysis. It is designed to run on multiple operating systems including Windows, macOS, and Linux, likely using Python.
