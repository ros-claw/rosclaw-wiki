> 🎖️ 🏎️ 🏠 ☁️ 🍎 🪟 🐧 - A CLI for interacting with GitKraken APIs. Includes an MCP server via `gk mcp` that not only wraps GitKraken APIs, but also Jira, GitHub, GitLab, and more. Works with local tools and remote services.

A command-line interface (CLI) for interacting with GitKraken APIs. It includes an MCP server (via `gk mcp`) that integrates not only GitKraken APIs but also Jira, GitHub, GitLab, and other services. Designed to work with both local developer tools and remote services, it streamlines access to multiple APIs through a unified interface.
