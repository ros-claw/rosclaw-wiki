> Microsoft 365 / Outlook CLI for calendar and email.

clippy is a command-line interface tool for Microsoft 365 and Outlook, focusing on calendar and email management. It enables users to interact with their Microsoft 365 accounts via the terminal for tasks like viewing, creating, and managing calendar events and emails. The tool aims to provide a fast, scriptable alternative to the graphical Outlook interface. It likely leverages the Microsoft Graph API for authentication and data retrieval.
