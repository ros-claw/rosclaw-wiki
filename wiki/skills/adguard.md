> Control AdGuard Home DNS filtering via HTTP API.

This project provides a way to control AdGuard Home's DNS filtering settings through its HTTP API. It allows users to programmatically manage ad blocking and tracking protection rules. The tool can be used to automate changes to DNS filtering without manual interaction with the AdGuard Home web interface. It is likely a client library or command-line interface for integration into scripts or applications.
