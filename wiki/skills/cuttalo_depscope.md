Zero auth, MIT. Remote URL https://mcp.depscope.dev/mcp or stdio `npx depscope-mcp`.

Depscope is an MCP server that provides package intelligence for AI agents across 17 package ecosystems. It offers 22 tools to check package health, vulnerabilities (including OSV, CISA KEV, EPSS), typosquats, malicious flags, alternatives, known bugs, breaking changes, stack compatibility, and error-to-fix. The tool covers over 31,000 packages and 2,200 enriched CVEs, requires zero authentication, and is available under an MIT license. It can be accessed via a remote URL or through stdio using npx.
