> 📇 ☁️ 🏠 🍎 🪟 🐧 - MapRag: RAG-focused subregistry + MCP server to discover and route to retrieval-capable MCP servers using structured constraints and explainable ranking.

MapRag is an aggregator server that focuses on retrieval-augmented generation (RAG). It acts as a subregistry and MCP server to help discover and route to other MCP servers that support retrieval. It uses structured constraints and explainable ranking to make the routing efficient and transparent. The project is listed under aggregators in server implementations.
