This MCP server provides trust infrastructure for the machine economy by enabling non-custodial smart accounts based on the ERC-4337 standard. It supports x402 payments for machine-to-machine transactions, on-chain reputation tracking via ERC-8004, and service discovery for AI agents. By integrating blockchain technology, it allows autonomous agents to transact, build reputation, and interact without human intermediaries.
