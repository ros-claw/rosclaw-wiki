This MCP server, Haiku Trading, enables DeFi execution across 22 blockchains, including token discovery, portfolio analysis, quoting, and execution. It provides 7 tools such as swap, liquidity provision, lending, bridging, and yield strategies. The server is listed under Finance & Fintech in server implementations and can be run with `npx haiku-mcp-server`. It aims to simplify multi-chain DeFi interactions for AI agents.
