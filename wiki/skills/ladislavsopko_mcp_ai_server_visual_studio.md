> #️⃣ 🏠 🪟 - MCP AI Server for Visual Studio. 20 Roslyn-powered tools giving AI assistants semantic code navigation, symbol search, inheritance trees, call graphs, safe rename, build/test execution. Works with Claude, Codex, Gemini, Cursor, Copilot, Windsurf, Cline.

This project implements a Model Context Protocol (MCP) server specifically for Visual Studio. It provides 20 Roslyn-powered tools that enable AI assistants to perform semantic code navigation, symbol search, inheritance trees, call graphs, safe rename, and build/test execution. Compatible with various AI assistant clients such as Claude, Codex, Gemini, Cursor, Copilot, Windsurf, and Cline. The server bridges the gap between AI and .NET development environments.
