> ![GitHub stars](https://img.shields.io/github/stars/ArchishmanSengupta/autovoiceevals?style=social) - Uses adversarial callers plus keep-or-revert prompt edits to harden voice AI agents across Vapi, Smallest AI, and ElevenLabs.

This project provides tools for stress-testing and hardening voice AI agents by simulating adversarial callers and applying iterative prompt edits. It supports platforms such as Vapi, Smallest AI, and ElevenLabs, focusing on improving security and reliability. The keep-or-revert prompt editing approach helps identify and patch vulnerabilities in real-world voice interactions.
