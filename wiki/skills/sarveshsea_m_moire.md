> [![m-moire MCP server](https://glama.ai/mcp/servers/sarveshsea/m-moire/badges/score.svg)](https://glama.ai/mcp/servers/sarveshsea/m-moire) 📇 🏠 — Design system MCP server. 20 tools: extract design tokens from any URL, pull from Figma (REST or WebSocket) and Penpot, generate React + shadcn/ui components from specs, run WCAG audits, sync tokens bidirectionally.

m-moire is an MCP server that provides 20 tools for managing design systems, including extracting design tokens from any URL, pulling designs from Figma and Penpot, generating React components with shadcn/ui from specs, running WCAG accessibility audits, and syncing tokens bidirectionally. It integrates with Figma via REST and WebSocket, and works with Penpot for collaborative design. The server helps developers maintain consistent design tokens and components across projects.
