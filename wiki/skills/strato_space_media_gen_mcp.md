> 📇 ☁️ 🏠 - TypeScript MCP server for OpenAI Images/Videos and Google GenAI (Veo) media generation, editing, and asset downloads.

This is a TypeScript MCP server that integrates OpenAI's image and video generation APIs with Google's Veo generative AI for multimedia creation, editing, and downloading assets. It provides a standardized interface for AI-driven media production pipelines. Developers can use it to generate, modify, and retrieve images and videos through the Model Context Protocol. The server simplifies combining multiple generative AI models into a single workflow.
