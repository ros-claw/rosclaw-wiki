> 📇 🏠  ☁️ 🍎 🪟 🐧 - MCPX is a production-ready, open-source gateway to manage MCP servers at scale—centralize tool discovery, access controls, call prioritization, and usage tracking to simplify agent workflows.

LunarMCPX is a production-ready open-source gateway that centralizes the management of multiple MCP servers at scale. It provides unified tool discovery, access control, call prioritization, and usage tracking to simplify agent workflows. The project supports various environments including cloud, Apple, Windows, and Linux. It serves as an aggregator for MCP server implementations.
