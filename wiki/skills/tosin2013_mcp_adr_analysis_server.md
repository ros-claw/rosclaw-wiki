> 📇 ☁️ 🏠 - AI-powered architectural analysis server for software projects. Provides technology stack detection, ADR management, security checks, enhanced TDD workflow, and deployment readiness validation with support for multiple AI models.

This MCP server provides AI-powered architectural analysis for software projects. It detects technology stacks, manages Architecture Decision Records (ADRs), performs security checks, and supports Test-Driven Development workflows. It also validates deployment readiness and integrates with multiple AI models. The server is designed to assist developers in maintaining architectural integrity and improving code quality.
