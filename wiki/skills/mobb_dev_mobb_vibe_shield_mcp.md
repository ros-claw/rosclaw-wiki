This project provides an MCP server implementation that integrates the Mobb Vibe Shield tool for security scanning. It identifies vulnerabilities in both human-written and AI-generated code. The server aims to automate remediation without slowing down development workflows. It is listed under security-focused server implementations within the MCP ecosystem.
