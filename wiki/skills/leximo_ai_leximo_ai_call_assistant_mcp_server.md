> 📇 ☁️ - Make AI-powered phone calls on your behalf — book reservations, schedule appointments, and view call transcripts

This MCP server enables AI assistants to make phone calls on behalf of users, such as booking reservations or scheduling appointments. It provides tools to initiate outbound calls and retrieve transcripts of completed calls. The server integrates seamlessly with AI agents to automate phone-based tasks. It is listed under communication tools for server implementations.
