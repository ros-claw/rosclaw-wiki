> Audit codebases, infrastructure, AND agentic AI systems for security issues.

This project provides a tool for auditing security risks across codebases, infrastructure, and agentic AI systems. It aims to identify vulnerabilities in AI agents that may act autonomously, as well as traditional security issues in code and cloud setups. By covering both conventional and AI-specific threats, it helps organizations maintain robust security postures.
