> 🐍 🏠 🪟 - Enable AI LLMs to execute trades using MetaTrader 5 platform

This project provides an MCP (Model Context Protocol) server that integrates AI language models with the MetaTrader 5 trading platform. It allows LLMs to execute trades and manage trading accounts programmatically. The server enables automated trading strategies driven by natural language instructions from AI agents. It is specifically designed for finance and fintech applications, bridging AI capabilities with real market operations.
