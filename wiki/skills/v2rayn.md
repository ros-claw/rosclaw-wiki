> Manage V2RayN proxy client on macOS with auto-failover.

v2rayn is a macOS proxy client that manages V2Ray connections with automatic failover capabilities. It provides a graphical interface to configure and switch between multiple V2Ray servers, ensuring uninterrupted access. The tool is designed for users who need reliable proxy management on macOS, similar to the V2RayN client on Windows.
