Built for AI agents automating phone verification across platforms.

This MCP server provisions dedicated real-SIM US phone numbers and enables AI agents to receive inbound SMS messages, poll for new messages, and extract OTP codes. It is built specifically for automating phone verification across various platforms. The server integrates with the Joltsms service to manage SMS-based authentication flows programmatically.
