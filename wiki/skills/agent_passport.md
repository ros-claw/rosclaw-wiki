> OAuth for the agentic era — consent-gating for ALL sensitive agent actions including purchases, emails, file.

Agent Passport is a framework that applies OAuth-like consent mechanisms to the actions of autonomous AI agents. It ensures that sensitive operations such as purchases, email sending, or file access require explicit user approval. This helps prevent unauthorized or harmful agent behaviors by gating actions behind user consent. It brings the concept of delegated authorization from human-to-service interactions to agent-to-service interactions.
