> 🐍 ☁️ - Simple Snowflake MCP server that works behind a corporate proxy. Read and write (optional) operations

This project provides a simple MCP (Model Context Protocol) server for interacting with Snowflake databases. It is designed to work behind corporate proxies, making it suitable for enterprise environments. The server supports both read and optional write operations on Snowflake, enabling AI agents to query and manage data through a standardized interface.
