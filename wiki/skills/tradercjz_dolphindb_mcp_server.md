> 🐍 ☁️ - TDolphinDB database integration with schema inspection and query capabilities

This MCP server integrates with DolphinDB, a time-series database, providing schema inspection and query capabilities. It allows AI agents to connect to DolphinDB and perform database operations through the Model Context Protocol. The server is listed under database server implementations, focusing on real-time data analysis and querying.
