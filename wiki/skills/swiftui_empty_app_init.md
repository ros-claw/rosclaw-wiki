> Initialize a minimal SwiftUI iOS app.

This project provides a command-line tool to quickly scaffold a minimal SwiftUI iOS app, generating essential files like AppDelegate, SceneDelegate, and ContentView. It simplifies starting new SwiftUI projects with a clean, blank slate, saving developers time from manually creating boilerplate code. The tool is designed for rapid prototyping or when a lightweight SwiftUI project setup is needed. It can be installed via a package manager or directly executed from the terminal.
