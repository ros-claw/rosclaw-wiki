> 📇 ☁️ - MCP server to interact with the Discogs API

The discogs-mcp-server is an MCP (Model Context Protocol) server that interfaces with the Discogs API. It enables AI models to access music discography data, such as artist information, releases, and labels. By connecting through the MCP protocol, it allows language models to query real-world music metadata. This tool is part of a collection of server implementations for art and culture domains.
