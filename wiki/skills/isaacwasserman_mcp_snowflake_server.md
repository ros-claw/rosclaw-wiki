> 🐍 ☁️ - Snowflake integration implementing read and (optional) write operations as well as insight tracking

This project provides a Snowflake integration for the Model Context Protocol (MCP), enabling AI agents to perform read and optional write operations on Snowflake databases. It also includes insight tracking to monitor queries and usage. The server is implemented in Python and can be used as a tool for large language models to interact with Snowflake data.
