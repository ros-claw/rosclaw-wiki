Agentdeals is an MCP server that aggregates over 1,500 developer infrastructure deals, free tiers, and startup programs across 54 categories. It allows users to search deals, compare vendors, plan tech stacks, and track pricing changes. The service provides a REST API and a web browser interface at agentdeals.dev.
