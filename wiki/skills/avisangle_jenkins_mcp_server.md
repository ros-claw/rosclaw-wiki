> 🐍 🏠 🍎 🪟 🐧 - Enterprise-grade Jenkins CI/CD integration with multi-tier caching, pipeline monitoring, artifact management, and batch operations. Features 21 MCP tools for job management, build status tracking, and queue management with CSRF protection and 2FA support.

This project is an enterprise-grade Jenkins CI/CD integration server built on the Model Context Protocol (MCP). It offers 21 tools for managing jobs, monitoring pipelines, handling artifacts, and performing batch operations. The server includes multi-tier caching, CSRF protection, and 2FA support for enhanced security. It runs on multiple platforms including Python, Windows, Linux, and macOS. This tool allows AI agents to interact directly with Jenkins for streamlined developer workflows.
