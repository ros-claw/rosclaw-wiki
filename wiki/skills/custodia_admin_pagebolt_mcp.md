Pagebolt MCP is a server that integrates with Claude Desktop, Cursor, and Windsurf to provide browser automation capabilities. It can capture screenshots, generate PDFs, create Open Graph images, and produce narrated video recordings. The server extends the Model Context Protocol to allow AI assistants to perform these web-based tasks on demand.
