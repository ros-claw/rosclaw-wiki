This project provides an MCP server that integrates DeepSeek AI models, enabling chat, reasoning, multi-turn conversations, function calling, and a thinking mode for enhanced responses. It also includes cost tracking to monitor usage. Designed for use with MCP-compatible clients, it acts as a bridge between the DeepSeek API and agent workflows.
