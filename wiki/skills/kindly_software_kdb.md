> 🦀 ☁️ - AI-powered time-travel debugger with bidirectional execution replay, audit-compliant hash-chain logging, and SIMD-accelerated stack unwinding. Free Hobby tier available.

KDB is an AI-powered time-travel debugger that supports bidirectional execution replay, allowing developers to step forwards and backwards through code execution. It features audit-compliant hash-chain logging for secure record keeping and uses SIMD acceleration for efficient stack unwinding. The tool offers a free Hobby tier for individual developers. It is designed for server implementations and developer tools.
