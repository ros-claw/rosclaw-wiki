> [![mcp-server-devutils MCP server](https://glama.ai/mcp/servers/ofershap/mcp-server-devutils/badges/score.svg)](https://glama.ai/mcp/servers/ofershap/mcp-server-devutils) 📇 🏠 - Zero-auth developer utilities: base64, UUID, hash, JWT decode, cron parse, timestamps, JSON, and regex.

This MCP server provides a collection of zero-authentication developer utilities accessible via the Model Context Protocol. It includes tools for base64 encoding and decoding, UUID generation, hashing, JWT decoding, cron expression parsing, timestamp conversion, JSON processing, and regex operations. Designed for AI assistants, it enables common data manipulation tasks without requiring user authentication. The server is listed under developer tools on the MCP server registry.
