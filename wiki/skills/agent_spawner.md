> Spawn a new OpenClaw agent through conversation.

Agent-spawner is a tool that allows users to create a new OpenClaw agent through a conversational interface. Instead of writing code, users can describe the desired agent in natural language. The system then interprets the conversation and spawns the corresponding agent. This lowers the barrier to agent creation and enables rapid prototyping.
