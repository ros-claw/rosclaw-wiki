This project provides a collection of prioritization frameworks implemented in TypeScript. It offers reusable utilities for applying common prioritization methods such as RICE, MoSCoW, and the Eisenhower Matrix. Designed for product managers and developers, it helps in making data-driven decisions on feature backlogs. The library is sponsored and aims to streamline backlog prioritization in TypeScript projects.
