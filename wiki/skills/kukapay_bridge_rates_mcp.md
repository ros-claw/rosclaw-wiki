> 📇 ☁️ - Delivering real-time cross-chain bridge rates and optimal transfer routes to onchain AI agents.

This MCP server provides onchain AI agents with real-time data on cross-chain bridge rates and optimal transfer routes. It aggregates information from multiple bridges to help agents choose the most cost-effective path. The tool is part of the Finance & Fintech server implementations.
