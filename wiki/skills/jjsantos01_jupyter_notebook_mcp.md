> 🐍 🏠 - connects Jupyter Notebook to Claude AI, allowing Claude to directly interact with and control Jupyter Notebooks.

This project implements an MCP server that connects Jupyter Notebook to Claude AI, allowing the AI to directly interact with and control Jupyter Notebook environments. It enables Claude to execute code, manipulate notebooks, and analyze data within a Jupyter session. Designed for data science workflows, it facilitates AI-assisted notebook automation and exploration. The tool is listed under Data Science Tools as a server implementation.
