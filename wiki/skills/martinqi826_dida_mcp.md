Compatible with OpenClaw, Claude Desktop, and any MCP client.

This project is a Model Context Protocol (MCP) server that connects the Dida365 (TickTick China) task management service with AI-powered assistants. It provides 13 tools for managing projects, tasks, tags, and habits, using OAuth 2.0 for secure authentication. Compatible with MCP clients like Claude Desktop, it enables users to control their task lists through natural language interactions, streamlining productivity workflows.
