> 📇 ☁️ - MCP Server for natural language querying of Snowflake, Google BigQuery, and DataBricks Data Products through Alkemi.ai.

Alkemi MCP is a server that enables natural language querying across Snowflake, Google BigQuery, and Databricks data platforms through the Alkemi.ai interface. It translates plain English questions into SQL queries, making data access intuitive for non-technical users. The project integrates with the Model Context Protocol (MCP) to serve as a bridge between AI agents and enterprise data warehouses.
