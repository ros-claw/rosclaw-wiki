This is a local MCP server for macOS that exposes 82 tools to connect AI agents like Claude, Cursor, and Windsurf to native Apple apps including Mail, Calendar, Contacts, Reminders, Notes, iMessage, Finder, Safari, OmniFocus, Microsoft Teams, Outlook, OneDrive, and Office documents. It runs entirely on the user's Mac without any cloud dependency, tokens, or API keys. The server is categorized under communication server implementations. It enables AI agents to read, write, and manage macOS native application data locally.
