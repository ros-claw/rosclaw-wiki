> 📇 ☁️ - A MCP server for The Movie Database API that enables AI assistants to search and retrieve movie, TV show, and person information.

This project provides a Model Context Protocol (MCP) server that wraps The Movie Database (TMDB) API. It enables AI assistants to search for and retrieve information about movies, TV shows, and people. The server exposes structured tools that allow AI agents to query the TMDB database without needing direct API access. It is part of a collection of MCP server implementations for art and culture.
