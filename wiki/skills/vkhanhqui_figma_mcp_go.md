This is a Figma MCP server implemented in Go that provides full read/write access to Figma designs through a plugin bridge, eliminating the need for API tokens and rate limits. It offers 58 tools for design automation including styles, variables, components, prototypes, and content. Listed under Developer Tools, it helps developers integrate Figma into AI workflows via the Model Context Protocol.
