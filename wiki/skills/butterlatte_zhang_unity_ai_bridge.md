This MCP server allows AI IDEs to remotely control the Unity Editor using file-based inter-process communication. It offers 62 tools across 13 categories, covering common Unity operations without any external dependencies. The bridge supports multiple AI coding tools such as Claude Code, Cursor, Copilot, Windsurf, and Claude Desktop. It is specifically designed to streamline game development workflows by enabling direct AI interaction with the Unity Editor.
