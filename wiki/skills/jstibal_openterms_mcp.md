Spending caps, action whitelists, escalation thresholds, and JWKS-backed provider verification. Independently verifiable.

OpenTerms-MCP is a security-focused server that enables AI agents to manage consent receipts signed with Ed25519 cryptography. It includes a programmable policy engine for enforcing spending caps, whitelisting actions, and setting escalation thresholds. Provider verification is handled through JSON Web Key Sets (JWKS), ensuring independently verifiable consent. This allows users to control and audit AI agent behavior with a cryptographic proof layer.
