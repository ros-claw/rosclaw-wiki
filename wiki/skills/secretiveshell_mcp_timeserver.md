> 🐍 🏠 - Access the time in any timezone and get the current local time

SecretiveShell/MCP-timeserver is a server implementation for the Model Context Protocol (MCP) that allows AI agents to retrieve the current local time or the time in any timezone. It is listed under location services and provides a simple API for time-related queries. This tool helps agents understand temporal context, such as answering questions about current time across different regions.
