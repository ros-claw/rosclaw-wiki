auth0/auth0-fastify-api is a Fastify plugin that integrates Auth0 authentication for protecting API routes. It validates JSON Web Tokens (JWT) for incoming requests, extracting user information based on Auth0 configuration. This simplifies adding secure, token-based authentication to Fastify backends. It is designed for TypeScript projects and helps developers implement OAuth 2.0 / OpenID Connect flows easily.
