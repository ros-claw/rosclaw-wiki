> 📇 ☁️ 🏠 - A MCP Server that enhance your IDE with AI-powered assistance for Intlayer i18n / CMS tool: smart CLI access, access to the docs.

This project provides an MCP (Model Context Protocol) server that integrates with Intlayer, an i18n and CMS tool. It enables AI-powered assistance within IDEs by offering smart CLI access and documentation lookup. The server helps developers manage translations and content through natural language interactions. It is designed to enhance productivity in multi-language web development workflows.
