> [![touch-browser MCP server](https://glama.ai/mcp/servers/nangman-infra/touch-browser/badges/score.svg)](https://glama.ai/mcp/servers/nangman-infra/touch-browser) 🦀 🏠 - Evidence-grounded web research for AI agents. Verifies page-local claims with citations, confidence bands, policy reports, and multi-page session synthesis via MCP.

Touch Browser is an MCP server that enables AI agents to perform evidence-grounded web research. It verifies claims by extracting citations, confidence bands, and policy reports from web pages. The tool supports multi-page session synthesis, allowing agents to aggregate findings across several pages. Built in Rust, it emphasizes reliability and local execution for research tasks.
