> Manage n8n workflows and automations via API.

n8n is a workflow automation platform that allows users to connect various services and automate tasks. It provides an API to manage workflows, enabling programmatic control over automation processes. The tool is open-source and can be self-hosted, offering flexibility and data privacy. It supports a wide range of integrations and uses a visual node-based editor.
