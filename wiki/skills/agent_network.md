> Multi-Agent group chat collaboration system inspired by DingTalk/Lark.

Agent-network is a multi-agent group chat collaboration system inspired by enterprise communication platforms like DingTalk and Lark. It enables multiple AI agents to interact and coordinate within a group chat environment, facilitating task delegation and information exchange. The system leverages the familiar interface of group messaging to orchestrate agent behaviors, making multi-agent collaboration more accessible and intuitive. It aims to improve productivity by allowing agents to communicate and work together in real-time, similar to human team collaboration.
