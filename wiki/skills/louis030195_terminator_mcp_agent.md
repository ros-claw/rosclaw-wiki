> 🦀 📇 🏠 🍎 🪟 🐧 - Desktop GUI automation using accessibility APIs. Control Windows, macOS, and Linux applications without vision models or screenshots. Supports workflow recording, structured data extraction, and browser DOM inspection.

This project is an MCP server for desktop GUI automation that leverages accessibility APIs to control applications on Windows, macOS, and Linux. It operates without relying on vision models or screenshots, making it efficient and privacy-preserving. The tool supports recording user workflows, extracting structured data from interfaces, and inspecting browser DOM elements. It is specifically designed to integrate with coding agents, allowing them to interact with desktop applications programmatically.
