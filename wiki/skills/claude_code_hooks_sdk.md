> A Laravel-inspired PHP SDK for building Claude Code hook responses with a clean, fluent API. This SDK makes it easy to create structured JSON responses for Claude Code hooks using an expressive, chainable interface.

This project provides a PHP SDK inspired by Laravel for constructing structured JSON responses for Claude Code hooks. It offers a clean, fluent API that allows developers to easily create hook responses using a chainable interface. The SDK simplifies the process of generating the expected JSON format required by Claude Code hooks, making integration with PHP applications seamless. It is listed under Hooks > General, indicating it is a general-purpose tool for Claude Code hook development.
