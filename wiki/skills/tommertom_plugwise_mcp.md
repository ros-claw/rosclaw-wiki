> 📇 🏠 🍎 🪟 🐧 - TypeScript-based smart home automation server for Plugwise devices with automatic network discovery. Features comprehensive device control for thermostats, switches, smart plugs, energy monitoring, multi-hub management, and real-time climate/power consumption tracking via local network integration.

Tommertom/plugwise-mcp is a TypeScript-based MCP server for controlling Plugwise smart home devices locally. It supports automatic network discovery and provides comprehensive control over thermostats, switches, smart plugs, and energy monitoring. The server enables real-time tracking of climate and power consumption across multiple hubs. It is listed under Other Tools and Integrations in the MCP server implementations list.
