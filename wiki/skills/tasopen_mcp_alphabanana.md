This MCP server generates image assets using Google Gemini models (Nano Banana 2 and Pro). It supports transparent PNG/WebP output, precise resizing and cropping, and can incorporate up to 14 reference images. It also uses Google Search grounding for context-aware generation. The server runs locally and is categorized under Art & Culture.
