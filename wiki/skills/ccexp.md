> Interactive CLI tool for discovering and managing Claude Code configuration files and slash commands with a beautiful terminal UI.

This tool provides an interactive command-line interface for managing Claude Code configuration files and custom slash commands. It offers a visually appealing terminal UI to discover and organize settings. Users can browse and modify configurations without editing files manually. It streamlines the workflow for developers using Claude Code by centralizing configuration management. The tool enhances productivity and simplifies the customization of Claude Code's behavior.
