No passwords — your wallet IS your account.

This is an MCP server for AI-powered commerce that gives AI agents 22 tools for e-commerce operations like managing shopping carts (TMF663), orders (TMF622), and shipment tracking (TMF621). It also integrates blockchain features such as Uniswap swaps, a P2P marketplace, and cryptographic identity using SLH-DSA and ECDSA. Users authenticate with their wallet instead of a password. The server combines traditional commerce workflows with decentralized finance and identity tools.
