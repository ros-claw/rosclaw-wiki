> Discover and create Agent Contact Cards - a vCard-like.

Agent Contact Card is a project that facilitates the discovery and creation of standardized contact cards for AI agents, similar to how vCard works for humans. It aims to provide a common format for sharing agent metadata, such as capabilities and identifiers. This enables interoperability between different agent systems and simplifies agent discovery.
