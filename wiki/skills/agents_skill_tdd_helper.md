This project provides a lightweight helper tool designed to enforce Test-Driven Development (TDD) loops for non-deterministic agents. The tool likely integrates with existing agent frameworks to ensure tests are written before implementation and iteratively refined. It aims to improve reliability and debuggability of agent-based systems.
