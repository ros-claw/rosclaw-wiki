> 📇 🏠 - MCP server that lets LLMs know everything about your OpenAPI specifications to discover, explain and generate code/mock data

This project is an MCP server that exposes OpenAPI specification details to large language models, enabling them to discover, explain, and generate code or mock data from the specs. It integrates LLM capabilities with developer tools for API documentation and automation. By connecting LLMs directly to OpenAPI definitions, it streamlines tasks like endpoint exploration and test data creation. It serves as a bridge between API specifications and AI-assisted code generation.
