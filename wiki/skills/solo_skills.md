This project provides seven bilingual (English and Chinese) skills designed for solo founders and indie developers. It covers practical tasks such as writing launch tweets, composing customer emails, applying decision frameworks, and conducting postmortems. Each skill includes a clear 'When NOT to use' section to help users avoid misapplication. The project aims to improve productivity and organization for solo operators.
