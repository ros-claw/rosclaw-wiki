> [![aidemd-mcp/server MCP server](https://glama.ai/mcp/servers/aidemd-mcp/server/badges/score.svg)](https://glama.ai/mcp/servers/aidemd-mcp/server) 📇 🏠 - Structured `.aide` spec files that give AI agents progressive disclosure into your codebase architecture via MCP.

This MCP server enables AI agents to progressively understand a codebase's architecture through structured `.aide` spec files. It provides a way to expose architectural context incrementally, so agents can navigate and reason about the code more effectively. The server is listed under Developer Tools and integrates with the Model Context Protocol (MCP) for tool discovery and usage.
