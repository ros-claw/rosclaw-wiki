> 🐍 🏠 - A MCP server playing chess against LLMs.

This project is a Model Context Protocol (MCP) server that allows large language models (LLMs) to play chess. It provides a standardized interface for AI agents to make moves, track board state, and follow chess rules. The server is designed to be a gaming tool for evaluating or entertaining LLMs in a strategic board game environment.
