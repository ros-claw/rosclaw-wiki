One rendering engine with JSON config, AI controls all design parameters. CSS @keyframes + SMIL animations, 16+ element types, parametric curves, filters, gradients, PNG preview.

The nakkas MCP server enables AI to act as an SVG artist, controlling all design parameters through a single JSON configuration. It supports 16+ element types, parametric curves, filters, gradients, and both CSS @keyframes and SMIL animations. The server provides a PNG preview and is designed for the Model Context Protocol (MCP) ecosystem, specifically under the Art & Culture category.
