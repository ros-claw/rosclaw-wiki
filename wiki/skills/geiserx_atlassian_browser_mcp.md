Enables AI tools to access Atlassian Server/Data Center instances behind corporate SSO (Okta, SAML, ADFS) where API tokens are not available.

This project is a Model Context Protocol (MCP) server that wraps mcp-atlassian with browser-based single sign-on (SSO) authentication using Playwright. It allows AI tools to interact with Atlassian Server/Data Center instances that are behind corporate SSO (like Okta, SAML, ADFS) where traditional API tokens are not available. By automating browser login, it bridges the gap between AI agents and enterprise Atlassian instances. This is useful for developer tools that need to query Jira, Confluence, etc., within a secured enterprise environment.
