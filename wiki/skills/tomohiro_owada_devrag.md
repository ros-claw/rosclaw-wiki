> 🏎️ 🏠 🍎 🪟 🐧 - Lightweight local RAG MCP server for semantic vector search over markdown documents. Reduces token consumption by 40x with sqlite-vec and multilingual-e5-small embeddings. Supports filtered search by directory and filename patterns.

Devrag is a lightweight local RAG (Retrieval-Augmented Generation) MCP server that performs semantic vector search over markdown documents. It uses sqlite-vec and multilingual-e5-small embeddings to reduce token consumption by up to 40x. The tool supports filtered search by directory and filename patterns, making it efficient for managing knowledge bases in AI agent workflows.
