Free REST APIs + MCP server.

This project is an MCP server that offers 17 tools for freight and logistics calculations, including ADR dangerous goods classification, HS code lookup, LDM/CBM and chargeable weight calculators, duty estimation, airline codes, and UN/LOCODE reference. It also provides free REST APIs alongside the MCP interface, making it a versatile tool for shipping and transportation applications. The server is designed to integrate with AI assistants via the Model Context Protocol, enabling automated freight-related tasks.
