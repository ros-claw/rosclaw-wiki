Oraclaw is a decision intelligence MCP server that provides a suite of 19 algorithms and 12 tools for data-driven decision-making. It supports techniques like bandits, Monte Carlo simulation, constraint optimization, forecasting, anomaly detection, risk analysis, and graph algorithms. Designed as a Model Context Protocol (MCP) server, it can be easily installed via npx and used in AI-agent workflows. This tool helps users analyze data, forecast trends, detect anomalies, and optimize decisions across various domains.
