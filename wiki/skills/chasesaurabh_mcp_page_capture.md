> 📇 🏠 - MCP server that captures webpage screenshots, with viewport or full-page options and base64 PNG output.

This MCP server captures webpage screenshots, allowing users to take images of web pages with options for viewport or full-page capture. The output is provided as a base64-encoded PNG image, making it easy to integrate into AI agent workflows that require visual context. It is designed to work within the Model Context Protocol ecosystem, enabling language models to request screenshots as a tool.
