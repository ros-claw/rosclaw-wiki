> [![Work90210/APIFold MCP server](https://glama.ai/mcp/servers/Work90210/APIFold/badges/score.svg)](https://glama.ai/mcp/servers/Work90210/APIFold) 📇 ☁️ - Turn any REST API into a hosted MCP server. 18 free public servers (GitHub, Stripe, Slack, OpenAI, Notion, and more) — no setup required, bring your own API key.

APIFold is an MCP aggregator that converts any REST API into an MCP server without needing to set up your own infrastructure. It provides 18 pre-configured public servers for popular services like GitHub, Stripe, Slack, OpenAI, and Notion, which work simply by adding your own API keys. This enables easy integration of external REST APIs into MCP-compatible clients like Claude Desktop, eliminating the need for local server configuration.
