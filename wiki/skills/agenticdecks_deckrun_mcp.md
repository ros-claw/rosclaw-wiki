deckrun-mcp is an MCP server that generates presentation PDFs, narrated videos, and MP3 audio from Markdown content. The free tier requires no API key or local installation, making it easy to start by adding a URL to an IDE configuration. The paid tier unlocks video generation, audio production, asynchronous job support, and account management tools. This tool is aimed at quickly turning Markdown slides into polished multimedia presentations.
