raindrop-mcp is a server implementation that enables deploying cloud infrastructure using Claude Code and the Model Context Protocol. It is listed under Cloud Platforms on the MCP servers list. The tool simplifies infrastructure management by integrating AI-powered code generation with cloud deployment. It likely supports provisioning resources through natural language commands.
