> Lightweight agent registry and JIT router.

Agent Dispatch is a lightweight system that serves as an agent registry and a just-in-time router. It allows agents to be registered and then dynamically dispatched as needed. The project aims to provide a minimal, efficient routing mechanism for agent-based systems.
