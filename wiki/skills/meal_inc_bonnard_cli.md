> 📇 ☁️ - Ultra-fast to deploy agentic-first MCP-ready semantic layer. Let your data be like water.

Bonnard CLI is an ultra-fast to deploy semantic layer designed for agentic-first architectures. It is MCP-ready, meaning it integrates with the Model Context Protocol to allow AI agents to interact with data seamlessly. The tool aims to make data 'like water' by providing a flexible, easy-to-use interface for data platforms. This project falls under server implementations for data platforms, emphasizing quick setup and agentic capabilities.
