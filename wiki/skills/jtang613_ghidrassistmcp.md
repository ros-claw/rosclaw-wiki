> ☕ 🏠 - A native Model Context Protocol server for Ghidra. Includes GUI configuration and logging, 31 powerful tools and no external dependencies.

GhidrAssistMCP is a native Model Context Protocol (MCP) server for Ghidra, a popular reverse engineering framework. It features a GUI for configuration and logging, and provides 31 powerful tools with no external dependencies. Listed under security server implementations, it enables AI agents to interact with Ghidra for automated reverse engineering tasks. This integration simplifies AI-assisted binary analysis and security research by bridging Ghidra's capabilities with MCP-compatible clients.
