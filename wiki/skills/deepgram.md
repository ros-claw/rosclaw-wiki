> — command-line interface for Deepgram speech-to-text.

Deepgram is a command-line interface tool that provides access to Deepgram's speech-to-text API. It allows users to transcribe audio files directly from the terminal, enabling efficient audio processing and transcription workflows. The tool is designed for developers and researchers who need to integrate speech recognition capabilities into scripts or automated pipelines.
