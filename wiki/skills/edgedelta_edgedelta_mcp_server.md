> 🎖️ 🏎️ ☁️ – Interact with Edge Delta anomalies, query logs / patterns / events, and pinpoint root causes and optimize your pipelines.

The Edge Delta MCP server allows users to interact with Edge Delta anomalies, query logs, patterns, and events. It aids in pinpointing root causes of issues and optimizing monitoring pipelines. This server integrates with the Model Context Protocol for seamless communication.
