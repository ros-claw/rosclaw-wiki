> 🏎️ 🏠 🍎 🪟 🐧 - Code intelligence MCP server with 80+ tools for semantic code search, impact analysis, call graphs, ownership detection, and architectural understanding. Supports Go, TypeScript, Python, Rust, Java via SCIP indexing.

CodeMCP is a Model Context Protocol (MCP) server that provides over 80 tools for code intelligence. It supports semantic code search, impact analysis, call graph generation, ownership detection, and architectural understanding. The server works with multiple programming languages including Go, TypeScript, Python, Rust, and Java by using SCIP indexing. It helps developers navigate and analyze large codebases efficiently.
