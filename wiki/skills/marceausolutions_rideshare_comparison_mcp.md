> 🐍 ☁️ - Compare Uber and Lyft prices for any route in real-time with fare estimates, surge pricing info, and cheapest option recommendations

This project is a Model Context Protocol (MCP) server that compares real-time fares from Uber and Lyft for any route. It provides fare estimates, surge pricing alerts, and recommends the cheapest option. Designed for integration into travel and transportation workflows, it allows seamless querying of rideshare costs via MCP. The server is implemented in Python and uses cloud-based deployment.
