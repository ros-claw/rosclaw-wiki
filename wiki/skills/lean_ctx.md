> MCP server and context runtime for AI coding agents: session caching, AST-aware compression, and 90+ shell patterns to reduce token usage. Supports Claude Code, Cursor, Copilot, and other integrations. Install the Claude Code skill with `lean-ctx init --agent claude-code`; docs at [leanctx.com](https://leanctx.com).

lean-ctx is a tool that helps AI coding agents work more efficiently by managing their context. It uses session caching and AST-aware compression to reduce the number of tokens consumed, which lowers costs and speeds up interactions. The tool includes over 90 shell patterns and supports popular AI coding tools like Claude Code, Cursor, and Copilot. It is installed as a Claude Code skill and has documentation available at leanctx.com.
