This MCP server provides a set of eight personal finance calculator tools, including mortgage payment estimation, compound interest projection, FIRE retirement target calculation, loan comparison, true cost of credit, and debt payoff planning. It requires no external API keys and runs directly via `uvx axiom-calculator-mcp`. Aimed at financial advisors and individuals seeking offline-capable, model-agnostic financial math within MCP-compatible assistants.
