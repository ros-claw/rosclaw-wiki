This MCP server provides a web scraping tool that extracts clean markdown, links, and metadata from any URL. It serves as a free alternative to Firecrawl, enabling LLMs to ingest structured webpage content directly. Designed for developer tooling, it integrates seamlessly into MCP-based workflows for enhanced data extraction capabilities.
