> Manage a local Hytale dedicated server using the official downloader.

This project provides a tool to manage a local Hytale dedicated server by leveraging the official server downloader. It automates the process of setting up, updating, and configuring the server, making it easier for players or server admins to host their own Hytale game server locally. The tool simplifies the complexities of server management, such as downloading the correct server software and handling updates. It is designed for those who want to run a private Hytale server without relying on third-party hosting.
