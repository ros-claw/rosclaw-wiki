> ![GitHub stars](https://img.shields.io/github/stars/Agent-Analytics/autoresearch-growth?style=social) - Applies autoresearch to landing-page positioning and A/B test candidates, using analytics snapshots and measured experiment results to seed subsequent rounds.

This project adapts autoresearch to the domain of growth, focusing on landing-page positioning and generating A/B test candidates. It uses analytics snapshots and measured experiment results to seed subsequent rounds of research. This allows for iterative improvement based on data-driven insights. The tool aims to automate the research process for optimizing conversion and user acquisition.
