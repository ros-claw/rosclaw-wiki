> #️⃣ 🏠 - 58 semantic C#/.NET analysis tools via Roslyn. Navigation, refactoring, find usages, and code intelligence for AI agents.

Sharplens MCP is a server implementation that provides 58 semantic analysis tools for C# and .NET code, built on top of the Roslyn compiler platform. It enables AI agents to perform code navigation, refactoring, find usages, and other code intelligence tasks. This tool helps developers and AI systems understand and manipulate C# codebases more effectively.
