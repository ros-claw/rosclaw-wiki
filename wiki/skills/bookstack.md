> BookStack Wiki & Documentation API integration.

BookStack is a self-hosted, open-source wiki and documentation platform designed for organizing knowledge. It offers a simple interface for creating and managing documentation pages, with hierarchical categorization using shelves, books, chapters, and pages. The platform includes an API for integrations, allowing automated content management and external tool connections. It supports Markdown and WYSIWYG editing, search, and permissions.
