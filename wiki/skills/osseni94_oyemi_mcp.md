> 🐍 🏠 - Deterministic semantic word encoding and valence/sentiment analysis using 145K+ word lexicon. Provides word-to-code mapping, semantic similarity, synonym/antonym lookup with zero runtime NLP dependencies.

Oyemi MCP is a server that provides deterministic semantic word encoding and valence/sentiment analysis using a large lexicon of over 145,000 words. It enables word-to-code mapping, semantic similarity comparisons, and synonym/antonym lookup without any runtime NLP dependencies. The tool is designed for data platforms within the Model Context Protocol ecosystem, offering lightweight and predictable text analysis capabilities.
