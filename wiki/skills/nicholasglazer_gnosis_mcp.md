> 🐍 🏠 - Zero-config MCP server for searchable documentation. Loads markdown into SQLite (default) or PostgreSQL with FTS5/tsvector keyword search and optional pgvector hybrid semantic search.

Gnosis MCP is a zero-configuration Model Context Protocol server for making documentation searchable. It loads markdown files and stores them in SQLite by default, with optional PostgreSQL support. The server provides full-text search using SQLite FTS5 or PostgreSQL tsvector, and can optionally perform hybrid semantic search using pgvector. This enables efficient retrieval of relevant information from documentation files without manual setup.
