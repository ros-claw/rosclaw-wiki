> [![primitiv MCP server](https://glama.ai/mcp/servers/AI-by-design/primitiv/badges/score.svg)](https://glama.ai/mcp/servers/AI-by-design/primitiv) 📇 🏠 🍎 🪟 🐧 - Design contract layer for your codebase. Scans Figma, code, Storybook, and token files, reconciles conflicts, and serves a single machine-readable source of truth over MCP so every agent gets the same authoritative design rules before it builds. Local-first — your code never leaves your machine.

Primitiv is a design contract layer that scans Figma files, codebases, Storybook components, and design token files to detect conflicts and reconcile them into a single authoritative source of truth. It makes this design intelligence available over the Model Context Protocol (MCP), ensuring AI agents always reference the same consistent rules before generating code. The tool operates local-first, meaning all processing happens on the user's machine and no code leaves their environment. It is categorized as a developer tool for server implementations.
