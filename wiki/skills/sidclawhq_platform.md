Sidclawhq/platform is a governance proxy for MCP servers that adds policy evaluation, human approval workflows, and hash-chain audit trails on top of any upstream server. It wraps existing MCP servers to enforce access control and compliance requirements without modifying the original server. The project supports over 18 framework integrations and is licensed under Apache 2.0. It helps organizations implement security and governance for AI agent tooling.
