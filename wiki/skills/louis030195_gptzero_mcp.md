> 📇 ☁️ 🍎 🪟 🐧 - AI detection for text content with GPTZero API. Detect AI-generated text, get confidence scores, multilingual support (French/Spanish), and detailed probability breakdowns.

This MCP server integrates the GPTZero API for detecting AI-generated text. It provides confidence scores, probability breakdowns, and supports multiple languages including French and Spanish. Designed for developer tools, it allows easy integration into MCP-compatible environments to check content authenticity.
