> Announce text throughout the house via AirPlay speakers using Airfoil +.

Announcer is a tool that allows users to broadcast text messages throughout their home using AirPlay-compatible speakers. It leverages Airfoil software to stream audio to multiple speakers simultaneously. This enables voice announcements for notifications, reminders, or smart home integrations. The project focuses on simple, scriptable text-to-speech delivery across a distributed audio system.
