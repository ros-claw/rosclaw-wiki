This is an MCP server that enables pay-per-call access to onchain data and AI models using x402 micropayments on the Base network. It provides nine tools including swap quotes, token prices, wallet balances, ENS resolution, and batch USDC transfers to multiple recipients. The server is designed for finance and fintech use cases, allowing users to pay for individual API calls with USDC without needing to hold tokens or manage subscriptions.
