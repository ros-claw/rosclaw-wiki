This project provides an MCP server for AI-powered scam and threat verification, checking various inputs like phone numbers, URLs, text messages, emails, documents, and QR codes. It leverages a database of over 8 million threat intelligence records from sources including FTC/FCC complaints and URLhaus/ThreatFox. The server returns risk scores, verdicts, and detailed signals for each input. It offers 10 tools, supports OAuth 2.1 and API key authentication, and uses Streamable HTTP transport.
