> LangChain's concise framing of an agent as model plus harness, with prompts, tools, middleware, orchestration, and runtime infrastructure.

This project by LangChain provides a conceptual framework for understanding AI agents as composed of two main parts: a model (the intelligence) and a harness (the operational infrastructure). The harness integrates prompts, tools, middleware, orchestration, and runtime components to manage agent behavior and interactions. It offers a structured way to design and build agents by clearly separating concerns.
