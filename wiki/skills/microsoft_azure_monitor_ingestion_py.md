This project provides a Python client library for ingesting logs into Azure Monitor. It is part of Microsoft's Python Skills initiative under the Sponsors program. The library simplifies sending log data to Azure Log Analytics workspaces. It supports batch uploads and handles authentication with Azure Active Directory.
