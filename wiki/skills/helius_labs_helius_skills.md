This project provides a set of community-contributed skills for AI agents to interact with the Solana blockchain via Helius infrastructure. It enables autonomous agents to perform on-chain actions such as queries, transactions, and data retrieval. The skills are designed to be integrated into agent frameworks that support tool-use or skill plugins. This repository is part of the Helius ecosystem's community skills collection.
