> 🎖️ 🏎️ 🏠 - Provides comprehensive integration with your [VictoriaMetrics instance APIs](https://docs.victoriametrics.com/victoriametrics/url-examples/) and [documentation](https://docs.victoriametrics.com/) for monitoring, observability, and debugging tasks related to your VictoriaMetrics instances

This project is an MCP server that integrates with VictoriaMetrics instance APIs and documentation. It enables AI agents to perform monitoring, observability, and debugging tasks related to VictoriaMetrics. The server provides tools for querying metrics, retrieving documentation, and interacting with VictoriaMetrics features. It is listed under the Monitoring category of server implementations.
