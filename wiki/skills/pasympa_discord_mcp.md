This project provides a lightweight MCP server that integrates with Discord across multiple guilds. It offers over 60 tools for managing messages, channels, roles, forums, webhooks, and moderation tasks. Built for agentic AI clients, it enables seamless interaction with Discord's features through the Model Context Protocol.
