> [![opendatalab/MinerU-Ecosystem MCP server](https://glama.ai/mcp/servers/opendatalab/MinerU-Ecosystem/badges/score.svg)](https://glama.ai/mcp/servers/opendatalab/MinerU-Ecosystem) 🎖️ 🐍 🏠 ☁️ - Official MinerU document parsing MCP ([mineru-open-mcp](https://pypi.org/project/mineru-open-mcp/) on PyPI). Converts PDFs, doc/docx/ppt/pptx, images, and spreadsheets to Markdown via the [MinerU](https://mineru.net) API; free Flash mode without an API key (about 20 pages per file); optional `MINERU_API_TOKEN` for higher limits.

This project is an MCP server that integrates MinerU's document parsing API, enabling conversion of PDFs, Office documents (doc/docx, ppt/pptx), images, and spreadsheets into Markdown format. It offers a free Flash mode with a limit of about 20 pages per file and no API key required, while an optional token provides higher usage limits. The server can be used as part of the MinerU Ecosystem to extract structured text from diverse document types for AI and data processing workflows.
