> A small set of well-written output styles, specifically focused on debugging - root cause analysis, systematic, methodical debugging, encouraging a more careful approach to bug-squashing from Claude Code.

This project provides output style prompts for Claude Code that are specifically designed for debugging tasks. The styles emphasize root cause analysis and a systematic, methodical approach to identifying and fixing bugs. They encourage a more careful and structured mindset during bug-squashing sessions. These output styles are categorized under General within Output Styles.
