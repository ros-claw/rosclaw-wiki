W3Ship/w3ledger-mcp-server is a Model Context Protocol server that implements a self-verifying ledger with dual-signed transactions. It provides support for gift cards, sponsor cards, and W3SH loyalty tiers. The server supports multiple signature schemes including EVM, ML-DSA-65, and SLH-DSA, which are post-quantum algorithms. It is listed under the Finance & Fintech category in the MCP server implementations directory.
