> Hardware-level mouse, keyboard & dialog automation on macOS via CGEvent + AppleScript.

This project enables hardware-level automation of mouse, keyboard, and dialogs on macOS using CGEvent and AppleScript. It simulates input events and controls dialogs without relying on higher-level accessibility APIs. Useful for automated testing, repetitive tasks, and system integration, it provides precise low-level control over user input.
