This is an Azure SDK for .NET that enables management of Cosmos DB resources through Azure Resource Manager. It provides CRUD operations for databases, containers, and other Cosmos DB entities. Developers use this library to automate infrastructure-as-code for Cosmos DB. The SDK follows Azure SDK design guidelines and supports the latest .NET runtime.
