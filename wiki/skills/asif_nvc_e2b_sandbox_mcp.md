This MCP server integrates Claude Code with E2B cloud sandboxes, offering 29 tools for provisioning isolated Linux virtual machines, cloning repositories, executing commands, managing files, and performing Git operations entirely in the cloud without affecting the local environment. It enables secure, remote code execution and testing within temporary or persistent sandboxes, enhancing Claude Code's capabilities for development workflows. The server is listed under the Code Execution category in the MCP server directory and supports multiple operating systems.
