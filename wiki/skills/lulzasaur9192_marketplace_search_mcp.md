> [![marketplace-search-mcp MCP server](https://glama.ai/mcp/servers/lulzasaur9192/marketplace-search-mcp/badges/score.svg)](https://glama.ai/mcp/servers/lulzasaur9192/marketplace-search-mcp) 📇 ☁️ - Search marketplaces (TCGPlayer, Reverb, Thumbtack), verify professional licenses (contractor, nurse across US states), and look up PSA card grading population data.

This MCP server allows users to search across multiple marketplaces, including TCGPlayer, Reverb, and Thumbtack, directly from MCP-compatible clients. It can also verify professional licenses, such as contractor and nurse licenses, across various US states. Additionally, the server can retrieve PSA card grading population data for trading cards. The tool aims to consolidate diverse search and verification tasks into a single MCP interface for efficiency.
