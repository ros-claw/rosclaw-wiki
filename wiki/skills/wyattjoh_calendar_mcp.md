> 📇 🏠 🍎 - MCP server for accessing macOS Calendar events

This is an MCP server for accessing macOS Calendar events. It provides a way to integrate calendar data with AI agents using the Model Context Protocol. The server runs on macOS and allows querying events from the system calendar. It is categorized under Workplace & Productivity tools.
