> 📇 ☁️ - Generate Pix QR codes and copy-paste strings with fallback across multiple providers (Efí, Cielo, etc.) for Brazilian instant payments.

This MCP server generates Pix QR codes and copy-paste payment strings for Brazilian instant payments. It supports multiple payment providers like Efí and Cielo, with automatic fallback for reliability. The tool simplifies integrating Pix payments into AI agent workflows using the Model Context Protocol. It is categorized under Finance & Fintech server implementations.
