> ![GitHub stars](https://img.shields.io/github/stars/MrTsepa/autoevolve?style=social) - GEPA-inspired autoresearch for self-play: mutate code strategies, evaluate head-to-head, rate with Elo/Bradley-Terry, branch from the Pareto front. Agent reads match traces to target mutations. Works as a Claude Code skill.

Autoevolve uses self-play to automatically evolve code strategies: it mutates existing code, pits new versions against each other, and rates them with Elo or Bradley-Terry scores. The system maintains a Pareto front of the best strategies and selects branches from it for further mutation. An AI agent reads match traces to target specific improvements, and the tool is designed to work as a skill for Claude Code.
