> Supabase MCP Server with support for SQL query execution and database exploration tools

The supabase-mcp-server is an MCP (Model Context Protocol) server implementation that enables AI assistants to interact with Supabase databases. It provides tools for executing SQL queries and exploring database schemas, allowing AI models to directly query and examine database structures. This integration simplifies database management tasks by giving AI agents the ability to run raw SQL and navigate tables, views, and functions. It is listed under database server implementations, highlighting its focus on database connectivity.
