This MCP server provides AI agents with tools to search and browse Japan-focused furniture and home products. It offers 15 tools including millimeter-precision search across 300+ products in 31 categories, curated sets like bundles and room presets, and a dimension-compatible replacement finder with fit scores. It also includes AI visibility diagnosis, live Rakuten API integration, and an OpenAPI 3.1 schema. The server can be installed via `npx ai-furniture-hub`.
