> 🐍 🏠 - A fully-featured coding agent that relies on symbolic code operations by using language servers.

Serena is a fully-featured coding agent that leverages symbolic code operations through language servers. It is designed to assist with coding tasks by understanding and manipulating code at a symbolic level, making it a powerful tool for developer workflows. The project is implemented in Python and is listed under the 'Coding Agents' category in the Server Implementations section of the repository. Its approach emphasizes symbolic reasoning for code analysis and generation, distinguishing it from purely machine learning-based agents.
