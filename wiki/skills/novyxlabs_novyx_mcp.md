Novyx MCP is a server implementation for persistent AI agent memory, supporting local SQLite or a cloud API. It offers rollback, audit trails, semantic search, and a knowledge graph. With 23 tools, 6 resources, and 3 prompts, it provides zero-config setup for local use. It is designed to maintain long-term context for AI agents.
