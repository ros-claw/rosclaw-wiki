> Security scanner and input sanitizer for AI agents.

Clawdefender is a tool designed to enhance the security of AI agents by scanning for vulnerabilities and sanitizing inputs. It helps prevent malicious inputs from compromising agent behavior or data. The project provides a simple interface for integrating security checks into AI agent pipelines.
