> [![avansaber/tailtest-cline MCP server](https://glama.ai/mcp/servers/avansaber/tailtest-cline/badges/score.svg)](https://glama.ai/mcp/servers/avansaber/tailtest-cline) 🐍 🏠 🍎 🪟 🐧 - Adversarial test generation for AI coding sessions. Detects language and framework; writes tests; runs them; classifies failures via R12 (real_bug / environment / test_bug). Ships 8 adversarial scenario categories. Works in Cline directly and in 8+ editors via Cline host coverage. 162 plugin tests. MIT.

This MCP server performs adversarial test generation for AI coding sessions, automatically detecting the programming language and framework used. It writes and runs tests, then classifies any failures into three categories: real bugs, environment issues, or test bugs. The server includes 8 adversarial scenario categories and works seamlessly with the Cline coding agent, supporting over 8 editors through Cline's host coverage. It is open source under MIT license and includes 162 plugin tests.
