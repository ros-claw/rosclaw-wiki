> Manage Apple Notes from the terminal using the inotes CLI.

A terminal-based CLI tool for managing Apple Notes. It allows users to interact with their Apple Notes database via command line, supporting operations like listing, searching, creating, and deleting notes. This tool is useful for developers or power users who prefer terminal workflows. It leverages the inotes library to interface with Apple Notes' SQLite database.
