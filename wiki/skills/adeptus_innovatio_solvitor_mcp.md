> 🦀 🏠 - Solvitor MCP server provides tools to access reverse engineering tools that help developers extract IDL files from closed-source Solana smart contracts and decompile them.

Solvitor MCP is a server that provides tools for reverse engineering closed-source Solana smart contracts. It enables developers to extract IDL (Interface Definition Language) files from compiled binaries and decompile them for analysis. This project is categorized under Security, reflecting its use in auditing and understanding proprietary blockchain code. It acts as a bridge between MCP clients and Solana reverse engineering utilities.
