> 🎖️ 📇 ☁️ - Klever blockchain MCP server for smart contract development, on-chain data exploration, account and asset queries, transaction analysis, and contract deployment tooling.

klever-io/mcp-klever-vm is an MCP server tailored for the Klever blockchain, enabling developers to interact with the chain for smart contract development, on-chain data queries, account and asset management, and transaction analysis. It provides tooling for deploying contracts and exploring blockchain data through the Model Context Protocol. This server is categorized under Finance and Fintech, leveraging Klever's blockchain capabilities for decentralized applications.
