> Query ecobee thermostat data via Beestat API including temperature.

Beestat is a tool for querying ecobee thermostat data through the Beestat API, including temperature readings. It enables users to access and analyze their smart thermostat information programmatically. This project simplifies retrieving historical and real-time data from ecobee devices for monitoring or automation purposes.
