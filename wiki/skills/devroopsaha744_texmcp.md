> 🐍 🏠 - An MCP server that converts LaTeX into high-quality PDF documents. It provides tools for rendering both raw LaTeX input and customizable templates, producing shareable, production-ready artifacts such as reports, resumes, and research papers.

TexMCP is an MCP server that converts LaTeX input into high-quality PDF documents. It supports both raw LaTeX and customizable templates, making it suitable for generating reports, resumes, and research papers. The output is production-ready and shareable, enhancing workplace productivity. It integrates with the Model Context Protocol to enable AI agents to produce PDFs from LaTeX.
