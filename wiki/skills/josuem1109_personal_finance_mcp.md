This is a self-hosted, read-only MCP (Model Context Protocol) server that connects to users' financial accounts—banks, credit cards, loans, and brokerage accounts—via the Plaid API. It exposes 9 distinct tools that allow AI assistants to retrieve balances, transactions, recurring charges, liabilities, and investment holdings. The server is designed to be run locally for privacy, providing a secure way to query financial data without write access. It acts as a bridge between the user's financial institutions and MCP-compatible AI tools.
