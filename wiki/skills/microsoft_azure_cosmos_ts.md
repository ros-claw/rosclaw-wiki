This is the official TypeScript SDK for Azure Cosmos DB, a globally distributed, multi-model database service. It provides a client library for Node.js and browser applications to interact with Cosmos DB resources. The SDK supports CRUD operations, queries, and stored procedures. It is designed for high performance and scalability.
