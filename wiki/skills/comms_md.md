> Create a COMMS.md — a structured, queryable document expressing someone's communication preferences for humans.

comms-md is a tool that generates a COMMS.md file, a structured Markdown document for specifying an individual's communication preferences. It makes these preferences queryable by machines while remaining readable by humans, facilitating smoother interactions. Users can define preferred channels, availability, response times, and other metadata. This helps teams and individuals align on communication norms without repeated back-and-forth.
