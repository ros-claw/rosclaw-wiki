> ₿ A Model Context Protocol (MCP) server that enables AI models to interact with Bitcoin, allowing them to generate keys, validate addresses, decode transactions, query the blockchain, and more.

This project is a Model Context Protocol (MCP) server that allows AI models to interact with the Bitcoin blockchain. It enables capabilities such as generating keys, validating addresses, decoding transactions, and querying blockchain data. By integrating Bitcoin functionality into MCP, it extends AI agents with native cryptocurrency tools.
