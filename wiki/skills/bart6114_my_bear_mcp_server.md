> 📇 🏠 🍎 - Allows to read notes and tags for the Bear Note taking app, through a direct integration with Bear's sqlitedb.

This project is an MCP server that integrates with the Bear note-taking app by directly accessing its SQLite database. It enables reading notes and tags from Bear using the Model Context Protocol. Users can leverage this server with any MCP-compatible client to programmatically retrieve Bear data. The tool is listed under Other Tools and Integrations in the MCP server ecosystem.
