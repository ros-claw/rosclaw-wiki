This project provides an MCP server that allows AI agents to perform comprehensive WHOIS lookups on domain names via the IP2WHOIS API. It retrieves domain registration details such as expiry dates, registrar information, and registrant data. The server integrates with the Model Context Protocol (MCP) to enable AI tools to access structured domain information. This is useful for tasks like domain ownership verification, cybersecurity analysis, and domain management.
