Hosted MCP server with OAuth 2.0 + Bearer auth, free trial available.

ThinAirData is a hosted MCP server that enables AI systems to connect to PostgreSQL, MySQL, or SQL Server databases. It provides 24 dialect-aware tools for tasks such as query execution, schema introspection, query optimization, migrations, and PII scanning. The server supports OAuth 2.0 and Bearer authentication and offers a free trial. This service allows AI agents to interact with relational databases in a secure and feature-rich manner.
