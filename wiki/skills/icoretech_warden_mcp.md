Warden MCP is a server implementation that integrates the Bitwarden and Vaultwarden password management systems with AI agents via the Model Context Protocol. It leverages the official `bw` CLI to provide capabilities such as searching, creating, editing, and organizing vault items including logins, notes, cards, identities, SSH keys, folders, collections, and Sends. This allows AI tools to securely interact with password vaults and manage credentials programmatically. Warden MCP is listed under security server implementations and supports multiple operating systems.
