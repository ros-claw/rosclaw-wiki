> Auto-transcribe voice messages using faster-whisper (local, no API key needed).

Audio-transcribe auto-transcribes voice messages using faster-whisper, a local model that does not require an API key. It processes audio files on your machine, ensuring privacy. This tool is useful for transcribing voice notes, meeting recordings, or any spoken audio. It runs entirely offline, making it suitable for sensitive data.
