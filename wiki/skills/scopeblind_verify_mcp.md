Ed25519 + JCS. No accounts, no API calls. Apache-2.0.

This is an MCP server for offline verification of signed artifacts like receipts, manifests, and audit bundles. It uses Ed25519 signatures and the JSON Canonicalization Scheme (JCS) to ensure data integrity without needing user accounts or API calls. The tool is designed for security-focused workflows where artifacts must be verified locally. It is licensed under Apache-2.0 and is available for multiple platforms (Mac, Windows, Linux).
