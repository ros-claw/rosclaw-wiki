> [![AceDataCloud/MCPSerp MCP server](https://glama.ai/mcp/servers/AceDataCloud/MCPSerp/badges/score.svg)](https://glama.ai/mcp/servers/AceDataCloud/MCPSerp) 🐍 ☁️ - Google SERP search including web, images, news, maps, places, videos, and knowledge graph results via Ace Data Cloud API.

This MCP server provides access to Google Search Engine Results Pages (SERP) through the Ace Data Cloud API. It supports multiple search types including web, images, news, maps, places, videos, and knowledge graph results. The server is listed under Search & Data Extraction categories in the MCP ecosystem. It enables AI agents to perform real-time web searches and retrieve structured data. The integration uses the Model Context Protocol for standardized tool calling.
