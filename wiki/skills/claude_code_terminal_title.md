> Gives each Claud-Code terminal window a dynamic title that describes the work being done so you don't lose track of what window is doing what.

Claude Code Terminal Title is a tool that dynamically updates terminal window titles for Claude Code sessions. It automatically sets the title to reflect the current task or work being done. This helps users quickly identify the purpose of each terminal window among many open windows. The tool aims to improve workflow organization and reduce confusion when multitasking.
