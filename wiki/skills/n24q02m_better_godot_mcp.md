better-godot-mcp is an MCP server that provides 18 composite tools for structured interaction with the Godot 4.x game engine. It enables AI assistants to control scenes, nodes, GDScript, shaders, animation, tilemaps, physics, audio, navigation, UI, input mapping, and signals through the Model Context Protocol. This tool is designed for game developers who want to integrate AI-driven features into Godot projects.
