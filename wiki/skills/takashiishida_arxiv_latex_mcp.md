> 🐍 ☁️ - Get the LaTeX source of arXiv papers to handle mathematical content and equations

This project is a Model Context Protocol (MCP) server that fetches the LaTeX source code of papers from arXiv. It allows AI agents to access raw mathematical content and equations directly, improving their ability to process scientific documents. The tool is listed under Search & Data Extraction in the MCP server ecosystem. It simplifies integrating arXiv's LaTeX sources into workflows that require handling complex mathematical notation.
