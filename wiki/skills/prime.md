> Sets up initial project context by viewing directory structure and reading key files, creating standardized context with directory visualization and key documentation focus.

The /prime command initializes project context by scanning the directory structure and reading essential files. It creates a standardized context that includes a visual representation of the directory tree and focuses on key documentation. This helps AI agents and users quickly understand the project's layout and critical files. The command is part of the Slash-Commands toolset for context loading and priming.
