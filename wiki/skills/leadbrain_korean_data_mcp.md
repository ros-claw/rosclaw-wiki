Requires APIFY_TOKEN.

This MCP server provides real-time Korean web data retrieval tools. It includes sources like Naver place reviews, Melon music charts, Daangn and Bunjang marketplace listings, Naver news, and Musinsa fashion rankings. It uses Apify actors for data extraction and requires an Apify API token. There are 7 tools available for different data sources.
