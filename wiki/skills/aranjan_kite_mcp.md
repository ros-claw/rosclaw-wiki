This project is an MCP server that allows you to trade Indian stocks on the Zerodha Kite platform using natural language. It provides 14 tools for managing holdings, orders, quotes, GTT triggers, and more. The server includes automated TOTP login for seamless authentication. It is designed for developers and traders who want to interact with the Kite API through conversational interfaces.
