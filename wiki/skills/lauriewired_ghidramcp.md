> ☕ 🏠 - A Model Context Protocol server for Ghidra that enables LLMs to autonomously reverse engineer applications. Provides tools for decompiling binaries, renaming methods and data, and listing methods, classes, imports, and exports.

GhidraMCP is a Model Context Protocol server that integrates Ghidra, a reverse engineering framework, with large language models. It allows LLMs to autonomously reverse engineer binary applications by providing tools for decompilation, renaming methods and data, and listing methods, classes, imports, and exports. This server bridges the gap between AI agents and binary analysis, enabling automated software understanding.
