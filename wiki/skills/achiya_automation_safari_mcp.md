Safari MCP is a native Safari browser automation tool for AI agents, offering over 80 tools without requiring Chrome. It is optimized for Apple Silicon, achieving 60% less CPU overhead compared to alternatives. This server implements the Model Context Protocol (MCP) to enable AI agents to control and interact with the Safari browser natively on macOS.
