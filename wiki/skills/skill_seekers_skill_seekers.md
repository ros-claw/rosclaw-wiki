Skill_Seekers is an MCP server that converts 17 types of content sources—including documents, GitHub repos, PDFs, videos, Jupyter notebooks, Confluence, Notion, Slack, and Discord—into AI-ready skills and knowledge for retrieval-augmented generation (RAG). It provides 35 tools for scraping, packaging, enhancing, and exporting processed data to vector databases such as Weaviate, Chroma, FAISS, and Qdrant. The server supports over 16 target platforms, making it a versatile pipeline for building knowledge bases or skill sets for AI agents. It aims to streamline the transformation of raw information into structured, queryable formats for AI applications.
