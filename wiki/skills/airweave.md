> Context retrieval layer for AI agents across users' applications.

Airweave is a context retrieval layer designed for AI agents, enabling them to access and use context from users' applications. It acts as a bridge between AI agents and the data sources users interact with, improving the relevance and personalization of AI responses. By providing a unified retrieval interface, it simplifies how agents fetch contextual information across different platforms.
