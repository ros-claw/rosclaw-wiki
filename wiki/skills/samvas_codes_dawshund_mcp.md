> ☁️ 🏠 - An MCP server based on dAWShund to enumerate AWS IAM data, analyze effective permissions, and visualize access relationships across users, roles, and resources. Built for cloud security engineers who want fast, easy and effective insights into AWS identity risk.

This MCP server based on dAWShund helps cloud security engineers enumerate AWS IAM data, analyze effective permissions, and visualize access relationships across users, roles, and resources. It provides fast and easy insights into AWS identity risk. The tool is designed for security engineers who need to understand and audit IAM configurations effectively.
