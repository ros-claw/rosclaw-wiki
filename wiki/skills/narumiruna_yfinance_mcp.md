> 🐍 ☁️ - An MCP server that uses yfinance to obtain information from Yahoo Finance.

This project provides a Model Context Protocol (MCP) server that uses the yfinance library to fetch financial data from Yahoo Finance. It exposes stock prices, financial statements, and other market information through the MCP interface, allowing AI agents to query real-time and historical financial data. The server integrates Yahoo Finance data into AI workflows, enabling applications like portfolio analysis or market research.
