> Simple website analytics your AI agent controls end-to-end.

Agent-analytics is a simple website analytics tool that is fully controlled by an AI agent from setup to reporting. The AI agent manages the entire analytics pipeline, allowing for automated insights and actions based on visitor data. It aims to provide end-to-end ownership of analytics without manual configuration. This project focuses on integrating AI agents with web analytics for streamlined monitoring.
