This MCP server acts as a pre-build reality check for AI coding agents. It scans platforms like GitHub, Hacker News, npm, PyPI, and Product Hunt to detect existing competition before developers start building. It returns a reality signal score (0-100), duplicate likelihood, similar projects, and pivot hints. The goal is to help AI agents avoid building projects that already exist or face strong competition.
