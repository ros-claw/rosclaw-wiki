> 🐍 ☁️ 🐧 🍎 🪟 - MCP server that lets LLMs execute code through the Piston remote code execution engine, with a zero-config `uv` setup and a ready-to-use Claude Desktop config example.

This MCP server enables large language models to execute code through the Piston remote code execution engine. It requires zero configuration for setup with uv and provides a ready-to-use Claude Desktop configuration example. The server supports multiple operating systems including Linux, macOS, and Windows. It is listed under Code Execution in the MCP server implementations.
