> 🐍 🏠 - LLM-based code review MCP server with AST-powered smart context extraction. Supports Claude, GPT, Gemini, and 20+ models via OpenRouter.

Selvage is an MCP server for LLM-based code review that uses AST-powered context extraction to provide intelligent feedback. It supports multiple models including Claude, GPT, Gemini, and over 20 models via OpenRouter. The tool is designed for developers seeking automated code review integrated with AI assistants.
