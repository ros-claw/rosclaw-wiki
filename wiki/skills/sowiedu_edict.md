> [![Sowiedu/Edict MCP server](https://glama.ai/mcp/servers/sowiedu/edict/badges/score.svg)](https://glama.ai/mcp/servers/sowiedu/edict) 📇 🏠 – Agent-first programming language: agents produce JSON AST, the compiler validates, type-checks, effect-checks, verifies contracts via Z3/SMT, and compiles to WASM. 19 MCP tools for the full compile-and-execute loop.

Edict is an agent-first programming language where AI agents produce a JSON abstract syntax tree (AST). The compiler validates, type-checks, effect-checks, and verifies contracts using a Z3/SMT solver, then compiles the AST to WebAssembly (WASM). It is implemented as an MCP server with 19 tools that provide a complete compile-and-execute loop for agents. This enables agents to safely generate and run code with formal verification of correctness and security constraints.
