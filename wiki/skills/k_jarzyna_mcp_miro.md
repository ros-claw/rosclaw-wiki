> 📇 ☁️ - Miro MCP server, exposing all functionalities available in official Miro SDK

This project is a Model Context Protocol (MCP) server that integrates with Miro, the online collaborative whiteboard platform. It exposes all functionalities available in the official Miro SDK, allowing AI agents to interact with Miro boards, shapes, text, and other elements. The server enables automation and AI-driven manipulation of Miro workspaces, and is designed to be used within the MCP ecosystem as a tool integration.
