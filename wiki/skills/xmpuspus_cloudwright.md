Cloudwright is an MCP server that lets you manage cloud architecture using natural language. It supports AWS, GCP, Azure, and Databricks with 19 tools for tasks like architecture design, cost estimation, compliance validation (HIPAA, SOC 2, FedRAMP, GDPR, PCI-DSS, Well-Architected), security scanning, Terraform/CloudFormation export, and blast-radius analysis. This simplifies cloud infrastructure management through conversational AI.
