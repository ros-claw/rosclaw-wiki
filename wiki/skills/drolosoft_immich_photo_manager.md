Claude Code plugin with 21 MCP tools, 11 skills, and 5 slash commands.

This MCP server integrates with the self-hosted Immich photo library, enabling natural language search based on CLIP embeddings, geographic album curation using GPS data, duplicate detection via perceptual hashing, library health reports, and generation of offline-ready interactive HTML galleries. It provides 21 MCP tools, 11 skills, and 5 slash commands for the Claude Code assistant, turning photo management into a conversational AI experience. The server is available for Python, with support for Home Assistant, macOS, Windows, and Linux.
