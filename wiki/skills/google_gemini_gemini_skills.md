Gemini Skills is an official Google project that provides a framework for defining custom skills or functions that can be invoked by Google's Gemini AI models. It enables developers to create modular, composable tools for agentic workflows, including tool calling and multi-step reasoning. The project integrates directly with the Gemini API, allowing for extensible and reusable skill definitions.
