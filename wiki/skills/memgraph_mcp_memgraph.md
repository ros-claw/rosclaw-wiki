> 🐍 🏠 - Memgraph MCP Server - includes a tool to run a query against Memgraph and a schema resource.

This project is an MCP server for Memgraph, a graph database management system. It provides a tool to run Cypher queries against Memgraph and a resource for retrieving the database schema. The server enables integration with AI assistants using the Model Context Protocol for natural language database interactions.
