> ![GitHub stars](https://img.shields.io/github/stars/greyhaven-ai/autocontext?style=social) - Closed-loop control plane for repeated agent improvement, with evaluation, persistent knowledge, staged validation, and optional distillation into cheaper local runtimes.

Autocontext is a closed-loop control plane that helps AI agents improve repeatedly through evaluation, persistent knowledge, and staged validation. It also supports optional distillation into cheaper local models, making agent self-improvement more autonomous and cost-effective. The system stores past experiences and uses feedback loops to iteratively enhance performance.
