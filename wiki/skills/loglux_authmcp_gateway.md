> [glama](https://glama.ai/mcp/servers/@loglux/auth-mcp-gateway) 🐍 ☁️ 🏠 🍎 🪟 🐧 - Auth proxy for MCP servers: OAuth2 + DCR, JWT, RBAC, rate limiting, multi-server aggregation, and monitoring dashboard.

AuthMCP Gateway is a security proxy for MCP servers that handles authentication and authorization. It supports OAuth2 with Dynamic Client Registration (DCR), JWT tokens, and role-based access control (RBAC). The gateway also includes rate limiting, can aggregate multiple MCP servers behind a single endpoint, and provides a monitoring dashboard. It acts as a central authentication layer to secure MCP server interactions.
