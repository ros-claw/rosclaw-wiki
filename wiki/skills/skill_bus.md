> The skill for connecting skills. Wire context, conditions, and other skills into any skill invocation — declaratively, without modification. Zero dependencies.

Skill-bus is a plugin that enables connecting and wiring together different skills in an AI agent system. It allows users to declaratively chain context, conditions, and other skills into any skill invocation without modifying the underlying code. The tool has zero dependencies, making it lightweight and easy to integrate into existing agent frameworks. It is categorized under developer productivity tools and aims to simplify complex multi-step agent workflows.
