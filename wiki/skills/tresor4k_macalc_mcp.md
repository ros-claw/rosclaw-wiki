This MCP server offers 501 calculator tools across 22 categories, including finance, health, math, science, construction, conversions, education, sport, cooking, and travel. It supports tax calculations for eight countries: France, Belgium, Switzerland, Canada, United States, United Kingdom, Morocco, and Senegal. The server is free to use and requires no API key. It is designed to be integrated as a tool set under the Model Context Protocol for financial and everyday calculations.
