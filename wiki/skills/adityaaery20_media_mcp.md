> 🐍 🏠 🍎 🪟 🐧 - Local image and video processing MCP server with 13 tools for resize, convert, compress, crop, thumbnail, metadata extraction, rotate, flip, filters, and ffmpeg-based video operations. No API keys required.

Adityaaery20/media-mcp is a local MCP server that provides 13 tools for image and video manipulation without requiring any API keys. It supports operations like resizing, converting, compressing, cropping, extracting metadata, rotating, flipping, applying filters, and ffmpeg-based video processing. The server is cross-platform, available for Python, Windows, macOS, and Linux. This tool is ideal for developers who need to integrate media processing capabilities into AI agent workflows while keeping data local.
