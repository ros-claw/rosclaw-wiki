> Code intelligence MCP server that builds knowledge graphs from source code with 42-language tree-sitter AST parsing and FalkorDB.

Codebase-graph is an MCP server that builds knowledge graphs from source code by leveraging tree-sitter for AST parsing across 42 programming languages. It stores the resulting graph in FalkorDB, enabling queries and insights about code structure and dependencies. This tool enhances developer productivity by providing code intelligence and semantic understanding of codebases.
