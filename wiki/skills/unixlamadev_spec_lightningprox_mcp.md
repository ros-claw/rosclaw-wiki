Supports vision/multimodal.

This project is an MCP server that integrates with LightningProx to enable pay-per-request access to AI models using the Bitcoin Lightning Network. It supports multimodal capabilities such as vision processing, allowing users to pay microtransactions per inference. The server is categorized under Finance & Fintech in the Server Implementations list. It provides a way for AI agents to leverage Bitcoin's lightening-fast payments for on-demand AI services.
