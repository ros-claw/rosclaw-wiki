> 📇 ☁️ - A MCP server integrating AniList API for anime and manga information

This project is a Model Context Protocol (MCP) server that integrates with the AniList API to provide structured access to anime and manga information. It allows AI agents to query and retrieve data about series, characters, and other metadata through standardized MCP tools. The server enables seamless interaction between AI assistants and the AniList database, making it useful for art and culture applications.
