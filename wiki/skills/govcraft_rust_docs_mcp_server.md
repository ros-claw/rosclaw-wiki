> 🦀 🏠 - Provides up-to-date documentation context for a specific Rust crate to LLMs via an MCP tool, using semantic search (embeddings) and LLM summarization.

This project is an MCP server that provides LLMs with up-to-date documentation context for Rust crates. It uses semantic search powered by embeddings and LLM summarization to retrieve relevant documentation snippets. Developers can integrate it into their workflows to get accurate, current API information for Rust libraries. It is classified as a developer tool within the MCP server ecosystem.
