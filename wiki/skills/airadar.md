> Distill the signal around AI-native tools/apps and their GitHub home bases: fast-growing, hyped, well-funded.

airadar is a project that distills signal from the AI-native tools and applications ecosystem by monitoring GitHub repositories. It focuses on projects that are fast-growing, hyped, or well-funded. The tool helps developers and enthusiasts discover trending AI projects and track their GitHub home bases.
