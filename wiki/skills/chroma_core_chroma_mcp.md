> 🎖️ 🐍 ☁️ 🏠 - Chroma MCP server to access local and cloud Chroma instances for retrieval capabilities

Chroma MCP is a server that implements the Model Context Protocol (MCP) to interface with Chroma, a vector database for AI retrieval-augmented generation. It allows MCP-compatible agents to query both local and cloud-hosted Chroma instances for storing and retrieving embeddings. This enables seamless integration of Chroma’s retrieval capabilities into AI agent workflows.
