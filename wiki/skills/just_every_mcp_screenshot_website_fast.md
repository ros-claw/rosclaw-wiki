> 📇 🏠 - Fast screenshot capture tool optimized for Claude Vision API. Automatically tiles full pages into 1072x1072 chunks for optimal AI processing with configurable viewports and wait strategies for dynamic content.

This MCP server provides a fast screenshot capture tool optimized for the Claude Vision API. It automatically captures full-page screenshots and tiles them into 1072x1072 pixel chunks to align with AI processing requirements. The tool supports configurable viewports and wait strategies to handle dynamic content. It is listed under Search & Data Extraction in the server implementations directory.
