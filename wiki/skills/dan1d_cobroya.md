Cobroya is an MCP server that integrates Mercado Pago payments into AI agent workflows, allowing agents to create payment links, search payments, and issue refunds. It is built for Latin American merchants to simplify payment operations through natural language or agent interactions. The tool bridges AI assistants with Mercado Pago's payment infrastructure, enabling automated payment processing.
