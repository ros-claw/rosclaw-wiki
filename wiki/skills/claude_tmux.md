> Manage Claude Code within tmux. A tmux popup of all your Claude Code instances, enabling quick switching, status monitoring, session lifecycle management, with git worktree and pull request support.

claude-tmux is a tool that integrates Claude Code sessions within tmux, providing a popup interface to view and manage all active instances. It allows users to quickly switch between sessions, monitor their status, and perform lifecycle management tasks. The tool also supports git worktree operations and pull request workflows, enhancing productivity for developers using Claude Code in a terminal multiplexer environment.
