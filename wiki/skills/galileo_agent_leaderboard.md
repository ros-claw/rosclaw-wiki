> An open evaluation platform tracking LLM agents on task completion and tool calling across business domains, useful for comparing harness quality in enterprise-grade agentic scenarios.

Galileo Agent Leaderboard is an open evaluation platform that tracks LLM agents on task completion and tool calling across business domains. It helps compare harness quality in enterprise-grade agentic scenarios. The platform provides a benchmark for assessing agent performance in practical business tasks. It is useful for developers and researchers evaluating agentic AI systems in enterprise contexts.
