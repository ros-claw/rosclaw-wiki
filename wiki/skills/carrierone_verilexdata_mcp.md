Free stats/sample endpoints, MCP + HTTP transport.

This MCP server provides access to 20 structured datasets including NPI healthcare, SEC filings, OFAC sanctions, crypto whale addresses, Polymarket prediction market signals, patents, and economic indicators. It uses a pay-per-query model with USDC cryptocurrency and offers free stats/sample endpoints. The server supports both MCP and HTTP transport protocols.
