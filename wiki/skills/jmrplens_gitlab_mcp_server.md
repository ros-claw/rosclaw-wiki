This project provides a complete GitLab REST API v4 coverage as an MCP server. It includes 1006 MCP tools across 162 domains, along with 42 meta-tools, 24 resources, and 38 prompts. It is a cross-platform Go binary supporting stdio and HTTP transports, OAuth, auto-update, and safety modes.
