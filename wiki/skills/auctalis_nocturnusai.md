Extracts structured facts with logical inference, proof chains, and truth maintenance. REST API, Python/TypeScript SDKs, and MCP server integration.

NocturnusAI is a deterministic reasoning engine that compresses context for AI agents by extracting structured facts and applying logical inference. It provides proof chains and truth maintenance to ensure reliable reasoning. The system offers a REST API along with Python and TypeScript SDKs, and it integrates as an MCP server. This helps AI agents manage large context windows efficiently while maintaining logical consistency.
