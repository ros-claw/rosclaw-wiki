> 📇 ☁️ 🏠 🍎 🪟 🐧 - Session memory, context health monitoring, reasoning quality, and truthfulness verification MCP server with 37 tools and tiered memory storage. `npx -y context-first-mcp`

This MCP server, named Context-First-MCP, focuses on session memory, context health monitoring, reasoning quality, and truthfulness verification. It provides 37 tools for managing and verifying conversational context, with tiered memory storage across local and cloud environments. The server supports multiple platforms including macOS, Windows, and Linux, and can be run via npx. It falls under the Knowledge & Memory category of server implementations.
