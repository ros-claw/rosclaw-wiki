> 🐍 ☁️ - Reclaim.ai calendar integration with 40 tools for tasks, habits, focus time, scheduling links, and productivity analytics.

This project is an MCP server that integrates Reclaim.ai, a smart calendar platform, into AI agent workflows. It provides over 40 tools for managing tasks, habits, focus time, scheduling links, and productivity analytics. The server allows AI assistants to directly interact with Reclaim.ai to automate scheduling and productivity optimization. It is suitable for workplace productivity enhancement within AI tool ecosystems.
