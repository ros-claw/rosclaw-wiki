> 🐍 ☁️ - Trade Robinhood through natural language. Portfolio analysis, real-time quotes, and order execution via Claude Code.

Trayd-MCP is a server implementation for the Model Context Protocol that allows users to trade on Robinhood using natural language. It provides capabilities for portfolio analysis, real-time stock quotes, and order execution. The tool is designed to work with Claude Code, enabling AI-assisted trading. It is listed under Finance & Fintech in the MCP server repository.
