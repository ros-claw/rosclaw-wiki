> 📇 ☁️ - MCP server implementation for ChatterBox.io, enabling AI agents to send bots to online meetings (Zoom, Google Meet) and obtain transcripts and recordings.

This project implements an MCP server that integrates with ChatterBox.io, allowing AI agents to deploy bots into online meetings on platforms like Zoom and Google Meet. The bots can capture transcripts and recordings, which are then made available for processing. It facilitates automated meeting attendance and data extraction for AI-driven insights.
