The BotBell MCP server enables AI assistants to send push notifications to Apple devices (iPhone, iPad, Mac). It supports two-way messaging, allowing users to reply directly in the BotBell app, which the AI can then read and continue the conversation. Additional features include action buttons, Markdown formatting, and multi-bot management using PATs.
