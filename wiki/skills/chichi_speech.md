> A RESTful service for high-quality text-to-speech using Qwen3.

chichi-speech is a RESTful web service that converts text into high-quality speech using the Qwen3 model. It provides a simple API interface for generating natural-sounding audio from written input, making it suitable for integration into various applications. The service is designed for AI agents and embodied intelligence systems that require real-time or on-demand speech synthesis. It abstracts the complexities of TTS model inference behind a standard HTTP API, allowing developers to easily add voice output to their projects.
