> 🐍 🏠 - An MCP Server to connect to searXNG instances

SecretiveShell/MCP-searxng is a Model Context Protocol (MCP) server that enables AI agents to perform web searches by connecting to SearXNG instances. It exposes search functionality as MCP tools, returning structured results like titles, URLs, and snippets. This allows MCP-compatible assistants to gather real-time web data for tasks such as fact-checking, research, and information extraction. The server can be configured with multiple SearXNG endpoints for redundancy or customized search behavior.
