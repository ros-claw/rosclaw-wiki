> 📇 ☁️ 🏠 - Token-efficient access to OpenAPI/Swagger specs via MCP Resources.

This project provides an MCP (Model Context Protocol) server that exposes OpenAPI and Swagger specifications as MCP Resources. It enables token-efficient access for AI agents to browse and utilize API schemas without excessive token usage. The tool is intended for developers who want to integrate API documentation into AI assistants in a structured manner.
