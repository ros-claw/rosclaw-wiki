> 🐍 ☕ 🏠 - MCP server for integrating Ghidra with AI assistants. This plugin enables binary analysis, providing tools for function inspection, decompilation, memory exploration, and import/export analysis via the Model Context Protocol.

GhidraMCP is a Model Context Protocol (MCP) server that integrates the Ghidra reverse engineering framework with AI assistants. It enables binary analysis tasks such as function inspection, decompilation, memory exploration, and import/export analysis. By exposing Ghidra's capabilities through the MCP interface, it allows AI agents to interact with and analyze binary programs programmatically. The project is listed under server implementations with a focus on security, indicating its use in security research and vulnerability analysis. This integration streamlines automated binary analysis workflows in AI-driven tooling.
