Inline rendering using MCP Apps UI and editable diagram URLs. Requires API key.

This MCP server integrates with AI Diagram Maker to generate various diagrams such as flowcharts, sequence diagrams, ERDs, UML, and mind maps. It accepts inputs in natural language, code, ASCII art, images, or Mermaid format. The server supports inline rendering through MCP Apps UI and provides editable diagram URLs. An API key is required to use the service.
