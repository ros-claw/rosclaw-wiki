> 📇 ☁️ - Deterministic refund eligibility notary MCP server. Returns ALLOWED / DENIED / UNKNOWN for subscription refunds (Adobe, Spotify, etc.) via a stateless rules engine.

This MCP server provides deterministic refund eligibility checking for subscriptions like Adobe and Spotify. It uses a stateless rules engine to return ALLOWED, DENIED, or UNKNOWN responses. It is listed under Finance & Fintech server implementations. The project aims to automate refund decisions in a predictable manner.
