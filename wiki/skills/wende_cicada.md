> 🐍 🏠 🍎 🪟 🐧 - Code Intelligence for Elixir: module search, function tracking, and PR attribution through tree-sitter AST parsing

Cicada is a code intelligence tool for the Elixir programming language. It enables module search, function tracking, and attribution of pull request changes. The tool leverages tree-sitter for abstract syntax tree (AST) parsing to understand code structure. It is listed as a server implementation under coding agents, suggesting it can be integrated into automated development workflows.
