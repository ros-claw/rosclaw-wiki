Create a test, get seed addresses, see per-provider placement (Inbox/Spam/Promotions), SPF/DKIM/DMARC verdicts, and screenshots. Install: `npx -y ldm-inbox-check-mcp`.

This MCP server tests email inbox placement across major providers like Gmail, Outlook, Yahoo, Mail.ru, and Yandex. It creates tests, generates seed addresses, and returns per-provider placement status (Inbox/Spam/Promotions) along with SPF/DKIM/DMARC verdicts and screenshots. The tool is designed for marketers and email senders to verify deliverability and identify issues before campaign launches. It can be installed quickly via npx without additional configuration.
