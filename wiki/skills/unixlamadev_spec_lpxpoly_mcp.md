This MCP server provides analysis of Polymarket prediction markets via LightningProx. It allows users to find mispriced markets, analyze specific markets, and get top markets by volume. Each request is paid per-use with Bitcoin Lightning spend tokens, enabling decentralized, real-time market data access.
