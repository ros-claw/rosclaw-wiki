> Reformats documentation to use React Stepper component, transforming heading formats, applying proper indentation, and maintaining markdown compatibility with admonition formatting.

This tool reformats documentation to use a React Stepper component, converting heading formats and applying proper indentation. It ensures markdown compatibility while preserving admonition formatting. The command is useful for structuring step-by-step documentation in a visual stepper UI.
