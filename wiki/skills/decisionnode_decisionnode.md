> [![decisionnode/DecisionNode MCP server](https://glama.ai/mcp/servers/decisionnode/DecisionNode/badges/score.svg)](https://glama.ai/mcp/servers/decisionnode/DecisionNode) 📇 🏠 🍎 🪟 🐧 - Record development decisions as structured JSON, embed as vectors via Gemini, and search semantically over MCP. Shared store across Claude Code, Cursor, Windsurf, and any MCP client. CLI + MCP server, local-only, free Gemini embedding tier.

DecisionNode is a tool for recording and retrieving development decisions as structured JSON. It uses Gemini to embed decisions as vectors, enabling semantic search over the Model Context Protocol (MCP). The shared store works across multiple MCP clients like Claude Code, Cursor, and Windsurf, and runs locally with a CLI and MCP server. It relies on the free tier of Gemini embeddings, making it accessible for local development workflows without external costs.
