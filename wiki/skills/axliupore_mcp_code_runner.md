> 📇 🏠 - An MCP server for running code locally via Docker and supporting multiple programming languages.

This MCP server enables AI assistants to run code in multiple programming languages by executing it inside Docker containers. It provides secure, isolated code execution for development and testing scenarios. The server supports languages such as Python, JavaScript, C++, and more. It is designed for use with the Model Context Protocol to allow agents to run arbitrary code locally.
