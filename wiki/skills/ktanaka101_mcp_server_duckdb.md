> 🐍 🏠 - DuckDB database integration with schema inspection and query capabilities

This MCP server provides integration with DuckDB, an embedded SQL database. It allows schema inspection and running queries against DuckDB from within a Model Context Protocol (MCP) environment. The server enables AI agents to interact with local or in-memory databases using SQL commands. It supports table listing, schema discovery, and query execution. This is useful for data analysis tasks where an AI needs to query structured data.
