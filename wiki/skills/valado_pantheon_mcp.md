> 🤖 - MCP server providing task specific agentic instructions. No more outdated Markdown files and synchronisation overhead.

This project is a Model Context Protocol (MCP) server that delivers task-specific agentic instructions. It aims to replace outdated markdown files and eliminate synchronization overhead by providing fresh instructions to AI agents on demand.
