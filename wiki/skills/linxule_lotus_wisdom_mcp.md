> 📇 🏠 ☁️ - Contemplative problem-solving using the Lotus Sutra's wisdom framework. Multi-perspective reasoning with skillful means, non-dual recognition, and meditation pauses. Available as local stdio or remote Cloudflare Worker.

This MCP server implements contemplative problem-solving inspired by the Lotus Sutra's wisdom framework. It enables multi-perspective reasoning, skillful means, non-dual recognition, and integrated meditation pauses. Designed as a Knowledge & Memory server, it can run via local stdio or as a remote Cloudflare Worker. The approach blends philosophical insight with practical reasoning for complex problem resolution.
