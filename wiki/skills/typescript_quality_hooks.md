> Quality check hook for Node.js TypeScript projects with TypeScript compilation. ESLint auto-fixing, and Prettier formatting. Uses SHA256 config caching for < 5ms validation performance during real-time editing.

TypeScript Quality Hooks is a tool that provides quality check hooks for Node.js TypeScript projects. It integrates TypeScript compilation, ESLint auto-fixing, and Prettier formatting into a single hook. The tool uses SHA256-based configuration caching to achieve validation performance under 5 milliseconds during real-time editing. It is designed to ensure code quality and consistency in TypeScript projects.
