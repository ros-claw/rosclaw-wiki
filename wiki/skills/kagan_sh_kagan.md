kagan-sh/kagan is an AI-powered Kanban terminal UI and MCP server that orchestrates 14 coding agents for autonomous development workflows. It manages task tracking, isolated git worktrees, code review, and merge operations. The tool integrates with the Model Context Protocol to enable AI agents to interact with development tasks.
