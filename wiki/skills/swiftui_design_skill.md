> SwiftUI 前端设计 skill — 反 AI Slop 六条铁律、设计方向顾问、品牌资产协议、五维评审。支持 Claude Code / Cursor / Codex / OpenCode 等全部 AI agent 平台。

This project defines a skill for SwiftUI frontend design that enforces six principles against generic AI-generated designs ('AI Slop'), acts as a design direction advisor, manages brand assets through a protocol, and applies a five-dimensional review process. It is designed for use across multiple AI agent platforms including Claude Code, Cursor, Codex, and OpenCode. The goal is to produce high-quality, brand-consistent user interfaces with the help of AI, avoiding low-quality automated outputs.
