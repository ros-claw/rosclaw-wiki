> 🐍 📟 - An MCP server that connects to OPC UA-enabled industrial systems.

This MCP server connects AI agents to OPC UA-enabled industrial systems, enabling read/write access to real-time data points and browsing of the OPC UA address space. It is designed for embedded systems and industrial automation scenarios. The server facilitates interaction between AI models and factory floor equipment via the Model Context Protocol.
