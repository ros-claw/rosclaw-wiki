> 🏎 🏠/☁️ 🐧/🍎 - An MCP server in Go for Lightpanda, the ultra fast headless browser designed for web automation

Lightpanda is a fast, headless browser designed for web automation, and this project implements an MCP server in Go to integrate it with AI agents. The server allows AI models to control the browser for tasks like web scraping and testing via the Model Context Protocol. It runs on Linux, macOS, and in cloud/container environments, making it versatile for automation pipelines. The focus is on high performance and low resource usage compared to full browsers.
