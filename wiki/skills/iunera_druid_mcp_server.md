> ☕ ☁️ 🏠 - Comprehensive MCP server for Apache Druid that provides extensive tools, resources, and prompts for managing and analyzing Druid clusters.

This project is an MCP (Model Context Protocol) server specifically designed for Apache Druid, a real-time analytics database. It provides a comprehensive set of tools, resources, and prompts to help AI agents interact with and manage Druid clusters. Users can execute queries, explore schema, and monitor cluster health through standardized MCP interfaces. The server bridges AI assistants like Claude with Druid's analytical capabilities.
