This .NET client library enables developers to integrate Azure AI Document Intelligence into their applications, extracting text, tables, key-value pairs, and structures from documents. It supports both prebuilt and custom models for tasks like invoice processing, form understanding, and OCR. The library is part of the Azure SDK for .NET and is listed under sponsored .NET skills.
