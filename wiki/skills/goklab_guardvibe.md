GuardVibe is a security tool designed as an MCP (Model Context Protocol) server for vibe coding workflows. It scans AI-generated code across 25+ modules (Next.js, Supabase, Clerk, Stripe, Prisma, Hono, GraphQL, etc.) using 330 security rules and 29 tools. Features include cross-file taint analysis, host security audit, automatic code fixes, SARIF export, pre-commit hooks, and CVE version detection. It requires no configuration and runs entirely locally.
