> [![mcp-tautulli MCP server](https://glama.ai/mcp/servers/lodordev/mcp-tautulli/badges/score.svg)](https://glama.ai/mcp/servers/lodordev/mcp-tautulli) 🐍 🏠 - Tautulli (Plex media server monitoring) with 11 read-only tools for activity, history, library stats, user stats, transcode analysis, and resolution breakdowns.

This MCP server integrates with Tautulli to provide read-only access to Plex media server monitoring data. It exposes 11 tools that allow AI agents to query current activity, historical usage, library statistics, user stats, transcode analysis, and resolution breakdowns. Designed for the monitoring category, it enables assistants to retrieve real-time metrics from a Plex environment without making modifications.
