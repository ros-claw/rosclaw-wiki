Scan from Claude/Cursor, opens a browser UI for human review (human-in-the-loop), applies fixes with explicit confirmation. Powered by OSV.dev.

This tool provides a visual dashboard for auditing CVEs in dependencies for npm, Python, Go, and Rust. It can be invoked from Claude or Cursor to scan dependencies, then opens a browser UI for human review before applying fixes. The workflow follows a human-in-the-loop pattern, requiring explicit confirmation for each fix. It is powered by OSV.dev, an open-source vulnerability database.
