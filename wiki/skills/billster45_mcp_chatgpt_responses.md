> 🐍 ☁️ - MCP server for Claude to talk to ChatGPT and use its web search capability.

This project is an MCP server that bridges Claude, an AI assistant, with ChatGPT, enabling Claude to access ChatGPT's web search capabilities. It allows Claude to make queries to ChatGPT and retrieve web search results through the Model Context Protocol. The integration expands Claude's functionality by leveraging ChatGPT's search features.
