Search vessels, get real-time positions, ETAs, port events, emissions, inspections, and NAVTEX safety messages.

The vessel-api/vesselapi-mcp project is an MCP server that enables AI agents to access maritime vessel tracking data via the VesselAPI service. It allows users to search for vessels, retrieve real-time positions, estimated times of arrival, port events, emissions data, inspections, and NAVTEX safety messages. This tool integrates with AI assistants to provide up-to-date maritime information through the Model Context Protocol. It is listed under Travel & Transportation server implementations.
