> 📇 ☁️ - An MCP server for interacting with [Bugsnag](https://www.bugsnag.com/)

This is an MCP server that integrates with the Bugsnag error monitoring platform. It provides tools and resources to interact with Bugsnag's API, allowing users to view and manage error reports, projects, and more. Designed for developers, it can be used to query bugs and errors from within AI assistants and tools via the Model Context Protocol.
