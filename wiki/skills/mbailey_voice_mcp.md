> 🐍 🏠 - Complete voice interaction server supporting speech-to-text, text-to-speech, and real-time voice conversations through local microphone, OpenAI-compatible APIs, and LiveKit integration

This project provides a voice interaction server for the Model Context Protocol. It supports speech-to-text, text-to-speech, and real-time conversational capabilities. The server can use a local microphone, OpenAI-compatible APIs, or LiveKit for voice processing. It is categorized under Text-to-Speech server implementations in the MCP ecosystem.
