> Secure sync for OpenClaw memory and workspace.

claw-sync is a tool that provides secure synchronization for the memory and workspace of the OpenClaw AI agent. It ensures that the agent's state is consistently backed up and shared across sessions or devices. The synchronization focuses on security to protect the agent's data. This tool is part of the ecosystem for embodied intelligence and AI agent tooling.
