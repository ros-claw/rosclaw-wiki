> 🐍 ☁️ - An MCP server that provides real-time data and insights from the Hyperliquid perp DEX for use in bots, dashboards, and analytics.

This project is an MCP (Model Context Protocol) server that provides real-time data and insights from the Hyperliquid perpetual decentralized exchange (perp DEX). It is designed to be used in bots, dashboards, and analytics applications, enabling automated trading and monitoring. The server acts as a bridge between AI agents or other tools and on-chain data from Hyperliquid, offering easy access to market information.
