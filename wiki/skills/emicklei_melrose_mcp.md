> 🏎️ 🏠 - Plays [Melrōse](https://melrōse.org) music expressions as MIDI

This project is a Model Context Protocol (MCP) server that enables AI agents to play music expressions written in the Melrōse language as MIDI output. It acts as a bridge between AI systems and real-time music generation, allowing agents to compose and perform musical pieces. The server integrates with the Melrōse environment to convert symbolic music expressions into audible MIDI signals. It is listed under server implementations for search and data extraction, but its primary function is music synthesis.
