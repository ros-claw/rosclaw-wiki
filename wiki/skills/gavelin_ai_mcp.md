Speaker-attributed hearing transcripts, bills, votes, and AI-generated reports from US state legislatures. Remote server at mcp.gavelin.ai/mcp.

This MCP server provides AI agents with access to US state legislative data, including speaker-attributed hearing transcripts, bills, votes, and AI-generated reports. It is a remote server hosted at mcp.gavelin.ai/mcp, designed to integrate state legislative intelligence into AI workflows. The tool allows agents to query and retrieve structured legal information from across US state legislatures.
