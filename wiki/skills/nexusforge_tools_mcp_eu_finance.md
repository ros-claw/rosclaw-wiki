> 📇 🏠 ☁️ - European financial data for AI agents — ECB rates, Eurostat inflation, GDP and unemployment by EU country. Zero API key needed. [![nexusforge-tools/mcp-eu-finance MCP server](https://glama.ai/mcp/servers/nexusforge-tools/mcp-eu-finance/badges/score.svg)](https://glama.ai/mcp/servers/nexusforge-tools/mcp-eu-finance)

This MCP server provides European financial and economic data for AI agents, including ECB interest rates, Eurostat inflation statistics, GDP figures, and unemployment rates by EU country. It requires zero API keys, making it easy to integrate. The server enables agents to access up-to-date financial indicators without authentication overhead. It is listed under Finance & Fintech server implementations.
