> 🏎️ ☁️ - An SSE-based MCP server that allows LLM-powered applications to interact with OCI registries. It provides tools for retrieving information about container images, listing tags, and more.

This project implements an SSE-based MCP server that enables LLM-powered applications to query and interact with OCI registries. It provides tools for retrieving container image metadata and listing tags within a registry. The server uses the Server-Sent Events protocol for real-time communication. It is designed for cloud platform environments where container images are stored and managed.
