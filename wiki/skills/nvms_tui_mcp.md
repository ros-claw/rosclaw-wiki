> [![tui-mcp MCP server](https://glama.ai/mcp/servers/nvms/tui-mcp/badges/score.svg)](https://glama.ai/mcp/servers/nvms/tui-mcp) 📇 🏠 🍎 🪟 🐧 - What Chrome DevTools MCP is for the browser, tui-mcp is for the terminal. Launch, screenshot, and interact with any TUI app.

tui-mcp is an MCP server that allows AI agents to launch, take screenshots of, and interact with any terminal user interface (TUI) application. It serves as the terminal equivalent of Chrome DevTools MCP for browsers, enabling agents to control command-line tools visually. The server integrates with MCP-compatible clients to provide real-time access to terminal programs.
