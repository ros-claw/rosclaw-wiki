> Anthropic's guide to a production-oriented agent SDK with sessions, tools, and orchestration support.

The Claude Agent SDK from Anthropic is a production-oriented framework for building AI agents. It supports sessions, tools, and orchestration, making it suitable for complex agent workflows. The SDK provides a structured way to define agent behavior with tool integration and state management. It aims to simplify the development of reliable and scalable agent applications.
