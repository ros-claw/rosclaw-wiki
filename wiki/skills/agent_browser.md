> A fast Rust-based headless browser automation CLI.

Agent Browser is a command-line tool written in Rust for fast, headless browser automation. It enables users to automate web interactions without a visible browser interface. The tool is optimized for performance, leveraging Rust's speed and safety. It is designed for developers and testers who need efficient browser control for tasks like web scraping or automated testing. Agent Browser provides a simple CLI interface for scripting browser actions.
