> 🐍 🍎/🐧 ☁️ - mcp server for [cert-manager](https://github.com/cert-manager/cert-manager) management and troubleshooting

This project is a Model Context Protocol (MCP) server for managing and troubleshooting cert-manager, a Kubernetes certificate management tool. It is written in Python and supports Apple and Linux platforms. The server enables AI agents to automate TLS certificate operations in cloud environments, such as issuing, renewing, and debugging certificates. It provides a programmatic interface for integrating certificate management into AI-driven workflows.
