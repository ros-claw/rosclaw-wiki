> 🐍 ☁️ - Providing real-time funding rate data across major crypto exchanges.

This project provides real-time funding rate data from major cryptocurrency exchanges via the Model Context Protocol (MCP). It enables AI agents and applications to access funding rate information for trading and analysis. The server aggregates data from multiple exchanges, allowing comparison and arbitrage opportunities. It simplifies integrating funding rate data into AI workflows, particularly for finance and fintech applications.
