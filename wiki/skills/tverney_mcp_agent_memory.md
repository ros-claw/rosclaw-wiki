Agents read/write/search memory through MCP; a background daemon handles consolidation and extraction. Works with Kiro, Claude Desktop, Cursor, and any MCP client. `npx mcp-agent-memory --setup`

This MCP server provides persistent memory for AI agents using a filesystem-based daemon. Agents can read, write, and search memory through the MCP protocol, while a background daemon handles consolidation and extraction. It is compatible with multiple clients including Kiro, Claude Desktop, and Cursor. Setup is done via npx with a single command.
