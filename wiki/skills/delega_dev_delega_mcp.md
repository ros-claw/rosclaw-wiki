Delega MCP is a task management API specifically designed for AI agents. It allows agents to create, delegate, and track tasks with features like agent identity, delegation chains, lifecycle webhooks, and persistent context. The server can be self-hosted or accessed via a hosted tier at delega.dev. It is listed under Workplace & Productivity server implementations.
