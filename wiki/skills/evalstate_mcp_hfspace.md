> 📇 ☁️ - Use HuggingFace Spaces directly from Claude. Use Open Source Image Generation, Chat, Vision tasks and more. Supports Image, Audio and text uploads/downloads.

This is a Model Context Protocol (MCP) server that enables Claude to directly interact with Hugging Face Spaces. It provides access to open-source AI tasks such as image generation, chat, and vision, and supports uploading and downloading images, audio, and text. Users can leverage Hugging Face Spaces through Claude's interface without leaving the chat environment.
