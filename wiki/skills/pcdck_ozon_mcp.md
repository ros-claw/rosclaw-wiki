This project provides a Model Context Protocol (MCP) server that fully integrates with the Ozon Seller and Performance APIs, exposing 466 methods and 15 MCP tools. It handles auto-pagination with four cursor styles, pre-flight checks for subscription tiers, and rate-limit management with exponential backoff. The server includes 13 curated analytical workflows for tasks such as out‑of‑stock risk assessment, cabinet health analysis, content auditing, pricing, and warehouse distribution. It also supports BM25‑based search in both Russian and English across the Ozon catalog.
