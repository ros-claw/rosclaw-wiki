PhpCodeArcheology is a Model Context Protocol (MCP) server that provides static analysis for PHP codebases. It offers 11 tools exposing over 60 code quality metrics, including dependency graphs, git hotspots, test coverage, and impact analysis. The tool helps developers understand architecture, detect problems, and prioritize refactoring. It is installable via Composer and supports multiple platforms.
