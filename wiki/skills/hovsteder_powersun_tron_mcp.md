Remote Streamable HTTP with 3 payment methods (API Key, HTTP 402, x402 USDC).

This MCP server enables AI agents to interact with the TRON blockchain by providing tools for buying and selling energy and bandwidth, swapping TRC-20 tokens via the SunSwap DEX, and earning passive income. It offers 27 distinct tools covering marketplace operations and token swaps, and supports three payment methods including API key, HTTP 402, and x402 USDC. The server communicates over Remote Streamable HTTP, making it suitable for agentic workflows in decentralized finance (DeFi).
