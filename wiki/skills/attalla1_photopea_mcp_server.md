This project is an MCP server that connects AI agents to Photopea, a web-based image editor. It provides 34 tools for tasks like document management, layering, text, shapes, filters, effects, and exporting. The server can be launched simply with 'npx photopea-mcp-server', enabling AI-driven image editing workflows. It is listed under Art & Culture in the MCP server registry.
