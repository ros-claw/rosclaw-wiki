> 📇 ☁️ - An MCP server that provides comprehensive US legislation.

This is an MCP server that provides comprehensive access to US legislation. It allows AI agents to query and retrieve legal information from United States laws and regulations. The tool is designed for use with the Model Context Protocol, enabling integration into AI workflows. It simplifies legal research by providing structured access to legislative data.
