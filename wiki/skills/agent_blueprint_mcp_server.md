The agent-blueprint/mcp-server is an MCP server that provides 8 tools for exploring and downloading AI agent blueprints. It allows agents to list blueprints, get summaries, and download full Agent Skills directories for implementation. The output is vendor-agnostic and works with any enterprise platform. Installation is done via npx agentblueprint. This server is specifically designed for coding agents to easily access and integrate blueprint resources.
