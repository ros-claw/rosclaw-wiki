> 📇 🏠 🍎 🪟 🐧 – A secure MCP (Model Context Protocol) server that enables AI agents to interact with the Authenticator App.

This project provides a secure Model Context Protocol (MCP) server that enables AI agents to interact with the Authenticator app, allowing retrieval and management of one-time passwords (OTPs) for two-factor authentication. It supports multiple platforms (macOS, Windows, Linux) and maintains security by requiring user consent for sensitive operations. AI assistants can use this server to fetch verification codes, list accounts, and add new TOTP entries, automating authentication workflows within agent systems. The tool is designed for privacy and security, with all processing happening locally on the user's machine.
