> 📇 🏠 - Open-source CLI and MCP server for LinkedHelper automation — 32 tools for campaign management, messaging, and profile queries via Chrome DevTools Protocol.

This open-source tool provides a CLI and MCP server for automating LinkedIn actions through LinkedHelper. It offers 32 tools to manage campaigns, send messages, and query profiles. The automation works by controlling the browser through Chrome DevTools Protocol. This allows developers to integrate LinkedIn automation into their workflows programmatically. It is listed under server implementations for marketing use cases.
