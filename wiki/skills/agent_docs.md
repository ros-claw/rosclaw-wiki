> Create documentation optimized for AI agent consumption.

Agent-docs is a project for creating documentation specifically designed to be easily consumed by AI agents. This likely involves structured formats, clear metadata, and optimized phrasing to improve agent understanding and task performance. The goal is to bridge the gap between human-written docs and machine parsing, making it simpler for AI tools to extract relevant information. It may include guidelines, templates, or tools for converting existing docs into agent-friendly formats.
