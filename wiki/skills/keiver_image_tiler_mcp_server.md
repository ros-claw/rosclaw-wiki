> [![image-tiler-mcp-server MCP server](https://glama.ai/mcp/servers/keiver/image-tiler-mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/keiver/image-tiler-mcp-server) 📇 🏠 🍎 🪟 🐧 - Full-resolution vision for LLMs. Tiles large images and captures web pages via Chrome CDP so vision models process every detail without downscaling. Generates interactive HTML tile previews. Supports Claude, OpenAI, Gemini presets with per-model token math and entropy-based tile classification.

This MCP server provides full-resolution vision processing for large images and web pages by tiling them before passing to AI models like Claude, OpenAI, or Gemini. It uses Chrome CDP to capture web pages without compromising details, generating interactive HTML previews of the tiles. The server includes preset configurations for different models with token-aware math and entropy-based classification to optimize processing. This approach avoids downscaling, ensuring vision models receive complete visual information for accurate understanding.
