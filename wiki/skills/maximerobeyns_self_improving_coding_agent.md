This project introduces a self-improving coding agent that autonomously generates, tests, and refines code using large language models. It iteratively improves its outputs by learning from test failures and error messages, aiming to produce higher-quality code without human intervention. The agent is designed as a general-purpose tool for automated code generation and debugging, with applications in software development and AI-assisted programming. Its approach combines iterative feedback loops with LLM-based code synthesis to achieve continuous improvement.
