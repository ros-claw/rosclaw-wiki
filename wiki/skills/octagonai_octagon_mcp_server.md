> 🐍 ☁️ - Octagon AI Agents to integrate private and public market data

OctagonAI/octagon-mcp-server is an MCP server implementation for integrating AI agents with financial market data. It focuses on both private and public market data, enabling seamless access through the Model Context Protocol. The project is listed under finance and fintech server implementations, highlighting its relevance to financial data analysis. It allows AI agents to query and interact with market data in a standardized way.
