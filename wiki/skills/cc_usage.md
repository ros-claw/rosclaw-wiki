> Handy CLI tool for managing and analyzing Claude Code usage, based on analyzing local Claude Code logs. Presents a nice dashboard regarding cost information, token consumption, etc.

CC Usage is a command-line tool that helps manage and analyze usage of Claude Code by reading local Claude Code logs. It provides a dashboard showing cost information, token consumption, and other usage statistics. This tool is useful for tracking spending and usage patterns of the Claude Code AI coding assistant. It falls under the category of usage monitors for AI agent tooling.
