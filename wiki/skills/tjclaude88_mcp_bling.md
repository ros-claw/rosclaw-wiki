This MCP server gives AI agents a persistent identity and cross-platform visual style. It includes a random-identity generator called 'WOW' (Weird Office Workers) with rarity tiers for uniqueness. It also provides screenshot-ready share cards for visual identity sharing. The tool can be run with the npx command 'bling-bag'.
