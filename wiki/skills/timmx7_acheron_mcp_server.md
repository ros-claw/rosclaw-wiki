Bridges context between Claude Chat, Code, and Cowork via local SQLite with full-text search. Save decisions, preferences, and insights in one surface, retrieve them in any other.

This project is a Model Context Protocol (MCP) server that provides cross-surface persistent memory for Claude AI across different interfaces like Chat, Code, and Cowork. It stores decisions, preferences, and insights using a local SQLite database with full-text search capabilities. Users can save information on one surface and retrieve it on any other, enabling continuity and context sharing.
