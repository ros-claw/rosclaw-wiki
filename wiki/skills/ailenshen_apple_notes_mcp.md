Fast SQLite queries for listing/searching, AppleScript + native import for full CRUD. Supports stdio and Streamable HTTP transports.

This MCP server provides an interface for AI agents to read, write, and manage Apple Notes through bidirectional Markdown conversion. It uses fast SQLite queries for listing and searching notes, while full create, read, update, and delete operations are handled via AppleScript and native import. The server supports both stdio and Streamable HTTP transports, making it easy to integrate with various MCP clients. Essentially, it bridges Apple Notes with AI workflows by exposing note content in a structured, machine-readable format.
