> 🐍 🏠 - Modern, secure MCP server for accessing ZIM format knowledge bases offline. Enables AI models to search and navigate Wikipedia, educational content, and other compressed knowledge archives with smart retrieval, caching, and comprehensive API.

openzim-mcp is a Model Context Protocol (MCP) server designed to provide offline access to ZIM-format knowledge bases, such as Wikipedia snapshots. It allows AI models to efficiently search, retrieve, and navigate compressed archives without an internet connection. The server includes smart caching and a comprehensive API, enabling secure and fast knowledge retrieval for embodied-intelligence and agent-based systems.
