> 🐍 🏠 - MCP Server for querying GreptimeDB.

GreptimeDB MCP Server is a tool that enables AI models to query GreptimeDB using the Model Context Protocol. It serves as a bridge between large language models and the time-series database for natural language querying. This server implementation facilitates database retrieval and analysis via standardized MCP interfaces.
