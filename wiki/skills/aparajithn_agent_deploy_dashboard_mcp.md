> [![agent-deploy-dashbaord MCP server](https://glama.ai/mcp/servers/@aparajithn/agent-deploy-dashbaord/badges/score.svg)](https://glama.ai/mcp/servers/@aparajithn/agent-deploy-dashbaord) 🐍 ☁️ - Unified deployment dashboard MCP server across Vercel, Render, Railway, and Fly.io. 9 tools for deploy status, logs, environment variables, rollback, and health checks across all platforms. Free tier with x402 micropayments.

This project is an MCP (Model Context Protocol) server that provides a unified deployment dashboard across multiple cloud platforms including Vercel, Render, Railway, and Fly.io. It offers nine tools for managing deployments, such as checking status, viewing logs, handling environment variables, performing rollbacks, and running health checks. The server is free to use with an integrated micropayment system (x402) for extended functionality. It simplifies multi-cloud deployment monitoring by centralizing operations through a single MCP interface.
