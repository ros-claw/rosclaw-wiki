> 📇 ☁️ - An MCP server to interface with the Google Calendar API. Based on TypeScript.

This MCP server provides an interface for AI agents to interact with the Google Calendar API. It allows reading, creating, updating, and deleting calendar events through the Model Context Protocol. Built with TypeScript, it serves as a bridge between AI assistants and Google Calendar data.
