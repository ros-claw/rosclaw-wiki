> 🎖️ 📇 ☁️ - MCP Server for Lara Translate API, enabling powerful translation capabilities with support for language detection and context-aware translations.

This project is an MCP (Model Context Protocol) server that wraps the Lara Translate API, allowing AI agents to perform translations, detect languages, and handle context-aware translations. It is designed for integration with tools like Claude Desktop, enabling seamless multilingual communication. The server supports both standard and enhanced translation features through a simple API interface.
