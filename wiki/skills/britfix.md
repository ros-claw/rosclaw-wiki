> Claude outputs American spellings by default, which can have an impact on: professional credibility, compliance, documentation, and more. Britfix converts to British English, with a Claude Code hook for automatic conversion as files are written. Context-aware: handles code files intelligently by only converting comments and docstrings, never identifiers or string literals.

Britfix is a tool that automatically converts American English spellings to British English in text and code files. It is designed as a Claude Code hook, ensuring that outputs are automatically transformed during development. This conversion helps maintain professional credibility, compliance with British English standards, and consistency in documentation. The tool is context-aware, intelligently handling code files by converting only comments and docstrings while leaving identifiers and string literals unchanged.
