> Get the current macOS Focus.

A command-line utility that retrieves the current macOS Focus mode (e.g., Do Not Disturb, Sleep, Work, Personal). It runs a simple script to query the system's focus state and returns the result in a machine-readable format. Useful for automation scripts or status bar integrations. Installation is typical via Homebrew or manual download.
