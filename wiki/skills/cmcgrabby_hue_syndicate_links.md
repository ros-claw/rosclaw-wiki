This MCP server provides AI agents with infrastructure for affiliate commission programs. It includes seven tools for program discovery, attribution tracking, commission status, and payouts. The system uses signed attribution tokens to track conversions and can trigger settlement cycles. It is installable via npx syndicate-links-mcp and listed under E-Commerce server implementations.
