Scans, analyzes, and remediates LangChain/CrewAI/AutoGen/OpenAI code across 6 articles with 10 tools including prompt injection detection, risk classification, and trust layer integration. The only MCP compliance server that generates fix code, not just findings.

The air-blackbox-mcp server is a Model Context Protocol (MCP) tool designed to scan Python AI agent code—such as that from LangChain, CrewAI, AutoGen, and OpenAI—for compliance with the European Union's AI Act. It provides 10 distinct tools covering six articles of the Act, including capabilities for prompt injection detection, risk classification, and trust layer integration. Unlike many compliance scanners, this tool not only identifies issues but also generates fix code to remediate them. This makes it a practical solution for developers who need to ensure their AI agents are secure and compliant with EU regulations.
