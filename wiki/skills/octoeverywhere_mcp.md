> #️⃣ ☁️ - A 3D printer MCP server that allows for getting live printer state, webcam snapshots, and printer control.

OctoEverywhere/mcp is a Model Context Protocol (MCP) server that enables AI agents to interact with 3D printers in real time. It provides live printer state updates, webcam snapshots, and remote printer control through OctoEverywhere's cloud infrastructure. This allows AI assistants like Claude to monitor prints, check status, and send commands as part of a natural language interface. The project simplifies integrating 3D printer management into AI-driven workflows.
