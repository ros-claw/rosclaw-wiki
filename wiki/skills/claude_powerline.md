> A vim-style powerline statusline for Claude Code with real-time usage tracking, git integration, custom themes, and more

claude-powerline is a plugin that provides a vim-style powerline statusline for Claude Code. It offers real-time usage tracking to monitor API token consumption and other metrics. The tool integrates with Git to display branch and status information directly in the status bar. Users can customize the appearance with themes, making it flexible for different preferences. Overall, it enhances the Claude Code CLI with a familiar and informative status display.
