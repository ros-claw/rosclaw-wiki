Transcriptor MCP is a server designed for browser automation that specializes in extracting transcripts and metadata from web content. It is tailored for use in AI pipelines, summarization tasks, and content analysis workflows. The tool integrates with the Model Context Protocol (MCP) to provide structured data for downstream processing. Its primary goal is to enable efficient capture of video or audio transcripts and associated metadata for further AI-driven analysis.
