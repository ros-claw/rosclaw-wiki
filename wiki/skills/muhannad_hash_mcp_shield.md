mcp-shield is a security scanner for MCP (Model Context Protocol) servers that helps detect potential threats before installation. It identifies backdoors, exfiltration code, obfuscation, dangerous code execution, prompt injection, and supply chain risks. The tool offers four main functions: scanning npm packages, scanning local directories, checking for prompt injection, and auditing supply chain trust scores. It can be run via npx and is designed to enhance the security posture of MCP deployments.
