> 📇 ☁️ - Google Maps integration for location services, routing, and place details

This is a server implementation for the Model Context Protocol (MCP) that integrates Google Maps API. It provides tools for location services, routing, and place details, enabling AI agents to access geolocation data and maps functionality. The server is listed under Location Services in the MCP ecosystem and supports travel planning, navigation, and location-based queries.
