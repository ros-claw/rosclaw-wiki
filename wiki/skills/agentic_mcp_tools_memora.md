> 🐍 🏠 ☁️ - Persistent memory with knowledge graph visualization, semantic/hybrid search, cloud sync (S3/R2), and cross-session context management.

Memora is a persistent memory server for AI agents that stores and retrieves context across sessions using a knowledge graph. It supports semantic and hybrid search, cloud synchronization via S3 or R2, and includes visualization tools. Designed for MCP (Model Context Protocol), it enables agents to maintain long-term memory and cross-session context.
