> 📇 ☁️ - Search and retrieve GIFs from Giphy's vast library through the Giphy API.

This project is an MCP server that connects AI agents to the Giphy API, enabling them to search and retrieve GIFs from Giphy's large library. It acts as a bridge between AI tools and Giphy's content, allowing agents to incorporate animated images into their responses. The server implements the Model Context Protocol, making it compatible with various AI assistants and frameworks. It provides a simple interface for searching GIFs by keyword or fetching trending and random GIFs.
