> [![yyyhy/nash-arena MCP server](https://glama.ai/mcp/servers/yyyhy/nash-arena/badges/score.svg)](https://glama.ai/mcp/servers/yyyhy/nash-arena) 🐍 ☁️ - A Chess and Card Game Arena For LLM, Agents can battle in game by mcp

Nash Arena is an MCP server that provides a game arena where AI agents can compete in chess and card games. It allows multiple large language model (LLM) agents to battle each other using the Model Context Protocol. The server exposes tools for game interactions, enabling agents to make moves and play against opponents. This project demonstrates multi-agent competition and game-playing capabilities for LLM-based systems.
