> 📇 ☁️ 🍎 🪟 🐧 - MCP server providing comprehensive Datadog observability access for AI assistants. Features grep-like log search, APM trace filtering with duration/status/error queries, smart sampling modes for token efficiency, and cross-correlation between logs, traces, and metrics.

This project is a Model Context Protocol (MCP) server that gives AI assistants access to Datadog's observability data. It includes features like log search similar to grep, APM trace filtering based on duration, status, and error queries, and smart sampling modes to save tokens. The server also enables cross-correlation between logs, traces, and metrics for deeper insights. It is designed to help AI tools interact with Datadog's monitoring capabilities efficiently.
