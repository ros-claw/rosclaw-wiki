> 🎖️ ☁️ - Official Infobip MCP server for integrating Infobip global cloud communication platform. It equips AI agents with communication superpowers, allowing them to send and receive SMS and RCS messages, interact with WhatsApp and Viber, automate communication workflows, and manage customer data, all in a production-ready environment.

Infobip/mcp is an official MCP server that connects AI agents to Infobip's global cloud communication platform. It enables AI agents to send and receive SMS, RCS, WhatsApp, and Viber messages, as well as automate communication workflows and manage customer data. This server is designed for production use, giving AI systems powerful communication capabilities.
