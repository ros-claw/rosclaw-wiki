> 🐍 🏠 🍎 🪟 🐧 - Persistent memory for AI coding agents with semantic search, auto-capture, cross-session learning, and intelligent forgetting. 12 MCP tools, local-first.

Omega Memory provides persistent memory for AI coding agents, enabling semantic search, automatic context capture, cross-session learning, and intelligent forgetting. It offers 12 MCP (Model Context Protocol) tools for interaction and is designed as a local-first system, ensuring privacy and offline functionality.
