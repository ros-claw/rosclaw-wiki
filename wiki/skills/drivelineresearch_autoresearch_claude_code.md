> ![GitHub stars](https://img.shields.io/github/stars/drivelineresearch/autoresearch-claude-code?style=social) - Claude Code plugin/skill port of `pi-autoresearch`, with a clean experiment-loop workflow and a concrete biomechanics case study.

Autoresearch-claude-code is a plugin for Claude Code that ports the pi-autoresearch framework, providing a clean experiment-loop workflow for autonomous research. It includes a concrete biomechanics case study to demonstrate its capabilities. The project enables Claude Code agents to conduct iterative, self-directed research experiments efficiently.
