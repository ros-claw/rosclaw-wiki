Trace-MCP is an MCP server that provides framework-aware code intelligence by indexing source code into a cross-language dependency graph. It understands framework semantics such as routes, ORM relations, component rendering, and dependency injection trees to enable advanced code navigation and analysis. The tool supports impact analysis, call graphs, refactoring, security scanning, and cross-session memory for developer tools.
