> 📇 🏠 🍎 - An MCP server for interacting with Apple Reminders on macOS

This is a Model Context Protocol (MCP) server that allows AI assistants to interact with the Apple Reminders app on macOS. It enables creating, reading, updating, and deleting reminders programmatically. Despite being listed under Browser Automation, it directly interfaces with the native Reminders application. This integration helps AI agents manage tasks and to-do items on a Mac.
