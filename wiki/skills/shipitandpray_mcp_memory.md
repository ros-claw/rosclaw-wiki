This MCP server implements a smart memory system that uses exponential decay to automatically strengthen memories on access and fade them when unused. It solves the problem of unbounded context growth in AI agents by managing memory retention dynamically. The system provides 7 tools, is built on SQLite with zero dependencies, and operates as a lightweight knowledge and memory server for MCP.
