> [![indigo-mcp MCP server](https://glama.ai/mcp/servers/IndigoProtocol/indigo-mcp/badges/score.svg)](https://glama.ai/mcp/servers/IndigoProtocol/indigo-mcp) 📇 ☁️ 🏠 - MCP server for Indigo Protocol on Cardano — iAsset prices, CDP/loan analytics, stability pools, INDY staking, governance, and DEX data for LLM agents

Indigo Protocol's indigo-mcp is an MCP server that connects AI agents to the Indigo Protocol on the Cardano blockchain. It provides real-time data on iAsset prices, CDP/loan analytics, stability pools, INDY staking, governance, and DEX information. This enables LLM agents to interact with and analyze DeFi protocols on Cardano through a standardized interface. The server is designed to be used as a tool in AI agent frameworks, allowing them to fetch, query, and monitor on-chain financial data.
