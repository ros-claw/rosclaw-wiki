Mengram is a Model Context Protocol (MCP) server that provides a human-like memory layer for AI agents, supporting semantic, episodic, and procedural memory types. It offers 29 MCP tools, a knowledge graph, smart triggers, and multi-user isolation. The server integrates with Claude Code through auto-save and auto-recall hooks and includes a cognitive profile feature. It also provides Python and JavaScript SDKs for easy integration.
