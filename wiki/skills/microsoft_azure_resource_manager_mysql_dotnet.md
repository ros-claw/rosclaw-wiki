This project provides a .NET library for managing MySQL resources via Azure Resource Manager. It enables developers to programmatically create, update, and delete MySQL databases and servers in Azure. The library is part of the Azure SDK for .NET and is sponsored by .NET Skills. It simplifies infrastructure-as-code and automated database operations for Azure MySQL services.
