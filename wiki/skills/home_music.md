> Control whole-house music scenes combining Spotify playback.

home-music is a system for orchestrating synchronized music playback across multiple speakers or rooms in a home. It integrates with Spotify to allow users to create and control 'scenes' that define which tracks play where. The project likely provides an interface to group devices, adjust volumes per room, and manage playlists. This enables a cohesive whole-house audio experience from a single streaming service.
