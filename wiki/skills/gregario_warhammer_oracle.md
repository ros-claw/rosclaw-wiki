> [![gregario/warhammer-oracle MCP server](https://glama.ai/mcp/servers/gregario/warhammer-oracle/badges/score.svg)](https://glama.ai/mcp/servers/gregario/warhammer-oracle) 📇 🏠 - Warhammer 40K, Combat Patrol, and Kill Team rules reference with unit datasheets, keyword definitions, phase sequences, and game flow. 6 tools, 3148 units embedded.

This MCP server provides a comprehensive rules reference for Warhammer 40,000, including Combat Patrol and Kill Team. It offers tools to look up unit datasheets, keyword definitions, phase sequences, and overall game flow. The server includes a large embedded database of 3,148 units and exposes six tools for querying game information. It is designed for players and hobbyists who want quick, in-game access to official rules without flipping through physical books.
