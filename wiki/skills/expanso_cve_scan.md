> Scan SBOM for known CVE vulnerabilities.

Expanso CVE Scan is a tool that scans Software Bill of Materials (SBOM) files to identify known Common Vulnerabilities and Exposures (CVEs). It helps users detect security risks in their software dependencies by cross-referencing the SBOM against vulnerability databases. The tool automates the process of vulnerability assessment, enabling proactive security measures. It is particularly useful for teams managing open-source components and ensuring supply chain security.
