> Interact with aria2 download manager via JSON-RPC 2.0.

This project offers a JSON-RPC 2.0 interface for the aria2 download manager, enabling remote control and automation. It allows applications to send commands to aria2 using standard JSON-RPC calls over HTTP. Users can manage downloads, monitor progress, and integrate with other tools programmatically. The interface is language-agnostic and straightforward to implement, making it ideal for scripting and automation workflows.
