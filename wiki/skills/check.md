> Performs comprehensive code quality and security checks, featuring static analysis integration, security vulnerability scanning, code style enforcement, and detailed reporting.

/check is a slash-command tool that performs comprehensive code quality and security checks. It integrates static analysis to detect potential bugs and code smells, scans for security vulnerabilities, enforces coding style guidelines, and generates detailed reports. This helps developers maintain high code standards and identify issues early in development.
