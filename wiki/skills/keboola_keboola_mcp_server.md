> 🐍 - interact with Keboola Connection Data Platform. This server provides tools for listing and accessing data from Keboola Storage API.

The keboola-mcp-server is a Model Context Protocol (MCP) server implementation that enables AI agents to interact with the Keboola Connection Data Platform. It provides tools for listing and accessing data from the Keboola Storage API, allowing agents to retrieve structured data from tables and buckets. This server is useful for AI-powered data analysis, automation, and integration workflows within the Keboola ecosystem. It is categorized under Data Platforms in the MCP server implementations list.
