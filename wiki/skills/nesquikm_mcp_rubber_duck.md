> 📇 🏠 ☁️ - An MCP server that bridges to multiple OpenAI-compatible LLMs - your AI rubber duck debugging panel for explaining problems to various AI "ducks" and getting different perspectives

This is an MCP server that allows you to connect to multiple OpenAI-compatible LLMs simultaneously, acting as a panel of AI 'rubber ducks' for debugging. By explaining your code problems to different models, you can get diverse perspectives to help identify issues. It implements the Model Context Protocol (MCP) to bridge between your development environment and various AI assistants, facilitating the classic rubber duck debugging technique with modern AI.
