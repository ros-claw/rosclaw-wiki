> 📇 ☁️ - Free HTML/URL to PDF conversion API powered by Playwright. No API key required.

This project provides a free API for converting HTML or URLs into PDF files, powered by Playwright. No API key is required, making it easy to use for developers. The API is listed under Developer Tools in a server implementation category, designed for simple integration into applications. It leverages browser automation to render web pages or raw HTML into high-quality PDF documents.
