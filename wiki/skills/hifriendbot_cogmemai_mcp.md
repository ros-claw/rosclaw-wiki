> 📇 ☁️ 🍎 🪟 🐧 - Persistent cognitive memory for Claude Code. Cloud-first with semantic search, AI-powered extraction, and project scoping. Zero local databases.

cogmemai-mcp is an MCP server that provides persistent cognitive memory for Claude Code. It is cloud-first with no local databases, using semantic search and AI-powered extraction to remember and retrieve information. It supports project scoping to keep memory organized per project. Compatible with macOS, Windows, Linux, and cloud platforms. Designed to enhance Claude Code's ability to maintain context over long sessions.
