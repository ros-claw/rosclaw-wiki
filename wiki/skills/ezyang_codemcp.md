> 🐍 🏠 - Coding agent with basic read, write and command line tools.

codemcp is a Model Context Protocol (MCP) server that implements a basic coding agent. It provides tools for reading and writing files, as well as executing command-line commands. This allows AI assistants to interact with the local file system and shell environment through a standardized interface. The project is listed under the Coding Agents category in the MCP server ecosystem.
