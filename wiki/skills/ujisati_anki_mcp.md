> 🐍 🏠 - Manage your Anki collection with AnkiConnect & MCP

This is an MCP server that integrates with Anki via AnkiConnect, enabling AI agents to manage a user's Anki flashcard collection. It allows operations like adding, updating, and querying cards and decks through the Model Context Protocol. The tool is designed for developers building AI-powered study assistants or automation workflows around Anki. It bridges the gap between AI agents and personal spaced-repetition systems.
