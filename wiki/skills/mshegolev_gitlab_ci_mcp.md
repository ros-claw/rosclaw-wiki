Works with any GitLab (SaaS or self-hosted); published on PyPI and in the MCP Registry.

This MCP server enables AI agents to interact with GitLab CI/CD, including pipelines, jobs, schedules, merge requests, and repository files. It supports both GitLab SaaS and self-hosted instances, and is published on PyPI and in the MCP Registry. The server allows automated management of CI/CD workflows directly from agent tools.
