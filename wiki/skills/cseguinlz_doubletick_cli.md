Send tracked emails, check if they were opened with open count, device, and timing.

Doubletick-cli is an MCP server that enables email read tracking through Gmail. It allows users to send emails with tracking, and then check if the emails have been opened, including details like open count, device, and timing. This tool integrates with the Model Context Protocol to provide communication-related capabilities. It is designed for server-side deployment and facilitates persistent, context-aware email tracking.
