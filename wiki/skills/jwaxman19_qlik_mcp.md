> 📇 ☁️ - MCP Server for Qlik Cloud API that enables querying applications, sheets, and extracting data from visualizations with comprehensive authentication and rate limiting support.

This project implements an MCP server that connects to the Qlik Cloud API, allowing users to query applications and sheets, and extract data from visualizations. It handles authentication and includes rate limiting to manage API usage. Essentially, it provides a standardized interface (via the Model Context Protocol) for AI agents to interact with Qlik Cloud analytics.
