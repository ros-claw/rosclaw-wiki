> An MCP Server to compile latex, download/organize/read cited papers, run visualization scripts and add figures/tables to latex.

This MCP server assists with LaTeX document preparation. It compiles LaTeX files, manages academic paper citations by downloading and organizing them, runs visualization scripts, and inserts figures and tables into LaTeX documents. It integrates with tools that support the Model Context Protocol.
