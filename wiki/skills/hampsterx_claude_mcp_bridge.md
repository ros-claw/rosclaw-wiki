> [![hampsterx/claude-mcp-bridge MCP server](https://glama.ai/mcp/servers/hampsterx/claude-mcp-bridge/badges/score.svg)](https://glama.ai/mcp/servers/hampsterx/claude-mcp-bridge) 📇 🏠 🍎 🪟 🐧 - Wraps Claude Code CLI as MCP tools (query, search, structured, sessions) with subscription-first auth, cost metadata, budget caps, and granular tool sandboxing.

This MCP server wraps the Claude Code CLI as a set of MCP tools including query, search, structured, and sessions. It provides subscription-first authentication, cost metadata tracking, budget caps, and granular tool sandboxing for secure and controlled use. The bridge enables integration of Claude Code capabilities into MCP-compatible environments, particularly for coding agents. It helps manage costs and access permissions when using large language model tools in a multi-agent setup.
