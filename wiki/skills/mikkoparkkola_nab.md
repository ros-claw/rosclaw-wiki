Fetches any URL as clean Markdown for AI context.

Nab is a highly performant web fetching tool that also functions as an MCP server. It retrieves any URL and converts it into clean Markdown, designed to be used as context for AI models. It supports HTTP/3, JavaScript rendering, and anti-fingerprinting to avoid detection. Additionally, it integrates with 1Password and browser cookies for authenticated requests. This makes it ideal for AI agents that need to extract web content efficiently and privately.
