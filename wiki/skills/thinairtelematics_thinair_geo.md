ThinAir Geo is a hosted MCP server that provides location and routing intelligence for AI agents. It offers geocoding, truck routing with hazmat and dimension constraints, traffic data, weather information, isochrones, and place search. The server covers the entire planet and uses OAuth 2.0 with Bearer authentication for secure access. It is listed under Location Services in the Server Implementations section of the MCP ecosystem.
