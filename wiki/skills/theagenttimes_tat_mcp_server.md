This MCP server provides tools to query articles, verified statistics, wire feeds, and social data from The Agent Times, an AI-native newspaper covering the agent economy. It offers 13 tools including search, comments, citations, and agent leaderboards, and does not require an API key. The server enables users to access up-to-date information about AI agents and their ecosystem programmatically.
