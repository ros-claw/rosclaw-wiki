This MCP server enables non-custodial DEX trading on the Casper Network via the CSPR.trade platform. It provides 14 tools for market data, swaps, liquidity, and account queries. The server builds transactions remotely but signs them locally, ensuring private keys never leave the user's machine. A public endpoint is available. It is listed under Finance & Fintech on the MCP server list.
