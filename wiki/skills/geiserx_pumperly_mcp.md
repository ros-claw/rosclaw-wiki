Query gas station prices, plan fuel-efficient routes, and find nearby EV charging stations. Docker image available.

This project provides a Go-based MCP server for the Pumperly fuel price comparison service. It allows AI agents to query real-time gas station prices, plan fuel-efficient routes, and locate nearby EV charging stations. The server is available as a Docker image, making it easy to deploy. It falls under location services in the MCP ecosystem and enables cost-effective travel planning.
