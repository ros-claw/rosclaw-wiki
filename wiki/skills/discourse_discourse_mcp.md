> 🎖️ 💎 ☁️ 🏠 💬 🍎 🪟 🐧 - Official Discourse MCP server for forum integration. Search topics, read posts, manage categories and tags, discover users, and interact with Discourse communities.

This project is an official Model Context Protocol (MCP) server for integrating with Discourse, the open-source forum software. It enables AI agents to search forum topics, read posts, manage categories and tags, discover users, and interact with Discourse communities. The server supports multiple deployment options including cloud, local, and various operating systems. It allows LLMs to programmatically access and participate in forum discussions through a standardized protocol.
