Full observability toolkit for LLM applications. (https://github.com/langfuse/langfuse)

This project is an MCP (Model Context Protocol) server implemented in Java that integrates with Langfuse, an open-source observability platform for LLM applications. It allows users to query traces, debug exceptions, and analyze sessions, scores, datasets, and observations. It also provides capabilities to manage prompts and explore schema, serving as a comprehensive observability toolkit for LLM applications. The server is listed under monitoring tools in the MCP server ecosystem.
