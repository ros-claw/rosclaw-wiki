> 📇 ☁️ - An MCP server that provides complete access to Ethereum Virtual Machine (EVM) JSON-RPC methods. Works with any EVM-compatible node provider including Infura, Alchemy, QuickNode, local nodes, and more.

The evm-mcp server provides a comprehensive interface to Ethereum Virtual Machine (EVM) JSON-RPC methods through the Model Context Protocol. It is compatible with major node providers like Infura, Alchemy, and QuickNode, as well as local nodes. This enables AI agents and LLMs to interact with EVM blockchains using natural language or tool calls. The server acts as a bridge, allowing AI assistants to execute blockchain queries and transactions without direct low-level API handling.
