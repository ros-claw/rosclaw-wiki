The iris-eval/mcp-server is an MCP-native server designed for evaluating and monitoring AI agents. It provides trace logging, output quality evaluation, cost tracking, and a real-time dashboard. The server includes 12 built-in evaluation rules and PII detection capabilities. It supports multiple platforms including cloud, home, Apple, Windows, and Linux.
