> [![Khamel83/argus MCP server](https://glama.ai/mcp/servers/Khamel83/argus/badges/score.svg)](https://glama.ai/mcp/servers/Khamel83/argus) 🐍 🏠 - Multi-provider search broker with automatic fallback, RRF ranking, content extraction, and budget enforcement.

Argus is a multi-provider search broker for MCP servers that automatically falls back between search providers, ranks results using Reciprocal Rank Fusion (RRF), extracts content from web pages, and enforces budget limits. It ensures reliable, cost-effective search with high availability and deterministic output.
