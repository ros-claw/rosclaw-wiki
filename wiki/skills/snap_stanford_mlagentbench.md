> ![GitHub stars](https://img.shields.io/github/stars/snap-stanford/MLAgentBench?style=social) - Benchmark suite for evaluating AI agents on ML experimentation tasks. 13 tasks from CIFAR-10 to BabyLM.

MLAgentBench is a benchmark suite designed to evaluate the performance of AI agents on machine learning experimentation tasks. It includes 13 diverse tasks ranging from classic datasets like CIFAR-10 to modern language modeling challenges like BabyLM. The suite provides a standardized environment for measuring how well agents can perform open-ended ML workflows, such as data preprocessing, model training, and hyperparameter tuning. This tool helps researchers compare different agent architectures and training approaches for automated machine learning.
