Perfect for AI agent automation. Server can run [locally](https://github.com/Metadrama/obscura-mcp) or as [hosted endpoint](https://glama.ai/mcp/connectors).

Obscura-MCP is a Model Context Protocol server adapter for Obscura, a lightweight headless browser written in Rust. It provides high-performance web scraping with anti-detection features, making it suitable for AI agent automation tasks. The server can run locally or as a hosted endpoint, integrating seamlessly into browser automation workflows.
