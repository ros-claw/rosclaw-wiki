> [![teolex2020-aurasdk MCP server](https://glama.ai/mcp/servers/teolex2020-aurasdk/badges/score.svg)](https://glama.ai/mcp/servers/teolex2020-aurasdk) 🐍 🏠 — Persistent cognitive memory for Claude Desktop. Sub-ms recall, offline, encrypted.

AuraSDK is an MCP server that provides persistent cognitive memory for Claude Desktop. It offers sub-millisecond recall times, works offline, and keeps data encrypted. This tool enables AI assistants to retain and retrieve context efficiently across sessions. It is implemented in Python and designed for local, privacy-preserving memory management.
