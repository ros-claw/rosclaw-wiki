> 🐍 🏠 - Share code context with LLMs via MCP or clipboard

llm-context.py is a Python tool that helps share code context with large language models. It supports both Model Context Protocol (MCP) and clipboard-based sharing. Designed for AI-agent tooling, it streamlines providing relevant code snippets to LLMs. The project is listed under File Systems in server implementations.
