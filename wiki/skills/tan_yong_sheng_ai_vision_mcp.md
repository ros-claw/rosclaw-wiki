> 📇 🏠 🍎 🪟 🐧 - Multimodal AI vision MCP server for image, video, and object detection analysis. Enables UI/UX evaluation, visual regression testing, and interface understanding using Google Gemini and Vertex AI.

This project provides an MCP server that adds multimodal AI vision capabilities to AI agents, enabling analysis of images, videos, and object detection. It leverages Google Gemini and Vertex AI to perform tasks such as UI/UX evaluation and visual regression testing. The server runs across multiple operating systems and integrates seamlessly with the Model Context Protocol for tool use by AI agents.
