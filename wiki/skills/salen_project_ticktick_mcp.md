Supports creating, listing, updating, completing, and deleting tasks. Includes a natural language skill for automatic task detection in Claude Cowork.

This project is a Model Context Protocol (MCP) server that integrates with the TickTick task management service via its official OAuth 2.0 API. It allows AI agents like Claude to create, list, update, complete, and delete tasks programmatically. The server includes a natural language skill that automatically detects and handles task-related requests in Claude Cowork, enabling seamless task management through conversation. It simplifies connecting AI tools to external todo list systems using standard web authentication.
