> Control Apple Music on macOS via the `clawtunes` CLI.

Clawtunes is a command-line tool for controlling Apple Music on macOS. It allows users to manage playback, volume, and other music functions directly from the terminal. This is useful for automation or for users who prefer keyboard-driven workflows. The tool integrates with Apple's media player framework.
