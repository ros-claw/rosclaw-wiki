> 📇 🏠 - MCP server that exercises all the features of the MCP protocol

This server is a reference implementation for the Model Context Protocol (MCP) that demonstrates and tests all capabilities of the protocol. It provides examples of various MCP features such as tools, resources, prompts, and sampling. Developers can use it to verify their MCP client implementations against a comprehensive server. It serves as both a testing utility and a learning resource for understanding MCP's full functionality.
