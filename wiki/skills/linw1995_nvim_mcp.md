> 🦀 🏠 🍎 🪟 🐧  -  A MCP server to interact with Neovim

An MCP server built in Rust that enables AI agents to interact with the Neovim editor. It supports multiple operating systems (macOS, Windows, Linux) and provides a bridge between AI tools and Neovim's editing capabilities. This server allows developers to automate and extend Neovim through the Model Context Protocol. It is listed under Developer Tools in the MCP server ecosystem.
