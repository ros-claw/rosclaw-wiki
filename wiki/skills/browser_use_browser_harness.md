> A thin CDP-based browser harness that lets agents extend helper functions during execution, useful for inspecting self-healing web-task workflows.

browser-harness is a lightweight browser automation library built on the Chrome DevTools Protocol (CDP). It enables AI agents to dynamically extend helper functions during execution, allowing flexible interaction with web pages. The tool is designed for inspecting and debugging self-healing web-task workflows where agents adapt to changing page structures. As a thin harness, it serves as a reference implementation for agent-browser interfaces in the browser-use ecosystem. It provides a minimal abstraction layer for precise control over browser sessions.
