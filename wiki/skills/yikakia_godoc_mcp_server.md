> 🏎️ ☁️ 🪟 🐧 🍎 - Query Go package information on pkg.go.dev

This MCP server allows users to query Go package information directly from pkg.go.dev. It supports multiple operating systems including Windows, Linux, and macOS, and can be integrated with MCP clients. The server provides access to package documentation, versions, and other metadata. It is categorized under developer tools in the MCP server implementations list.
