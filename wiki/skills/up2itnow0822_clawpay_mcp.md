Agents sign transactions from their own wallet with on-chain spend limits — no custodial infrastructure, no API keys. Built on Base.

Clawpay-MCP is a non-custodial payment layer for AI agents, enabling secure transactions directly from their own wallet with on-chain spending limits. It uses the x402 protocol to facilitate payments without needing custodial infrastructure or API keys. Built on the Base blockchain, it integrates with the Model Context Protocol to give agents autonomous payment capabilities. This approach empowers agents to control their funds while respecting predefined spending boundaries.
