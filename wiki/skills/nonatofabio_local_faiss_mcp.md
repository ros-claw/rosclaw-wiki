> 🐍 🏠 🍎 🐧 - Local FAISS vector database for RAG with document ingestion (PDF/TXT/MD/DOCX), semantic search, re-ranking, and CLI tools for indexing and querying

This is an MCP server that implements a local FAISS vector database for Retrieval-Augmented Generation (RAG). It supports document ingestion from PDF, TXT, Markdown, and DOCX files, and provides semantic search with re-ranking. The server includes CLI tools for indexing and querying, making it easy to run locally on macOS, Windows, or Linux.
