> 🐍 🏠 - MCP Server that uses the open weight Kokoro TTS models to convert text-to-speech. Can convert text to MP3 on a local driver or auto-upload to an S3 bucket.

This project implements an MCP (Model Context Protocol) server that uses the open-weight Kokoro text-to-speech models to convert text input into spoken audio. It can generate MP3 files and either save them locally or automatically upload them to an Amazon S3 bucket. The server is designed to integrate with AI agents and applications that need speech output capability through a standardized interface. It simplifies adding TTS functionality to MCP-compatible tools by leveraging Kokoro's efficient neural network models.
