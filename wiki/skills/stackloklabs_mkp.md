> 🏎️ ☁️ - MKP is a Model Context Protocol (MCP) server for Kubernetes that allows LLM-powered applications to interact with Kubernetes clusters. It provides tools for listing and applying Kubernetes resources through the MCP protocol.

MKP is a Model Context Protocol (MCP) server that enables large language model (LLM) applications to interact with Kubernetes clusters. It acts as a gateway, providing tools to list and apply Kubernetes resources via the standardized MCP interface. This allows AI agents to manage cloud infrastructure declaratively, bridging the gap between natural language commands and Kubernetes API operations. MKP is tailored for server implementations on cloud platforms, simplifying cluster management for LLM-powered tools.
