> 📇 🏠 🍎 - Search, read, create, and update Bear Notes directly from Claude. Local-only with complete privacy.

This is a server implementation for Claude Desktop that allows users to search, read, create, and update Bear Notes directly from Claude. It runs locally with complete privacy, ensuring no data leaves the user's machine. The tool is specifically designed for Apple users since Bear Notes is an Apple-only app. It enhances productivity by integrating note management into the Claude interface.
