Rhumb is an MCP aggregator that provides agent-native tool intelligence across over 1,000 scored services. It offers 21 MCP tools for discovering services, checking AN Scores, comparing alternatives, and resolving capabilities to ranked providers. The server supports three credential modes (managed, BYOK, agent vault), tracks costs with receipts, and inspects failure modes. Notably, it includes a zero-signup option via x402 micropayments.
