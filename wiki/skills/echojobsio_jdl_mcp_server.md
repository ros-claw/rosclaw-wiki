Filter by skills, salary, location, seniority, remote type, and more. Free — 500 calls/day, no signup required. Also available as a remote MCP server at `https://mcp.jobdatalake.com`.

This MCP server provides a tool for searching over a million job listings from 20,000+ companies. It offers filtering by various criteria such as skills, salary, location, seniority, and remote type. The service is free up to 500 calls per day without requiring a signup. It can be used as a remote MCP server endpoint, making job data accessible through the Model Context Protocol.
