> 📇 🏠 - A Model Context Protocol Server for MongoDB

An MCP server that enables AI agents to interact with MongoDB databases through the Model Context Protocol. It provides tools for querying, inserting, updating, and deleting documents in MongoDB collections. This allows large language models to directly access and manipulate data in MongoDB instances.
