> [![capsule-mcp-server MCP server](https://glama.ai/mcp/servers/mavdol/capsule-mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/mavdol/capsule-mcp-server) 🦀 🏠 🍎 🪟 🐧 - Run untrusted Python/JavaScript code in WebAssembly sandboxes.

This MCP server allows AI agents to execute untrusted Python and JavaScript code in secure WebAssembly sandboxes using the Capsule runtime. It ensures that code runs in an isolated environment, preventing harm to the host system. The server supports macOS, Windows, and Linux operating systems. It provides a standardized interface via the Model Context Protocol for safe code execution.
