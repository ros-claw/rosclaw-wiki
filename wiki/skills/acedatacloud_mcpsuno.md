> [![AceDataCloud/MCPSuno MCP server](https://glama.ai/mcp/servers/AceDataCloud/MCPSuno/badges/score.svg)](https://glama.ai/mcp/servers/AceDataCloud/MCPSuno) 🐍 ☁️ - Suno AI music generation, lyrics, covers, and vocal extraction via Ace Data Cloud API.

AceDataCloud/MCPSuno is an MCP server that integrates with Suno AI to enable music generation, lyric creation, song covers, and vocal extraction through the Ace Data Cloud API. It provides a server implementation for the Model Context Protocol (MCP), allowing AI applications to access Suno's music capabilities programmatically. This tool simplifies adding AI-powered audio production features to AI agents and systems.
