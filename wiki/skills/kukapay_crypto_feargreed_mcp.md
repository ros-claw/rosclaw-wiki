> 🐍 ☁️ -  Providing real-time and historical Crypto Fear & Greed Index data.

This project implements a Model Context Protocol (MCP) server that supplies real-time and historical Crypto Fear & Greed Index data. It allows AI agents and coding tools to query sentiment metrics for cryptocurrencies via standardized MCP interfaces. Developers can integrate this data into their applications or AI workflows to gauge market emotions. The server is listed under Finance & Fintech in the MCP ecosystem.
