> High-performance Rust-based statusline for Claude Code with persistent stats tracking, progress bars, and optional cloud sync. Features SQLite-first persistence, git integration, context progress bars, burn rate calculation, XDG-compliant with theme support (dark/light, NO_COLOR).

Claudia-statusline is a high-performance statusline tool for Claude Code, written in Rust. It tracks persistent statistics across sessions using SQLite, and provides progress bars, git integration, and burn rate calculation. The tool is XDG-compliant and supports dark/light themes as well as the NO_COLOR standard. Optional cloud sync is available for sharing stats across devices. It is listed under Status Lines in the project directory.
