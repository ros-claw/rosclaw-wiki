Instinct is a self-learning memory system for AI coding agents that observes tool sequences, user preferences, and recurring fixes. It uses a confidence-based promotion mechanism where memories become mature after 5 hits and rules after 10, enabling agents to avoid repeating mistakes without explicit instruction. The system is SQLite-backed, project-aware, and has zero external dependencies. It works with multiple coding agents including Claude Code, Cursor, Windsurf, Goose, and Codex, and is published on PyPI as instinct-mcp.
