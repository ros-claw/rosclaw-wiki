> 🐍 ☁️ - Bitbucket MCP server with 58 tools for repository management, PRs, pipelines, branches, commits, deployments, webhooks, tags, branch restrictions, and source browsing.

This is an MCP server for Bitbucket Cloud that provides 58 tools for repository management, pull requests, pipelines, branches, commits, deployments, webhooks, tags, branch restrictions, and source browsing. It integrates AI assistants with Bitbucket version control via the Model Context Protocol. The server enables automated workflows and code review management through a standardized interface, streamlining DevOps tasks.
