This MCP server provides search capabilities for the Russian software registry (каталогпо.рф), which lists over 26,000 products. It is built for discovering import-substitution software and applications certified by Russian authorities (ФСТЭК/ФСБ). Three tools are offered: full-text search, manufacturer listing, and featured products. It is intended for security and compliance teams working under Russian laws 152-ФЗ (personal data) and 187-ФЗ (critical infrastructure). The server integrates with Claude through the Model Context Protocol.
