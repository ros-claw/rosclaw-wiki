> Use when the user asks to create or manage AdsPower browsers, groups, tags, proxies, or check status via AdsPower Local API.

This tool enables automated creation and management of AdsPower browsers, including grouping, tagging, proxy configuration, and status checks via the AdsPower Local API. It is designed for agent-based workflows where users need to control multiple browser profiles. The integration simplifies handling AdsPower browser instances programmatically.
