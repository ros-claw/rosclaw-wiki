> 📇 📟 - A JavaScript-driven M5Stack-embedded super-kawaii robot with MCP server functionality for AI-controlled interactions and emotions.

This project is an embedded system robot built on the M5Stack hardware platform, driven entirely by JavaScript. It features an integrated MCP server that allows AI agents to control the robot's interactions and simulate emotions in real-time. Dubbed 'super-kawaii', the robot is designed to be cute and responsive, bridging the gap between physical embedded devices and AI-driven autonomous behavior. The project demonstrates how AI tooling can be applied to low-power robotics for interactive experiences.
