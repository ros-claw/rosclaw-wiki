No headless browser, no re-authentication.

This project provides an MCP server and Chrome extension that enables AI agents to control a real browser, using existing sessions, logins, and cookies. It eliminates the need for headless browsers or repeated authentication, allowing seamless integration with AI tools for automation tasks. The extension bridges the gap between AI agents and the user's current browser state for more natural and efficient interactions.
