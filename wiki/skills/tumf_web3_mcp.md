> 🐍 ☁️ - An MCP server implementation wrapping Ankr Advanced API. Access to NFT, token, and blockchain data across multiple chains including Ethereum, BSC, Polygon, Avalanche, and more.

This MCP server wraps the Ankr Advanced API to provide a standardized interface for accessing blockchain data. It supports querying NFTs, tokens, and on-chain information across multiple networks including Ethereum, BSC, Polygon, and Avalanche. Designed for integration with AI agents via the Model Context Protocol, it simplifies fetching real-time blockchain data for decentralized applications. The server enables developers to easily incorporate multi-chain data into their toolchains.
