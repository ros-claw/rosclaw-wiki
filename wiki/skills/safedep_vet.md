> 🎖️ 🏎️ ☁️ 🍎 🪟 🐧 - vet-mcp checks open source packages—like those suggested by AI coding tools—for vulnerabilities and malicious code. It supports npm and PyPI, and runs locally via Docker or as a standalone binary for fast, automated vetting.

vet-mcp is a tool that checks open source packages, especially those suggested by AI coding tools, for vulnerabilities and malicious code. It supports npm and PyPI packages and can run locally via Docker or as a standalone binary for fast vetting. The tool helps ensure security when using AI-generated code suggestions by automating the vetting process.
