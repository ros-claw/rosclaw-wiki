> 📇 ☁️ - A MCP server that provides gene set enrichment analysis using the Enrichr API

This project is an MCP server that enables gene set enrichment analysis by connecting to the Enrichr API. It allows users to perform biological pathway and gene function enrichment queries through the Model Context Protocol. The server is listed under search and data extraction tools, facilitating integration with AI agents for genomic data analysis. It simplifies access to Enrichr's comprehensive database of gene sets and annotations.
