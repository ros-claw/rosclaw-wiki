repocrunch is an MCP (Model Context Protocol) server that gives AI agents structured intelligence about GitHub repositories. It provides deterministic JSON output covering tech stack, dependencies, architecture, health metrics, and security indicators. This tool helps AI agents access ground-truth repository data for analysis and decision-making.
