> 📇 ☁️ - Metropolitan Museum of Art Collection API integration to search and display artworks in the collection.

This project provides an MCP server that integrates the Metropolitan Museum of Art's Collection API, allowing users to search and retrieve artwork data from the museum's vast collection. It enables AI agents to query artworks by various criteria and access detailed information such as images, titles, and cultural context. The server acts as a bridge between natural language requests and structured museum data, making art exploration more accessible through conversational interfaces.
