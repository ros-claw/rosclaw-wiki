> 🎖️ 📇 🏠 ☁️ - Official MCP server for InfluxDB 3 Core/Enterprise/Cloud Dedicated

This is an official MCP server for InfluxDB 3, a time series database. It supports InfluxDB 3 Core, Enterprise, and Cloud Dedicated deployments. The server enables AI agents to interact with InfluxDB databases using the Model Context Protocol. It provides tools for querying, writing, and managing time series data.
