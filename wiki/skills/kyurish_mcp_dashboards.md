mcp-dashboards is an MCP server offering over 45 interactive chart types such as bar, line, pie, candlestick, sankey, geo, radar, funnel, and treemap. It enables building dashboards with KPI cards, drill-down navigation, live API polling, and 20 themes. Users can export dashboards to PNG, PPT, or A4 format. The server is built with MCP Apps and runs on multiple platforms.
