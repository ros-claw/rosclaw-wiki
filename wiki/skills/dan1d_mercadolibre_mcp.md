The MercadoLibre MCP server provides AI agents with direct access to Latin America's largest e-commerce marketplace. It enables product search, item details retrieval, category browsing, trend tracking, and currency conversion across Argentina, Brazil, Mexico, Chile, and Colombia. This integration allows AI assistants to perform real-time e-commerce queries and transactions through the standard MCP protocol.
