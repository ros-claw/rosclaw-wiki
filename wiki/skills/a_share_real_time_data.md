> Fetch China A-share stock market data (bars, realtime quotes, tick-by-tick transactions) via mootdx/TDX protocol.

This tool provides programmatic access to real-time and historical data for Chinese A-share stocks, including bars, quotes, and tick-by-tick transactions. It uses the Mootdx library and the TDX protocol to fetch data from China's stock exchanges. Designed for developers and quantitative traders, it enables efficient retrieval of market data without manual API integration.
