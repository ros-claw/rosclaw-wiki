First free standalone AWS security MCP server.

This is an open-source AWS security scanner that detects attack chains, estimates breach costs, and provides copy-paste remediation. It includes 47 security checks and 16 attack chain rules. It is the first free standalone AWS security MCP server, supporting both CLI and Terraform. The tool helps organizations identify and fix security vulnerabilities in their AWS environments.
