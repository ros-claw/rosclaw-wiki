docx-mcp is an MCP server that enables reading and editing Word (.docx) documents with support for track changes, threaded comments, footnotes, and structural validation. It uniquely combines w:ins/w:del tracked changes, threaded comments, and footnotes with OOXML-level paraId validation and document auditing. The server provides 18 tools and requires Python 3.10 or higher. It is listed under Knowledge & Memory server implementations, suggesting use in document-centric knowledge management workflows.
