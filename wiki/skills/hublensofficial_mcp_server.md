HubLensOfficial/mcp-server is an MCP server that queries daily trending open-source projects from GitHub and Hacker News. It generates AI-powered bilingual summaries in English and Chinese, along with categories, use cases, and custom scoring. The server is stateless and requires no API key, making it easy to deploy and use. It helps developers discover popular projects quickly with enriched context.
