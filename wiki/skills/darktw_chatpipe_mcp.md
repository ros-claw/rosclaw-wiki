Instant URLs with access control (public, password-protected, email-restricted).

This MCP server allows AI coding agents to instantly publish HTML content as live, shareable web pages with unique URLs. It provides flexible access control options including public, password-protected, and email-restricted sharing. Designed for developer tooling, it streamlines the process of making AI-generated outputs accessible online. The server integrates seamlessly with AI agents to enable real-time web publishing.
