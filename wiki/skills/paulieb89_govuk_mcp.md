This project provides a server that implements the Model Context Protocol (MCP) to allow AI assistants to search and retrieve content from GOV.UK, the UK government's website. It offers five read-only tools for searching pages, getting full page content, looking up government organisations, and resolving UK postcodes to local authorities. No API keys are required, making it easy to integrate into AI workflows. The server is written in Python and designed to be used with MCP-compatible clients.
