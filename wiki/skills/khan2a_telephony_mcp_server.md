> 🐍 💬 - MCP Telephony server for automating voice calls with Speech-to-Text and Speech Recognition to summarize call conversations. Send and receive SMS, detect voicemail, and integrate with Vonage APIs for advanced telephony workflows.

This project provides an MCP server for telephony operations, enabling voice calls with speech-to-text and speech recognition to summarize conversations. It supports sending and receiving SMS, detecting voicemail, and integrates with Vonage APIs for advanced telephony workflows. The server is designed to automate communication tasks within the Model Context Protocol ecosystem.
