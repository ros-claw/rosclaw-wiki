> 📇 🏠 🍎 🪟 🐧 - Premium MCP server for Godot game engine with 84 tools for scene editing, scripting, animation, tilemap, shader, input simulation, and runtime debugging.

The godot-mcp-pro project is a premium MCP (Model Context Protocol) server designed specifically for the Godot game engine. It provides 84 different tools that allow AI assistants to interact with Godot, covering scene editing, scripting, animation, tilemaps, shaders, input simulation, and runtime debugging. This enables developers to leverage large language models for automating and enhancing game development workflows directly within Godot. The server is cross-platform, available on Windows, macOS, Linux, and potentially iOS/Android via Godot exports.
