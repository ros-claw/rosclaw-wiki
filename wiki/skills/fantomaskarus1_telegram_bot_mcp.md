This is an MCP server that exposes the full Telegram Bot API as 174 tools, enabling AI agents to send messages, manage chats, handle media, and interact with Telegram users programmatically. It is listed under Communication in the MCP server registry, making it suitable for integrating Telegram messaging into AI workflows. The server is open source and designed for easy deployment, allowing developers to connect AI models to Telegram's messaging infrastructure.
