MCP Doctor is a zero-configuration tool that diagnoses MCP servers. It automatically discovers server configurations from popular client tools like Claude Code, Cursor, VS Code, Windsurf, and Claude Desktop. It then tests connectivity via a JSON-RPC handshake, audits for security issues, and benchmarks latency. Additionally, MCP Doctor can function as an MCP server itself to provide diagnostic capabilities to other clients.
