Agent Trust Stack MCP is a security-focused server that implements a set of trust protocols for AI agent interactions. It provides cryptographic provenance, bilateral blind reputation scoring that resists gaming, and tamper-evident logging. The system includes seven specific protocols covering code of conduct, agent registration, service agreements, job execution, leasing, marketplace, and context window escrow. Provenance chains are anchored to Bitcoin for immutability, and it supports machine-readable contracts, dispute resolution, and trust-weighted matchmaking. Available as Python and TypeScript packages with extensive testing.
