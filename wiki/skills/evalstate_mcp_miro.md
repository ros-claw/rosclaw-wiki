> 📇 ☁️ - Access MIRO whiteboards, bulk create and read items. Requires OAUTH key for REST API.

This project is an MCP server that connects to Miro whiteboards, allowing automated access to create and read items in bulk. It uses Miro's REST API and requires an OAuth key for authentication. The tool is designed for integration with AI agents that need to manage or retrieve whiteboard content programmatically. It enables efficient manipulation of whiteboard elements through the Model Context Protocol.
