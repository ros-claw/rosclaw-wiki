The Azure Identity library for Rust provides authentication capabilities using Azure Active Directory. It enables Rust applications to obtain access tokens for Azure services. This library is part of the Azure SDK for Rust and follows common Azure Identity patterns. It supports various authentication flows including client credentials, device code, and interactive browser authentication.
