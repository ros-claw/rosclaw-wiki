better-auth/twoFactor is a plugin for the Better Auth authentication library that adds two-factor authentication capabilities. It allows users to enable a second layer of security for their accounts, typically via TOTP (Time-based One-Time Password) codes or other methods. This plugin integrates seamlessly with Better Auth's existing authentication flows to provide enhanced account protection. It is listed among sponsor-supported skills by the Better Auth Team, indicating official support and maintenance.
