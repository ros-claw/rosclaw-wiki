> 📇 ☁️ - Exercise-to-muscle mapping MCP server. Look up muscles worked by 856 exercises across 65 muscles and 14 muscle groups, analyze workouts for gaps, and find alternative exercises ranked by muscle overlap.

This MCP server maps exercises to the muscles they work, covering 856 exercises, 65 muscles, and 14 muscle groups. It allows users to look up which muscles are engaged by a given exercise, analyze workout routines for muscle group gaps, and find alternative exercises ranked by muscle overlap. Designed for sports and fitness applications, it provides a structured query interface for exercise-muscle relationships. The server is listed under 'Sports' in server implementations.
