> Lets Claude Code chat directly with NotebookLM for source-grounded answers based exclusively on uploaded documents.

NotebookLM Integration is a communication skill that connects Claude Code, an AI coding agent, with Google's NotebookLM. It allows Claude Code to chat directly with NotebookLM and receive answers grounded exclusively in the user's uploaded documents. This ensures responses are source-cited and based only on provided content, avoiding general AI knowledge. The integration enhances Claude Code's capabilities by leveraging NotebookLM's document-focused retrieval for accurate, evidence-backed answers.
