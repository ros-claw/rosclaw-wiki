> 🐍 ☁️ - Japanese corporate data via government APIs (gBizINFO, EDINET, e-Stat). Search companies, financials, patents, subsidies, procurement, and government statistics.

This project provides a Model Context Protocol (MCP) server that fetches Japanese corporate data from official government APIs such as gBizINFO, EDINET, and e-Stat. It allows users to search for companies, financial statements, patents, subsidies, procurement details, and government statistics. The server acts as a bridge between AI agents and structured public data from Japanese governmental sources.
