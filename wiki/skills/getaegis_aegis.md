Aegis is a credential isolation proxy designed for AI agents that injects secrets at the network boundary. It enforces domain restrictions, agent authentication, and audit logging without requiring an SDK. The tool operates as a transparent HTTP proxy or as a dedicated MCP server, making it easy to integrate into existing workflows. It is cross-platform, supporting Linux, macOS, and Windows.
