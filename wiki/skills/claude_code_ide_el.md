> claude-code-ide.el integrates Claude Code with Emacs, like Anthropic’s VS Code/IntelliJ extensions. It shows ediff-based code suggestions, pulls LSP/flymake/flycheck diagnostics, and tracks buffer context. It adds an extensible MCP tool support for symbol refs/defs, project metadata, and tree-sitter AST queries.

claude-code-ide.el integrates Claude Code with Emacs, providing AI-powered code suggestions displayed via ediff diffs. It pulls diagnostics from LSP, flymake, and flycheck, and tracks buffer context for better suggestions. The package includes extensible MCP tool support for symbol references, definitions, project metadata, and tree-sitter AST queries. This brings the functionality of Anthropic's VS Code and IntelliJ extensions to the Emacs environment.
