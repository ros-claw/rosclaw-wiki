This MCP server translates design tokens between platforms. It can extract tokens from Tailwind, CSS, Figma, or W3C DTCG formats, and generate output for Material 3 (Kotlin), SwiftUI, Tailwind config, and CSS Variables. It also includes WCAG contrast validation to ensure accessibility.
