> [![mcp-server-logs-sieve MCP server](https://glama.ai/mcp/servers/Oluwatunmise-olat/mcp-server-logs-sieve/badges/score.svg)](https://glama.ai/mcp/servers/Oluwatunmise-olat/mcp-server-logs-sieve) 📇 ☁️ 🏠 🍎 🪟 🐧 - Query, summarize, and trace logs in plain English across GCP Cloud Logging, AWS CloudWatch, Azure Log Analytics, Grafana Loki, and Elasticsearch

This MCP server lets you query, summarize, and trace logs using plain English across multiple log management platforms including GCP Cloud Logging, AWS CloudWatch, Azure Log Analytics, Grafana Loki, and Elasticsearch. It integrates with the Model Context Protocol to enable AI assistants to perform log analysis and troubleshooting. The server supports cloud and self-hosted environments (Linux, macOS, Windows). It is designed for monitoring and observability workflows, helping users find patterns and issues without writing complex queries.
