> 🏎️ ☁️/🏠 - Get up-to-date EC2 pricing information with one call. Fast. Powered by a pre-parsed AWS pricing catalogue.

This project implements an MCP server that provides up-to-date EC2 pricing information from AWS. It uses a pre-parsed AWS pricing catalogue to deliver fast responses with a single API call. The tool is designed for cloud cost estimation and optimization, enabling developers to query current EC2 instance prices easily. It is listed under Cloud Platforms for MCP server implementations.
