> 🦀 🏠 - An MCP tool for querying Solana transactions using natural language with Solscan API.

This tool provides a bridge between natural language queries and the Solana blockchain. It uses the Solscan API to fetch transaction data and make it accessible via the Model Context Protocol. Users can ask questions about Solana transactions in plain English and get structured data in return. It is designed for developers and analysts who need to interact with Solana blockchain data without writing custom scripts. The project is part of the MCP ecosystem for finance and fintech.
