> 📇 🏠 🍎 🪟 🐧 - Token usage tracker for OpenAI and Claude APIs with MCP support, real-time session tracking, and accurate pricing for 2025 models

LLM Token Tracker is a tool for monitoring token usage and costs when using OpenAI and Claude APIs. It provides real-time session tracking and accurate pricing for 2025 models. The tool supports the Model Context Protocol (MCP), making it easy to integrate with MCP-enabled environments. It is designed for developers who need to keep track of API expenditures and token consumption.
