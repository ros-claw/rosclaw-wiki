Read-only OAuth scope, installable via `uvx mcp-google-search-console`.

This MCP server connects Google Search Console data to AI agents, enabling queries on search performance, URL indexing, and crawl stats. It can generate branded SEO audit reports with 30/60/90-day roadmaps for actionable insights. The server uses read-only OAuth for secure access and is installed via `uvx mcp-google-search-console`. It is listed under marketing server implementations.
