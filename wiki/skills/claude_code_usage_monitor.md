> A real-time terminal-based tool for monitoring Claude Code token usage. It shows live token consumption, burn rate, and predictions for token depletion. Features include visual progress bars, session-aware analytics, and support for multiple subscription plans.

Claude Code Usage Monitor is a real-time terminal tool that tracks token consumption for Claude Code. It displays live token usage, burn rate, and predicts when tokens will run out. The tool includes visual progress bars and session-aware analytics. It supports multiple subscription plans to tailor monitoring to user needs. This helps developers manage their token budget effectively.
