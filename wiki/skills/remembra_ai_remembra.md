Self-hosted.

Remembra is a persistent memory layer for AI agents that supports entity resolution and PII detection. It provides AES-256-GCM encryption at rest and hybrid search capabilities. The system achieves 100% on the LoCoMo benchmark and is designed to be self-hosted. It integrates with the Model Context Protocol for serving memories to AI agents.
