GUCCI-atlasv/skillssafe-mcp is a security scanner designed for AI agent skills. It scans SKILL.md files, MCP configurations, and system prompts to detect credential theft, prompt injection, zero-width character attacks, and ClawHavoc indicators. The tool supports OpenClaw, Claude Code, Cursor, and Codex, and requires no signup. It is listed under security-related server implementations.
