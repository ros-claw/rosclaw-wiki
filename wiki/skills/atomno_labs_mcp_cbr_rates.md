Five typed tools backed by an in-memory TTL cache. No API key required.

This MCP server provides access to financial data from the Central Bank of Russia. It offers tools for retrieving daily and historical currency exchange rates, the key interest rate, inflation data, and aggregated macroeconomic statistics. The server features five typed tools with an in-memory TTL cache and does not require an API key. It is designed to be used within AI agent frameworks that support the Model Context Protocol (MCP).
