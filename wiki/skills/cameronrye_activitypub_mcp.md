> 📇 🏠 🐧 🍎 🪟 - A comprehensive MCP server that enables LLMs to explore and interact with the Fediverse through ActivityPub protocol. Features WebFinger discovery, timeline fetching, instance exploration, and cross-platform support for Mastodon, Pleroma, Misskey, and other ActivityPub servers.

This project provides an MCP server that lets AI assistants interact with the Fediverse using the ActivityPub protocol. It supports discovering users via WebFinger, fetching timelines, and exploring instances on platforms like Mastodon, Pleroma, and Misskey. The server enables LLMs to read and search public social media data across the decentralized social web. It is aimed at developers building AI tools for social media analysis or interaction with the Fediverse.
