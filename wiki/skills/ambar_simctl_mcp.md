> 📇 🏠 🍎 A MCP server implementation for iOS Simulator control.

This project implements a Model Context Protocol (MCP) server for controlling Apple iOS Simulators. It wraps the `simctl` command-line tool, enabling programmatic management of simulator devices through MCP interactions. Developers can integrate this server into AI agents or tools to automate iOS simulator tasks like booting, installing apps, and taking screenshots. The server is listed under Developer Tools in the MCP server ecosystem, targeting Apple platform development workflows.
