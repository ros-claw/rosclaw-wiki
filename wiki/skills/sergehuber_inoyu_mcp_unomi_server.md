> 📇 ☁️ - An MCP server to access and updates profiles on an Apache Unomi CDP server.

This project implements a Model Context Protocol (MCP) server that connects to an Apache Unomi Customer Data Platform (CDP). It provides tools and resources to read and update customer profiles stored in Unomi. The server enables AI agents to interact with customer data through the standard MCP interface. It is designed for use in customer data management and personalization workflows.
