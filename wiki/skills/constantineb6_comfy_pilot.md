> 🐍 🏠 - MCP server for ComfyUI that lets AI agents view, edit, and run node-based image generation workflows with an embedded terminal.

comfy-pilot is an MCP server that integrates with ComfyUI, enabling AI agents to view, edit, and execute node-based image generation workflows. It provides an embedded terminal for agent interaction, allowing autonomous generation and manipulation of images. This tool bridges AI agents with a visual programming environment for generative art.
