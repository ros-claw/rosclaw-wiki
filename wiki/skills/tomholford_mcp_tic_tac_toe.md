> 🏎️ 🏠 - Play Tic Tac Toe against an AI opponent using this MCP server.

This MCP server implements a Tic Tac Toe game where users can play against an AI opponent. The server exposes game logic as a tool through the Model Context Protocol, handling moves and win detection. It is listed under Gaming in the server implementations registry. Players interact via a simple API to make moves and receive game state updates.
