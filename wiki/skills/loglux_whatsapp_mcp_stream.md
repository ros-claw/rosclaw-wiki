> [![whatsapp-mcp-stream MCP server](https://glama.ai/mcp/servers/@loglux/whatsapp-mcp-stream/badges/score.svg)](https://glama.ai/mcp/servers/@loglux/whatsapp-mcp-stream) 📇 🏠 🍎 🪟 🐧 - WhatsApp MCP server over Streamable HTTP with web admin UI (QR/status/settings), bidirectional media upload/download, and SQLite persistence.

This project provides an MCP server that enables AI agents to interact with WhatsApp through the Model Context Protocol. It uses Streamable HTTP for communication and includes a web admin interface for QR code authentication, status monitoring, and settings configuration. The server supports bidirectional media upload and download, and stores data in SQLite for persistence. This allows AI agents to send and receive WhatsApp messages, media, and manage conversations.
