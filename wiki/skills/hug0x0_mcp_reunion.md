MCP Reunion is an MCP server that exposes 96 tools across 21 modules for accessing open data from the French overseas region of La Réunion. It covers domains such as economy, demographics, geography, transport, health, education, elections, tourism, housing, and the environment. Data is sourced from data.regionreunion.com and data.gouv.fr. The server can be installed via npx with the command `npx -y mcp-reunion`. It is listed under data platforms in the MCP server ecosystem.
