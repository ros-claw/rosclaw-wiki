Point it at a Dependabot PR and get back semver classification, breaking changes from GitHub release notes, CVEs fixed in range, migration links, and a per-package recommendation. Bulk tool ranks up to 50 changes by risk (security > caution > review > likely-safe > safe). Install via `npx -y @digicatalyst/dep-diff-mcp`.

This MCP server translates lockfile diffs from npm and PyPI into human-readable upgrade plans. It can analyze Dependabot pull requests to provide semantic versioning classification, breaking changes from GitHub release notes, CVE fixes, migration links, and per-package recommendations. A bulk tool ranks up to 50 changes by risk level: security, caution, review, likely-safe, and safe. It is installed via npx and is designed for developer tooling.
