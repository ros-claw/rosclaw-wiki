> A hardware-aware, hybrid (SMB + SSH) suite for ASUSTOR NAS metadata.

nas-master is a hardware-aware tool for ASUSTOR NAS devices that uses both SMB and SSH protocols to manage and extract metadata. It adapts to the specific hardware configuration of the NAS, providing a hybrid approach that combines network file sharing and remote shell access. This enables users to efficiently organize and retrieve metadata from their NAS storage, improving data accessibility and management.
