This project is a bridge that connects Spinnaker, a continuous delivery platform, to the Model Context Protocol (MCP). It exposes any Spinnaker instance as an MCP server by leveraging the Gate API, allowing MCP-based AI agents to manage applications, pipelines, executions, and cloud infrastructure. This integration enables AI-driven orchestration of deployment workflows and infrastructure management within the MCP ecosystem.
