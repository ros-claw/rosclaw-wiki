> [![jnMetaCode/shellward MCP server](https://glama.ai/mcp/servers/jnMetaCode/shellward/badges/score.svg)](https://glama.ai/mcp/servers/jnMetaCode/shellward) 📇 🏠 🍎 🪟 🐧 - AI Agent Security Middleware & MCP Server with 8-layer defense including prompt injection detection, DLP data flow tracking, command blocking, and PII detection. 7 MCP tools, zero dependencies.

Shellward is an MCP server and security middleware designed to protect AI agents from threats like prompt injection and data leakage. It offers an eight-layer defense system that includes detection of malicious commands, tracking of sensitive data flows, and redaction of personally identifiable information (PII). The server provides seven tools for interacting with the system and has no external dependencies, making it lightweight. Its primary goal is to enable secure execution of agent actions while blocking risky operations and monitoring for compliance.
