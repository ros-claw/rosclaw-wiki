> Manage grocery and shopping lists via AnyList.

AnyList is a project that provides integration with the AnyList grocery and shopping list service. It enables AI agents or automation tools to manage shopping lists programmatically. Users can add, remove, or query items through an API or command interface. This is useful for smart home assistants, voice-controlled agents, or personal productivity bots.
