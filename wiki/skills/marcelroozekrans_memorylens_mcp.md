This is an MCP server that performs on-demand memory profiling for .NET applications. It wraps JetBrains dotMemory with a heuristic rule engine containing 10 rules to detect common memory issues like leaks, LOH fragmentation, and anti-patterns. The server provides AI-actionable code fix suggestions based on its analysis. It is designed to integrate memory diagnostics into AI-assisted development workflows.
