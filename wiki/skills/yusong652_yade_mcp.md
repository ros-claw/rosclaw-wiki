This project provides an MCP server for YADE, an open-source discrete element method (DEM) engine used for granular and particle simulations. It allows users to browse YADE's API documentation using BM25 search, execute code through a synchronous REPL or asynchronous background tasks, monitor simulation progress, and review task history. The server integrates YADE's simulation capabilities with AI-agent workflows, enabling interactive and automated control over DEM simulations.
