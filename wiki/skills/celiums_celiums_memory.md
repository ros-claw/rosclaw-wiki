Celiums Memory is a cognitive memory engine for AI agents that stores and retrieves knowledge with context awareness. It includes over 5,100 knowledge modules and tracks circadian rhythms and emotional states using the PAD model. The system uses a hybrid search combining PostgreSQL, Qdrant vector embeddings, and Valkey caching for efficient retrieval. It supports multiple protocols including MCP, REST, OpenAI, LangChain, and A2A, and provides per-user memory isolation for safe multi-agent environments.
