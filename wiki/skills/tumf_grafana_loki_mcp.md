> 🐍 🏠 - An MCP server that allows querying Loki logs through the Grafana API.

This project is an MCP (Model Context Protocol) server that enables querying Loki logs through the Grafana API. It provides an interface for AI agents to interact with log data stored in Loki, a log aggregation system. The server acts as a bridge between MCP-compatible clients and Grafana's Loki data source, allowing natural language or structured queries to retrieve logs. It simplifies monitoring and debugging by making log data accessible within AI-driven workflows.
