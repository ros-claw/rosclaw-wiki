> 📇 🏠 – A Node.js MCP server that spins up isolated Docker-based sandboxes for executing JavaScript snippets with on-the-fly npm dependency installation and clean teardown

This project is a Node.js-based MCP server that creates isolated Docker sandboxes for executing JavaScript code snippets. It automatically installs any required npm dependencies on the fly and ensures clean teardown after execution. Designed for safe execution of code as part of AI agent tooling, it provides a secure, ephemeral environment for running untrusted scripts.
