delimit is an API governance server that detects breaking changes between two versions of an OpenAPI specification. It supports OpenAPI 3.0, 3.1, and Swagger 2.0. Users can configure policy rules (strict, default, or relaxed) to classify changes as passing or failing. It identifies 23 change types, 10 of which are breaking. It is implemented as an MCP server and is available as a developer tool.
