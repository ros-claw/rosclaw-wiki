> ☕ 🏠 - A JetBrains IDE plugin that exposes an MCP server, giving AI coding assistants full programmatic control over the debugger.

A JetBrains IDE plugin that integrates an MCP (Model Context Protocol) server, enabling AI coding assistants to programmatically control the debugger. This allows AI agents to set breakpoints, step through code, inspect variables, and manage debugging sessions directly from the IDE. The plugin bridges the gap between AI tools and the native debugger, empowering autonomous debugging workflows in IntelliJ-based IDEs.
