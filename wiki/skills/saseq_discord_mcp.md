> ☕ 📇 🏠 🍎 🪟 🐧 - A MCP server for the Discord integration. Enable your AI assistants to seamlessly interact with Discord. Enhance your Discord experience with powerful automation capabilities.

This project provides a Model Context Protocol (MCP) server that integrates with Discord. It allows AI assistants to interact with Discord channels, messages, and users. The server enables automation tasks such as sending messages and managing channels. It supports multiple operating systems, including macOS, Windows, and Linux. The goal is to enhance Discord with AI-powered capabilities.
