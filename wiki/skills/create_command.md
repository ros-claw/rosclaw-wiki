> Guides Claude through creating new custom commands with proper structure by analyzing requirements, templating commands by category, enforcing command standards, and creating supporting documentation.

This project provides a tool that guides Claude through creating new custom commands with proper structure. It analyzes user requirements, templates commands by category, enforces command standards, and creates supporting documentation. The tool is listed under Slash-Commands > Project & Task Management, helping to streamline command creation. It standardizes the process of adding new functionality to Claude through structured command development.
