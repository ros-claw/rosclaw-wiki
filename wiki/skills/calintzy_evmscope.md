evmscope is an MCP server that provides a toolkit for EVM blockchain intelligence, offering 20 tools for tasks like fetching token prices, comparing gas fees, obtaining swap quotes, checking yield rates, detecting honeypots, and simulating transactions. It supports multiple EVM-compatible chains including Ethereum, Polygon, Arbitrum, Base, and Optimism. The server requires zero configuration and no API keys, making it easy to integrate into AI agent workflows. It is listed under Finance & Fintech in the MCP server directory.
