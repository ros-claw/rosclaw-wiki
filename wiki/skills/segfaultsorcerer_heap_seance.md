Two-stage escalation model with conservative scan and deep forensics.

Heap-seance is a Model Context Protocol (MCP) server that diagnoses Java memory leaks by combining multiple diagnostic tools such as jcmd, jmap, jstat, JFR, Eclipse MAT, and async-profiler. It uses a two-stage escalation model: a conservative initial scan followed by deep forensic analysis, and provides structured, confidence-based verdicts. The tool is cross-platform (Windows, macOS, Linux) and is designed for developers debugging Java applications within an MCP environment.
