> Consult, commit, extend, and challenge reasoning chains.

Agent-commons is a library for managing reasoning chains in AI agents. It provides tools to consult, commit to, extend, and challenge chains of thought. This allows agents to collaboratively build and critique reasoning steps, aiding in more robust decision-making. It is designed to support flexible workflows where multiple agents or a single agent can iterate on reasoning.
