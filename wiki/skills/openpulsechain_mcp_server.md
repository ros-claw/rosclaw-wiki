> [![openpulsechain/public MCP server](https://glama.ai/mcp/servers/openpulsechain/public/badges/score.svg)](https://glama.ai/mcp/servers/openpulsechain/public) 📇 ☁️ - PulseChain on-chain analytics: token safety scores (0-100), honeypot detection, whale tracking, smart money feed, scam alerts, DEX volume, bridge stats, holder leagues. 11 free + 9 pro tools. `npx @openpulsechain/mcp-server`

This MCP server provides AI agents with real-time on-chain analytics for the PulseChain blockchain. It includes token safety scores (0-100), honeypot detection, whale tracking, smart money feeds, and scam alerts. The server offers 11 free and 9 pro tools for tasks like DEX volume analysis, bridge stats, and holder league tracking. It enables AI assistants to retrieve up-to-date financial data from PulseChain without manual querying. The tool can be launched via npx and integrates seamlessly with the Model Context Protocol.
