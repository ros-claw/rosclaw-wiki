> 🐍 ☁️ - Tracking the latest trending tokens on CoinGecko.

This project provides an MCP server that tracks the latest trending tokens on CoinGecko. It allows users to query trending cryptocurrencies through a simple tool interface. The server is designed to be used with the Model Context Protocol (MCP) for AI agents. It is categorized under finance and fintech tools.
