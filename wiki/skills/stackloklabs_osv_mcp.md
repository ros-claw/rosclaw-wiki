> 🏎️ ☁️ - Access the OSV (Open Source Vulnerabilities) database for vulnerability information. Query vulnerabilities by package version or commit, batch query multiple packages, and get detailed vulnerability information by ID.

This MCP server provides access to the Open Source Vulnerabilities (OSV) database, enabling users to query vulnerabilities by package version or commit, batch query multiple packages, and retrieve detailed information by vulnerability ID. It is designed for security-focused tooling and integrates with AI agents to check software dependencies for known vulnerabilities. The server helps developers and security teams identify and track open source vulnerabilities in their supply chain.
