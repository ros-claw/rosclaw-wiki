This MCP server provides access to the Austrian Rechtsinformationssystem (RIS) API, giving AI agents 12 specialized tools to retrieve federal laws, state laws, court decisions, and legal documents. It simplifies legal research by wrapping Austrian legal data into a structured interface for use with MCP-compatible systems. The project is implemented in TypeScript and is listed under Legal server implementations in the MCP registry.
