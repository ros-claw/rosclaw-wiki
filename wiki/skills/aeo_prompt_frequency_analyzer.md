> Analyze what search queries Gemini uses when answering a prompt, by running it multiple times with Google Search.

This tool analyzes the search queries that Google's Gemini model uses when answering a given prompt. It runs the same prompt multiple times with Google Search enabled to collect the queries. The goal is to understand how Gemini formulates search queries based on the prompt. This can help users optimize prompts for better search-driven responses.
