This MCP server provides live seasonal travel data for Japan, including cherry blossom forecasts, autumn leaves information, flower spots, fruit picking locations, and festivals. It draws from over 1,700 GPS-tagged spots supplied by the Japan Meteorological Corporation and is updated daily. The server helps users plan trips based on current seasonal conditions and attractions.
