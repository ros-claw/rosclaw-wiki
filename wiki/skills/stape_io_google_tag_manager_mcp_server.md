> 📇 ☁️ – This server supports remote MCP connections, includes built-in Google OAuth, and provide an interface to the Google Tag Manager API.

This server enables remote MCP connections and integrates Google OAuth to provide an interface to the Google Tag Manager API. It is designed for marketing use cases, allowing AI agents to manage tags, triggers, and variables within Google Tag Manager. By combining the Model Context Protocol with Tag Manager's API, it facilitates automated marketing tag deployment and management.
