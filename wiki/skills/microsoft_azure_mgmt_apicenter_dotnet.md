This project is a .NET SDK for managing Azure API Center resources, enabling programmatic control of API centers through Azure Resource Manager. It provides CRUD operations for API center instances and related metadata. The library is part of the Azure SDK for .NET and is sponsored under the .NET Skills initiative.
