> 🎖️ 🐍 🏠 ☁️ - Search dashboards, investigate incidents and query datasources in your Grafana instance

This MCP server integrates Grafana, a leading open-source monitoring and observability platform, with MCP-compatible AI agents. It allows users to search dashboards, investigate incidents, and query various data sources through natural language interactions. The server provides MCP tools for interacting with Grafana's APIs, enabling AI-driven monitoring workflows. It is designed to help with common tasks like finding relevant metrics or diagnosing issues in real-time.
