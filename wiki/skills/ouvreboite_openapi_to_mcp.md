> #️⃣ ☁️ - Lightweight MCP server to access any API using their OpenAPI specification. Supports OAuth2 and full JSON schema parameters and request body.

A lightweight MCP server that automatically converts any OpenAPI specification into MCP tools, enabling AI agents to interact with external APIs through the Model Context Protocol. It supports OAuth2 authentication and full JSON Schema for parameters and request bodies, allowing seamless integration of diverse APIs without custom coding. This tool simplifies exposing RESTful APIs as tools for AI assistants.
