> 📇 ☁️ - MCP server for Altegio API — appointments, clients, services, staff schedules for salon/spa/clinic management. 18 tools with Docker support.

This project is an MCP server that integrates with the Altegio API, enabling AI assistants to manage appointments, clients, services, and staff schedules for salons, spas, and clinics. It provides 18 tools for tasks like booking, client management, and scheduling, with support for Docker deployment. The server streamlines operations for beauty and wellness businesses through the Model Context Protocol.
