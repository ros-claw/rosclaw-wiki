> 🐍 🏠 - Locust MCP Server for performance testing

The Locust MCP Server bridges AI agents with Locust, an open-source load testing tool, enabling automated performance test execution and metric retrieval. It allows developers to programmatically manage test scenarios through natural language commands from AI assistants. This integration streamlines performance testing workflows within AI-augmented development environments, making it easier to incorporate load testing into CI/CD pipelines.
