Invoices, disbursements, balance checks, and bank transfers across Indonesia, Philippines, Thailand, Vietnam, and Malaysia. Install via `npx xendit-mcp`.

This MCP server integrates the Xendit payment gateway, allowing AI agents to handle invoices, disbursements, balance checks, and bank transfers across Southeast Asian countries such as Indonesia, Philippines, Thailand, Vietnam, and Malaysia. It simplifies fintech operations by exposing Xendit's APIs through the Model Context Protocol. The server can be installed easily via npx.
