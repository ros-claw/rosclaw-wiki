Crafty-MCP is a Model Context Protocol (MCP) server that allows AI agents to manage Minecraft servers through the Crafty Controller 4 API. It provides capabilities such as starting, stopping, backing up servers, sending commands, and managing files, schedules, webhooks, and users. The server runs on Linux, macOS, and Windows, making it accessible across platforms. This integration enables automated server administration tasks via natural language or programmatic interactions.
