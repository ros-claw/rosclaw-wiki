> 🐍 🪟 🏠 MCP server for analyzing ROADrecon gather results from Azure tenant enumeration

This MCP server is designed to analyze and process the output gathered by ROADrecon, a tool used for enumerating Azure Active Directory tenants. It provides a standardized interface via the Model Context Protocol (MCP) to query and interact with reconnaissance results. Security professionals can use it to integrate Azure AD enumeration data into AI-assisted analysis workflows. The server helps in identifying misconfigurations and potential vulnerabilities in Azure environments.
