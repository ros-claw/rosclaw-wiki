> Rendering server for AI agents doing CAD work.

Cad-agent is a rendering server specifically designed to support AI agents in performing computer-aided design (CAD) tasks. It provides graphical rendering capabilities to AI systems, enabling them to visualize and manipulate CAD models. The server acts as an interface between AI agents and CAD software, facilitating automated design workflows.
