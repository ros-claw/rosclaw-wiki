The sieve-mcp MCP server provides an AI-powered tool for startup due diligence. It evaluates startups across seven IMPACT-X dimensions, generating a Sieve Score from 0 to 140 with evidence-typed findings. The tool is designed for venture capitalists, solo general partners, and angel investors, offering a clear meeting recommendation based on the analysis. It integrates with the Model Context Protocol to simplify investment screening.
