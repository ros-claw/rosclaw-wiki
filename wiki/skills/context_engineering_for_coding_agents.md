> Thoughtworks guidance on shaping the task environment so coding agents can stay grounded and productive.

Context Engineering for Coding Agents is a Thoughtworks-provided guidance that focuses on designing and shaping the task environment for AI coding agents. The goal is to keep these agents grounded and productive by managing the context they operate within. This involves providing relevant information and avoiding distractions, drawing on principles from context and memory management. The guidance is particularly relevant for developers working with AI coding assistants.
