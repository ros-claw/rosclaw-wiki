Email MCP server that integrates with IMAP and SMTP to manage emails across multiple accounts. It provides 42 tools for reading, searching, sending, scheduling, and managing emails. The server supports push notifications via IMAP IDLE, AI-powered email triage, and desktop notifications. It automatically detects providers like Gmail, Outlook, and iCloud, enabling comprehensive email management through the MCP protocol.
