This MCP server provides tools to access the Sovereign AI Blog, an engineering log about self-hosted AI on NVIDIA DGX Spark hardware. It offers three tools: full-text search, article retrieval, and an SGLang config validator for GB10 hardware. The blog has 44+ articles covering topics like SGLang, Mistral, Voxtral, and OpenClaw. The server is free, requires no authentication, and has no client-side tracking.
