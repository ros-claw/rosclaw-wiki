> [![ypollak2/llm-router MCP server](https://glama.ai/mcp/servers/ypollak2/llm-router/badges/score.svg)](https://glama.ai/mcp/servers/ypollak2/llm-router) 🐍 🏠 🍎 🪟 🐧 - Subscription-aware LLM router for Claude Code. Routes tasks to 20+ providers (OpenAI, Gemini, Groq, Ollama, Codex) based on complexity classification, Claude subscription pressure, and cost. Free tasks stay on Claude subscription; expensive tasks fall back to the cheapest capable model. Includes 30 MCP tools, 6 auto-routing hooks, semantic dedup cache, prompt caching, daily spend cap, and a live web dashboard.

This MCP server acts as an intelligent router for Claude Code, directing tasks to over 20 language model providers based on complexity, subscription pressure, and cost. It keeps simple tasks on the paid Claude subscription while routing expensive ones to cheaper models like OpenAI, Groq, or local Ollama. The tool includes 30 MCP tools, automatic routing hooks, semantic dedup caching, prompt caching, a daily spending cap, and a live web dashboard. It helps developers optimize costs without sacrificing performance by smartly balancing between subscription and pay-as-you-go models.
