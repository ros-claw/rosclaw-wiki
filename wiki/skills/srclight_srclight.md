> [![srclight MCP server](https://glama.ai/mcp/servers/@srclight/srclight/badges/score.svg)](https://glama.ai/mcp/servers/@srclight/srclight) 🐍 🏠 - Deep code indexing MCP server with SQLite FTS5, tree-sitter, and embeddings. 29 tools for symbol search, call graphs, git intelligence, and hybrid semantic search.

srclight is an MCP server that deeply indexes codebases using SQLite FTS5 for full-text search, tree-sitter for parsing code structure, and embeddings for semantic understanding. It offers 29 tools for symbol search, call graphs, git intelligence, and hybrid semantic search. This server enables AI agents to gain structured access to code intelligence for contextual understanding and analysis.
