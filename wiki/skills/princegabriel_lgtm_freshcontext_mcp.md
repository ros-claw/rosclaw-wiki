GitHub, HN, Scholar, arXiv, YC, jobs, finance, package trends — every result stamped with how old it is.

This MCP server provides real-time intelligence from various web sources like GitHub, Hacker News, Google Scholar, arXiv, Y Combinator, jobs, finance, and package trends. Each result includes a freshness timestamp indicating how old the information is, helping users assess recency. It aims to deliver up-to-date context for browsing and analysis tasks within the Model Context Protocol ecosystem.
