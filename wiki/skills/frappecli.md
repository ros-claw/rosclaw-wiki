> CLI for Frappe Framework / ERPNext instances.

frappecli is a command-line interface tool for managing Frappe Framework and ERPNext instances. It offers administrative commands to simplify common tasks such as backup, restore, and site management. The tool is intended for developers and system administrators working with Frappe-based applications.
