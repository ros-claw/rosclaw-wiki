> 🐍 🏠 – A Python Runtime Interpreter MCP Server that executes user-submitted code in an isolated environment.

PRIMS is an MCP server that provides a Python runtime interpreter for executing user-submitted code in an isolated environment. It is listed under server implementations for code execution in the MCP ecosystem. This server enables AI agents to run Python code safely within a sandboxed context, preventing unauthorized system access. It serves as a tool for embedding code execution capabilities into MCP-based applications.
