> Lint your repo for AI agent compatibility. 33 evidence-backed checks across 5 dimensions. Claude Code plugin.

AgentLint is a linting tool that scans code repositories for compatibility with AI coding agents such as Claude Code. It performs 33 evidence-backed checks across five dimensions, including documentation, code structure, and dependency management. By identifying potential issues, it helps developers make their codebases more accessible to AI assistants. It is available as a plugin for Claude Code.
