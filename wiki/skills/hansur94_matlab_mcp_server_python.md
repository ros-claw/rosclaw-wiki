This project implements a Model Context Protocol (MCP) server that bridges AI agents with MATLAB, enabling code execution, asynchronous job management with progress updates, and interactive Plotly visualizations. It exposes custom .m functions as tools for AI agents and provides a live monitoring dashboard. Designed for cross-platform use, it supports Windows, macOS, and Linux systems.
