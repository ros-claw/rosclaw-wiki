This MCP server enables AI agents to safely interact with multiple databases by executing read-only SQL queries. It currently supports PostgreSQL and MySQL, offering schema discovery, data sampling, and query plan inspection. The server ensures clear boundaries for database interactions, making it suitable for AI-driven data exploration and analysis.
