> 📇 🏠 🍎 🪟 🐧 - A Mermaid diagram rendering MCP server for Claude Code with live reload functionality, supporting multiple export formats (SVG, PNG, PDF) and themes.

This project is a Model Context Protocol (MCP) server that enables Claude Code to render Mermaid diagrams directly. It features live reload functionality, so diagram updates are reflected in real-time. The server supports exporting diagrams in SVG, PNG, and PDF formats, and offers multiple theme options. It is cross-platform, available for macOS, Windows, and Linux.
