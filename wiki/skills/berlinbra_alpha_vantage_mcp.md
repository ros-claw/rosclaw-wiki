> 🐍 ☁️ - Alpha Vantage API integration to fetch both stock and crypto information

This project is a Model Context Protocol (MCP) server that wraps the Alpha Vantage API, allowing AI agents to retrieve real-time and historical data for both stocks and cryptocurrencies. It provides a standardized interface for fetching financial information such as prices, volumes, and technical indicators. The server simplifies integration of market data into AI-powered tools and chatbots, enabling natural language queries about financial markets.
