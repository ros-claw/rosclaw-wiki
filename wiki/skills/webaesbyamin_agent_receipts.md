> [![webaesbyamin/agent-receipts MCP server](https://glama.ai/mcp/servers/webaesbyamin/agent-receipts/badges/score.svg)](https://glama.ai/mcp/servers/webaesbyamin/agent-receipts) 📇 🏠 - Cryptographic accountability for AI agents. Ed25519-signed receipts for every MCP tool call — constraints, chains, AI judgment, invoicing, local dashboard.

This server provides cryptographic accountability for AI agents by generating Ed25519-signed receipts for every MCP tool call. It enables auditing, constraint enforcement, invoicing, and a local dashboard to track agent actions. The receipts ensure that each tool execution is verifiable and non-repudiable, supporting trust in autonomous systems. Useful for monitoring agent behavior and integrating billing or compliance workflows.
