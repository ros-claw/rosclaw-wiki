> 📇 🪟 ☁️ - MCP server for maigret, a powerful OSINT tool that collects user account information from various public sources. This server provides tools for searching usernames across social networks and analyzing URLs.

This project provides an MCP server interface for the maigret OSINT tool, enabling AI agents to search for usernames across hundreds of social networks and public sources. It exposes tools to query a given username and return associated profile links and metadata. The server also supports analyzing URLs to extract usernames or platform info. By integrating maigret's capabilities into the MCP ecosystem, it allows automated intelligence gathering within agent workflows. The project falls under security-focused server implementations.
