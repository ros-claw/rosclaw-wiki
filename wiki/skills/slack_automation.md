> Automate Slack: messages, channels, search, reactions, threads, and scheduling.

This project provides a composable skill for automating various Slack operations. It enables agents to send messages, manage channels, search content, add reactions, handle threads, and schedule posts. Built on Composio, it integrates Slack automation into AI-agent tooling. This allows users to streamline communication workflows without manual intervention.
