> 📇 🦀 🏠 🍎 🐧 🪟 - Persistent intelligence infrastructure for agentic development that gives AI coding assistants cumulative memory and pattern learning. Hybrid TypeScript/Rust implementation with local-first storage using SQLite + SurrealDB for semantic analysis and incremental codebase understanding.

In-Memoria is a persistent intelligence infrastructure for AI coding assistants, enabling cumulative memory and pattern learning across interactions. It uses a hybrid TypeScript and Rust implementation with local-first storage using SQLite and SurrealDB for semantic analysis. The system provides incremental codebase understanding, allowing agents to learn from past context and improve over time. This approach aims to give AI assistants a form of long-term memory for more coherent and personalized development support.
