> 📇 🏠 🛠️ - A middleware server that enables multiple isolated instances of the same MCP servers to coexist independently with unique namespaces and configurations.

This project is a middleware server for the MCP protocol that allows multiple isolated instances of the same MCP server to run concurrently. Each instance operates with its own unique namespace and configuration, preventing conflicts and interference. Designed for developers, it enables testing multiple versions or settings of the same server side by side. The tool simplifies development workflows where separate environments for the same MCP server are needed.
