Agent Fleet-O is an open-source AI Agent Mission Control framework that provides over 200 MCP (Model Context Protocol) tools. It enables management of agents, experiments, workflows, crews, and skills through stdio and HTTP/SSE interfaces. The project is self-hosted under AGPL-3.0 license and offers a remote server at fleetq.net.
