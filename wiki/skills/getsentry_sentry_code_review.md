Sentry Code Review is a GitHub Action that uses AI to automatically review pull requests, providing feedback on code quality and helping teams catch issues early. It integrates with Sentry's error monitoring to reduce manual review work. The tool is designed to speed up development workflows by automating parts of the code review process.
