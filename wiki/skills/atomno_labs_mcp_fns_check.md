> [![atomno-labs/mcp-fns-check MCP server](https://glama.ai/mcp/servers/atomno-labs/mcp-fns-check/badges/score.svg)](https://glama.ai/mcp/servers/atomno-labs/mcp-fns-check) 🐍 ☁️ - Russian counterparty due diligence — INN/OGRN lookup against EGRUL/EGRIP, bankruptcy registry (EFRSB), tax debts (Transparent Business), FSSP enforcement proceedings, and arbitration courts (KAD). Aggregated verdict with risk flags and recommendations. No API key required (public Federal Tax Service data).

This MCP server provides due diligence on Russian counterparties using public government data sources without requiring an API key. It can look up company INN/OGRN to retrieve information from the Unified State Register of Legal Entities (EGRUL) and Individual Entrepreneurs (EGRIP), as well as check bankruptcy records, tax debts, enforcement proceedings, and arbitration cases. The server then aggregates these results into a verdict with risk flags and recommendations, making it useful for compliance and risk assessment in business dealings with Russian entities.
