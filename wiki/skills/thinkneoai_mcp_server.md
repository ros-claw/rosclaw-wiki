> [![ThinkneoAI/mcp-server MCP server](https://glama.ai/mcp/servers/ThinkneoAI/mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/ThinkneoAI/mcp-server) 🐍 ☁️ - ThinkNEO Control Plane — Enterprise AI governance MCP server with runtime guardrails, observability, AI FinOps, and agent lifecycle control.

ThinkneoAI/mcp-server is an enterprise AI governance MCP server that functions as a control plane for monitoring and managing AI agents. It provides runtime guardrails, observability, AI FinOps capabilities, and agent lifecycle control. This server enables organizations to enforce governance policies, track AI system performance, and optimize costs associated with AI operations. It is designed for use with the ThinkNEO platform and integrates with the Model Context Protocol for standardized agent management.
