> 🐍 ☁️ 📇 - MCP Server to do dynamic AI SOC Security Threat analysis for a  Text2SQL  AI Agent.

This project implements an MCP (Model Context Protocol) server designed for dynamic AI-driven SOC (Security Operations Center) threat analysis. It specifically targets Text2SQL AI agents, enabling them to assess security threats in real-time. By integrating with AI agent workflows, it helps automate security analysis for database queries. The server acts as a developer tool, bridging AI agents and threat intelligence.
