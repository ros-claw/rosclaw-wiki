> A benchmark that emulates dynamic conversations between a simulated user and a language agent equipped with domain-specific API tools and policy guidelines, making it useful for evaluating harnesses built around structured tool use and policy enforcement.

τ-Bench is a benchmark that simulates dynamic conversations between a user and a language agent. The agent is equipped with domain-specific API tools and policy guidelines. This benchmark tests structured tool use and policy enforcement. It is particularly useful for evaluating harnesses that manage tool calls and compliance. τ-Bench helps measure how well agents follow guidelines during interactions.
