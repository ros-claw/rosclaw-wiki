> 📇 ☁️ 🏠 🍎 🪟 🐧 - A soundboard MCP server with millions of meme sounds from myinstants.com. Search, play, and browse categories — let your AI agent play vine boom when code compiles. `npx myinstants-mcp`

This project provides an MCP server that connects AI agents to a vast library of meme sounds from myinstants.com. It allows agents to search, play, and browse sound categories, enabling playful audio feedback like playing a 'vine boom' sound when code compiles. The server is easy to run via npx and supports multiple platforms. It adds a cultural and entertainment layer to AI interactions.
