This MCP server allows AI assistants to generate professional PDF documents such as invoices, contracts, reports, and certificates. It integrates the Rendoc API with support for reusable templates or inline HTML and Handlebars markup. The server offers seven tools covering document generation, template management, and usage tracking. It is designed for the Workplace & Productivity category and runs on cloud, macOS, Windows, and Linux platforms.
