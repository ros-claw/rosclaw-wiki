> 🦀 🏠 - An MCP server implementation to interact with Substrate-based blockchains. Built with Rust and interfacing the [subxt](https://github.com/paritytech/subxt) crate.

Substrate-mcp-rs is an MCP server implementation for interacting with Substrate-based blockchains. Built in Rust, it uses the subxt crate to interface with blockchain data and transactions. This server enables AI agents to connect to Substrate networks, facilitating decentralized finance (DeFi) applications. It is categorized under Finance & Fintech server implementations.
