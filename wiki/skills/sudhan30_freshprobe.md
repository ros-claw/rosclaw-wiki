Freshprobe is a tool that verifies data freshness for AI agents by probing endpoints for HTTP cache staleness, latency percentiles, content fingerprinting, TLS health, DNS timing, and redirect chains. It returns deterministic verdicts (FRESH, STALE, or UNKNOWN) with mappings to the NIST AI RMF. The tool can be used as a CLI, an MCP server, or an HTTP API, and it includes Prometheus metrics and a YAML policy engine for configuration. This helps AI agents ensure they are working with current and reliable data.
