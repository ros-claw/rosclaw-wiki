> 🐍 ☁️ - Providing latest cryptocurrency news to AI agents, powered by CryptoPanic.

This project is a Model Context Protocol (MCP) server that integrates with the CryptoPanic API to deliver the latest cryptocurrency news directly to AI agents. It enables AI systems to query and receive real-time news updates about various cryptocurrencies. The server is categorized under Finance & Fintech, focusing on providing timely market information for automated decision-making.
