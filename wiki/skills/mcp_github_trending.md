> MCP server for getting github trending repos & developers

mcp-github-trending is a Model Context Protocol (MCP) server that retrieves trending repositories and developers from GitHub. It exposes tools and resources for AI agents to query current trending data without manual browsing. The server simplifies access to GitHub's trending page by wrapping it in a standardized MCP interface. This enables AI assistants to fetch trending topics, languages, and popular developers programmatically.
