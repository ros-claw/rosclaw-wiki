> Sets context for model training by referencing pipeline files, establishing working context, and preparing for pipeline work with relevant documentation.

This slash command is used to load a 'dango' pipeline, setting the context for model training. It references specific pipeline files to establish the working environment and prepares the system by priming with relevant documentation. The command streamlines the process of starting pipeline work by ensuring all necessary context is in place.
