> 🐍 🏠 - Pharo Smalltalk integration enabling code evaluation, class/method introspection, package management, test execution, and project installation for interactive development with Pharo images.

This is an MCP server that integrates Pharo Smalltalk with AI agents, enabling code evaluation, class and method introspection, package management, test execution, and project installation. It allows AI tools to interact directly with Pharo images for interactive development, debugging, and automation. Designed as a server implementation under Developer Tools, it bridges the gap between AI assistants and Smalltalk environments.
