icogenie-mcp is an MCP (Model Context Protocol) server that uses AI to generate production-ready SVG icons from text descriptions. It supports customizable styles, making it easy for developers and designers to create tailored icons without manual drawing. The tool integrates with AI chat interfaces to provide on-demand icon generation. It is listed under the Art & Culture category of MCP server implementations.
