> Local-first persistent memory for AI agents with SQLite storage, orchestrated retrieve/extract loops, hybrid.

Agent-brain provides a local-first, persistent memory system for AI agents, using SQLite for storage. It implements orchestrated retrieve/extract loops and hybrid search to enable agents to recall and manage context. This tool is designed to run locally, ensuring data privacy and low latency.
