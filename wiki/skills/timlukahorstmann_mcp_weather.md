> 📇 ☁️  - Accurate weather forecasts via the AccuWeather API (free tier available).

mcp-weather is a server implementation for the Model Context Protocol that provides accurate weather forecasts. It leverages the AccuWeather API, which offers a free tier for accessing weather data. The server is categorized under Location Services in the MCP server repository. This tool can be integrated with AI agents to answer weather-related queries effectively.
