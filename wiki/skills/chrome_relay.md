> Drives the user's already-open Chrome session — cookies, SSO, extensions, localhost — through a local CLI bridge. Real-Chrome counterpart to Playwright Browser Automation; install via `npx skills add chrome-relay` + a [Chrome Web Store extension](https://chromewebstore.google.com/detail/chrome-relay/cpdiapbifblhlcpnmlmfpgfjlacebokb). No remote relay, no Playwright fixtures, no MCP server needed.

Chrome Relay is a tool that controls a user's existing Chrome browser session through a local command-line interface (CLI). It leverages the user's cookies, SSO sessions, extensions, and localhost connections, acting as a real-Chrome alternative to Playwright's browser automation. Installation requires adding the skill via `npx skills add chrome-relay` and installing a Chrome Web Store extension. It operates locally without needing remote relays, Playwright fixtures, or an MCP server.
