Free via MCP, pay-per-use via x402. Remote MCP endpoint: `https://anybrowse.dev/mcp`

anybrowse is an MCP server that converts any URL into LLM-ready Markdown using real Chrome browsers. It provides three tools: scrape (fetch single page), crawl (follow links), and search (web search and fetch results). The service is free via MCP (Model Context Protocol) and offers pay-per-use via the x402 protocol. It is hosted at a remote MCP endpoint and listed under Search & Data Extraction server implementations.
