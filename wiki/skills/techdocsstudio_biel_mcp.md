> 📇 ☁️ - Let AI tools like Cursor, VS Code, or Claude Desktop answer questions using your product docs. Biel.ai provides the RAG system and MCP server.

Biel MCP is a server that connects AI tools like Cursor, VS Code, and Claude Desktop to your product documentation. It uses a RAG (Retrieval-Augmented Generation) system from Biel.ai to answer questions based on your docs. This allows AI assistants to provide accurate, context-aware responses using your own knowledge base. The project is listed under Knowledge and Memory server implementations.
