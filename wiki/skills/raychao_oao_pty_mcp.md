Single Go binary, no tmux dependency.

This MCP server enables AI agents to interact with interactive command-line sessions. It supports local shell access, SSH connections with persistent sessions that can be attached and detached, and serial port communication. The server is distributed as a single Go binary and does not require tmux to be installed, using its own ai-tmux daemon for session management.
