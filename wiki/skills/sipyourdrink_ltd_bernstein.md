MCP server mode (stdio + HTTP/SSE) exposes the orchestrator to any MCP client. Git worktree isolation per agent, HMAC-chained audit trail, cost-aware model routing via contextual bandit. Apache 2.0.

Bernstein is a deterministic multi-agent orchestrator that manages 37 different CLI coding agents, including Claude Code, Codex, Aider, and Gemini CLI. It operates as an MCP server via stdio or HTTP/SSE, exposing the orchestration to any MCP client. Key features include Git worktree isolation per agent for clean state management, an HMAC-chained audit trail for verifiable logs, and cost-aware model routing using a contextual bandit algorithm. The project is licensed under Apache 2.0 and designed for systematic, reproducible multi-agent workflows.
