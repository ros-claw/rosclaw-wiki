pt-edge is an MCP server that provides AI project intelligence by tracking over 300 open-source AI projects across platforms like GitHub, PyPI, npm, HuggingFace, Docker Hub, and Hacker News. It offers 47 MCP tools for discovering, comparing, and analyzing trends in AI repositories, models, datasets, and public APIs. The server enables semantic search and trend analysis, making it easier for developers to stay updated on the AI ecosystem.
