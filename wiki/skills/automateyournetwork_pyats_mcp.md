> Cisco pyATS server enabling structured, model-driven interaction with network devices.

pyATS_MCP is a server implementation that integrates Cisco's pyATS framework with the Model Context Protocol (MCP), enabling structured, model-driven interaction with network devices. This allows AI coding agents to programmatically test, validate, and configure network infrastructure in a standardized way. The project focuses on bridging network automation and intelligent agents for efficient network management.
