> 🐍 ☁️ - Open-source MCP server for Snowflake from official Snowflake-Labs supports prompting Cortex Agents, querying structured & unstructured data, object management, SQL execution, semantic view querying, and more. RBAC, fine-grained CRUD controls, and all authentication methods supported.

This is an open-source MCP server developed by Snowflake Labs that connects AI agent tools to Snowflake databases. It supports querying structured and unstructured data, executing SQL commands, managing database objects, and prompting Cortex Agents. The server includes role-based access control, fine-grained CRUD permissions, and all major Snowflake authentication methods.
