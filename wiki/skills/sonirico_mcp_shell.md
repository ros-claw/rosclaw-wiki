> 🏎️ 🏠 🍎 🪟 🐧 Give hands to AI. MCP server to run shell commands securely, auditably, and on demand on isolated environments like docker.

MCP-shell is an MCP server that allows AI agents to execute shell commands in isolated, auditable environments like Docker. It provides a secure bridge for AI coding agents to run scripts, manage files, or perform system tasks on demand. The tool ensures that all commands are logged and executed within sandboxed containers, preventing unauthorized access to the host system. This makes it suitable for use cases where AI needs to interact with a shell without compromising security or compliance.
