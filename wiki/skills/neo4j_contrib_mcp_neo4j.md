> 🐍 🏠 - Model Context Protocol with Neo4j (Run queries, Knowledge Graph Memory, Manaage Neo4j Aura Instances)

This project implements the Model Context Protocol (MCP) for Neo4j, allowing AI agents to run Cypher queries, manage knowledge graph memory, and administer Neo4j Aura cloud instances. It serves as a bridge between large language models and graph databases for context-aware interactions. The server enables persistent memory storage using Neo4j's graph structure. It is designed for building AI applications that require structured knowledge retrieval and dynamic graph data management.
