> 🎖️ 🐍 ☁️ Access real-time X/Reddit/YouTube data directly in your LLM applications  with search phrases, users, and date filtering.

This project provides an MCP server that enables LLM applications to access real-time data from social media platforms including X (Twitter), Reddit, and YouTube. It supports filtering by search phrases, users, and dates, allowing AI agents to retrieve current social media content. The server is designed for integration with the Model Context Protocol, making social media data accessible directly within LLM workflows.
