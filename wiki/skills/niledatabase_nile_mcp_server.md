> MCP server for Nile's Postgres platform - Manage and query Postgres databases, tenants, users, auth using LLMs

This is an MCP server for Nile's Postgres platform, allowing AI assistants such as LLMs to manage and query Postgres databases, tenants, users, and authentication. It provides a standardized interface through the Model Context Protocol for natural language database operations. The server enables multi-tenant database management and user authentication via AI-driven interactions.
