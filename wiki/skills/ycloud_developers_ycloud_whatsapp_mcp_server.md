> 📇 🏠 - MCP server for WhatsApp Business Platform by YCloud.

This project is an MCP server for the WhatsApp Business Platform, built by YCloud. It allows AI agents to send and receive WhatsApp messages through the Model Context Protocol. The server integrates with YCloud's APIs to manage conversations and contacts. It is listed under Communication server implementations.
