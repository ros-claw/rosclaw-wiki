> 🐍 ☁️ - Unsplash photo search with proper attribution. Returns ready-to-use attribution text and HTML for each photo, making it easy for LLMs to build content pages with properly credited images. Includes search, random photos, and download tracking.

This project provides an MCP server that enables LLMs to search Unsplash photos and receive ready-to-use attribution text and HTML. It includes search, random photo retrieval, and download tracking. The server is designed to help AI agents build content pages with properly credited images. It is listed under Search & Data Extraction in the MCP server implementations.
