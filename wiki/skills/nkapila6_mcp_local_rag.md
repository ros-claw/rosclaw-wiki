> 🏠 🐍 - "primitive" RAG-like web search model context protocol (MCP) server that runs locally. No APIs needed.

This project is an MCP server that provides a primitive RAG-like web search capability, running entirely locally without requiring any external APIs. It implements the Model Context Protocol to allow AI agents to perform search and data extraction tasks using local resources. The server is designed for privacy and offline use, making it suitable for development or air-gapped environments. It leverages local embeddings and retrieval to simulate RAG workflows.
