Apollo MCP Server is a TypeScript-based server that bridges GraphQL APIs with AI assistants using the Model Context Protocol (MCP). It enables natural language queries and mutations against Apollo GraphQL endpoints, allowing AI agents to interact with live data. The tool is designed for developers integrating GraphQL into AI workflows, supporting schema discovery and secure execution.
