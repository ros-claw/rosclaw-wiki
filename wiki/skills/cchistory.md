> Like the shell history command but for your Claude Code sessions. Easily list all Bash or "Bash-mode" (`!`) commands Claude Code ran in a session for reference.

cchistory is a tool that provides a history command for Claude Code sessions, similar to the shell's built-in history command. It allows users to list all Bash or Bash-mode commands that Claude Code executed during a session. This makes it easy to reference and review the commands run by the AI assistant. The tool is designed to improve workflow transparency and debugging for Claude Code users.
