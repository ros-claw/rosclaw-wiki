This project implements an MCP server as middleware for aiogram, a Python framework for Telegram bots. It provides 30 tools, 7 resources, and 3 prompts covering messaging, rich media, moderation, interactive keyboards, real-time event streaming, rate limiting, permissions, and audit logging. Developers can use it to enable AI agents to interact with Telegram bots via the Model Context Protocol.
