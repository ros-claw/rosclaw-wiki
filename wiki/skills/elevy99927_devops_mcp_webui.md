> 🐍 ☁️/🏠 - MCP Server for Kubernetes integrated with Open-WebUI, bridging the gap between DevOps and non-technical teams. Supports `kubectl` and `helm` operations through natural-language commands.

This project is a Model Context Protocol (MCP) server that integrates Kubernetes operations with the Open-WebUI interface. It allows users to execute kubectl and Helm commands using natural language, making Kubernetes management accessible to non-technical team members. The tool bridges the gap between DevOps and other teams by providing a user-friendly web-based interface for cloud platform operations. It supports both cloud and on-premises Kubernetes clusters.
