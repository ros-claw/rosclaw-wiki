> 🦀 🏠 🪟 - High-performance, token-efficient spreadsheet analysis/editing (xlsx/xlsm) with region detection, structured reads, formula/style inspection, forking mechanics, and recalculation. Cross-platform.

This project provides a high-performance MCP server for analyzing and editing spreadsheet files (xlsx/xlsm) with minimal token usage. It supports region detection, structured data reads, formula and style inspection, file forking mechanics, and recalculation. Built with Rust, it is cross-platform and optimized for efficiency. Designed for developer tools, it integrates with AI agents for programmable spreadsheet manipulation.
