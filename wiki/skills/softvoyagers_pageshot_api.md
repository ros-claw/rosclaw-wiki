> 📇 ☁️ - Free webpage screenshot capture API with format, viewport, and dark mode options. No API key required.

Pageshot API is a free web service for capturing screenshots of webpages. It supports multiple image formats, customizable viewport sizes, and dark mode. No API key is required to use the service, making it easy to integrate into any project.
