> 📇 ☁️ Allows AI models to interact with [Kibela](https://kibe.la/)

This MCP server allows AI models to interact with Kibela, a collaborative knowledge base and wiki platform. It enables AI assistants to read, search, and manage Kibela content through the Model Context Protocol. The integration helps teams leverage AI for knowledge management within their Kibela workspace. This server is listed under Other Tools and Integrations for MCP server implementations.
