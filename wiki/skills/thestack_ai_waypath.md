Waypath is a local-first external brain CLI for coding agents, providing persistent memory and context using SQLite as the backend. It offers graph-aware recall through FTS5 full-text search and Reciprocal Rank Fusion (RRF) for improved relevance ranking. The system includes governed memory with explicit promote and review gates to control knowledge retention. It ships with shims for Codex and Claude Code hosts, plus a native MCP server for integration.
