Continuous awareness engine (Cortex) with freshness + side-effect detection. Works offline with Ollama + local models.

Cellar is a hybrid computer-use runtime that combines accessibility tree data, Chrome DevTools Protocol, and computer vision to create structured context with per-element confidence. It offers four MCP tools: see, act, think, and perceive. The system includes a continuous awareness engine called Cortex that tracks freshness and detects side effects. It can operate offline using Ollama and local models, making it suitable for autonomous desktop automation.
