> [finmap.org](https://finmap.org/) MCP server provides comprehensive historical data from the US, UK, Russian and Turkish stock exchanges. Access sectors, tickers, company profiles, market cap, volume, value, and trade counts, as well as treemap and histogram visualizations.

This MCP server provides comprehensive historical stock market data from US, UK, Russian, and Turkish exchanges via the finmap.org API. It offers access to sectors, tickers, company profiles, market cap, volume, value, trade counts, and visualizations like treemaps and histograms. The server enables AI agents to query financial data programmatically through the Model Context Protocol, making it useful for financial analysis and investment research applications.
