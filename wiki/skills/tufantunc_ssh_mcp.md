> 📇 🏠 🐧 🪟 - MCP server exposing SSH control for Linux and Windows servers via Model Context Protocol. Securely execute remote shell commands with password or SSH key authentication.

This project is an MCP server that allows AI agents to remotely execute shell commands on Linux and Windows servers via SSH. It supports both password and SSH key authentication for secure connections. The server exposes SSH control as a tool, enabling large language models to manage remote systems. It is categorized under coding agents and facilitates cross-platform remote administration.
