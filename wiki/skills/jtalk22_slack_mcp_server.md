> 📇 ☁️ 🏠 🍎 🪟 🐧 - Your complete Slack context for Claude—DMs, channels, threads, search. No OAuth apps, no admin approval. `--setup` and done, 11 tools, auto-refresh.

This MCP server integrates Slack with Claude, enabling access to direct messages, channels, threads, and search without requiring OAuth apps or admin approval. Setup is straightforward with a single `--setup` flag, and it provides 11 tools with automatic refresh. It is designed for users who want a seamless Slack context for AI interactions.
