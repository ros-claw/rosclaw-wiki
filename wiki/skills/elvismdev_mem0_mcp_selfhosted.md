Zero-config OAT auth, split-model graph routing, session hooks for automatic cross-session memory, and 11 tools. Supports both Anthropic and fully local Ollama setups.

This project is a self-hosted MCP server that integrates the mem0 memory system with Claude Code. It uses Qdrant for vector search, Neo4j as a knowledge graph database, and Ollama for local embeddings, enabling memory persistence across sessions. The server features zero-config OAT authentication, split-model graph routing, and session hooks for automatic cross-session memory. It provides 11 tools and supports both Anthropic and fully local Ollama setups, making it suitable for users who want to run memory-enhanced AI agents with full data control.
