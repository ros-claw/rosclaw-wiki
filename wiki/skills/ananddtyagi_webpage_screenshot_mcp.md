> 📇 🏠 - A MCP server for taking screenshots of webpages to use as feedback during UI developement.

This project implements a Model Context Protocol (MCP) server that takes screenshots of webpages. It is designed to provide visual feedback during UI development, allowing AI agents to capture and analyze webpage visuals. The server integrates with MCP clients to enable screenshot-based interactions for debugging or review purposes.
