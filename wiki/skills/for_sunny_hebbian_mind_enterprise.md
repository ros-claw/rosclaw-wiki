This project implements a self-organizing neural graph memory system for AI agents. It uses Hebbian learning to strengthen connections between nodes based on co-activation and weakens them through temporal decay. The system features over 118 learning nodes, a dual-write architecture for efficient storage, and sub-millisecond read times. It is designed to be used as an MCP server for knowledge and memory management in AI applications.
