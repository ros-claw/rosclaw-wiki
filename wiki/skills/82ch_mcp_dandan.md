> 🐍 📇 🏠 🍎 🪟 🐧 - Real-time security framework for MCP servers that detects and blocks malicious AI agent behavior by analyzing tool call patterns and intent across multiple threat detection engines.

Dandan is a real-time security framework for MCP (Model Context Protocol) servers. It detects and blocks malicious AI agent behavior by analyzing tool call patterns and intent across multiple threat detection engines. The project aims to protect MCP servers from attacks by AI agents, ensuring safe and secure interactions.
