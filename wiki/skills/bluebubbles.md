> Build or update the BlueBubbles external channel plugin.

BlueBubbles enables Android users to send and receive iMessages by bridging to Apple's messaging service. This README guides developers through building or updating the external channel plugin, which allows BlueBubbles to interface with alternative communication channels. It provides instructions for compiling the plugin from source and integrating it with the BlueBubbles server. This is essential for customizing message delivery beyond the default iMessage protocol.
