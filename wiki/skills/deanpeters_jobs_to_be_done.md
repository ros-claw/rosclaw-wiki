This project provides a TypeScript implementation or toolkit for applying the Jobs-to-be-Done (JTBD) framework in product development. It helps developers and product managers define user needs in terms of functional, social, and emotional jobs. The tool may assist in structuring job statements, identifying customer segments, or integrating JTBD concepts into development workflows. It aims to bridge product management theory with code, enabling teams to build features aligned with user goals.
