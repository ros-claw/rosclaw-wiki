Real-time access to PubMed (35M+ papers) and ClinicalTrials.gov (400K+ trials). No API key required.

Aria MCP server is a Model Context Protocol server designed for clinical research, enabling trial coordinators and life sciences teams to access real-time data from PubMed (over 35 million papers) and ClinicalTrials.gov (over 400,000 trials) without requiring an API key. It streamlines the discovery of biomedical literature and clinical trial information through a standardized interface, making it easier for researchers and coordinators to integrate this data into their workflows. The server is open-source and categorized under biology, medicine, and bioinformatics tooling.
