> ☕ 🏠 - A JetBrains IDE plugin that exposes an MCP server, enabling AI coding assistants to leverage the IDE's indexing and refactoring capabilities (rename, safe delete, find references, call hierarchy, type hierarchy, diagnostics and more).

This project is a plugin for JetBrains IDEs that exposes a Model Context Protocol (MCP) server. It allows AI coding assistants to access the IDE's powerful indexing and refactoring features such as renaming, safe deletion, finding references, call hierarchy, type hierarchy, and diagnostics. By integrating MCP, the plugin enables seamless interaction between AI tools and the development environment. It aims to enhance developer productivity by leveraging JetBrains' code analysis capabilities.
