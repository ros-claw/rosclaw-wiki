> 🐍 🏠 - Generate visualizations from fetched data using the VegaLite format and renderer.

This project provides an MCP (Model Context Protocol) server that allows agents to generate visualizations from fetched data using the Vega-Lite grammar. It automatically renders charts in a format compatible with common viewing tools. The server is designed to integrate seamlessly with AI agents that need to present data graphically.
