Sitelauncher MCP server lets you deploy live HTTPS websites in seconds using subdomains ($1 USDC) or custom .xyz domains ($10 USDC) on the Base blockchain. It provides templates tailored for crypto tokens and AI agent profiles. Payment is handled in USDC, making it a blockchain-based website deployment tool. This server integrates with MCP to offer a simple cloud platform for rapid site creation.
