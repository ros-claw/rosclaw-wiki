> 🎖️ 🐍 ☁️ 🪟 🐧 🍎 - Create, manage, and automate Label Studio projects, tasks, and predictions for data labeling workflows.

This project is an MCP (Model Context Protocol) server for Label Studio, enabling AI agents to create, manage, and automate data labeling workflows. It allows programmatic interaction with Label Studio projects, tasks, and predictions. Designed for integration with AI tools, it supports cross-platform operation and streamlines annotation processes for machine learning datasets.
