> Control Apple TV, HomePod, and AirPlay devices via pyatv.

apple-media is a tool that allows you to control Apple TV, HomePod, and AirPlay devices using the pyatv library. It enables automation and integration of Apple media devices into smart home or AI-agent workflows. The project leverages pyatv for communication with these devices. It is useful for developers building systems that need to manage Apple's media ecosystem.
