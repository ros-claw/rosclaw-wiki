> 📇 🏠 - Instagram MCP server for analytics and insights. Get account overviews, posts, followers, following lists, post insights, and search for users, hashtags, or places.

This is an MCP server that provides analytics and insights for Instagram. It allows users to retrieve account overviews, posts, follower and following lists, and post insights. The server also supports searching for users, hashtags, or places. It integrates Instagram data into the Model Context Protocol, enabling AI agents to access and analyze social media information programmatically.
