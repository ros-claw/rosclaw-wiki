> 📇 ☁️ - Enforces team naming consistency for AI-generated code via Cursor MCP integration. [Guide ↗](https://var.gg)

This project provides an MCP server that integrates with Cursor to enforce team naming conventions for AI-generated code. It helps maintain consistency in codebases by automatically applying naming rules. The tool is designed for developers using AI coding assistants to ensure generated code adheres to predefined standards. This simplifies the process of keeping code uniform across teams.
