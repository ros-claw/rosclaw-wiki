> 🏎️ 🏠 - Some useful tools for developer, almost everything an engineer need: confluence, Jira, Youtube, run script, knowledge base RAG, fetch URL, Manage youtube channel, emails, calendar, gitlab

This is a comprehensive Model Context Protocol (MCP) server that integrates multiple developer tools and services, including Confluence, Jira, YouTube, GitLab, email, calendar, and a knowledge base with RAG. It provides functionalities like running scripts, fetching URLs, managing YouTube channels, and more, aiming to serve as an all-in-one tool for engineers. The server is designed to work within the MCP ecosystem to enhance AI assistants with access to these services.
