Validate, query, diff, lint, version, and govern knowledge graphs via Oxigraph triple store.

This MCP server provides AI-native ontology engineering capabilities with 39 tools and 5 prompts for working with OWL, RDF, and SPARQL. It enables users to validate, query, diff, lint, version, and govern knowledge graphs using an embedded Oxigraph triple store. Designed for integration with AI agents, it facilitates the creation and management of open ontologies in a semantic web context.
