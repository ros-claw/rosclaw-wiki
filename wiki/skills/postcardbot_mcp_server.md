PostcardBot/mcp-server is a Model Context Protocol (MCP) server that enables AI agents to send real physical postcards worldwide. It supports bulk sending to up to 500 recipients at once, with volume pricing starting at $0.72 per card. This tool allows any AI to trigger a tangible, physical mailing via a simple integration, bridging digital agents with offline postal delivery.
