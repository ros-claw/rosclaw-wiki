This MCP server connects to the Google Search Console API, providing a set of 13 SEO tools. It enables tasks such as search analytics, URL inspection, sitemap management, keyword opportunity identification, brand analysis, and performance comparison. The server is designed to integrate with AI assistants that support the Model Context Protocol (MCP) for automated SEO workflows.
