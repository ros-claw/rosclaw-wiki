> A highly customizable status line formatter for Claude Code CLI that displays model info, git branch, token usage, and other metrics in your terminal.

This is a highly customizable status line formatter specifically built for the Claude Code CLI. It displays important real-time information such as the active AI model, current git branch, token usage, and other performance metrics directly in the terminal. Users can tailor the display to fit their preferences, making it a flexible tool for developers using Claude Code. It enhances terminal productivity by providing at-a-glance insights during development sessions.
