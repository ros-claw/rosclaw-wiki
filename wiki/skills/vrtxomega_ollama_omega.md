Exposes ollama_chat, ollama_generate, ollama_pull_model, ollama_list_models and ollama_show_model tools for advanced AI interactions.

VrtxOmega/Ollama-Omega is an official MCP server for Ollama, providing tools to interact with large language models. It exposes five key functions: chat, generate, pull models, list models, and show model details. Designed for developers, it enables advanced AI interactions through the Model Context Protocol.
