> 📇 🏠 🍎 🪟 - Double entry plain text accounting, right in your LLM! This MCP enables comprehensive read, and (optional) write access to your local [HLedger](https://hledger.org/) accounting journals.

This MCP server provides double-entry plain text accounting functionality by enabling LLMs to read and optionally write to local HLedger journals. It is listed under Finance & Fintech and supports comprehensive journal access directly within AI conversations.
