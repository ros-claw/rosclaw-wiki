Touch Grass is a fully local MCP server and Claude Code plugin that reminds you to take outdoor breaks. It uses local weather data, sunset timing, and your break history to suggest activities and track streaks. The server provides four tools: checking current grass conditions, suggesting an outdoor activity, logging a break, and viewing stats. No API keys or cloud storage are required, making it privacy-friendly. It aims to improve well-being by encouraging time in nature.
