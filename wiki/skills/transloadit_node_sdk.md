Hosted or self-hosted via npx.

This MCP server provides agent-native access to Transloadit's media processing platform, which offers over 86 processing robots. It supports video encoding (HLS, H.264, VP9), image manipulation (resize, watermark, smart crop), document conversion, OCR, and speech transcription. The server can be used either hosted or self-hosted via npx, enabling AI agents to integrate multimedia processing capabilities seamlessly.
