Steam-MCP is a server implementation that connects AI assistants like Claude to a user's Steam library. It allows natural language queries to retrieve information about games, playtime, recently played titles, and store metadata. This tool enhances gaming-related interactions by providing direct access to Steam data through the Model Context Protocol.
