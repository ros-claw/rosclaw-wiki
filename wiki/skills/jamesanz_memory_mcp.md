> 📇 🏠 - An MCP server that stores and retrieves memories from multiple LLMs using MongoDB. Provides tools for saving, retrieving, adding, and clearing conversation memories with timestamps and LLM identification.

This MCP server stores and retrieves conversation memories using MongoDB, supporting multiple LLMs. It provides tools to save, retrieve, add, and clear memories, each with timestamps and LLM identification. This enables persistent memory across conversations for LLM agents.
