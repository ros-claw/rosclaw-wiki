> [![mcp-server-sqlite MCP server](https://glama.ai/mcp/servers/ofershap/mcp-server-sqlite/badges/score.svg)](https://glama.ai/mcp/servers/ofershap/mcp-server-sqlite) 📇 🏠 - SQLite operations — query databases, inspect schemas, explain queries, and export data.

This MCP server provides SQLite database operations for AI agents, including executing queries, inspecting table schemas, explaining query plans, and exporting data. It is listed under Database server implementations and allows language models to interact directly with SQLite databases. The server is maintained by ofershap and integrates with the Model Context Protocol.
