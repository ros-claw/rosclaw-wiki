Measure MCP Server is a privacy-first web analytics tool that integrates natively with the Model Context Protocol (MCP). It allows querying pageviews, referrers, trends, and AI-generated insights for websites without compromising user privacy. The server is listed under monitoring implementations, indicating it supports observability for AI agent applications.
