> 🏎️ ☁️ 📟 🪟 🐧 🍎 - A zero-configuration Go library to automatically expose any existing Echo web framework APIs as MCP tools.

echo-mcp is a Go library that automatically exposes existing Echo web framework APIs as MCP (Model Context Protocol) tools with zero configuration. It is designed for developers using the Echo framework who want to integrate with MCP-compatible clients. The library supports cross-platform usage and aims to simplify bridging HTTP APIs to MCP tooling. By leveraging reflection, it eliminates manual setup, making Echo APIs instantly available as MCP tools.
