Built by an actual CallRail customer for agency use. Install: `pipx install callrail-mcp`.

This MCP server integrates CallRail's REST API v3 to provide 49 tools for managing call tracking, form submissions, and transcripts. It supports full CRUD operations on tags, trackers, companies, and users, and includes agency-specific aggregation tools such as usage_summary for per-client cost attribution, compare_periods for month-over-month deltas, and utilities for Google Ads conversion debugging. Built by an actual CallRail customer for agency use, it streamlines multi-client call data management and analysis.
