> A stress-testing benchmark for model and agent capabilities in real-world MCP tasks across tools like Notion, GitHub, and Postgres, making harness MCP integration quality directly measurable.

MCPMark is a benchmark designed to stress-test the capabilities of AI models and agents when performing real-world tasks using the Model Context Protocol (MCP). It evaluates performance across popular tools and services such as Notion, GitHub, and Postgres, making the quality of MCP integrations directly measurable. The benchmark focuses on practical, multi-step tasks that require understanding context and tool usage, helping researchers and developers assess and improve agent reliability.
