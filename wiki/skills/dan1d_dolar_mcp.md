This MCP server provides real-time Argentine exchange rates via DolarAPI. It supports multiple rate types including blue dollar, official, MEP, CCL, crypto, and tarjeta. It also includes currency conversion and spread calculation. Designed for AI agents to access financial data from Argentina.
