Works with any REST API without writing auth code.

Rest API MCP is a Model Context Protocol server that simplifies making authenticated REST API calls. It handles auto-login, token caching, and 2FA/OTP support, and can fetch Swagger specs for fuzzy endpoint search. Users can interact with any REST API without writing custom authentication code.
