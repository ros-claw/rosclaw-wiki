> 🐍 ☁️ - Jupiter API Access (allow AI to Trade Tokens on Solana + Access Balances + Search Tokens + Create Limit Orders )

This project provides an MCP server that allows AI agents to interact with the Jupiter API on the Solana blockchain. It enables trading tokens, checking balances, searching tokens, and creating limit orders. The server is implemented in Python and can be deployed in the cloud, giving AI systems direct access to Solana DeFi functionality.
