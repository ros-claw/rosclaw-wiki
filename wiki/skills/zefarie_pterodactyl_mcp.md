This project is an MCP server that enables AI agents to manage Pterodactyl and Pelican game server panels. It provides 73 tools covering server management, power control, file operations, backups, schedules, databases, users, nodes, and eggs. The server acts as a bridge between AI assistants and game server hosting platforms, allowing automated administrative tasks. It is listed under the Gaming category of server implementations.
