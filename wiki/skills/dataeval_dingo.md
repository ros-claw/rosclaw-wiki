> 🎖️ 🐍 🏠 🍎 🪟 🐧 - MCP server for the Dingo: a comprehensive data quality evaluation tool. Server Enables interaction with Dingo's rule-based and LLM-based evaluation capabilities and rules&prompts listing.

This is an MCP server for Dingo, a comprehensive data quality evaluation tool. It enables interaction with Dingo's rule-based and LLM-based evaluation capabilities, as well as listing of rules and prompts. The server is cross-platform, supporting multiple operating systems including macOS, Windows, and Linux. It is designed to integrate data quality evaluation into workflows via the Model Context Protocol.
