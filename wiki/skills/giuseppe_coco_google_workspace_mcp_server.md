> 🐍 ☁️ 🍎 🪟 🐧 - MCP server that seamlessly interacts with your Google Calendar, Gmail, Drive and so on.

This project implements an MCP server that allows seamless interaction with Google Workspace services, including Calendar, Gmail, and Drive. It is designed to enhance workplace productivity by integrating these tools into the MCP ecosystem. The server supports multiple platforms and aims to simplify automation and access to Google data.
