This project provides a tool that detects when a task or instruction is underspecified and prompts the user to ask clarifying questions. It helps reduce ambiguity in AI agent interactions by ensuring all necessary details are covered. The tool is developed by Trail of Bits and sponsored under the Skills by Typefully program. It can be integrated into systems that require precise specification for automated execution.
