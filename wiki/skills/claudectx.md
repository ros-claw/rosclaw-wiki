> claudectx lets you switch your entire Claude Code configuration with a single command.

ClaudeCTX is a configuration manager for Claude Code, an AI coding assistant. It enables users to switch between entire configuration profiles with a single command. This simplifies adjusting settings for different projects or workflows. The tool is categorized under config managers within the AI-agent tooling ecosystem.
