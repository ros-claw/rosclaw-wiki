This MCP server connects AI agents to Binance USDT-M Futures trading. It provides tools for fetching market data, checking account state, managing orders, and controlling positions and margins. The server enables automated futures trading strategies through the Model Context Protocol. It is designed for developers building finance and fintech applications that need programmatic access to Binance futures.
