> 🎖️ 📇 ☁️ - A Model Context Protocol server for generating visual charts using [AntV](https://github.com/antvis).

This project is a Model Context Protocol (MCP) server that enables generating visual charts using the AntV charting library. It provides tools for MCP clients to create and customize charts, likely by sending structured data and receiving chart specifications or images. Although listed under Customer Data Platforms, its primary function is chart generation for data visualization. It integrates with the AntV ecosystem to produce various chart types. This server helps agents and LLMs produce visual outputs in applications.
