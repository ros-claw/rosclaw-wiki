clipwise-mcp is an MCP server designed for short-form video creators on platforms like TikTok, Instagram Reels, YouTube Shorts, and Facebook Reels. It provides three main tools: a viral trend search across 20+ countries, service information, and use-case scenarios for video analysis, competitor research, and content strategy. The server can be installed via npx and offers a free plan at tryclipwise.com. It aims to streamline content creation and social media strategy using AI-powered insights.
