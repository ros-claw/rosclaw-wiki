Market data, AI tools, crypto analytics — pay-per-call in USDC on Base. SEPA Instant EUR off-ramp.

This MCP server enables AI agents to pay for API calls using USDC on the Base blockchain via the x402 protocol. It provides market data, crypto analytics, and other AI tools on a pay-per-call basis. Users can off-ramp their earnings to EUR through SEPA Instant transfers. The server is designed for fintech and finance use cases, integrating blockchain payments with traditional banking rails.
