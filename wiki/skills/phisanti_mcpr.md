> 🏠 🍎 🪟 🐧 - Model Context Protocol for R: enables AI agents to participate in interactive live R sessions.

MCPR is a server implementation of the Model Context Protocol (MCP) for the R programming language. It enables AI agents to connect to and interact with live R sessions, supporting data analysis and statistical computing. The tool runs on Linux, macOS, and Windows, and is categorized under Data Science Tools in the MCP ecosystem.
