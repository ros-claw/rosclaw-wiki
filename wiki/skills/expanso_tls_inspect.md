> Inspect TLS certificate (expiry, SANs, chain, cipher)

expanso-tls-inspect is a tool that inspects TLS certificates, extracting key details such as expiration dates, subject alternative names (SANs), the full certificate chain, and cipher information. It is useful for debugging TLS configuration, verifying certificate validity, and understanding security properties of a connection. The tool likely operates via command line or programmatic interface, making it suitable for integration into security checks or automated workflows.
