Supports CRUD operations, model inspection, and user/company context with readonly mode and delete confirmation safety.

This project provides a Model Context Protocol (MCP) server for Odoo 19 ERP, enabling AI agents to interact with Odoo's business data. It uses the JSON-RPC API and is built with FastMCP, supporting CRUD operations, model inspection, and context management for users and companies. Safety features include a read-only mode and delete confirmation to prevent accidental data loss. It is categorized as a Workplace & Productivity server implementation.
