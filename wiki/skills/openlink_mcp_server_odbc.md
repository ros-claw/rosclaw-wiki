> 🐍 🏠 - An MCP server for generic Database Management System (DBMS) Connectivity via the Open Database Connectivity (ODBC) protocol

The openlink/mcp-server-odbc is an MCP server for generic database connectivity via the ODBC protocol. It allows AI agents to interact with various database management systems (DBMS) using the Model Context Protocol. This server is listed under database implementations within the MCP server ecosystem and is written in Python.
