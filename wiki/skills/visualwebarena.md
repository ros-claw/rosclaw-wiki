> A benchmark for multimodal web agents on realistic visually grounded tasks, extending WebArena with image and screenshot inputs that stress harness support for visual context in browser environments.

VisualWebArena is a benchmark that extends WebArena to evaluate multimodal web agents. It introduces realistic visually grounded tasks that require agents to process images and screenshots within browser environments. This benchmark stresses the ability of agents to handle visual context, moving beyond purely text-based interactions. It aims to advance research in autonomous web navigation and task completion using visual inputs.
