This is a Model Context Protocol (MCP) server that enables AI-powered image generation and editing. It supports virtual try-on of clothing and product placement within realistic scenes. The tool allows users to seamlessly integrate products into images. It is listed under Art & Culture in the MCP server registry. The project is open-source and provides a badge for integration.
