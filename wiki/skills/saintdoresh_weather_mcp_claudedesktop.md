> 🐍 ☁️ - An MCP tool that provides real-time weather data, forecasts, and historical weather information using the OpenWeatherMap API.

This project implements a Model Context Protocol (MCP) server that provides real-time weather data, forecasts, and historical weather information using the OpenWeatherMap API. It is designed to integrate with Claude Desktop to allow the AI assistant to access current conditions, 5-day forecasts, and past weather records when asked. The tool processes user queries about weather for specific locations and returns structured results. This enables conversational AI to answer weather-related questions with up-to-date data.
