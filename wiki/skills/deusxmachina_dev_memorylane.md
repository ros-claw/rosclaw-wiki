> 📇 ☁️ 🏠 🍎 - Desktop app that captures screen activity via event-driven screenshots, stores AI-generated summaries and OCR text locally in SQLite, and exposes your activity history to AI assistants via MCP with semantic search, timeline browsing, and event detail retrieval.

MemoryLane is a desktop application that captures screenshots of the user's screen activity based on events. It processes these screenshots using AI to generate summaries and OCR text, which are stored locally in a SQLite database. The application exposes the captured activity history to AI assistants via the Model Context Protocol (MCP), enabling semantic search, timeline browsing, and event detail retrieval. It is designed for local, private storage of personal knowledge and memory.
