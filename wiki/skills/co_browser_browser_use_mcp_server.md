> 🐍 - browser-use packaged as an MCP server with SSE transport. includes a dockerfile to run chromium in docker + a vnc server.

This project packages the browser-use library as an MCP (Model Context Protocol) server with SSE transport for browser automation. It includes a Dockerfile to run Chromium in a Docker container along with a VNC server for remote access. The server enables AI agents to control a browser via MCP, providing a standardized interface for web automation. It is designed for easy deployment and integration with other MCP-compatible tools.
