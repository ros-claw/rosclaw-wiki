NOUZ-MCP is an MCP server that integrates with Obsidian to build a semantic knowledge graph. It uses local embeddings and cosine similarity to classify notes into user-defined categories called cores. The system operates in three modes: pure graph, semantic classification, and strict hierarchy. It also provides features like bottom-up aggregation, semantic bridge discovery, and drift detection. Install via pip with `pip install nouz-mcp`.
