Claude Codex Settings is a set of plugins for the Claude Codex AI coding assistant. These plugins cover core developer activities and integrate with common cloud platforms like GitHub, Azure, and MongoDB, as well as services like Tavily and Playwright. The plugins are designed to be well-organized, clear, and not overly opinionated. They are also compatible with a few other providers, making them flexible for various development workflows.
