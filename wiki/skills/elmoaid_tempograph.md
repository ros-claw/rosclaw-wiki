TempoGraph is a code graph context engine that provides structural code intelligence via 24 MCP tools. It uses tree-sitter to parse over 170 programming languages, enabling features like dependency graphs, blast radius analysis, hotspot detection, dead code identification, and adaptive context injection. The system has been benchmarked to achieve a +27% improvement in F1 score for change-localization tasks. It is listed as a developer tool in server implementations.
