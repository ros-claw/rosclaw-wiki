Go + Next.js + TypeScript.

MARUCIE/authbox is a zero-knowledge password manager with an integrated MCP credential gateway. It uses BIP-39 seed phrases for recovery and generates deterministic passwords. The tool provides policy-gated access for AI agents, including scope, rate limits, time windows, and step-up approval. It supports over 70 API key providers and maintains a hash-chain audit trail. Built with Go, Next.js, and TypeScript, it enables secure credential management and AI agent authentication.
