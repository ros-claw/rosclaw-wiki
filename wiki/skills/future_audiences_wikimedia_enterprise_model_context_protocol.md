> 🐍 ☁️  - Wikipedia Article lookup API

This project is an implementation of the Model Context Protocol (MCP) server that provides a Wikipedia article lookup API. It is built with Python and designed for cloud deployment. It allows AI agents to query Wikipedia articles through a standardized MCP interface. The project is listed under 'Other Tools and Integrations' in the MCP ecosystem. It aims to integrate Wikipedia's knowledge into AI workflows via MCP.
