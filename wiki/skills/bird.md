> X/Twitter CLI for reading, searching, and posting via cookies or Sweetistics.

This project is a command-line tool for interacting with the X/Twitter platform. It allows users to read tweets, search content, and post updates. The tool authenticates using either browser cookies or the Sweetistics external service, both methods enabling access without official API keys. This makes it useful for automated or scripted interactions with Twitter. It is likely intended for developers or power users who need a lightweight Twitter client.
