> 🐍 ☁️ 🏠 🍎 🪟 🐧 - SerpApi MCP Server for Google and other search engine results. Provides multi-engine search across Google, Bing, Yahoo, DuckDuckGo, YouTube, eBay, and more with real-time weather data, stock market information, and flexible JSON response modes.

This project provides a Model Context Protocol (MCP) server that integrates with SerpApi to fetch search results from multiple search engines like Google, Bing, Yahoo, DuckDuckGo, YouTube, and eBay. It also retrieves real-time weather data and stock market information. The server returns results in flexible JSON formats, making it easy for AI agents to query various sources through a single interface. It is designed for use within MCP-compatible environments such as Claude or other AI assistants.
