> 🐍 🏠 - Enterprise-grade sentiment analysis with 95+ labels, keyword extraction, and batch processing for AI agents

Keyneg MCP is an enterprise-grade sentiment analysis server that provides over 95 sentiment labels, keyword extraction, and batch processing capabilities. It is designed for AI agents to integrate sentiment analysis into their workflows via the Model Context Protocol (MCP). The tool supports both individual and bulk text analysis, making it suitable for large-scale data processing. It is listed under Data Platforms in the MCP server implementations.
