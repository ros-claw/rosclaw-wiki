> 🔍 📚 - Search Google and do deep web research on any topic

This project provides a Model Context Protocol (MCP) server that enables AI agents to perform web research by querying Google and conducting deep analysis of web content. It supports searching for information on any topic and extracting relevant data from multiple sources. The tool is designed for integration with AI assistants to enhance their research capabilities.
