> 📇 🏠 🍎 🪟 🐧 - Visual DOM element selector for agentic coding tools. Chrome extension + MCP server bridge for Claude Code, Cursor, Windsurf etc. Option+Click to capture elements.

MCP-Pointer is a visual DOM element selector designed for agentic coding tools. It consists of a Chrome extension and an MCP server bridge that integrates with tools like Claude Code, Cursor, and Windsurf. Users can Option+Click on any webpage element to capture it for use in AI-driven development workflows. This allows AI coding agents to directly reference and manipulate specific parts of a user interface.
