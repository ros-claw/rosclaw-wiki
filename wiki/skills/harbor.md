> A generalized harness for evaluating and improving agents at scale, released alongside Terminal-Bench 2.0.

Harbor is a generalized harness for evaluating and improving agents at scale, released alongside Terminal-Bench 2.0. It provides a runtime environment for benchmarking and refining autonomous agent performance. The tool is listed under Runtimes, Harnesses & Reference Implementations, indicating its role as a foundational component for agent workflows.
