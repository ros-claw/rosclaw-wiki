> 📇 🏠 🍎 - A Model Context Protocol (MCP) server for interacting with iOS simulators. This server allows you to interact with iOS simulators by getting information about them, controlling UI interactions, and inspecting UI elements.

ios-simulator-mcp is a Model Context Protocol (MCP) server that allows developers to interact with iOS simulators programmatically. It provides capabilities to get information about simulators, perform UI interactions like tapping and swiping, and inspect UI elements. This tool is designed to facilitate automated testing and development workflows for iOS applications. It is one of the server implementations listed under Developer Tools in the MCP ecosystem.
