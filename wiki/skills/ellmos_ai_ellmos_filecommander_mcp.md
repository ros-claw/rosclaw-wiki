ellmos-ai/ellmos-filecommander-mcp is a comprehensive local filesystem MCP server that provides file management, process control, interactive sessions, and async search capabilities. It supports safe deletion by moving files to the Recycle Bin, enhancing data safety. The server integrates with Model Context Protocol for AI assistants to perform filesystem operations. It is cross-platform, working on macOS, Windows, and Linux.
