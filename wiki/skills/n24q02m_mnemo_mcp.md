Built-in Qwen3 embedding, rclone sync across machines. Zero config, no cloud, no limits.

Mnemo-MCP is a persistent memory system for AI agents, using SQLite with hybrid search combining full-text (FTS5) and semantic embeddings. It includes built-in Qwen3 embedding generation and supports cross-machine synchronization via rclone. Designed with zero configuration, no cloud dependency, and no limits on data size.
