> 📇 ☁️ - Open-source customer feedback platform with built-in MCP server. Agents can search feedback, triage posts, update statuses, create and comment on posts, vote, manage roadmaps, merge duplicates, and publish changelogs.

Quackback is an open-source customer feedback platform that integrates a built-in MCP (Model Context Protocol) server. It enables AI agents to search feedback, triage posts, update statuses, create and comment on posts, vote, manage roadmaps, merge duplicates, and publish changelogs. Designed for customer data platforms, it streamlines feedback management and agent-driven workflows.
