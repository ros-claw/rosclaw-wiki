> 📇 ☁️ - Bluesky instance integration for querying and interaction

This project implements a server that integrates with Bluesky, a decentralized social network, enabling AI agents to query and interact with the platform. It allows agents to fetch context from posts, engage with users, and perform actions within Bluesky. The server is part of a set of communication-focused tools for embodied intelligence and AI-agent systems.
