> Manage Apple Notes via the `memo` CLI on macOS.

This project offers a CLI tool called 'memo' for managing Apple Notes on macOS. It enables users to create, read, edit, and delete notes through terminal commands. The tool uses direct interaction with the Apple Notes app database and automation scripting. It is designed for power users who prefer command-line productivity or want to integrate note management into scripts and workflows.
