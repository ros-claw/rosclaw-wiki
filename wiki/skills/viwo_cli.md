> Run Claude Code in a Docker container with git worktrees as volume mounts to enable safer usage of `--dangerously-skip-permissions` for frictionless one-shotting prompts. Allows users to spin up multiple instances of Claude Code in the background easily with reduced permission fatigue.

viwo-cli runs Claude Code inside Docker containers with git worktrees as volume mounts, enabling safer use of the `--dangerously-skip-permissions` flag for efficient one-shot commands. It reduces permission fatigue and allows users to easily spin up multiple Claude Code instances in the background. This approach enhances safety while maintaining frictionless automation.
