> 📇 ☁️ 🏠 🍎 🪟 🐧 - Connects Claude Desktop to your Gmail so you can start managing your inbox using natural language. Bulk delete promos & newsletters, organize labels and get useful insights.

Gmail Manager MCP is a server implementation that connects Claude Desktop to your Gmail account, allowing you to manage your inbox using natural language commands. It enables bulk deletion of promotional emails and newsletters, label organization, and provides useful insights about your email activity. The tool supports multiple platforms and integrates seamlessly with the Model Context Protocol (MCP) to give Claude Desktop access to your Gmail data.
