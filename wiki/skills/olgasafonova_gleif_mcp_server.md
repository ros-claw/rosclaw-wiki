> 🏎️ ☁️ - Access the Global Legal Entity Identifier (LEI) database for company verification, KYC, and corporate ownership research via GLEIF's public API.

This MCP server provides access to the Global Legal Entity Identifier (LEI) database through GLEIF's public API. It enables company verification, Know Your Customer (KYC) checks, and corporate ownership research. The server exposes tools for querying legal entity information, making it useful for finance and fintech applications. It is designed to be used as a Model Context Protocol (MCP) tool with AI assistants.
