> Integrates the ffuf web fuzzer so Claude can run fuzzing tasks and analyze results for vulnerabilities.

This skill integrates the ffuf web fuzzer into Claude, enabling automated web fuzzing tasks directly. Claude can run fuzzing commands and analyze the results to identify potential vulnerabilities. It assists in security testing by leveraging ffuf's capabilities within an AI-assisted workflow. This tool helps developers and security professionals streamline web application security assessments.
