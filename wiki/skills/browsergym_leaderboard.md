> A gym environment and leaderboard for evaluating LLMs, VLMs, and agents on web navigation tasks, offering a reproducible framework for comparing harnesses across multiple web benchmarks in one place.

BrowserGym Leaderboard is a gym environment and leaderboard designed for evaluating large language models, vision-language models, and AI agents on web navigation tasks. It provides a reproducible framework for comparing different agent harnesses across multiple web benchmarks in a unified setting. This enables standardized evaluation and transparent leaderboard rankings for web-based agent performance. The platform facilitates benchmarking and progress tracking in the research community.
