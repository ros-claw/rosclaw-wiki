Cohort-analysis is a TypeScript library for performing cohort analysis on user data. It helps in grouping users by shared characteristics and tracking their behavior over time, enabling insights into retention and engagement. The tool is designed for developers integrating analytics into web applications. It provides functions to compute cohort metrics from event logs.
