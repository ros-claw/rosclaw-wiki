> 🐍 🏠 🍎 🪟 🐧 - Two-tier memory with hot cache (instant injection) and cold semantic search. Auto-promotes frequently-used patterns, extracts knowledge from Claude outputs, and organizes via knowledge graph relationships.

This project implements a two-tier memory system for AI agents, combining a hot cache for instant retrieval of frequently used patterns with a cold semantic search for broader knowledge. It automatically promotes frequently used patterns into the hot cache, extracts knowledge from Claude's outputs, and organizes all information using a knowledge graph. This allows the AI to maintain both short-term and long-term memory, improving response relevance and learning over time.
