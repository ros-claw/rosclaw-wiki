This MCP server provides AI agents with structured read and write access to a story-based project backlog. Agents can list stories, read content, update status, and append notes, all backed by plain markdown files versioned in your repository. It works with any markdown-based backlog and enables AI tools to directly manage project tasks through the Model Context Protocol.
