> Lab for creating an MCP Server and using it in Microsoft Copilot Studio.

This project is a lab environment for creating an MCP (Model Context Protocol) server and integrating it with Microsoft Copilot Studio. It provides hands-on guidance on building the server and connecting it to the Copilot platform. The goal is to explore how MCP can extend Copilot capabilities. This is useful for developers experimenting with AI agent tooling and custom copilot extensions.
