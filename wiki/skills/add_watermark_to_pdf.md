> Add a text watermark to one or multiple PDFs by uploading them to the Solutions API, polling until completion.

This project provides a way to add a text watermark to one or more PDF files by uploading them to a Solutions API and then polling until the processing is complete. It automates the watermarking process, likely for batch operations. The tool handles the upload and status checking, simplifying integration into workflows that need to mark PDFs with text overlays.
