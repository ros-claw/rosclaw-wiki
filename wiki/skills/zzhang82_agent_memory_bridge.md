Agent-Memory-Bridge is a Model Context Protocol (MCP)-native tool that provides local-first memory for AI coding agents. It captures coding sessions—including decisions, gotchas, and domain knowledge—and turns them into reusable engineering memory. The system is designed to work seamlessly with MCP-compatible agents, helping them persist and recall context across sessions without relying on external cloud services.
