> 📇 🏠 - Extract structured data from any website. Just prompt and get JSON.

Ashra MCP is an AI-powered server that extracts structured data from any website using natural language prompts. It leverages the Model Context Protocol (MCP) to connect with AI assistants for browser automation. Users can simply describe the data they need, and the tool returns structured JSON output. This project enables seamless web scraping and data extraction without manual coding.
