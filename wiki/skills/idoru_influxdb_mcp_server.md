> 📇 ☁️ 🏠 - Run queries against InfluxDB OSS API v2.

This project is an MCP server implementation that allows AI agents to run queries against InfluxDB OSS API v2. It serves as a bridge between large language models and InfluxDB, enabling natural language or structured querying of time-series data. By providing this integration, it extends the capabilities of AI tools to interact with database systems for data retrieval and analysis. The server is listed under the databases category in the MCP ecosystem.
