> 🎖️ 🐍 ☁️ 🍎 - MCP server for the incident management platform [Rootly](https://rootly.com/).

Rootly-AI-Labs/Rootly-MCP-server is a Model Context Protocol (MCP) server that integrates Rootly's incident management platform with AI tools. It allows developers to manage incidents, services, and on-call schedules programmatically through MCP. This enables AI assistants to create, update, and resolve incidents, as well as manage related resources, streamlining incident response workflows.
