> Anthropic follow-up focused on improving long-running app generation with better task state and evaluator design.

This project is a follow-up to earlier work by Anthropic, aiming to improve the generation of long-running applications. It focuses on designing better ways to manage task state and evaluators for such applications. The goal is to make AI agents more reliable and effective over extended periods of operation.
