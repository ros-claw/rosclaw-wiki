> 📇 🏠 - Hand off conversation context between Claude Desktop projects and across MCP clients. Memory-based, no file clutter.

This server enables handing off conversation context between different Claude Desktop projects and across multiple MCP clients. It uses an in-memory store rather than files, avoiding clutter. The tool is designed for knowledge and memory management within the MCP ecosystem. It helps maintain continuity across sessions and clients.
