> Search hotel prices and availability via Amadeus API.

This project provides a tool to search for hotel prices and availability using the Amadeus API. It allows users to query hotel data and retrieve pricing and room availability information programmatically. The tool is designed for developers building travel-related applications that need integration with Amadeus' hotel services.
