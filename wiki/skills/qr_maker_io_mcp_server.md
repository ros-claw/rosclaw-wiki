> [![qr-maker-io/mcp-server MCP server](https://glama.ai/mcp/servers/qr-maker-io/mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/qr-maker-io/mcp-server) 📇 ☁️ - Generate styled QR codes, manage dynamic short links with click analytics, and publish micro-landing pages. Install: `npx @qr-maker/mcp-server --api-key=YOUR_KEY`.

This MCP server allows users to generate styled QR codes with customization, manage dynamic short links that can be updated without changing the QR code, and publish micro-landing pages. It includes click analytics for tracking link performance, making it useful for marketing and URL management tasks. The tool is easily run via npx with an API key.
