Pay per request via Lightning (L402) — no signup or API keys.

The sats4ai MCP server is a permissionless tool that enhances AI agents with communication and content generation capabilities. It supports phone calls, SMS, fax, translation in 119 languages, text-to-speech, audiobook creation, image/video/music/text generation, and document extraction. Users pay per request via the Lightning Network (L402 protocol) without needing signup or API keys. This server integrates with the Model Context Protocol (MCP) to allow AI agents to access these services programmatically.
