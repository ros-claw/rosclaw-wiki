> 🦀 🏠 - Cognitive memory for AI agents with Hebbian learning, 3-tier architecture, and knowledge graphs. Single ~15MB binary, runs offline on edge devices.

Shodh Memory is a cognitive memory system for AI agents built in Rust. It uses Hebbian learning to mimic biological memory formation and features a three-tier architecture with knowledge graphs. The system compiles into a single 15MB binary that runs entirely offline on edge devices. It provides persistent, contextual memory for agents without requiring cloud connectivity.
