> ![GitHub stars](https://img.shields.io/github/stars/sentient-agi/EvoSkill?style=social) - Automated skill discovery for coding agents: evolves reusable skills and prompts from failed trajectories against benchmarks, with support for Claude Code, Codex CLI, OpenCode, OpenHands, and Goose.

EvoSkill automatically discovers reusable skills for coding agents by evolving prompts from failed trajectories on benchmarks. It supports multiple agent frameworks like Claude Code, Codex CLI, OpenCode, OpenHands, and Goose. The tool improves agent performance over time by learning from mistakes, enabling continuous refinement of agent capabilities.
