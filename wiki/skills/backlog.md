> Persistent, cross-session task management. 24 MCP tools for tasks, projects, tags, dependencies, and docs. 7 skills for planning, standups, and handoffs. Event-sourced storage, agent coordination, pure TypeScript. ([Website](https://backloghq.io))

Backlog is a plugin for AI agents that provides persistent, cross-session task management. It includes 24 MCP tools for handling tasks, projects, tags, dependencies, and documents, as well as 7 skills for planning, standups, and handoffs. The system uses event-sourced storage and is built in pure TypeScript, enabling agent coordination and reliable state tracking. It helps developers and agents maintain productivity across sessions with a structured task management approach.
