> 📇 🏠 - Visualizes code, architecture and other concepts as mermaid diagrams in a locally hosted web app. Just ask your agent to "show me this in a diagram".

This project provides an MCP server that enables AI agents to generate Mermaid diagrams from code, architecture, and other concepts. The diagrams are displayed in a locally hosted web application for easy visualization. Users can simply instruct an agent to 'show me this in a diagram' to trigger the generation. It is listed under Developer Tools and serves as a bridge between AI agents and diagram creation.
