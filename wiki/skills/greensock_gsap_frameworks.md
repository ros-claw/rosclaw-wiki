This project provides TypeScript support and framework-specific integrations for GSAP (GreenSock Animation Platform), a widely used JavaScript animation library. It includes type definitions and helpers to streamline the use of GSAP within modern front-end frameworks like React, Vue, and Angular. By offering strong typing and framework-specific patterns, it improves developer productivity and code reliability in animation-heavy applications.
