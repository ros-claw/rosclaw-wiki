> [![gws-mcp-server MCP server](https://glama.ai/mcp/servers/@conorbronsdon/gws-mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/@conorbronsdon/gws-mcp-server) 📇 ☁️ 🍎 🪟 🐧 - Google Workspace MCP server exposing 23 curated tools for Drive, Sheets, Calendar, Docs, and Gmail via the gws CLI.

This project provides a Model Context Protocol (MCP) server that integrates with Google Workspace, offering 23 curated tools for Drive, Sheets, Calendar, Docs, and Gmail via the gws command-line interface. It enables AI agents to interact with Google productivity services in a structured, programmatic way. The server is listed under workplace and productivity tools, and supports cross-platform usage.
