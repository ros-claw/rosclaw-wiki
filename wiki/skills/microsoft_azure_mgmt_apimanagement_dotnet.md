This is the official .NET SDK from Microsoft for managing Azure API Management services. It provides client libraries to create, update, and delete API Management instances, APIs, policies, and products programmatically. Developers typically use it in automation scripts, CI/CD pipelines, or custom tooling. The package is part of the Azure SDK for .NET ecosystem and is listed under the .NET Skills sponsor category.
