> Multi-agent UX for OpenClaw Control UI — agent selector, per-agent sessions, session history viewer with search.

This project provides a multi-agent user interface for the OpenClaw Control UI. It includes an agent selector to choose between different AI agents, per-agent chat sessions that keep separate conversation histories, and a session history viewer with search capability. The interface is designed to manage and interact with multiple AI agents simultaneously, making it easier to track and retrieve past conversations.
