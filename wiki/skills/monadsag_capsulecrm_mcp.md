> 📇 ☁️ Allows AI clients to manage contacts, opportunities and tasks in Capsule CRM including Claude Desktop ready DTX-file

This is an MCP (Model Context Protocol) server that allows AI clients such as Claude Desktop to interact with Capsule CRM. It enables managing contacts, opportunities, and tasks through a standardized tool interface. The server includes a ready-to-use DTX file for easy integration with Claude Desktop. It is listed under 'Other Tools and Integrations' in the MCP server directory.
