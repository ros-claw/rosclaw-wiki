> Universal Adobe application automation via ExtendScript bridge.

This project enables universal automation of Adobe applications through an ExtendScript bridge. It allows users to write scripts that control multiple Adobe tools, streamlining repetitive tasks and cross-application workflows. The automation is based on ExtendScript, a JavaScript-based scripting language native to Adobe software.
