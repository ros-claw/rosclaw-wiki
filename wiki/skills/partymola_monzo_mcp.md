OAuth with auto-refresh, local SQLite transaction cache, full-text search, and spending analysis with category breakdowns.

The monzo-mcp project is a read-only MCP server that connects AI agents to the Monzo banking API for UK users. It uses OAuth authentication with automatic token refresh, and caches transaction data in a local SQLite database for fast retrieval. Features include full-text search across transactions and spending analysis with category breakdowns. This tool enables AI assistants to securely access and analyze a user's Monzo financial data without write permissions.
