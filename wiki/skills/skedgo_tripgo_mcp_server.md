> 📇 ☁️ - Provides tools from the TripGo API for multi-modal trip planning, transport locations, and public transport departures, including real-time information.

This MCP server integrates the TripGo API to provide tools for multi-modal trip planning. It allows searching for transport locations and retrieving public transport departures with real-time updates. The server supports various transportation modes and offers real-time information for trip planning. It is categorized under travel and transportation server implementations.
