> VisualAgentBench evaluates large multimodal models as visual foundation agents across embodied, GUI, and visual design tasks, useful for comparing harnesses on visually grounded, multi-step agent workflows.

VisualAgentBench (VAB) is a benchmark that evaluates large multimodal models acting as visual foundation agents. It assesses performance across three domains: embodied tasks, GUI interaction, and visual design. The benchmark is particularly useful for comparing different agent frameworks on visually grounded, multi-step reasoning and action workflows.
