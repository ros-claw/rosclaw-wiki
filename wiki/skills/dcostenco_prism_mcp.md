Prism MCP is a zero-configuration Model Context Protocol (MCP) server that provides persistent memory for AI agents using local SQLite storage. It features a Mind Palace web dashboard for visualization, time-travel capabilities to rewind and replay sessions, and agent telepathy enabling cross-client memory sharing. Additional tools include code mode templates, morning briefings, and progressive context loading. With 25 tools, 6 resources, and 4 prompts, it extends AI assistants like Claude with long-term memory and context management.
