> 🐍 🏠 - A `minimal` server/client MCP implementation using Azure OpenAI and Playwright.

This project implements a minimal server/client Model Context Protocol (MCP) setup using Azure OpenAI and Playwright for browser automation. It enables LLMs to perform web browsing tasks through a controlled browser interface. The design is lightweight, focusing on core functionality without extra dependencies. It is listed under browser automation tools for MCP.
