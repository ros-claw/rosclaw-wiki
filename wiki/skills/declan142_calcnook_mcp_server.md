calcnook-mcp-server is an MCP server that provides personal finance calculations for seven countries (US, UK, CA, AU, AE, SA, India) and supports Sharia-compliant Islamic finance tools like Zakat and Murabaha. It offers 17 tools covering income tax, loans, retirement planning, VAT, currency formatting, and health metrics (BMI, BMR, TDEE). No API keys are required, as it uses the deterministic calcnook engine with Python's standard library. The server can be easily installed via `uvx calcnook-mcp`.
