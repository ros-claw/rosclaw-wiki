> 🐍 🏠 - Powerful tools for automating Apple Notes using Model Context Protocol (MCP). Full CRUD support with HTML content, folder management, and search capabilities.

This MCP server enables automation of Apple Notes through the Model Context Protocol. It provides full CRUD (Create, Read, Update, Delete) operations on notes, supporting HTML content and folder management. Users can integrate with AI agents to programmatically manage notes, search, and organize folders. The tool is designed for developers building applications that interact with Apple Notes via MCP.
