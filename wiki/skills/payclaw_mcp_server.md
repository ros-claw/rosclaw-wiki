Just-in-time card issuance per transaction, human-approved spend authorization, MCP-native. Works anywhere Visa is accepted.

payclaw/mcp-server is a Model Context Protocol server that enables AI agents to make purchases using virtual Visa cards. It features just-in-time card issuance for each transaction and requires human approval for spending. This allows AI agents to access financial services securely and flexibly, working anywhere Visa is accepted. The tool integrates natively with MCP workflows.
