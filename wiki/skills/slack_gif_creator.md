> Creates animated GIFs optimized for Slack with validators for size constraints and composable animation primitives.

This tool creates animated GIFs specifically optimized for use within Slack. It includes validators to ensure GIFs meet Slack's file size and dimension constraints. The project provides composable animation primitives to build custom animations. It helps users avoid common issues like oversized files that get rejected by Slack.
