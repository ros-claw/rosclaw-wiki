> 🏎️ ☁️ 🏠 🐧 🪟 🍎 - Debug your Container and Kubernetes workloads with an AI interface powered by eBPF.

This MCP server provides an AI-powered interface for debugging container and Kubernetes workloads. It leverages eBPF to inspect system behavior in real time. Users can interact with eBPF-based observability tools through natural language queries. The server integrates with AI models to simplify complex debugging tasks.
