> A TypeScript-based system for configuring and customizing Claude Code hooks with a powerful and flexible interface.

claude-hooks is a TypeScript-based system for configuring and customizing hooks in Claude Code. It provides a flexible interface that allows developers to define custom behaviors and integrations. This project extends the functionality of Claude Code by enabling event-driven scripts or responses. It is designed to help tailor the AI assistant's behavior within a development environment.
