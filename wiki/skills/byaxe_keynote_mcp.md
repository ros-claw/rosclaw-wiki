This MCP server enables full control over Apple Keynote presentations using natural language commands, leveraging AppleScript automation. It offers over 30 tools for creating, editing, and exporting slides, including content, layout, and Unsplash image integration. Additionally, it includes a Claude Skill for design patterns and font workarounds, making it useful for automated presentation generation.
