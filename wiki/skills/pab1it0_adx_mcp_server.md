> 🐍 ☁️ - Query and analyze Azure Data Explorer databases

This is a Model Context Protocol (MCP) server that enables AI agents to query and analyze Azure Data Explorer databases. It exposes data exploration capabilities through the MCP interface, allowing agents to run Kusto queries and retrieve results. Designed for integration with AI assistants that support MCP tools, it simplifies access to cloud-scale analytics. Ideal for natural language interfaces to Azure Data Explorer.
