> 🐍 ☁️ - Interact with Twitter search and timeline

This project provides an MCP (Model Context Protocol) server that integrates with Twitter using the Twikit library, allowing users to search for tweets and access timelines. It enables AI agents to interact with Twitter data without needing official API keys, leveraging Twitter's web interface. The server supports both search queries and timeline retrieval, making it useful for social media analysis and content gathering.
