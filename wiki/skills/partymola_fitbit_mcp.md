OAuth 2.0 PKCE, local SQLite cache with auto-sync, and trend analysis. Tools for heart rate, activity, exercises, sleep, weight, SpO2, and HRV.

This is an MCP server that connects to the Fitbit Web API, enabling AI agents to access personal health data. It uses OAuth 2.0 PKCE for authentication and stores data locally in SQLite with automatic syncing and trend analysis. The server provides tools to retrieve heart rate, activity, exercises, sleep, weight, SpO2, and HRV metrics.
