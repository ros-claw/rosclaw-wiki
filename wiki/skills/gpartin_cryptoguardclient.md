Validate trades (PROCEED/CAUTION/BLOCK), scan tokens, detect rug pulls — powered by WaveGuard physics engine. 5 free calls/day, x402 USDC payments. `pip install CryptoGuardClient`

CryptoGuardClient is a Python server that validates cryptocurrency trades for AI trading agents. It uses a physics engine called WaveGuard to detect rug pulls and other scams, providing per-transaction decisions such as PROCEED, CAUTION, or BLOCK. The tool scans tokens and offers 5 free API calls per day, with additional usage paid via x402 USDC micropayments. It is available for installation via pip and integrates as a Model Context Protocol (MCP) server for AI agent tooling.
