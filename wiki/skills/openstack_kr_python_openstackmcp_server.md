> 🐍 ☁️ - OpenStack MCP server for cloud infrastructure management based on openstacksdk.

This project provides a Model Context Protocol (MCP) server for managing OpenStack cloud infrastructure. Built on the openstacksdk, it enables AI agents to interact with OpenStack APIs for provisioning and managing cloud resources like virtual machines and networks. The server acts as a bridge between AI tools and OpenStack environments, facilitating automated infrastructure management. It is designed for integration with AI assistants to perform cloud operations through natural language or tool calls.
