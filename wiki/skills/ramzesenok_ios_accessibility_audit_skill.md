This project provides a skill for AI voice assistants to perform accessibility audits on iOS applications. It enables automated testing of app accessibility features like VoiceOver, Dynamic Type, and color contrast. The skill integrates with common CI/CD pipelines and reports issues in a structured format. It is listed under community skills for a broader embodied-intelligence platform.
