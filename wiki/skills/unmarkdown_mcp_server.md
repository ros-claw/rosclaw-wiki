UnMarkdown/mcp-server is an MCP server that acts as a document publishing layer for AI tools. It converts markdown content into formatted documents for platforms like Google Docs, Microsoft Word, Slack, OneNote, Email, and plain text. The server includes 62 templates to customize output formatting. It enables AI agents to directly publish and share content in commonly used workplace formats.
