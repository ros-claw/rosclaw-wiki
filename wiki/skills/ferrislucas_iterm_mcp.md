> 🖥️ 🛠️ 💬 - A Model Context Protocol server that provides access to iTerm. You can run commands and ask questions about what you see in the iTerm terminal.

iterm-mcp is a Model Context Protocol (MCP) server that integrates with iTerm2, the macOS terminal emulator. It allows AI coding agents to run shell commands and ask questions about terminal output directly. This enables agents to interact with the command line environment in real time, effectively turning the terminal into a tool for AI assistance.
