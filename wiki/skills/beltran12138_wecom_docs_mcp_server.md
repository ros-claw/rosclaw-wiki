Fills the doc-CRUD gap — existing WeCom MCP servers only support webhook messaging.

This MCP server enables AI agents to perform Create, Read, Update, and Delete operations on WeCom (Enterprise WeChat) documents, specifically Docs and Smartsheets. It provides nine tools that fill a gap left by existing WeCom MCP servers, which only support webhook messaging. Written in Python, the server is compatible with Windows, macOS, and Linux, making it a versatile addition to communication-focused MCP tooling.
