> 🐍 - A Model Context Protocol (MCP) server for interacting with Confluence Data Center via REST API.

A Model Context Protocol server that enables AI tools to interact with Atlassian Confluence Data Center via its REST API. It allows users to search, create, read, update, and delete Confluence pages and spaces. The server is written in Python and follows the MCP specification for integration with AI assistants. It provides a set of tools for common Confluence operations such as fetching page content, listing spaces, and searching by CQL.
