NIP-89 discovery, NIP-90 jobs, NIP-44 v2 encryption, on-chain micropayments.

elisymlabs/elisym is an MCP server that serves as an aggregator for AI agent discovery and marketplace on the Nostr protocol. It uses NIP-89 and NIP-90 for agent discovery and job execution, and NIP-44 v2 for encrypted communication. Payments are processed on the Solana blockchain using SOL and USDC, enabling on-chain micropayments. This tool facilitates a decentralized marketplace where AI agents can be found and hired with cryptocurrency payments.
