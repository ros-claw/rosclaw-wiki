This MCP server creates pre-action gates that prevent AI coding agents from repeating known mistakes. It captures explicit feedback from developers and automatically promotes failures into prevention rules. These rules are enforced via hooks before any action is executed. The system improves agent reliability by learning from past errors and blocking their recurrence.
