> 🎖️ 🐍 🏠 ☁️ - Official MCP server for [dbt (data build tool)](https://www.getdbt.com/product/what-is-dbt) providing integration with dbt Core/Cloud CLI, project metadata discovery, model information, and semantic layer querying capabilities.

This project is an official MCP server for dbt (data build tool), integrating with dbt Core and dbt Cloud command-line interfaces. It enables users to discover project metadata, retrieve model information, and query the semantic layer. The server helps AI assistants and tools interact with dbt projects programmatically, supporting data platform operations.
