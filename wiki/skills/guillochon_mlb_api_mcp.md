> 🐍 🏠 - MCP server that acts as a proxy to the freely available MLB API, which provides player info, stats, and game information.

This is a Model Context Protocol (MCP) server that acts as a proxy to the official MLB (Major League Baseball) API. It provides AI agents with access to live baseball data including player information, statistics, and game information. The server translates MCP requests into MLB API calls and returns structured data. It is designed for use with AI assistants that need real-time sports data. The tool is written in Python and uses the MCP protocol to integrate with AI applications.
