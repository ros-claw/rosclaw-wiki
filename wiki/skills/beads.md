> Git-backed issue tracker for AI agents.

Beads is a git-backed issue tracker designed specifically for AI agents. It allows AI agents to manage tasks, bugs, and feature requests using Git as the underlying data store. This enables version control and collaboration on issues just like code, optimized for automated agents rather than human users. The project integrates seamlessly with AI development workflows.
