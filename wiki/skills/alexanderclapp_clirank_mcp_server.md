Install: `npx clirank-mcp-server`. Web: [clirank.dev](https://clirank.dev).

This MCP server provides an aggregate score for APIs based on how friendly they are to AI coding agents. It offers tools to recommend, compare, check scores, and discover APIs. Users can install and run it via npx. It aims to help AI agents choose the best APIs for integration.
