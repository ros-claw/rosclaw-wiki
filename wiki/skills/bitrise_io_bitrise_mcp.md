> 🎖️ 🐍 ☁️ 🍎 🪟 🐧 - MCP Server for the [Bitrise](https://bitrise.io) API, enabling app management, build operations, artifact management and more.

This is an MCP server that wraps the Bitrise API, enabling AI agents to manage Bitrise apps, trigger builds, and handle artifacts. It provides tools for build operations and app management through the Model Context Protocol. The server supports multiple platforms including cloud, macOS, Windows, and Linux.
