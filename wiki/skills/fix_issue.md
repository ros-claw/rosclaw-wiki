> Addresses GitHub issues by taking issue number as parameter, analyzing context, implementing solution, and testing/validating the fix for proper integration.

The /fix-issue slash command streamlines fixing GitHub issues by accepting an issue number, analyzing the context, implementing a solution, and testing the fix. It automates the entire lifecycle from issue identification to validated integration. This reduces manual effort in version control and bug resolution workflows.
