This project is a Model Context Protocol (MCP) server for the Pyxel retro game engine. It allows AI agents to run Pyxel games, capture screenshots, inspect sprites, and analyze audio. This enables AI to interact with and understand retro game environments, facilitating debugging, automation, and creative generation.
