> 🎖️ 📇 ☁️ - Flag features directly from chat in your IDE with [Reflag](https://reflag.com).

Reflag's MCP server allows developers to toggle feature flags directly from a chat interface within their IDE using the MCP protocol. It integrates with the Reflag feature flag platform, enabling real-time flag management without leaving the development environment. This streamlines the workflow for developers who use chat-based tools in their IDE, such as chat in VSCode or JetBrains. It is listed under Developer Tools in the MCP server ecosystem.
