Browserbase is a cloud-based browser automation platform designed for AI agents and developers. The 'browserbase/browser' repository contains the core TypeScript SDK for programmatically controlling headless browsers at scale. It enables tasks like web scraping, testing, and data extraction with minimal infrastructure overhead. The SDK integrates seamlessly with popular frameworks like Puppeteer and Playwright, and provides features like session management, stealth mode, and geolocation control.
