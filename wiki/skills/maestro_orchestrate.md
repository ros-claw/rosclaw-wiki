> Multi-agent development orchestration coordinating 22 specialized subagents through 4-phase workflows with native parallel execution, persistent sessions, and standalone commands for code review, debugging, security audit, and more.

Maestro-orchestrate is a plugin that coordinates multiple specialized subagents for development tasks. It uses 22 subagents in a 4-phase workflow with parallel execution and persistent sessions. The tool offers standalone commands for activities like code review, debugging, and security audits. It is listed under backend and architecture plugins.
