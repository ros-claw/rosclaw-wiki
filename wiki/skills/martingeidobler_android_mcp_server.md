One-command install via `npx android-mcp-server`.

This project provides an MCP server for controlling Android devices via ADB, offering 21 tools including screenshot capture with compression, UI tree inspection, touch automation, logcat access, and compound actions like tap-and-wait. It is designed for developer tooling and can be installed with a single command using npx. The server integrates with AI agents through the Model Context Protocol to enable automated Android device interaction.
