Manage participants, official rules, winner drawings, entry pages, billing, and more. Requires a [Sweeppea](https://www.sweeppea.com/) subscription.

Sweeppea MCP Info is a server that provides 70 tools to manage sweepstakes campaigns, from participant handling and official rules to winner drawings and entry pages, ensuring legal compliance in the US and Canada. It integrates with the Sweeppea subscription platform to automate promotion workflows for marketers. The server simplifies running legally sound sweepstakes by offering a comprehensive set of tools via the Model Context Protocol.
