endiagram/mcp is an MCP server that provides 12 deterministic graph analysis tools for structural analysis of any system described using EN syntax. The tools include topology mapping, bottleneck detection, blast radius analysis, trace, diff, and centrality calculations, all without using AI. Designed for developers, it can be installed via npx and is listed under Developer Tools in the MCP server ecosystem. This enables precise, repeatable system analysis.
