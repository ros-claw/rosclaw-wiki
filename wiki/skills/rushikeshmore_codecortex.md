CodeCortex is an MCP server that provides a persistent knowledge layer for AI coding agents. It pre-digests codebases into structured knowledge including symbols, dependency graphs, co-change patterns, and architectural decisions using tree-sitter parsing for 28 languages. The server offers 14 tools and achieves approximately 85% token reduction for AI agents. It is compatible with Claude Code, Cursor, Codex, and any MCP client.
