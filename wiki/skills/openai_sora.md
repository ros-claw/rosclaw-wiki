This project is a TypeScript client or implementation for OpenAI's Sora, a text-to-video generative AI model. It enables developers to integrate video generation from text descriptions into TypeScript applications. The library handles API communication, authentication, and response processing. It is part of OpenAI's developer tools for programmatic access to Sora's capabilities.
