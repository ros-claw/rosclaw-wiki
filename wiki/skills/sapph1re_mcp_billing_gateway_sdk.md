Add Stripe subscriptions, per-call credits, tiered pricing, and x402 crypto micropayments to any MCP server without writing billing code. Operator dashboard included.

This project provides a billing infrastructure SDK for MCP server operators, allowing them to add payment features like Stripe subscriptions, per-call credits, tiered pricing, and x402 crypto micropayments without writing billing code. It includes an operator dashboard for management. The SDK simplifies monetization for MCP servers by integrating multiple payment methods.
