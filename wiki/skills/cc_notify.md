> CCNotify provides desktop notifications for Claude Code, alerting you to input needs or task completion, with one-click jumps back to VS Code and task duration display.

CC Notify is a hook for Claude Code that sends desktop notifications when the AI needs user input or completes a task. It allows users to jump back to VS Code with one click and displays the task duration. This tool helps developers stay focused by alerting them only when action is required.
