> 🐍 ☁️ - Connect to Databricks API, allowing LLMs to run SQL queries, list jobs, and get job status.

This MCP server connects to the Databricks API, enabling large language models to run SQL queries, list jobs, and check job status. It serves as a bridge between AI agents and Databricks data platforms, allowing natural language-driven interactions. The server is categorized under Data Platforms within the MCP ecosystem.
