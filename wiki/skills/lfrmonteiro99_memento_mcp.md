Memento-MCP is an MCP server that provides local-first persistent memory for AI coding agents, storing facts, decisions, patterns, and architecture notes in SQLite. It reduces the need to repeat context across sessions by capturing and retrieving information automatically. Optional cloud embeddings allow for semantic search across stored memory.
