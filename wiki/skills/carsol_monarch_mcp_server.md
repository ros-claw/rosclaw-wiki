> 🐍 ☁️ - MCP server providing read-only access to Monarch Money financial data, enabling AI assistants to analyze transactions, budgets, accounts, and cashflow data with MFA support.

This MCP server provides read-only access to Monarch Money financial data, allowing AI assistants to analyze transactions, budgets, accounts, and cashflow. It supports multi-factor authentication (MFA) for secure access. The tool is designed for finance and fintech use cases, enabling automated financial insights without write access. It is listed under the Finance & Fintech category of server implementations.
