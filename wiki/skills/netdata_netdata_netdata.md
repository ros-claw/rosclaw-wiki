> 🎖️ 🏠 ☁️ 📟 🍎 🪟 🐧 - Discovery, exploration, reporting and root cause analysis using all observability data, including metrics, logs, systems, containers, processes, and network connections

Netdata is an open-source observability platform that provides real-time monitoring and troubleshooting for systems, containers, and applications. It collects metrics, logs, and network data to help with root cause analysis. The platform supports various operating systems including Linux, macOS, and Windows, and can be deployed on-premises or in the cloud. Netdata focuses on ease of setup and interactive visualizations for discovery and exploration of system performance.
