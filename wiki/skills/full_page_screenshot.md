> Captures full-page screenshots of web pages via Chrome DevTools Protocol with zero dependencies.

Full-Page Screenshot is a lightweight tool that captures entire web pages as images without requiring additional dependencies. It leverages the Chrome DevTools Protocol to take full-page screenshots, making it useful for developers and QA teams. The tool is simple to integrate and works with any Chrome-based browser.
