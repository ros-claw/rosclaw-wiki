Temporal Cortex MCP is an AI-native calendar middleware that enables scheduling, availability checks, and conflict-free booking across Google Calendar, Outlook, and CalDAV. It provides 15 tools organized into 5 layers including temporal context, calendar operations, multi-calendar availability, open scheduling, and Two-Phase Commit booking. The system uses a Truth Engine for deterministic datetime resolution and RRULE expansion, making it suitable for autonomous AI agents that need calendar integration.
