> 📇 ☁️ - An MCP server for CSV files.

This MCP server provides a standardized interface for AI models to read and manipulate CSV files. It acts as a bridge between large language models and tabular data stored in CSV format. Developers can use it to give their AI agents the ability to work with spreadsheet-like data during tasks.
