> ![GitHub stars](https://img.shields.io/github/stars/lucasgelfond/autoresearch-webgpu?style=social) - Browser/WebGPU port that lets agents generate training code, run experiments in-browser, and feed results back into the loop without a Python setup.

This project is a browser-based port of the AutoResearch framework that leverages WebGPU for hardware acceleration. It enables AI agents to generate machine learning training code and run experiments directly in the browser without requiring a Python environment. Results from experiments are fed back into the agent loop, allowing for iterative research and development entirely on the client side. This lowers the barrier to entry for automated ML research by eliminating local setup dependencies.
