> 📇 🏠 🍎 🪟 🐧 - Interact with Obsidian vaults for knowledge management. Create, read, update, and search notes. Works with local Obsidian vaults using filesystem access.

This MCP server allows interaction with Obsidian vaults for knowledge management. It supports creating, reading, updating, and searching notes via filesystem access on local Obsidian vaults. The server is categorized under Knowledge and Memory in the MCP server implementations list. It provides a convenient way to integrate Obsidian note-taking with AI agents.
