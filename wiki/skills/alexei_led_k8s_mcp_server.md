> 🐍 - A lightweight yet robust server that empowers AI assistants to securely execute Kubernetes CLI commands (`kubectl`, `helm`, `istioctl`, and `argocd`) using Unix pipes in a safe Docker environment with multi-architecture support.

This is a lightweight server that allows AI assistants to securely execute Kubernetes CLI commands such as kubectl, helm, istioctl, and argocd. Commands are run via Unix pipes inside a safe Docker environment with support for multiple CPU architectures. It bridges the gap between AI tools and Kubernetes management without compromising security. The project is categorized under cloud platform server implementations.
