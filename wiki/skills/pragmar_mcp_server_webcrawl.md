> 🐍 🏠 - Advanced search and retrieval for web crawler data. Supports WARC, wget, Katana, SiteOne, and InterroBot crawlers.

This MCP server enables advanced search and retrieval of data from multiple web crawler formats, including WARC, wget, Katana, SiteOne, and InterroBot. It provides a unified interface for querying crawled content, allowing AI agents to access historical web data efficiently. The server supports various crawler outputs, making it versatile for different web archiving and scraping workflows.
