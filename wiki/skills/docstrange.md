> Document extraction API by Nanonets.

Docstrange is a document extraction API developed by Nanonets. It allows developers to programmatically extract structured data from various document types, such as invoices, receipts, and forms. The API uses machine learning models to identify and extract key fields with high accuracy. It is designed to be easily integrated into existing workflows to automate data entry and processing.
