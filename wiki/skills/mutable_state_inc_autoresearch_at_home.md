> ![GitHub stars](https://img.shields.io/github/stars/mutable-state-inc/autoresearch-at-home?style=social) - Collaborative fork of upstream autoresearch that adds experiment claiming, shared best-config syncing, hypothesis exchange, and swarm-style coordination across many single-GPU agents.

This project is a collaborative fork of the Autoresearch system, adding features that let multiple single-GPU agents work together. It includes experiment claiming, shared best-configuration syncing, hypothesis exchange, and swarm-style coordination. The goal is to enable distributed, multi-agent research without requiring large server clusters.
