> 🦀 🏠 🐧 🍎 - A Javascript code execution sandbox that uses v8 to isolate code to run AI generated javascript locally without fear. Supports heap snapshotting for persistent sessions.

MCP-JS is a JavaScript code execution sandbox that leverages V8 to safely run AI-generated JavaScript code locally. It provides isolation to prevent malicious actions and supports heap snapshotting for persistent sessions across interactions. Designed as a server implementation under Code Execution, it allows developers to execute untrusted JS with confidence.
