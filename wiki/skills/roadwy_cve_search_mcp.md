> 🐍 🏠 - A Model Context Protocol (MCP) server for querying the CVE-Search API. This server provides comprehensive access to CVE-Search, browse vendor and product、get CVE per CVE-ID、get the last updated CVEs.

This project implements an MCP (Model Context Protocol) server that provides a programming interface to the CVE-Search database. It allows users to browse vendors and products, look up specific CVEs by their ID, and retrieve the most recently updated vulnerabilities. Designed primarily for AI agents and LLM tooling, it enables security-related queries through a standardized protocol. The server acts as a bridge between the CVE-Search API and MCP-compatible clients, facilitating automated vulnerability intelligence gathering.
