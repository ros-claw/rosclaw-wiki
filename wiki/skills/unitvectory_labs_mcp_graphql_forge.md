> 🏎️ ☁️ 🍎 🪟 🐧 - A lightweight, configuration-driven MCP server that exposes curated GraphQL queries as modular tools, enabling intentional API interactions from your agents.

This MCP server lets you define GraphQL queries in a configuration file, which are then exposed as modular tools for AI agents. It is lightweight and configuration-driven, making it easy to integrate curated API interactions. The server supports multiple platforms and is designed for intentional agent interactions with GraphQL APIs.
