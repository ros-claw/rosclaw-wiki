AgentKits Memory is a persistent memory system for AI coding assistants. It uses SQLite with hybrid search combining FTS5 and vector embeddings. It tracks sessions and provides automatic context hooks and a web viewer. It works with multiple MCP clients like Claude Code, Cursor, and Windsurf, requiring no daemon process.
