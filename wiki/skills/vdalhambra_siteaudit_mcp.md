This MCP server provides a comprehensive website auditing toolset with 11 distinct tools for SEO, security, performance, and accessibility checks. It performs full SEO audits with over 20 checks, validates security headers and SSL, and runs Lighthouse performance metrics without requiring any API keys. Additional features include broken link detection, WCAG accessibility audits, Schema.org structured data validation, competitor gap analysis, and robots.txt parsing. The tool is suitable for instant, multi-site comparisons and automated monitoring workflows.
