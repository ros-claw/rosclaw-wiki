> 🐍 ☁️ - A Model Context Protocol (MCP) server that enables Claude Desktop to check domain availability across 50+ TLDs. Features DNS/WHOIS verification, bulk checking, and smart suggestions. Zero-clone installation via uvx.

This MCP server enables Claude Desktop to check domain name availability across over 50 top-level domains. It uses DNS and WHOIS verification for accurate results, supports bulk checking, and offers smart suggestions. Installation is straightforward via uvx without needing to clone the repository. The tool is part of the MCP ecosystem for search and data extraction tasks.
