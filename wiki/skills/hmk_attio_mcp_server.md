> 📇 ☁️ Allows AI clients to manage records and notes in Attio CRM

This project implements a Model Context Protocol (MCP) server that allows AI clients to manage records and notes in Attio CRM. It provides a standardized interface for AI agents to interact with Attio's data, enabling tasks like creating, updating, and querying records and notes. The server bridges AI tooling with the Attio CRM platform. It is listed under other tools and integrations in the MCP server ecosystem.
