> Watchdog that monitors your AI agent gateway and restarts it when it crashes.

Agent-defibrillator is a watchdog tool that monitors an AI agent gateway for crashes. When a crash is detected, it automatically restarts the gateway to maintain uptime. This ensures the AI agent remains operational without manual intervention, improving reliability and resilience.
