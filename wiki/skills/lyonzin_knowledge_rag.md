lyonzin/knowledge-rag is a local RAG (Retrieval-Augmented Generation) system designed for Claude Code. It uses hybrid search combining BM25 and semantic search, with cross-encoder reranking and markdown-aware chunking. The system runs entirely offline with no external servers, and provides 12 MCP tools for interacting with knowledge. It supports multiple platforms including macOS, Windows, Linux, and is built in Python.
