> 📇 🏠 - Automate your local Chrome browser

This MCP server enables local Chrome browser automation by providing an interface that AI agents can use to perform browser actions via natural language. It leverages the Model Context Protocol (MCP) to integrate with AI assistants, allowing them to control a desktop Chrome instance. The server simplifies browser automation tasks like clicking, navigation, and form filling, making them accessible through AI interactions.
