Literature search, citation verification, citation graph exploration, and autonomous deep research workflows.

PapersFlow MCP is a hosted server that connects AI agents to academic research databases, providing access to over 474 million papers from Semantic Scholar and OpenAlex. It includes seven specialized AI agents for tasks like literature search, citation verification, and citation graph exploration. The server enables autonomous deep research workflows, allowing users to execute complex research tasks through natural language interactions. It is listed under Knowledge & Memory server implementations for the Model Context Protocol (MCP).
