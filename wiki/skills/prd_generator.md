> A Claude Code plugin that generates comprehensive Product Requirements Documents (PRDs) from conversation context. Invoke `/create-prd` after discussing requirements and it produces a complete PRD with all standard sections including Executive Summary, User Stories, MVP Scope, Architecture, Success Criteria, and Implementation Phases.

This project is a slash-command plugin for Claude Code that automatically generates Product Requirements Documents (PRDs) from ongoing conversation context. After discussing product requirements with the AI, users invoke `/create-prd` to produce a complete PRD covering standard sections like Executive Summary, User Stories, MVP Scope, Architecture, Success Criteria, and Implementation Phases. It streamlines the process of documenting product ideas directly within the AI coding assistant environment. The plugin is categorized under Project & Task Management tools for Claude Code.
