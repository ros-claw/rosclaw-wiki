repo-graph is an MCP server that generates a structural graph map of any codebase for AI coding assistants. It scans entities, relationships, and feature flows across 13 programming languages, allowing LLMs to navigate code by its structure rather than relying on raw text search. The tool helps AI assistants understand codebase architecture, dependencies, and feature implementations more efficiently. It's designed for developer tools and integrates with AI coding workflows via the Model Context Protocol.
