> LangChain's open-source project for building deeper, longer-running agents with middleware and harness patterns.

deepagents is an open-source project by LangChain designed for constructing more sophisticated and persistent AI agents. It focuses on supporting longer-running agent executions and deeper reasoning loops through the use of middleware and harness patterns. The project provides a runtime framework and reference implementation for developers to build complex multi-step agent workflows. It addresses challenges like state management, error handling, and orchestration of extended agent interactions.
