This MCP server enables AI assistants to control WeMo smart home devices using natural language. Built on pywemo, it operates fully locally without cloud dependency. It supports dimmer brightness, device renaming, HomeKit codes, and multi-phase discovery. Compatible with multiple operating systems including macOS, Windows, and Linux.
