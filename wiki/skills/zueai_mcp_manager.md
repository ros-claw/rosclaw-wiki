> 📇 ☁️ - Simple Web UI to install and manage MCP servers for Claude Desktop App.

This is a simple web UI that allows users to install and manage MCP (Model Context Protocol) servers for use with the Claude Desktop application. It provides an interface to browse available servers and easily add or remove them. The tool streamlines the setup and configuration of MCP servers, making it more accessible for Claude Desktop users.
