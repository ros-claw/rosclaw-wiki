> 📇 ☁️ - Clojars MCP Server for upto date dependency information of Clojure libraries

This project is an MCP server that provides up-to-date dependency information for Clojure libraries from Clojars. It is listed under Server Implementations for Search & Data Extraction. The server integrates with the Model Context Protocol to allow AI agents to query Clojure library dependencies. It helps developers keep their projects updated with accurate dependency data.
