> Desktop app for managing the Claude Code ecosystem — MCP marketplace, config profiles, skills & plugins browser, workflow templates, security audit. Built with Tauri v2 + React + Rust.

CCHub is a desktop application that serves as a central management tool for the Claude Code ecosystem. It includes an MCP marketplace, configuration profiles, a skills and plugins browser, workflow templates, and a security audit feature. The app is built using Tauri v2, React, and Rust, focusing on developer productivity and tool integration.
