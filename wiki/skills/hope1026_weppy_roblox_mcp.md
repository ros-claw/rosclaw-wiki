> [![roblox-mcp MCP server](https://glama.ai/mcp/servers/hope1026/roblox-mcp/badges/score.svg)](https://glama.ai/mcp/servers/hope1026/roblox-mcp) 📇 🏠 🍎 🪟 - MCP server and plugin that lets AI agents (Claude Code, Cursor, Codex, Gemini) directly control a live Roblox Studio session — create scripts, instances, terrain, lighting, and assets via natural language. 21 tools, 140+ actions, bidirectional sync, and automated playtest.

The weppy-roblox-mcp project provides an MCP (Model Context Protocol) server and plugin that enables AI agents such as Claude Code, Cursor, Codex, and Gemini to directly control a live Roblox Studio session. It offers 21 tools and over 140 actions for creating scripts, instances, terrain, lighting, and assets using natural language. The tool supports bidirectional synchronization and automated playtesting, allowing developers to integrate AI-powered workflows into Roblox game development. This open-source server is listed under the Gaming section of the MCP server directory.
