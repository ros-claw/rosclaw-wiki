> Automatically creates user-facing changelogs from git commits by analyzing history and transforming technical commits into customer-friendly release notes.

This tool automatically generates user-facing changelogs from git commit history. It analyzes technical commit messages and transforms them into customer-friendly release notes. The goal is to streamline the release process by reducing manual effort in documenting changes. It is designed for development teams who want to maintain clear communication with their users about new features, fixes, and improvements.
