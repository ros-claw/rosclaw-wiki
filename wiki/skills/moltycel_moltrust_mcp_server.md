This MCP server provides trust infrastructure for AI agents, enabling features like DID registration, identity verification, reputation score queries, agent rating, and management of W3C Verifiable Credentials. It also supports handling USDC credit deposits on the Base blockchain, making it suitable for secure agent-to-agent interactions. The server is listed under security-focused server implementations.
