> Audit an iOS app repo.

This tool audits an iOS app repository to verify its readiness for App Store submission. It checks code, configuration, and metadata for common issues like missing icons or versioning errors. The tool helps developers comply with Apple's guidelines and automates the review process to save time. It can be integrated into CI pipelines for continuous checks.
