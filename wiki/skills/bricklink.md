> BrickLink Store API helper/CLI (OAuth 1.0 request signing).

Bricklink is a command-line tool and library that simplifies interactions with the BrickLink Store API by handling OAuth 1.0 request signing. It allows users to authenticate and make API calls to manage BrickLink stores, inventory, and orders. The tool is designed for developers and sellers who want to automate tasks on the BrickLink marketplace. It abstracts the complexities of OAuth signing, making it easier to integrate with the BrickLink API.
