> [![gsmethells/preflight-mcp MCP server](https://glama.ai/mcp/servers/gsmethells/preflight-mcp/badges/score.svg)](https://glama.ai/mcp/servers/gsmethells/preflight-mcp) 🐍 ☁️ - TrustPilot for APIs — independent reliability ratings for APIs and MCP servers, powered by synthetic probes and crowdsourced agent telemetry.

Preflight-MCP is a monitoring server that acts like a 'TrustPilot' for APIs and MCP servers, providing independent reliability ratings. It uses synthetic probes to test endpoints and collects crowdsourced telemetry from AI agents to evaluate service trustworthiness. This helps developers assess the quality and uptime of external APIs and AI tool integrations before using them. The tool is designed for the Model Context Protocol ecosystem, offering real-time and historical reliability data.
