> 🐍 🏠 - Your AI agents' home directory — privacy-first MCP server for portable AI identity. Configure once, use everywhere. It supports profile management, skills, resume import, and team sync.

Tilde is a privacy-first MCP (Model Context Protocol) server that provides AI agents with a portable home directory for managing identity and knowledge. It enables users to configure profiles, skills, and resume data once, then synchronize across teams and agent platforms. The server emphasizes privacy by keeping data local and under user control. It integrates with various AI agent ecosystems via the MCP protocol, ensuring consistent knowledge and memory management.
