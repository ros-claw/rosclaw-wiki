The urldna/mcp project is a Model Context Protocol (MCP) server designed for automated URL scanning and forensic phishing triage. It captures full DOM snapshots, network requests, and visual screenshots to identify malicious redirects and infrastructure. The tool supports historical threat hunting using a Custom Query Language (CQL) to map attack patterns across millions of recorded scans. It runs on multiple platforms including Linux, macOS, and Windows.
