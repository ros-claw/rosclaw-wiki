> Tiered stranger access control for AI agents.

Agent-access-control is a system for managing access permissions of unknown (stranger) users interacting with AI agents. It implements a tiered access model where different levels of interaction are granted based on trust or identity verification. This helps ensure that AI agents only expose sensitive capabilities to authenticated or trusted entities. The project likely provides APIs or middleware for integrating such control into agent frameworks. It promotes safety and security in open agent environments.
