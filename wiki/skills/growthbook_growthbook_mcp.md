> 🎖️ 📇 🏠 🪟 🐧 🍎 — Tools for creating and interacting with GrowthBook feature flags and experiments.

This MCP server implementation provides tools for creating and interacting with GrowthBook feature flags and experiments. It allows AI agents and other Model Context Protocol clients to programmatically manage flags and run A/B tests within the GrowthBook platform. Listed under Data Science Tools, it is designed to support data-driven experimentation workflows. The server integrates with GrowthBook's API to enable feature flag creation, experiment configuration, and result retrieval.
