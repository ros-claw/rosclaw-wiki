> A community marketplace for discovering, sharing, and installing reusable AI agent skills across runtimes like Claude Code and OpenClaw, making harness capabilities portable and composable.

skills.sh is a community-driven marketplace that allows users to discover, share, and install reusable AI agent skills. These skills can be used across different runtimes such as Claude Code and OpenClaw. The project aims to make harness capabilities portable and composable, enhancing interoperability between agent platforms.
