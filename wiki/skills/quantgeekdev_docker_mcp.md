> 🏎️ 🏠 - Docker container management and operations through MCP

This project integrates Docker container management with the Model Context Protocol (MCP), enabling AI agents to perform operations on Docker containers. It serves as a developer tool for automating container lifecycle tasks through MCP endpoints. The tool allows agents to list, create, start, stop, and inspect containers, bridging the gap between AI interactions and Docker infrastructure.
