> 🐍 ☁️ - MCP server that controls [MultiViewer](https://multiviewer.app), an app for watching motorsports like Formula 1, World Endurance Championship, IndyCar and others.

This project implements an MCP (Model Context Protocol) server designed to control the MultiViewer application, which is used for watching motorsports. It supports popular racing series such as Formula 1, the World Endurance Championship, and IndyCar. The server enables programmatic control of MultiViewer, likely for automation and integration with AI agents. This tool is part of the ecosystem of MCP servers that enhance AI interaction with real-world applications.
