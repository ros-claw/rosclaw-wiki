> [![godot-forge MCP server](https://glama.ai/mcp/servers/gregario/godot-forge/badges/score.svg)](https://glama.ai/mcp/servers/gregario/godot-forge) 📇 🏠 🍎 🪟 🐧 - Godot 4 development companion with test running (GUT/GdUnit4), API docs with 3→4 migration mapping, script analysis, scene parsing, screenshots, and LSP diagnostics.

godot-forge is an MCP server that acts as a development companion for Godot 4, enabling AI agents to run tests (via GUT or GdUnit4), access API documentation with migration guides from Godot 3 to 4, analyze scripts, parse scenes, capture screenshots, and use LSP diagnostics. It supports Windows, macOS, and Linux platforms, and integrates directly with the Godot editor to streamline game development workflows. This tool helps developers and AI agents collaborate more effectively on Godot projects by providing a standardized interface for common development tasks.
