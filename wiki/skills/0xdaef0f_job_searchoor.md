> 📇 🏠 - An MCP server for searching job listings with filters for date, keywords, remote work options, and more.

This project provides a Model Context Protocol (MCP) server for searching job listings. It supports filters such as date, keywords, and remote work options. The server enables AI agents to query and retrieve job postings programmatically. It is listed under Search & Data Extraction in the MCP server ecosystem.
