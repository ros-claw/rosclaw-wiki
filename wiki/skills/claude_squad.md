> Claude Squad is a terminal app that manages multiple Claude Code, Codex (and other local agents including Aider) in separate workspaces, allowing you to work on multiple tasks simultaneously.

Claude Squad is a terminal application designed to manage multiple AI coding agents, such as Claude Code, Codex, and Aider, in separate workspaces. It enables users to run several tasks simultaneously by orchestrating these agents concurrently. This tool is categorized under orchestrators and is intended for developers who need to handle multiple coding tasks efficiently.
