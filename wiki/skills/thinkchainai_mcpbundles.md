> MCP Bundles: Create custom bundles of tools and connect providers with OAuth or API keys. Use one MCP server across thousands of integrations, with programmatic tool calling and MCP UI for managing bundles and credentials.

MCP Bundles is an aggregator tool that allows users to create custom bundles of tools and connect various providers using OAuth or API keys. It enables using a single MCP server to access thousands of integrations, supporting programmatic tool calling. The project includes a UI for managing bundles and credentials, simplifying the orchestration of multiple services.
