> 📇 🏠/☁️ - A Model Context Protocol Server for [SearXNG](https://docs.searxng.org)

MCP-SearXNG is a Model Context Protocol (MCP) server that integrates SearXNG, a self-hosted metasearch engine, into AI agent toolchains. It enables AI models to perform web searches via the MCP interface, retrieving results from multiple search engines. This tool is designed for server-to-server use cases where privacy and control over search sources are important. It falls under the Search & Data Extraction category of MCP server implementations.
