> 🐍 ☁️ - Access Twitter/X data including user profiles, tweets, followers, trends, lists, and communities via the ScrapeBadger API.

Scrapebadger-mcp is an MCP server that provides access to Twitter/X data through the ScrapeBadger API. It enables retrieval of user profiles, tweets, followers, trends, lists, and communities. The tool utilizes a third-party scraping service to interact with the social media platform programmatically. This server integrates with the Model Context Protocol to offer structured data for AI agents and applications.
