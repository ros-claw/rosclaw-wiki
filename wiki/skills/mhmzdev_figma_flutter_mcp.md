> 📇 🏠 - Provide coding agents direct access to Figma data to help them write Flutter code for building apps including assets exports, widgets maintenance and full screens implementations.

This project is a Model Context Protocol (MCP) server that provides AI coding agents with direct access to Figma design data, enabling them to automatically generate Flutter code for app development. It supports tasks such as exporting assets, maintaining widgets, and implementing entire screens from Figma designs. By bridging Figma and AI agents, it streamlines the design-to-code workflow, reducing manual coding effort for Flutter developers.
