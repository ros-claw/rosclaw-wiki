> 🏎️ 🏠 - Natural language PostgreSQL queries with automatic streaming, read-only safety, and universal database compatibility.

This project is a Model Context Protocol (MCP) server that enables natural language queries against PostgreSQL databases. It automatically streams query results, enforces read-only safety to prevent accidental writes, and is designed for compatibility with various database systems beyond PostgreSQL. The server bridges language models and databases by translating plain English requests into SQL queries.
