> 🐍 🏠 - Expose all Home Assistant voice intents through a Model Context Protocol Server allowing home control.

This project is a Model Context Protocol (MCP) server that exposes all Home Assistant voice intents, enabling natural language control of smart home devices. It bridges Home Assistant's voice assistant capabilities with MCP-compatible AI agents, allowing users to control their home via voice commands processed through the MCP interface. The server translates intents into Home Assistant actions, making home automation accessible through conversational AI.
