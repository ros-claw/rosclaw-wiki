Hybrid vector + keyword search with Reciprocal Rank Fusion, fully local, background indexing, project-selective.

Lore is an MCP server that enables semantic search across Claude Code conversations. It uses a hybrid approach combining vector and keyword search with Reciprocal Rank Fusion for high-quality results. The tool runs fully locally, performs background indexing, and allows project-selective search. This helps developers retrieve relevant context from past coding sessions.
