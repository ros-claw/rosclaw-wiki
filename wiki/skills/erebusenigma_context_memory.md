> 🐍 🏠 🍎 🪟 🐧 - Persistent, searchable context storage across Claude Code sessions using SQLite FTS5. Save sessions with AI-generated summaries, two-tier full-text search, checkpoint recovery, and a web dashboard.

Context-memory is a tool that provides persistent, searchable storage for context across Claude Code sessions. It uses SQLite with FTS5 (full-text search) to save sessions with AI-generated summaries. Users can perform two-tier full-text search, recover checkpoints, and browse a web dashboard. This enables continuity and retrieval of prior conversations and context.
