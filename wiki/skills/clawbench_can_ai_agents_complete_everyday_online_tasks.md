> A browser-agent benchmark of 153 everyday web tasks across 144 live production sites in 15 categories, using a lightweight interception layer that captures and blocks only the final submission request so agents can be scored end-to-end on real websites without real-world side effects.

ClawBench is a benchmark for evaluating AI agents on everyday online tasks. It consists of 153 tasks across 144 live production websites in 15 categories. The benchmark uses a lightweight interception layer that blocks only the final submission request, allowing end-to-end scoring on real websites without side effects. This enables safe evaluation of browser agents performing real-world tasks.
