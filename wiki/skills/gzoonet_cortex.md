Cortex is a local-first knowledge graph tool for developers that monitors project files and uses LLMs to extract entities and relationships. It builds a queryable knowledge graph accessible via a web dashboard and command-line interface. The tool offers four MCP server tools: get_status, list_projects, find_entity, and query_cortex. This enables developers to maintain a dynamic understanding of their codebase's structure and dependencies.
