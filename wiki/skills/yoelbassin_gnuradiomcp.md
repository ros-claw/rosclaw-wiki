> 🐍 📟 🏠 - An MCP server for GNU Radio that enables LLMs to autonomously create and modify RF `.grc` flowcharts.

This project provides an MCP (Model Context Protocol) server that connects large language models (LLMs) to GNU Radio, enabling them to autonomously create and modify RF flowcharts (.grc files). It allows AI agents to design and simulate software-defined radio systems without human intervention. The server translates LLM requests into GNU Radio operations, making it easier for developers to incorporate radio design into AI-driven workflows.
