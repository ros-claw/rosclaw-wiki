ArcadeData/arcadedb provides a built-in MCP server for ArcadeDB, a multi-model database that supports graph, document, key-value, time-series, and vector data models. It offers multiple query languages including SQL, Cypher, Gremlin, and MongoDB Query Language. This MCP server allows AI agents to interact with the database using the Model Context Protocol for tasks like querying and managing data. It is listed under Server Implementations for databases in the MCP ecosystem.
