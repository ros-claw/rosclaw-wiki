auth0-react is a React SDK for integrating Auth0 authentication into React applications. It provides hooks and components for login, logout, and user profile management. The library is written in TypeScript, offering type-safe authentication flows. It supports OAuth 2.0 and OpenID Connect protocols. Ideal for React apps needing secure user authentication.
