> Brevo (formerly Sendinblue) email marketing API for managing contacts, lists,.

Brevo is a Python client library for the Brevo (formerly Sendinblue) email marketing API. It provides tools to manage contacts, contact lists, and send transactional emails or marketing campaigns. Developers can integrate email marketing functionality into their applications using this wrapper. The library simplifies authentication and API calls to the Brevo service.
