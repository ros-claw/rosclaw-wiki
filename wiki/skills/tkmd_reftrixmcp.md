TKMD/ReftrixMCP is an MCP server that analyzes web design using 26 tools for layout extraction, motion detection, quality scoring, and semantic search. It leverages Playwright for web automation, pgvector with HNSW indexing for vector similarity, and Ollama Vision for multimodal understanding. The tool transforms web pages into structured, searchable design knowledge, aiding developers in design analysis and retrieval.
