Selvedge is an MCP server designed for change tracking in AI-era codebases. It enables AI agents to log structured change events containing entity, diff, and reasoning before a session ends. Agents can later query history using commands like diff, blame, history, changeset, and search. This captures the intent behind changes that would otherwise be lost.
