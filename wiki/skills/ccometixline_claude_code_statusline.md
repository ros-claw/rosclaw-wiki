> A high-performance Claude Code statusline tool written in Rust with Git integration, usage tracking, interactive TUI configuration, and Claude Code enhancement utilities.

CCometixLine is a high-performance statusline tool for Claude Code, written in Rust. It integrates with Git for version control awareness, tracks usage statistics, and provides an interactive TUI for configuration. The tool enhances the Claude Code development environment with customizable status displays and utilities. It aims to be efficient and fast, leveraging Rust's performance.
