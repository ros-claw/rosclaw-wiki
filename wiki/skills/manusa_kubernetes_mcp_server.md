This project provides a powerful MCP (Model Context Protocol) server for Kubernetes with additional support for OpenShift. It enables CRUD operations on Kubernetes resources, allowing AI agents to interact with cloud-native infrastructure. The server is designed for managing containers and deployments programmatically through standard protocols. It is listed under Cloud Platforms in the MCP server ecosystem.
