Pure Python, zero heavy dependencies, 42 KB wheel. Install: `pip install blackmount-nlp-mcp`.

BlackMount-nlp-mcp is a lightweight, deterministic NLP server that provides local text analysis capabilities without requiring heavy dependencies. It supports sentiment analysis, readability scoring, keyword extraction, text similarity, summarization, and language detection across 18 languages. The tool is implemented in pure Python and installable via pip with a 42 KB wheel. It is designed for use as an MCP (Model Context Protocol) server, making it suitable for AI agent tooling and data science workflows.
