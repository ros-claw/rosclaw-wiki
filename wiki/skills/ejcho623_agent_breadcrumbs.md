> 📇 ☁️ 🏠 - Unified agent work logging and observability across ChatGPT, Claude, Cursor, Codex, and OpenClaw with config-first schemas and pluggable sinks.

Agent Breadcrumbs is a unified logging and observability tool for AI agents that supports multiple platforms including ChatGPT, Claude, Cursor, Codex, and OpenClaw. It uses a config-first schema approach, allowing users to define how agent actions are recorded. The system features pluggable sinks, enabling flexible data storage and export to various backends. This helps developers monitor, debug, and analyze agent behavior across different AI environments in a consistent way.
