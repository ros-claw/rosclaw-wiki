> 🐍 ☁️ - Query Langfuse traces, debug exceptions, analyze sessions, and manage prompts. Full observability toolkit for LLM applications.

This project is an MCP server that integrates with Langfuse, a platform for monitoring and debugging LLM applications. It enables users to query traces and spans for observability, debug exceptions by examining errors, analyze sessions to understand user interactions, and manage prompts for LLM models. Essentially, it provides a full toolkit for LLM observability directly through the MCP protocol, making it easier to inspect and improve AI applications.
