> Provides a structured set of commands for bootstrapping and managing a new project, including meta-commands for creating and editing custom slash-commands.

This project offers a set of structured commands for initializing and managing new projects. It includes meta-commands that allow users to create and edit custom slash-commands. The tool is categorized under Workflows & Knowledge Guides, focusing on general project bootstrapping and task management.
