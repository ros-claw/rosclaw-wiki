An MCP server that integrates with RomM, a retro game library manager, providing 19 read-only tools for browsing platforms, searching ROMs, viewing metadata, managing collections, tracking saves, firmware, devices, and task monitoring. It supports OAuth2 authentication with automatic token refresh. This server enables AI agents to interact with a personal retro game collection through standardized tool calls.
