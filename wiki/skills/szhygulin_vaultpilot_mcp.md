Hardware-verified DeFi for AI agents — designed for when the AI can be compromised. The agent proposes, you approve on your Ledger. Read balances + DeFi positions (Aave V3, Compound V3, Morpho Blue, Uniswap V3 LP, Lido, EigenLayer, MarginFi, Kamino) and prepare transactions across Ethereum / Arbitrum / Polygon / Base / TRON / Solana / Bitcoin; private keys never leave the hardware wallet.

Vaultpilot-MCP is a safety-first MCP server that lets AI agents interact with DeFi protocols while keeping private keys on a hardware wallet like Ledger. The AI can propose transactions, but the user must approve them on the device, ensuring no compromise of funds even if the AI is attacked. It supports reading balances and DeFi positions across major protocols (Aave, Compound, Uniswap, Lido, EigenLayer, MarginFi, Kamino) and multiple blockchains (Ethereum, Arbitrum, Polygon, Base, TRON, Solana, Bitcoin). Transactions can be prepared but never executed without hardware approval. This tool is designed specifically for finance and fintech use cases where security is paramount.
