panther-labs/mcp-panther is an MCP server that integrates with Panther's SIEM platform. It enables security professionals to use natural language for writing detections, querying logs, and managing alerts. This tool bridges AI capabilities with security operations, simplifying workflows. It is listed under Security in the MCP server implementations.
