> 📇 🏠 🪟 - Desktop task manager with clean To Do-style UI and 25+ MCP tools for prioritization, goal tracking, and multi-profile workflows.

UpTier is a desktop application that serves as a task manager with a clean to-do style interface. It integrates over 25 MCP (Model Context Protocol) tools to help with task prioritization, goal tracking, and managing multiple profiles or workflows. This makes it suitable for workplace and productivity scenarios.
