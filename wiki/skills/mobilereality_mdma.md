> [![MobileReality/mdma MCP server](https://glama.ai/mcp/servers/MobileReality/mdma/badges/score.svg)](https://glama.ai/mcp/servers/MobileReality/mdma) 📇 ☁️ 🏠 🍎 🪟 🐧 - MCP server for MDMA (interactive Markdown applications with mounted components). Exposes the MDMA spec, authoring prompts, package metadata, and live docs to AI assistants. Tools: `get-spec`, `get-prompt`, `build-system-prompt`, `validate-prompt`, `list-packages`, `list-docs`, `get-doc`. Install: `npx @mobile-reality/mdma-mcp`.

This is an MCP (Model Context Protocol) server that exposes the MDMA (interactive Markdown applications with mounted components) ecosystem to AI assistants. It provides tools for retrieving the MDMA specification, authoring prompts, building system prompts, validating prompts, listing packages, and accessing live documentation. The server is installable via npx and is designed to help AI agents interact with and understand MDMA-based projects.
