> 📇 🏠 🍎 🪟 🐧 - Advanced filesystem operations with large file handling capabilities and Claude-optimized features. Provides fast file reading/writing, sequential reading for large files, directory operations, file search, and streaming writes with backup & recovery.

This project implements a Model Context Protocol (MCP) server for advanced filesystem operations. It is optimized for large files with features such as sequential reading, streaming writes, and backup with recovery. The server supports directory operations, file search, and fast reading/writing. It is designed to work with Claude, an AI assistant. The tool aims to improve file handling efficiency in agentic workflows.
