Traces CUDA Runtime/Driver APIs and host kernel events to build causal chains explaining GPU latency.

Ingero is an eBPF-based GPU observability agent that provides an MCP server interface. It traces CUDA Runtime and Driver API calls along with host kernel events to build causal chains that explain GPU latency. This tool helps in monitoring and diagnosing performance issues in GPU-accelerated applications by linking GPU and host activities.
