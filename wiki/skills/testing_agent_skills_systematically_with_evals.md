> OpenAI's concrete guide to turning agent traces into repeatable evals with JSONL logs and deterministic checks.

This project is a guide from OpenAI that provides a systematic approach to testing agent skills using evaluations (evals). It focuses on converting agent interaction traces into repeatable, reliable evaluation formats. The method uses JSONL log files to store traces and applies deterministic checks for consistency. This enables developers to rigorously test and improve agent behaviors in a structured manner.
