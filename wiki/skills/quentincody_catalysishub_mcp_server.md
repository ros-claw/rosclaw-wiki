> 🐍 - Unofficial MCP server for searching and retrieving scientific data from the Catalysis Hub database, providing access to computational catalysis research and surface reaction data.

This MCP server provides an unofficial interface to the Catalysis Hub database, enabling AI agents to search and retrieve computational catalysis research data. It focuses on surface reaction data for materials science and chemistry applications. The server allows querying specific catalytic reactions, materials, and related computational results.
