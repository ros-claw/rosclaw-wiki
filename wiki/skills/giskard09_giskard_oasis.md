Oasis is an MCP server implementation that serves as a memory and clarity tool for AI agents. It helps agents regain their original purpose when they lose their thread, distilling context to restore focus. The service operates on a pay-per-use model using Lightning Network or Arbitrum, with discounts based on ARGENTUM reputation. It can be self-hosted with phoenixd, offering a decentralized and private solution for agent memory management.
