This is the official Python SDK for Azure Cosmos DB, a fully managed NoSQL database service by Microsoft. It enables Python developers to interact with Cosmos DB for building scalable applications. The SDK provides features like CRUD operations, querying, and transaction support. It is maintained by Microsoft and is part of the Azure ecosystem.
