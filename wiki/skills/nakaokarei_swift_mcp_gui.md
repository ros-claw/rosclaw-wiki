> 🏠 🍎 - MCP server that can execute commands such as keyboard input and mouse movement

swift-mcp-gui is a server implementation for the Model Context Protocol (MCP) that runs on macOS. It exposes tools for controlling the local graphical interface, including keyboard input and mouse movement. This allows AI assistants to directly interact with desktop applications through GUI automation. The project is written in Swift and provides a practical bridge between language models and native macOS UI actions.
