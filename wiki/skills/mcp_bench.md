> A benchmark for evaluating AI models on MCP server interactions, measuring tool accuracy, latency, and token use across server types, which directly reflects harness design choices around MCP integration.

MCP Bench is a benchmark for evaluating AI models on their interactions with MCP servers, measuring tool accuracy, latency, and token use across different server types. It directly reflects harness design choices for MCP integration, enabling comparison of model performance in tool-using scenarios. The benchmark helps researchers and developers assess how well AI models can leverage external tools via the Model Context Protocol.
