> 🐍 ☁️ - Trino MCP Server to query and access data from Trino Clusters.

This project provides an MCP (Model Context Protocol) server that allows AI models to connect to and query Trino clusters. Trino is a distributed SQL query engine for big data. The server enables AI agents to access and analyze data from various databases and data lakes through Trino. It acts as a bridge between MCP-compatible tools and Trino's query capabilities, making data accessible to language models in a controlled manner.
