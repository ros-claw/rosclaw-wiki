> 🐍 🏠 - Control HarmonyOS-next devices with AI through MCP. Support device control and UI automation.

This project provides an MCP server that enables AI agents to control HarmonyOS-next devices. It supports both device control and UI automation, allowing AI to interact with the operating system. Built on the Model Context Protocol, it offers a standardized interface for tool integration. The server is intended for developers building AI-powered automation for HarmonyOS devices.
