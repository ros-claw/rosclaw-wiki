> 📇 🏠 🍎 🪟 🐧 - Security-hardened Chrome automation with post-quantum encryption (ML-KEM-768 + ChaCha20-Poly1305), secure credential vault, memory scrubbing, and audit logging. 22 tools for browser automation and secure logins.

This project provides a security-hardened Chrome automation server for MCP (Model Context Protocol) integrations. It uses post-quantum encryption (ML-KEM-768 + ChaCha20-Poly1305) to protect all communications, includes a secure credential vault, memory scrubbing, and audit logging. The server exposes 22 tools for browser automation and secure logins, making it suitable for environments requiring high-security browser control.
