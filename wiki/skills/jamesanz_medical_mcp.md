> 📇 🏠 - An MCP server that provides access to medical information, drug databases, and healthcare resources. Enables AI assistants to query medical data, drug interactions, and clinical guidelines.

This project is a Model Context Protocol (MCP) server that gives AI assistants access to medical information. It can query drug databases, check drug interactions, and retrieve clinical guidelines. The server provides healthcare resources for AI agents to answer medical queries. It is designed for use with AI assistants that need reliable medical data.
