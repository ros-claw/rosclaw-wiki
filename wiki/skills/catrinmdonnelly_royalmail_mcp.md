This MCP server integrates with Royal Mail and Parcelforce to handle shipping tasks such as booking, labeling, tracking, and canceling shipments. It supports 33 UK and international services, accessible via friendly keys or raw Service Register codes. The server can be run via npx and is listed under the Delivery category of server implementations.
