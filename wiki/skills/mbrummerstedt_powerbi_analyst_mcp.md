Browse workspaces, tables, and measures, run DAX queries, and automatically page large results via local CSV.

This MCP server connects large language models to Microsoft Power BI semantic models, enabling AI agents to browse workspaces, tables, and measures, execute DAX queries, and automatically paginate large result sets into local CSV files. It provides a programmatic interface for LLMs to interact with Power BI data without requiring direct user interaction. The server is listed under Data Platforms and is implemented in Python. It is designed for data analysts and AI developers who want to query Power BI models through natural language or automated workflows.
