Five tools: blame context, commit story, file history, commit search, and file contributors. `npx git-context-mcp`

This MCP server provides tools to understand code history, such as tracing any line back to its commit and linked GitHub issues. It offers five specific tools: blame context, commit story, file history, commit search, and file contributors. The server helps answer why code exists by linking code lines to commits, pull request descriptions, and issues. It is designed for developers using AI agents to analyze codebases and understand the reasoning behind code changes.
