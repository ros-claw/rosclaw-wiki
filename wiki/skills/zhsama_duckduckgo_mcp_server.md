> 📇 🏠 ☁️ - This is a TypeScript-based MCP server that provides DuckDuckGo search functionality.

This project is a TypeScript-based MCP server that provides DuckDuckGo search functionality. It allows users to perform web searches through the Model Context Protocol without needing any API keys. The server is listed under search and data extraction tools for easy integration with AI agents.
