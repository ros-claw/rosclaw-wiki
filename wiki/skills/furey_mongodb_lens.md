> 📇 🏠 - MongoDB Lens: Full Featured MCP Server for MongoDB Databases

MongoDB Lens is a server implementation that uses the Model Context Protocol (MCP) to connect AI agents with MongoDB databases. It provides a full-featured interface for performing database operations such as CRUD, aggregation, and indexing. This enables AI agents to query and manipulate MongoDB data directly within their workflows.
