> 📇 ☁️ 🍎 🪟 🐧 - Multi-cloud pricing comparison across AWS, Azure, GCP, and OCI with 2,700+ instance types. Real-time pricing from public APIs, workload calculators, and migration savings estimator.

This project provides a multi-cloud pricing comparison tool across major cloud providers AWS, Azure, GCP, and OCI. It includes real-time pricing from public APIs, covering over 2,700 instance types. It also offers workload calculators and migration savings estimators. It is implemented as an MCP server under Cloud Platforms.
