This MCP server automatically generates Architecture Decision Records (ADRs) from Claude Code conversations using Claude Opus. It includes AI-powered quality review, duplicate detection, a dependency graph, and alerts for stale ADRs. The tool is designed for developer tooling and helps maintain architectural documentation.
