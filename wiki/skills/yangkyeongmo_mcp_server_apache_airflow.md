> 🐍 🏠 - MCP server that connects to [Apache Airflow](https://airflow.apache.org/) using official client.

This MCP server enables Model Context Protocol (MCP) clients to connect to Apache Airflow using the official Airflow client library. It allows AI agents to interact with Airflow workflows, such as triggering DAGs or checking task status. Built as a developer tool, it simplifies integrating Airflow into AI-driven automation pipelines. The server handles authentication and API calls, making it easy to manage workflows programmatically.
