> 🐍 💬 - An MCP server acting as an adapter into the [ACP](https://agentcommunicationprotocol.dev) ecosystem. Seamlessly exposes ACP agents to MCP clients, bridging the communication gap between the two protocols.

This project provides an MCP server that acts as an adapter between the Model Context Protocol (MCP) and the Agent Communication Protocol (ACP). It exposes ACP agents to MCP clients, enabling them to communicate seamlessly. This bridges the interoperability gap between the two protocols, allowing agents built on ACP to be used within MCP ecosystems.
