> ☁️ 🏠 - MySQL database integration in NodeJS with configurable access controls and schema inspection

This project is an MCP (Model Context Protocol) server that enables AI agents to interact with MySQL databases. It is implemented in Node.js and provides configurable access controls to restrict database operations. The server also supports schema inspection, allowing agents to discover table structures and relationships. By connecting via the MCP protocol, this tool allows language models to execute SQL queries and retrieve database information in a controlled manner.
