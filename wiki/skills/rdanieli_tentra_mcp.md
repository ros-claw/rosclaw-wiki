tentra-mcp is an AI-native architecture platform that allows engineering teams to describe systems in natural language and generate interactive typed diagrams with 167 cloud components. It can export diagrams to 14 production frameworks including Spring Boot, FastAPI, Rails, Terraform, and more. The platform includes drift detection that scores saved diagrams against live code, and quality lint rules to catch architectural issues. It also provides a persistent code-graph layer for AI coding agents, and operates on an agent-as-LLM pattern with zero LLM cost. It offers 35 MCP tools and works with Cursor, Claude Code, Codex, and Windsurf.
