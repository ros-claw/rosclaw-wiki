This is an MCP server that provides 93 tools for interacting with Spotify, including smart shuffle, natural language search for songs, vibe analysis of music, mapping artist networks, tracking taste evolution, and playlist power tools. It is designed to work with Spotify's API after the February 2026 changes. The server enables AI agents to perform advanced music curation and analysis tasks.
