> 🐍 ☁️ 🏠 🍎 🪟 🐧 - An MCP server that executes SQL via ConnectorX and streams the result to a CSV or Parquet file. Supports PostgreSQL, MariaDB, BigQuery, RedShift, MS SQL Server, etc.

This MCP server enables AI agents to execute SQL queries across multiple databases (PostgreSQL, MariaDB, BigQuery, RedShift, MS SQL Server, etc.) via the ConnectorX library. It streams query results directly to CSV or Parquet files, handling large datasets efficiently without memory overflow. The server is cross-platform (Windows, macOS, Linux). It integrates with Model Context Protocol for tool-based data retrieval workflows.
