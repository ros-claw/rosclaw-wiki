> 🏎️ ☁️ – Access structured sports data via the Cloudbet API. Query upcoming events, live odds, stake limits, and market info across soccer, basketball, tennis, esports, and more.

This MCP server provides structured sports data from Cloudbet's API. It allows users to query upcoming events, live odds, stake limits, and market information for various sports including soccer, basketball, tennis, and esports. The server is designed for integration with MCP-compatible applications to facilitate sports betting data retrieval.
