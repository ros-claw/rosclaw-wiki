> 🐍 🏠 - Universal SQLAlchemy-based database integration supporting PostgreSQL, MySQL, MariaDB, SQLite, Oracle, MS SQL Server and many more databases. Features schema and relationship inspection, and large dataset analysis capabilities.

mcp-alchemy is a universal database integration server built on SQLAlchemy, supporting a wide range of databases including PostgreSQL, MySQL, MariaDB, SQLite, Oracle, and MS SQL Server. It provides schema and relationship inspection, as well as capabilities for analyzing large datasets. This tool enables AI agents to interact with various relational databases through a unified interface.
