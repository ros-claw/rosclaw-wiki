> 🐍 ☁️ - MCP server for ZapCap API providing video caption and B-roll generation via natural language

This project implements a Model Context Protocol (MCP) server that interfaces with the ZapCap API to generate video captions and B-roll footage. Users can describe desired video content in natural language, and the server translates that into API calls for automated multimedia processing. It is built with Python and designed for cloud deployment, enabling integration into AI agent toolchains. The server simplifies video editing tasks by abstracting away direct API complexity.
