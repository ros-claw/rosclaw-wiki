Clawguard MCP is a security scanner for AI agents that use the Model Context Protocol (MCP). It detects prompt injection attacks by matching against over 42 regex patterns. The tool is listed under Security server implementations and helps protect AI agents from malicious inputs. It provides a lightweight, pattern-based defense layer for agentic systems.
