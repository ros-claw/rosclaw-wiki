> 🐍☁️ - MCP server to interact with browser-based meeting platforms (Zoom, Teams, Google Meet). Enables AI agents to send bots to online meetings, gather live transcripts, speak text, and send messages in the meeting chat.

Joinly is an MCP (Model Context Protocol) server that enables AI agents to interact with popular browser-based meeting platforms like Zoom, Microsoft Teams, and Google Meet. It allows agents to deploy bots into online meetings to collect live transcripts, speak text aloud, and send messages in the meeting chat. This tool bridges the gap between AI decision-making and real-time meeting participation, making it useful for automation, note-taking, and live assistance use cases.
