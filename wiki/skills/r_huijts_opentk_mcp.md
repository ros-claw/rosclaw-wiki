> 📇 ☁️ - Access Dutch Parliament (Tweede Kamer) information including documents, debates, activities, and legislative cases through structured search capabilities (based on opentk project by Bert Hubert)

This project is a Model Context Protocol (MCP) server that provides access to Dutch Parliamentary (Tweede Kamer) data. It enables AI agents to search and retrieve documents, debates, activities, and legislative cases from the opentk project by Bert Hubert. The server exposes structured search capabilities, allowing tools to query parliamentary information programmatically. It is listed under Search & Data Extraction in the MCP server ecosystem.
