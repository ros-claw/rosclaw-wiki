> 🎖️ 📇 ☁️ 🍎 🪟 🐧 - Coinpaprika's DexPaprika MCP server exposes high-performance [DexPaprika API](https://docs.dexpaprika.com) covering 20+ chains and 5M+ tokens with real time pricing, liquidity pool data & historical OHLCV data, providing AI agents standardized access to comprehensive market data through Model Context Protocol.

This project provides a Model Context Protocol (MCP) server that wraps the DexPaprika API, giving AI agents standardized access to decentralized exchange data. It covers over 20 blockchain chains and supports real-time pricing, liquidity pool information, and historical OHLCV data for more than 5 million tokens. Designed for the finance and fintech sector, it simplifies integration of comprehensive DeFi market data into AI-driven applications.
