> 🐍 🏠 - Telegram API integration for accessing user data, managing dialogs (chats, channels, groups), retrieving messages, sending messages and handling read status.

This project implements an MCP (Model Context Protocol) server that integrates with the Telegram API. It enables AI agents to access user data, manage chats, channels, and groups, retrieve and send messages, and handle read status. The tool serves as a bridge between Telegram's messaging platform and AI applications using the MCP standard.
