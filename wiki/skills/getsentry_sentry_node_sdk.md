Sentry for Node.js is an official SDK that provides error tracking, performance monitoring, and release health for Node.js applications. It helps developers capture exceptions, trace performance issues, and improve application reliability. The SDK integrates easily with popular Node frameworks and supports distributed tracing across microservices. It is maintained by Sentry and sponsored by Typefully under their skills initiative.
