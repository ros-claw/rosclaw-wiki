> A humble but handy utility for viewing Claude Code `.jsonl` conversation files in a pretty HTML UI.

cclogviewer is a utility designed to visually display Claude Code conversation logs stored in .jsonl format. It converts these log files into an attractive HTML interface, making it easier to read and analyze conversations. The tool is categorized under general tooling and is described as humble but handy for developers working with Claude Code. It serves as a simple yet effective way to inspect AI agent interactions without raw file parsing.
