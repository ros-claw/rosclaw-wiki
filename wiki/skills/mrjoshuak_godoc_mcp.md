> 🏎️ 🏠 - Token-efficient Go documentation server that provides AI assistants with smart access to package docs and types without reading entire source files

godoc-mcp is a token-efficient Go documentation server designed for AI assistants. It provides smart access to package documentation and types without requiring AI models to read entire source files, reducing token usage. The server implements the Model Context Protocol (MCP) to integrate with AI tools and IDEs. It is useful for developers who want to query Go package information programmatically.
