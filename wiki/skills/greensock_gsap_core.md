GSAP (GreenSock Animation Platform) is a high-performance JavaScript library for creating animations on the web. It enables animating CSS properties, SVG, canvas, and more with smooth, cross-browser performance. The library works standalone or with jQuery, and is widely used for interactive web experiences. GSAP Core specifically refers to the lightweight base module of the GSAP ecosystem.
