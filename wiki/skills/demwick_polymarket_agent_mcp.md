This project provides an MCP server that exposes 49 tools for AI agents to interact with Polymarket prediction markets. It includes direct trading, smart money flow detection, copy trading with auto-monitoring, backtesting, arbitrage scanning, portfolio optimization, and real-time WebSocket price streaming. Users can operate in preview mode for simulation or live mode for real orders. It's designed to integrate AI agents with decentralized prediction markets for automated trading strategies.
