> 📇 ☁️ 🏠 - Streaming KoliBri MCP server (NPM: `@public-ui/mcp`) delivering 200+ guaranteed accessible web component samples, specs, docs, and scenarios via hosted HTTP endpoint or local `kolibri-mcp` CLI.

This is an MCP server for the KoliBri UI library that delivers over 200 guaranteed accessible web component samples, specifications, documentation, and scenarios. It can be used as a hosted HTTP endpoint or run locally via the `kolibri-mcp` CLI tool. The server streamlines development of accessible interfaces by providing ready-to-use, standards-compliant components. The NPM package is `@public-ui/mcp`.
