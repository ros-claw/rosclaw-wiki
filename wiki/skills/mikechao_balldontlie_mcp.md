> 📇 - MCP server that integrates balldontlie api to provide information about players, teams and games for the NBA, NFL and MLB

This is an MCP server that connects to the balldontlie API to provide information about players, teams, and games for major US sports leagues: NBA, NFL, and MLB. It allows AI agents to query real-time sports data through the Model Context Protocol, making it useful for sports-related queries and applications.
