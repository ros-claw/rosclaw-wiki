> 🏎️ ☁️ - OpenAPI-MCP: Dockerized MCP Server to allow your AI agent to access any API with existing api docs.

This project provides a Dockerized MCP (Model Context Protocol) server that allows AI agents to dynamically access and interact with any external API using existing OpenAPI documentation. It automatically converts API specifications into tool definitions that agents can call, enabling real-time execution of API requests without manual integration. The server runs in an isolated Docker container for security and ease of deployment.
