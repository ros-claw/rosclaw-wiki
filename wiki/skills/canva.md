> Create, export, and manage Canva designs via the Connect API.

This project is a client for Canva's Connect API, enabling users to create, export, and manage Canva designs programmatically. It simplifies interactions with the Canva platform for automating design workflows. Developers can integrate Canva functionality into their applications to generate and manipulate designs. The tool handles authentication and API calls, making it easier to build solutions that require on-demand design creation or bulk export operations.
