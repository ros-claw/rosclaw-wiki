This project provides an AI-powered HR management toolkit that parses resumes from PDFs, DOCX, TXT, Markdown, and URLs into structured JSON. It extracts skills, experience, and keywords, scores and ranks candidates, and runs a full Applicant Tracking System (ATS) pipeline including jobs, candidates, interviews, offers, notes, and analytics. The toolkit includes 21 MCP tools, 20 of which are fully algorithmic and require no API keys. It is designed as an MCP server for integration into AI workflows.
