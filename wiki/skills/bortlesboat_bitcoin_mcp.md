This is a Model Context Protocol (MCP) server for Bitcoin Core. It provides 43 tools for interacting with a Bitcoin node, including fee estimation with USD conversion and send-now-or-wait advice, mempool analysis, mining pool rankings, market sentiment, block/transaction inspection, and BTC price. It can be self-hosted on your local node or used via the Satoshi API with no installation required.
