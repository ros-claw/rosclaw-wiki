HCOM is a lightweight CLI tool designed for real-time communication between Claude Code sub-agents. It leverages hooks to enable multi-agent collaboration, featuring @-mention targeting and a live dashboard for monitoring. The tool has zero dependencies, making it simple to integrate into existing workflows. Note: As of the time of posting, the tool is slightly unstable but shows great promise for production readiness.
