Powered by [OPDSTAR](https://opdstar.com). Install: `npx @opdstar/nhi-mcp`.

This MCP server provides access to Taiwan's National Health Insurance (NHI) data, including 234 rejection codes, 1,497 ICD-10-to-procedure mappings across 20 specialties, and audit indicators (008/014/027/P043). It also enables semantic wiki search over 8,232 chunks of official NHI documentation. Built on the OPDSTAR platform, it is the first public MCP server for NHI data. It is installable via npx and designed to assist with medical coding and insurance-related queries.
