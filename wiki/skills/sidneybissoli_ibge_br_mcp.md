> 📇 ☁️ - Brazilian Census Bureau (IBGE) data server with 23 tools for demographics, geography, economics, and statistics. Covers localities, SIDRA tables, Census data, population projections, and geographic meshes.

This is an MCP server that provides access to various datasets from the Brazilian Institute of Geography and Statistics (IBGE). It includes 23 tools for querying demographic, geographic, economic, and statistical information from the IBGE. The server covers data on localities, SIDRA tables, Census data, population projections, and geographic meshes. It enables users to interact with IBGE data through a standardized interface.
