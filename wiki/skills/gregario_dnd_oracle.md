> [![dnd-oracle MCP server](https://glama.ai/mcp/servers/gregario/dnd-oracle/badges/score.svg)](https://glama.ai/mcp/servers/gregario/dnd-oracle) 📇 🏠 - D&D 5e SRD reference and analysis with monster search, spell lookup, encounter building, and loadout analysis. 10 tools, 1198 entities embedded.

dnd-oracle is an MCP server that provides a comprehensive reference and analysis tool for D&D 5th Edition's System Reference Document (SRD). It includes 10 tools and 1198 embedded entities for searching monsters, looking up spells, building encounters, and analyzing loadouts. Designed for game masters and players, it integrates with AI assistants via the Model Context Protocol to offer on-demand game data and insights.
