Smartest TV is an MCP server that lets you control any smart TV using natural language commands. You can play Netflix, YouTube, and Spotify with deep linking, cast URLs, and use scene presets. It supports multi-room audio and multi-TV sync, working with LG, Samsung, Android TV, and Roku. The server provides 21 MCP tools and requires no cloud connection.
