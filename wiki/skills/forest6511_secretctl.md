> 🏎️ 🏠 🍎 🪟 🐧 - AI-safe secrets manager with MCP integration. Run commands with credentials injected as environment variables - AI agents never see plaintext secrets. Features output sanitization, AES-256-GCM encryption, and Argon2id key derivation.

secretctl is a secrets manager designed for AI agents, enabling secure execution of commands with credentials injected as environment variables without exposing plaintext secrets to the agent. It integrates with the Model Context Protocol (MCP) and features AES-256-GCM encryption with Argon2id key derivation for robust security. Output sanitization ensures that sensitive data is redacted from agent responses, making it suitable for AI-driven automation in security-conscious environments.
