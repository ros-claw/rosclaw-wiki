> 📇 🏠 🍎 🪟 🐧 - Exposes a large catalog of coding assistant prompts as MCP tools with model-aware suggestions and persona activation to emulate agents like Cursor or Devin.

This MCP server provides a large catalog of system prompts for coding assistants, accessible as MCP tools. It includes model-aware suggestions to match prompts with appropriate AI models. The server supports persona activation, allowing users to emulate specialized coding agents like Cursor or Devin. It aims to streamline interactions with AI coding assistants by offering pre-defined prompt templates. The project runs on multiple platforms including macOS, Windows, and Linux.
