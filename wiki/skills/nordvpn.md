> Control NordVPN on Linux via the `nordvpn` CLI.

This project provides a command-line interface to control NordVPN on Linux systems. It allows users to connect, disconnect, and manage VPN settings directly from the terminal. The tool wraps the official NordVPN CLI for easier automation and scripting. It is useful for users who prefer terminal-based VPN management over GUI alternatives.
