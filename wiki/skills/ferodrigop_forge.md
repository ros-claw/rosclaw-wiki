> [![forge MCP server](https://glama.ai/mcp/servers/ferodrigop/forge/badges/score.svg)](https://glama.ai/mcp/servers/ferodrigop/forge) 📇 🏠 - Terminal MCP server for AI coding agents with persistent PTY sessions, ring-buffer incremental reads, headless xterm screen capture, multi-agent orchestration, and a real-time web dashboard.

Forge is a Model Context Protocol (MCP) server that provides terminal capabilities to AI coding agents. It supports persistent PTY sessions with incremental ring-buffer reads, allowing agents to interact with long-running terminal processes efficiently. The server includes headless xterm screen capture for visual context and a real-time web dashboard for monitoring. Additionally, Forge enables multi-agent orchestration, letting multiple AI agents share or coordinate terminal sessions.
