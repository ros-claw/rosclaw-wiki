> 📇 ☁️ - upload and manipulation of IPFS storage

This MCP server enables AI agents to upload and manipulate files on IPFS (InterPlanetary File System), a decentralized, peer-to-peer hypermedia protocol. It provides an interface for storing and retrieving content-addressed data, allowing seamless integration with cloud platform workflows. Users can add, list, and manage IPFS objects through MCP tools.
