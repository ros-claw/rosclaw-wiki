> A lightweight open format for repo-local instructions that tell agents how to work inside a codebase.

AGENTS.md is a lightweight open format for repository-local instructions that guide AI agents in working within a codebase. It is designed to be a spec and workflow definition file that tells agents how to operate effectively. The format is meant to be simple and stored directly in the repo, enabling consistent agent behavior across development tasks.
