> Wrap MCP servers with a WebSocket (for use with [kitbitz](https://github.com/nick1udwig/kibitz))

ws-mcp is a utility that wraps MCP (Model Context Protocol) servers to expose them over a WebSocket interface. It is designed for use with Kibitz, enabling seamless integration between MCP-based tools and WebSocket clients. This wrapper simplifies connecting MCP servers to web applications or other systems that communicate via WebSockets.
