This MCP server provides read-only access to the Agentic AI Blueprint, which is the industry standard reference for safe, observable, and steerable AI agent UX. It allows browsing and searching of 10 core principles, curated implementation examples, and application guides for production agentic AI systems. The server includes 13 public tools that require no credentials, making it easy for developers to integrate the blueprint's knowledge into their AI tooling. It is designed to support the creation of responsible and well-designed AI agents.
