No API key required.

This is a Model Context Protocol (MCP) server for real-time public transport information in Lviv, Ukraine. It provides stop arrivals, live vehicle positions, route geometry, and nearby stop discovery without requiring an API key. The server is implemented in Node.js and listed under Travel & Transportation in the MCP server ecosystem.
