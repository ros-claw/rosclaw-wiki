> Model-driven arXiv retrieval workflow for building a paper set with a manual language parameter: initialize a run.

This project provides a model-driven workflow for retrieving papers from arXiv to build a paper set. It uses a manual language parameter to control the retrieval process, allowing users to initialize a new run. The tool is designed to streamline the creation of research paper collections based on specific criteria.
