> A secure shell command execution server implementing the Model Context Protocol (MCP)

This project is an MCP server that enables secure execution of shell commands by AI agents. It provides controlled command execution with safety constraints, suitable for coding agent workflows. The server implements the Model Context Protocol to allow agents to run shell operations in a sandboxed environment.
