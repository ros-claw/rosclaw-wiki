nullpath-labs/mcp-client is a server implementation under Finance & Fintech that provides an AI agent marketplace using the Model Context Protocol (MCP). It supports x402 micropayments, allowing users to discover, execute, and pay for AI agents per request with USDC on the Base blockchain. This enables a pay-per-use model for AI agent interactions via MCP.
