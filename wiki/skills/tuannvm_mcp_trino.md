> 🏎️ ☁️ - A Go implementation of a Model Context Protocol (MCP) server for Trino

This project is a Go implementation of a Model Context Protocol (MCP) server that connects to Trino, a distributed SQL query engine. It exposes MCP tools and resources for AI agents to query databases via Trino, handling query execution, caching, and error management. The server enables seamless integration of large language models with Trino-based data sources for natural language database interactions. It provides a bridge between AI agents and Trino's federated query capabilities.
