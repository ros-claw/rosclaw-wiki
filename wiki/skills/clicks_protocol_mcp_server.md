Non-custodial, no lockup, MIT licensed. `npx @clicks-protocol/mcp-server`

This MCP server enables AI agents on the Base blockchain to earn autonomous yield on USDC deposits. It provides nine tools for registering agents, splitting payments 80/20 between liquid and yield portions, withdrawing funds at any time, simulating splits, checking APY, and tracking on-chain referrals. The system is non-custodial with no lockup period and is licensed under MIT. It is listed under the Finance & Fintech category of server implementations.
