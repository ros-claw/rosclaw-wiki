> A project-based course repository on making Codex and Claude Code more reliable, centered on an Electron personal knowledge base app with lecture handouts, example artifacts, and practical harness projects.

This course repo teaches techniques to make AI coding tools like Codex and Claude Code more reliable through structured projects. Learners build an Electron-based personal knowledge base app while studying lecture handouts and example artifacts. The curriculum emphasizes practical harness projects to validate and improve AI-generated code. It's designed for developers seeking to reduce errors when using large language models for software development.
