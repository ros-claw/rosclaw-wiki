This project provides a GitHub Action to set cookies in a browser context, useful for authentication and session management in automated tests. It is written in TypeScript and integrates seamlessly with GitHub Actions workflows. The action simplifies injecting cookies before running browser-based tests, helping developers simulate authenticated sessions without manual intervention.
