> [![giskard09/giskard-search MCP server](https://glama.ai/mcp/servers/giskard09/giskard-search/badges/score.svg)](https://glama.ai/mcp/servers/giskard09/giskard-search) 🐍 🏠 - Pay-per-use semantic web search for AI agents. Powered by SearxNG, agents pay in sats via Lightning Network micropayments — no API keys required. Self-hosted with phoenixd.

This is an MCP server that provides semantic web search for AI agents, powered by the SearxNG metasearch engine. It uses a pay-per-use model where agents pay in satoshis via Lightning Network micropayments, eliminating the need for API keys. The server is self-hosted using phoenixd, allowing full control and privacy. Designed for integration with AI agent workflows, it offers a decentralized and cost-efficient search solution.
