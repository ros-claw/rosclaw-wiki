Agentward is an MCP proxy that enforces least-privilege YAML policies on every tool call to control AI agent permissions. It classifies sensitive data like PII/PHI, detects dangerous chains of skill calls, and generates compliance audit trails. The project supports both stdio and HTTP proxy modes, acting as a security control plane for AI agents. It is listed under Server Implementations in the Security category.
