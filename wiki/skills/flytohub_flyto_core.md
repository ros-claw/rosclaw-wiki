Flyto Core is a deterministic execution engine designed for AI agents, offering 412 modules across 78 categories including browser, file, Docker, data, crypto, and scheduling. It ensures reproducible agent actions through execution traces, evidence snapshots, and the ability to replay from any step. The engine supports both STDIO and Streamable HTTP transport for flexible integration. It is listed as a developer tool under MCP server implementations.
