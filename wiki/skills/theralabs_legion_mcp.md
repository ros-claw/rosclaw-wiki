> 🐍 🏠 Universal database MCP server supporting multiple database types including PostgreSQL, Redshift, CockroachDB, MySQL, RDS MySQL, Microsoft SQL Server, BigQuery, Oracle DB, and SQLite.

Legion-MCP is a universal database MCP server that supports a wide range of relational databases, including PostgreSQL, MySQL, SQL Server, BigQuery, and SQLite. It allows AI agents to query, manage, and interact with databases through the Model Context Protocol. This tool simplifies database access for AI workflows by providing a unified interface across different database engines.
