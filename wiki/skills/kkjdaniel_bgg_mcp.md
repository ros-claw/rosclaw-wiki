> 🏎️ ☁️ - An MCP server that enables interaction with board game related data via the BoardGameGeek API (XML API2).

This project is an MCP (Model Context Protocol) server that connects to the BoardGameGeek API to provide board game data. It allows AI agents to query information about board games, such as details, ratings, and descriptions. The server uses the XML API2 from BoardGameGeek to fetch data and expose it through MCP tools. This enables integration of board game data into AI workflows and applications.
