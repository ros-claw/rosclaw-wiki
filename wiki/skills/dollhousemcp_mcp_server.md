Dynamic permissioning for safe AI operations, a robust validation architecture, versioning, and a public collection of shareable content. Install: `npx @dollhousemcp/mcp-server@latest --web`.

This MCP server provides a collection of reusable customization tools—including personas, skills, templates, agents, memory, and ensembles—that can be added to any MCP client application. It features dynamic permissioning for safe AI operations, a robust validation architecture, versioning support, and a public collection of shareable content. The server is designed to enhance knowledge and memory capabilities within the MCP ecosystem.
