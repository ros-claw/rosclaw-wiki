> 📇 ☁️ - MCP server for Naver Search API integration, supporting blog, news, shopping search and DataLab analytics features.

This project is an MCP server that integrates Naver Search API, allowing AI agents to search blogs, news, and shopping, as well as access DataLab analytics for trend data. It uses the Model Context Protocol to enable structured querying of Naver's search services. The server is designed to bring Korean web search capabilities into AI agent workflows.
