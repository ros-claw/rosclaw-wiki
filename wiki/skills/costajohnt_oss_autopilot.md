Available as CLI, MCP server, and Claude Code plugin.

This tool helps manage open source contributions by tracking pull requests across multiple repositories, discovering issues, diagnosing CI failures, and drafting maintainer responses. It can be used as a command-line interface, an MCP server, or a Claude Code plugin. It's designed to streamline the workflow for maintainers of open source projects.
