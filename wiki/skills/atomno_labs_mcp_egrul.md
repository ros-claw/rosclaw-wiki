Self-hosted via local SQLite, no API key required.

This MCP server provides access to Russian state registries EGRUL (legal entities) and EGRIP (individual entrepreneurs) using official open-data dumps from the Federal Tax Service. It is self-hosted via local SQLite, requiring no API key. The tool is designed for finance and fintech applications needing reliable, offline-capable registry data.
