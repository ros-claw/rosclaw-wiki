> [![AgiMaulana/HuaweiAppGalleryMcp MCP server](https://glama.ai/mcp/servers/AgiMaulana/HuaweiAppGalleryMcp/badges/score.svg)](https://glama.ai/mcp/servers/AgiMaulana/HuaweiAppGalleryMcp) 🐍 ☁️ 🍎 🪟 🐧 - Huawei AppGallery Connect publishing: upload APK/AAB, update metadata and localizations, submit for review, and manage phased rollouts.

This MCP server integrates with Huawei AppGallery Connect to automate app publishing tasks. It allows developers to upload APK and AAB files, update app metadata and localizations, submit apps for review, and manage phased rollouts. The project is primarily a developer tool that streamlines the deployment workflow for Android apps on Huawei's app store. It is implemented in Python and supports multiple operating systems including macOS, Windows, and Linux.
