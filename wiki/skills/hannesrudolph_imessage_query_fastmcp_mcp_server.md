> 🐍 🏠 🍎 - An MCP server that provides safe access to your iMessage database through Model Context Protocol (MCP), enabling LLMs to query and analyze iMessage conversations with proper phone number validation and attachment handling

This project implements an MCP server that allows LLMs to safely access and query the local iMessage database. It uses the Model Context Protocol to provide structured tools for reading conversations, with built-in phone number validation and attachment handling. The server enables AI agents to analyze iMessage data without exposing sensitive information, ensuring controlled access. It is designed for local execution on macOS and requires appropriate permissions.
