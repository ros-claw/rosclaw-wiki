> ☁️ 📇 🍎 🪟 🐧 - A list of MCP servers so you can ask your client which servers you can use to improve your daily workflow.

This project provides an aggregated list of MCP servers, enabling users to discover and query which servers are available for their workflow. It functions as a registry of MCP servers across multiple platforms including cloud, note-taking, macOS, Windows, and Linux. The goal is to streamline the process of finding and integrating relevant MCP servers into daily workflows.
