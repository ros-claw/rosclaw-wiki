> 📇 ☁️ - An MCP server that enables cross-chain token transfers via the Stargate protocol.

A Model Context Protocol (MCP) server that integrates the Stargate cross-chain bridge protocol, enabling AI agents to perform token transfers across different blockchains. It provides tools for initiating bridge transactions, estimating fees, and checking transfer status. This server simplifies cross-chain DeFi interactions by abstracting the complexity of the Stargate protocol into accessible MCP commands.
