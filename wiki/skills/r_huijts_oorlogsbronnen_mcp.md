> 📇 ☁️ - Oorlogsbronnen (War Sources) API integration for accessing historical WWII records, photographs, and documents from the Netherlands (1940-1945)

This MCP server integrates the Oorlogsbronnen (War Sources) API, enabling AI assistants to access Dutch World War II records, photographs, and documents from 1940-1945. It provides a structured interface for querying historical data, such as personal stories, locations, and archival materials. The server is categorized under Art and Culture, reflecting its focus on preserving and providing access to cultural heritage. Researchers, historians, and AI applications can leverage this tool to retrieve and analyze WWII information from the Netherlands.
