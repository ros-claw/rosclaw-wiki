> 🐍 🏠 ☁️ - Model Context Protocol server for Fast Healthcare Interoperability Resources (FHIR) APIs. Provides seamless integration with FHIR servers, enabling AI assistants to search, retrieve, create, update, and analyze clinical healthcare data with SMART-on-FHIR authentication support.

The wso2/fhir-mcp-server is a Model Context Protocol (MCP) server designed for Fast Healthcare Interoperability Resources (FHIR) APIs. It enables AI assistants to perform operations such as searching, retrieving, creating, updating, and analyzing clinical healthcare data. The server supports SMART-on-FHIR authentication for secure access to healthcare systems. This tool bridges AI agents with standardized healthcare data, facilitating integration in medical and bioinformatics applications.
