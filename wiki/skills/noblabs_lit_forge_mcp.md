Companion to https://lit-forge.com/nisa-simulator. npm: `lit-forge-mcp`. MIT, no telemetry.

This MCP server provides tools for personal asset planning tailored to Japan's tax-advantaged investment accounts (つみたて NISA and iDeCo). It offers four zero-authentication tools: a NISA simulator with monthly compounding, a retirement gap analysis with Japanese pension defaults, a back-calculator to determine required monthly savings, and a general compound interest tool. Designed as a companion to the lit-forge.com web simulator, it is distributed as an npm package with an MIT license and no telemetry.
