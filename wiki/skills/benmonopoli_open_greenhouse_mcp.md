Open Greenhouse MCP is a production-ready server that integrates Greenhouse's Applicant Tracking System (ATS) with the Model Context Protocol (MCP). It offers 175 tools for recruiting teams, including role-based profiles for full access, recruiter, and read-only users. The server provides composite workflow tools for pipeline views, analytics, candidate search, and bulk operations, aiming to streamline recruitment processes.
