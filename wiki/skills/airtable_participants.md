> Read and query retreat participant data from the Ceremonia Airtable base.

Airtable-participants is a tool that reads and queries participant data specifically for the Ceremonia retreat from an Airtable base. It provides a way to access and filter retreat participant information programmatically. This project simplifies data retrieval for event organizers or developers working with Ceremonia's participant records.
