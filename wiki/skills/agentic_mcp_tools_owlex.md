> 🐍 🏠 🍎 🪟 🐧 - AI council server: query CLI agents (Claude Code, Codex, Gemini, and OpenCode) in parallel with deliberation rounds

Owlex is an MCP server that orchestrates an AI council by querying multiple CLI-based coding agents in parallel. It supports agents such as Claude Code, Codex, Gemini, and OpenCode, and employs rounds of deliberation to synthesize their responses. This allows users to leverage diverse AI perspectives for coding and development tasks within a single workflow.
