Detects 9 categories of threats in AI-generated code (invisible Unicode, Trojan Source, homoglyphs, Glassworm steganography, rules file backdoors, dependency typosquatting, obfuscation) using static analysis plus CodeBERT deep learning. Runs locally, free tier.

The Cleaner Code project is an MCP server designed to scan AI-generated code for security threats. It detects nine categories of vulnerabilities, including invisible Unicode characters, Trojan Source attacks, homoglyph substitutions, Glassworm steganography, rules file backdoors, dependency typosquatting, and obfuscation techniques. The scanner uses a combination of static analysis and a CodeBERT deep learning model to identify these issues, all running locally on the user's machine. It offers a free tier for community use.
