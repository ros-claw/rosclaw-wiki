Handles all three embed types: Tencent Video (yt-dlp keyframes), WeChat-native (mp4 keyframes), Channels/视频号 (metadata + cover via public API).

This MCP server allows AI agents to read WeChat Official Account articles, extracting body text, images, and video keyframes as multimodal content blocks. It handles three types of video embeds: Tencent Video (using yt-dlp), WeChat-native MP4, and Channels/视频号 (via public API for metadata and cover). The tool is listed under Social Media server implementations and runs Python across multiple platforms. It enables seamless integration of WeChat content into AI agent workflows.
