> Amazing comprehensive set of comments for code analysis, QA, design, documentation, project structure, project management, optimization, and many more.

This project provides a comprehensive set of comment templates designed for code analysis, quality assurance, design, documentation, project structure, management, and optimization. It is intended for use within n8n workflow automation agents to guide AI models in various tasks. The collection serves as a knowledge base of structured prompts to enhance agent performance in software development contexts.
