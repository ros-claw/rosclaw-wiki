Grovs MCP server provides 16 tools for mobile app marketing including deep linking, attribution, analytics, and campaign management. It is an open-source, privacy-first alternative to commercial services like Branch and AppsFlyer. The server integrates with the Model Context Protocol to enable AI agents to manage mobile app marketing tasks.
