> 🐍 ☁️ - MCP server that provides AI assistants with access to the Smithsonian Institution's Open Access collections.

This project provides an MCP (Model Context Protocol) server that grants AI assistants access to the Smithsonian Institution's Open Access collections. It allows AI tools to query and retrieve data from the Smithsonian's vast repository of artworks, artifacts, and cultural objects. The server is designed for integration with AI assistants, enabling them to fetch information about art and culture in real time.
