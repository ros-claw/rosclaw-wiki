Checks security posture of third-party MCP servers and tools with signed attestations (Ed25519/JWS) before interaction.

AgentGraph is a tool for trust verification and security scanning of AI agents. It checks the security posture of third-party MCP servers and tools before they interact with agents. The system uses signed attestations, specifically Ed25519 keys and JSON Web Signatures (JWS), to ensure the authenticity and integrity of the servers. This helps protect AI agents from potentially malicious or insecure servers.
