> 🐍 ☁️ - Analyzing order book depth and imbalance across major crypto exchanges.

This MCP server provides tools for analyzing order book depth and imbalance across major cryptocurrency exchanges. It allows AI assistants to fetch real-time market data from exchanges like Binance and Coinbase. The server can compute metrics such as bid-ask spread, depth ratio, and order flow imbalance. It helps traders and analysts make informed decisions based on market liquidity and supply-demand dynamics. The project is listed under Finance and Fintech server implementations.
