> 📇 ☁️ - An MCP server that prevents cascading errors and scope creep by calling a "Vibe-check" agent to ensure user alignment.

This MCP server acts as a safeguard by calling a 'vibe-check' agent before each operation to confirm the user's intent. It prevents cascading errors and scope creep by ensuring alignment between the user's request and the system's actions. The server integrates with the Model Context Protocol (MCP) to provide this validation as a tool for other AI agents.
