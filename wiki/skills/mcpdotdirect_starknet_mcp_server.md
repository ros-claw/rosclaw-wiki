This server provides comprehensive integration with the Starknet blockchain, supporting native tokens like ETH and STRK. It enables smart contract interactions, StarknetID resolution, and token transfers. Categorized under Finance & Fintech, it allows AI agents to perform blockchain operations for financial applications.
