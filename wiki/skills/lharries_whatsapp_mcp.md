> 🐍 🏎️ - An MCP server for searching your personal WhatsApp messages, contacts and sending messages to individuals or groups

This project is a Model Context Protocol (MCP) server that allows AI agents to search personal WhatsApp messages and contacts, and send messages to individuals or groups. It provides a standardized interface for AI tools to interact with WhatsApp data. This enables workflows like retrieving past conversations or automating message sending. The server is designed for easy integration with MCP-compatible clients.
