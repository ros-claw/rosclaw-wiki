Cryptopolitan MCP is a server that provides AI agents with real-time cryptocurrency news, analysis, and price predictions. It offers five tools to search over 50,000 articles across 12 categories, with filtering by over 120 coin tickers. Content includes built-in attribution and is free to use with attribution. Transport methods include SSE and Streamable HTTP.
