MiSTerClaw is an MCP server that provides remote control for MiSTer-FPGA hardware. It allows users to launch games, search ROMs, take screenshots, and manage systems via natural language commands. The server auto-discovers 70+ systems with dynamic core and ROM scanning. It also integrates Tailscale VPN for secure remote access.
