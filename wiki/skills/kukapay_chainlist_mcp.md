> 📇 ☁️ -  An MCP server that gives AI agents fast access to verified EVM chain information, including RPC URLs, chain IDs, explorers, and native tokens.

This MCP server allows AI agents to quickly retrieve verified EVM chain data such as RPC URLs, chain IDs, block explorers, and native token details. It integrates with the Model Context Protocol to provide structured, real-time blockchain information to AI assistants. Designed for finance and fintech use cases, it simplifies access to multi-chain Ethereum-compatible networks.
