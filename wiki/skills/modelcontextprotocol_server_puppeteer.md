> 📇 🏠 - Browser automation for web scraping and interaction

This MCP server provides browser automation capabilities using Puppeteer, enabling web scraping, interaction with web pages, and screenshot capture. It integrates with the Model Context Protocol to allow AI agents to control a headless browser. The server exposes tools for navigation, clicking, form filling, and extracting page content. It simplifies adding web browsing abilities to AI applications that follow the MCP standard.
