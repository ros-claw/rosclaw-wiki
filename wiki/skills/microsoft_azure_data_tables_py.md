Azure Data Tables client library for Python enables interaction with Azure Table storage, a NoSQL key-value store. It supports creating, querying, updating, and deleting tables and entities. This SDK is part of the Azure SDK for Python, providing seamless integration with other Azure services. Ideal for storing structured data without requiring complex schemas.
