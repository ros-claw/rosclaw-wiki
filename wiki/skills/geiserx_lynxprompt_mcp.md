Create, search, and organize AI prompts and AGENTS.md/CLAUDE.md configuration files. Docker image available.

This project implements a Go-based Model Context Protocol (MCP) server for managing prompts and configuration files in LynxPrompt. Users can create, search, and organize AI prompts as well as AGENTS.md and CLAUDE.md files. A Docker image is available for easy deployment. The server is listed under Developer Tools in the MCP server ecosystem.
