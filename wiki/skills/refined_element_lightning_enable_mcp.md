Pay invoices, create invoices, check balances, and access L402 paywalled APIs. Supports Strike, OpenNode, NWC wallets.

This MCP server integrates Bitcoin Lightning payments into AI agents, enabling them to handle Lightning invoices and access L402 paywalled APIs. It supports multiple wallet providers like Strike, OpenNode, and NWC, allowing agents to pay invoices, generate invoices, and check balances. The project is designed for finance and fintech applications, bridging AI agents with the Lightning Network for fast, low-cost Bitcoin transactions.
