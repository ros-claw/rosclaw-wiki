This Rust library provides a client for interacting with Azure Blob Storage, a cloud object storage service. It is part of the Azure SDK for Rust ecosystem, allowing developers to manage containers and blobs programmatically. The library supports common operations such as uploading, downloading, listing, and deleting blobs. It leverages the Rust language's safety and concurrency features for efficient cloud storage management.
