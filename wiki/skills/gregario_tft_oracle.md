> [![tft-oracle MCP server](https://glama.ai/mcp/servers/gregario/tft-oracle/badges/score.svg)](https://glama.ai/mcp/servers/gregario/tft-oracle) 📇 🏠 - Teamfight Tactics champion, trait, item, and augment reference. 8 tools with full Set 16 data from CommunityDragon, including synergy lookups, item recipes, and rolling odds.

The TFT Oracle MCP server provides a comprehensive reference for Teamfight Tactics (TFT) game data, covering champions, traits, items, and augments from Set 16. It offers 8 tools for querying synergy lookups, item recipes, and rolling odds, using data sourced from CommunityDragon. This server enables AI agents to access detailed TFT information through the Model Context Protocol.
