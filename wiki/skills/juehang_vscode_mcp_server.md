> 📇 🏠 - A MCP Server that allows AI such as Claude to read from the directory structure in a VS Code workspace, see problems picked up by linter(s) and the language server, read code files, and make edits.

This project provides a Model Context Protocol (MCP) server that integrates with VS Code workspaces. It allows AI assistants like Claude to observe the directory structure, access code files, review linter and language server problems, and make code edits. It is categorized under coding agents in the MCP server implementations list, enabling AI-powered code analysis and modification within the VS Code environment.
