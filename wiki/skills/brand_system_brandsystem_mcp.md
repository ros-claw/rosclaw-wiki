This MCP server extracts brand identity elements like colors, fonts, logos, voice, and visual rules from any website by analyzing static CSS and rendered page content. It compiles the extracted data into Design Tokens Community Group (DTCG) tokens, brand runtime contracts, and interaction policies, offering 34 tools organized across four progressive sessions. The server provides subscribable MCP resources (brand://runtime and brand://policy) and includes content compliance scoring (0-100), pass/fail gates, and HTML/CSS preflight checks. It also connects to Brandcode Studio for hosted brand synchronization, making brand information machine-readable and actionable.
