This project provides a comprehensive AI marketing toolkit implemented as an MCP server with 41 tools. It enables trend scouting on X/Reddit, competitor analysis, content gap identification, and SEO article generation in 55 languages with AI illustrations and voice-overs. It also supports creating social media adaptations for 9 platforms, AI avatar videos with subtitles, and ingesting content from URLs (YouTube, PDF, audio). Additionally, it can generate lead magnets and run content autopilot workflows, making it a full-stack solution for automated marketing.
