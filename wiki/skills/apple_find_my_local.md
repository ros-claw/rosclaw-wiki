> Control Apple Find My app via Peekaboo to locate people, devices, and items (AirTags)

This tool integrates with Apple's Find My network using the Peekaboo library to locate people, devices, and items like AirTags. It provides a local interface to control Find My features programmatically. Users can automate location queries or integrate into larger systems for tracking and notifications. The project simplifies access to Find My data without needing reverse-engineering efforts.
