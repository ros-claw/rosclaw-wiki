Apollo Router is a high-performance GraphQL gateway written in Rust that serves as the central entry point for federated GraphQL architectures. It routes queries to multiple underlying GraphQL services, handles request planning and execution, and provides built-in observability, caching, and security features. Designed for production use, it offers low latency and high throughput while supporting the Apollo Federation specification.
