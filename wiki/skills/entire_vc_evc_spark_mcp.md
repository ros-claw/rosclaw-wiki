This project provides an MCP server that acts as an aggregator for discovering AI agents, skills, prompts, bundles, and MCP connectors. It offers a curated catalog containing over 4,500 assets, enabling users to search and find relevant AI resources. It is designed to be integrated with clients that support the Model Context Protocol (MCP).
