> 📇 🏠 - Knowledge graph-based persistent memory system for maintaining context

This is a server implementation for the Model Context Protocol that provides persistent memory using a knowledge graph. It allows AI agents to store and retrieve contextual information. The system maintains long-term memory across sessions, enabling more coherent interactions. It is designed to integrate with MCP-compatible hosts.
