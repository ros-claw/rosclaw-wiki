> 🏎️ ☁️/🏠 - MCP Server for kubernetes management, and analyze your cluster, application health

This MCP server provides Kubernetes cluster management and health analysis capabilities. It allows users to interact with their Kubernetes clusters through the Model Context Protocol, enabling tasks such as inspecting resources, analyzing application health, and managing deployments. The tool supports both cloud and local (home) clusters, making it versatile for various environments. It is designed to integrate with MCP-compatible AI assistants to simplify Kubernetes operations.
