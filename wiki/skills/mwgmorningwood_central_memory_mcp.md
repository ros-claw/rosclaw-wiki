> 📇 ☁️ - An Azure PaaS-hostable MCP server that provides a workspace-grounded knowledge graph for multiple developers using Azure Functions MCP triggers and Table storage.

This project is an MCP (Model Context Protocol) server designed for collaborative development environments. It creates a knowledge graph that is grounded in a specific workspace, allowing multiple developers to share and access structured information. The server is built to be deployed on Azure PaaS, leveraging Azure Functions for MCP triggers and Azure Table storage for persistence.
