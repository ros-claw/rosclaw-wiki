> Text-to-speech using macOS built-in `say` command.

mac-tts is a lightweight tool that provides text-to-speech functionality on macOS by wrapping the built-in `say` command. It allows users to convert text into spoken audio directly from the command line or within scripts. The tool supports various system voices and languages, making it useful for accessibility, automation, and prototyping. It offers a simple interface for generating speech output without requiring external dependencies or APIs.
