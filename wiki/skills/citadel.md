> A harness for Claude Code and OpenAI Codex with isolated worktrees, multi-agent coordination, and persisted memory and campaign state.

Citadel is a runtime and harness designed for use with AI coding agents like Claude Code and OpenAI Codex. It provides isolated worktrees to keep agent actions contained and safe. Citadel enables multi-agent coordination, allowing multiple AI agents to work together on a project. It also features persisted memory and campaign state, allowing agents to maintain context over long-term tasks. This makes Citadel a robust infrastructure for running AI code generation agents in a controlled, scalable environment.
