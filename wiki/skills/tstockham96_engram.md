This project, engram, is an MCP server for intelligent agent memory. It uses semantic recall, automatic consolidation, contradiction detection, and a bi-temporal knowledge graph. It achieves 80% on the LOCOMO benchmark while using 96% fewer tokens than full-context approaches, enabling efficient long-term memory for agents.
