> 🎖️ 🏎️ ☁️ - Query and interact with kubernetes environments monitored by Metoro

The metoro-mcp-server project implements a Model Context Protocol (MCP) server that allows users to query and interact with Kubernetes environments monitored by Metoro. It provides a bridge between AI agents and Metoro's monitoring data, enabling natural language queries about cluster state, performance, and incidents. The server supports retrieving metrics, logs, and events from Kubernetes clusters managed by Metoro.
