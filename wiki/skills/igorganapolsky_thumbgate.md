Install: `npx thumbgate`.

ThumbGate is an MCP server that uses thumbs-up/down feedback to prevent AI coding agents from repeating past mistakes. It enforces pre-action gates via PreToolUse hooks, blocking actions that have previously been flagged as undesirable. The tool is installed using 'npx thumbgate' and is listed under developer tools in server implementations. This enables teams to teach coding agents through simple feedback rather than complex rule-based configurations.
