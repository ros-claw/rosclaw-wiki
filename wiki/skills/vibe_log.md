> Analyzes your Claude Code prompts locally (using CC), provides intelligent session analysis and actionable strategic guidance - works in the statusline and produces very pretty HTML reports as well. Easy to install and remove.

Vibe-Log is a local tool that analyzes prompts used with Claude Code (CC) to provide intelligent session analysis and actionable strategic guidance. It integrates into the statusline for real-time feedback and can also generate detailed HTML reports. The tool is designed to be easy to install and remove, making it a lightweight addition to a developer's workflow. It helps users understand and improve their interaction patterns with AI coding assistants through prompt-level insights.
