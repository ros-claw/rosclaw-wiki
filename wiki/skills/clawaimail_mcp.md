Clawaimail/mcp is an MCP server that provides email infrastructure for AI agents. It allows creating dynamic inboxes, sending and receiving real emails, searching messages, and managing threads via a simple API. Designed to integrate seamlessly with AI agents using the Model Context Protocol, it can be installed via npx. This tool enables agents to autonomously handle email communication in a scalable manner.
