This project is a framework for AI agents to manage Google Ads, Meta Ads, and Google Search Console campaigns. It relies on a local STRATEGY.md file for decision-making instead of chasing metrics. Security is implemented with a defense-in-depth approach and the system operates local-first. It is licensed under Apache 2.0.
