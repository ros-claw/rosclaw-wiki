> 🏎️ 🏠 🍎 🐧 🪟 - A fully functional MCP server and CLI for YouTube to automate YouTube operation

Yutu is a fully functional MCP (Model Context Protocol) server and command-line interface designed to automate YouTube operations. It supports multiple platforms including web browsers and desktop environments. The tool enables programmatic control of YouTube tasks, such as video management or content interaction. It is listed under browser automation in the MCP server ecosystem.
