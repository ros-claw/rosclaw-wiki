> 🏎️ ☁️ 📟 🪟 🐧 🍎 - A zero-configuration Go library to automatically expose existing Gin web framework APIs as MCP tools.

A Go library that automatically exposes existing Gin web framework APIs as MCP (Model Context Protocol) tools with zero configuration. It allows developers to quickly turn their Gin-based web services into MCP-compatible tools for AI agents. This simplifies integration between web APIs and AI systems by eliminating manual setup.
