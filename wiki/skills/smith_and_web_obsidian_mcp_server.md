> 📇 🏠 🍎 🪟 🐧 - SSE-enabled MCP server for remote Obsidian vault management with 29 tools for notes, directories, frontmatter, tags, search, and link operations. Docker-ready with health monitoring.

This project provides an MCP server for remote management of Obsidian vaults using Server-Sent Events (SSE). It offers 29 tools covering operations on notes, directories, frontmatter, tags, search, and links. The server is Docker-ready and includes health monitoring, making it suitable for integrating knowledge management into AI-agent workflows.
