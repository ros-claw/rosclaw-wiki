> 🐍 ☁️ 🏠 - MCP Server for Yandex Tracker. Provides tools for searching and retrieving information about issues, queues, users.

This is a Model Context Protocol (MCP) server that integrates with Yandex Tracker, a project management and issue tracking service. It allows AI agents to search and retrieve information about issues, queues, and users from Yandex Tracker. This enables embodied AI systems to interact with project management workflows.
