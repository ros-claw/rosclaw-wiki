> 🐍 ☁️ - An MCP server for checking and revoking ERC-20 token allowances across multiple blockchains.

This MCP server allows users to check and revoke ERC-20 token allowances across multiple blockchains. It provides a tool to manage token approvals on Ethereum-compatible networks, helping users withdraw excessive allowances to improve security. The server is implemented in Python and uses the Model Context Protocol for integration with AI assistants. It is categorized under Finance & Fintech.
