Neon is a serverless PostgreSQL database platform that separates compute and storage, enabling instant branching, autoscaling, and point-in-time recovery. It is designed for modern cloud-native applications, offering a fast and scalable alternative to traditional PostgreSQL hosting. The project provides the open-source code for Neon's Postgres engine, which powers these capabilities.
