> [![mcp-server MCP server](https://glama.ai/mcp/servers/keepgoing-dev/mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/keepgoing-dev/mcp-server) 📇 🏠 🍎 🪟 🐧 - Project memory for AI coding sessions. Auto-captures checkpoints on git commits, branch switches, and inactivity, then provides re-entry briefings so AI assistants pick up where you left off. Local-first, no account required.

This MCP server automatically captures checkpoints of AI coding sessions based on git commits, branch switches, and inactivity. It provides re-entry briefings so AI assistants can resume context seamlessly. The tool is local-first and requires no account, ensuring privacy and offline capability.
