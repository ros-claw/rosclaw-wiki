This is the official Python SDK for Azure AI Translator, part of Azure Cognitive Services. It provides methods to translate text between languages, detect source languages, and transliterate scripts. The library supports both synchronous and asynchronous operations with easy-to-use client abstractions. It is used by developers integrating multilingual functionality into their applications. The SDK is maintained by Microsoft and follows the Azure SDK guidelines for Python.
