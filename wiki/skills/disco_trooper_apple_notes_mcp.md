> 📇 🏠 🍎 - Apple Notes MCP with semantic search, hybrid vector+keyword search, full CRUD operations, and incremental indexing. Uses JXA for native macOS integration.

This MCP server provides a native macOS integration for Apple Notes, enabling semantic search and hybrid vector-plus-keyword search. It supports full CRUD operations (create, read, update, delete) and incremental indexing for efficient note management. The server uses JXA (JavaScript for Automation) to interface directly with Apple Notes on macOS.
