> 📇 🏠 - Translation quality evaluation using xCOMET models. Provides quality scoring (0-1), error detection with severity levels (minor/major/critical), and optimized batch processing with 25x speedup.

This MCP server provides translation quality evaluation using xCOMET models, offering quality scoring on a 0-1 scale, error detection with severity levels (minor, major, critical), and optimized batch processing achieving up to 25x speedup. It is listed under Translation Services in the server implementations directory. The service enables automated evaluation of translation output to help users assess and improve machine translation quality.
