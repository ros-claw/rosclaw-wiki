Connapse is a self-hosted knowledge backend designed for AI agents, offering hybrid vector and keyword search capabilities. It uses container-isolated indexes to keep data separate and secure, and provides 11 MCP tools for integration. Built with .NET and Docker-ready, it allows developers to run their own knowledge infrastructure for AI applications.
