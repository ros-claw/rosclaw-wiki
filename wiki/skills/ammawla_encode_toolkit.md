> [![encode-toolkit MCP server](https://glama.ai/mcp/servers/ammawla/encode-toolkit/badges/score.svg)](https://glama.ai/mcp/servers/ammawla/encode-toolkit) 🐧 - MCP server and Claude Plugin for a full ENCODE Project genomic data and analysis toolkit — search, download, track, and analyze functional genomics experiments.

This is an MCP server and Claude plugin that provides a full toolkit for the ENCODE Project's genomic data. It enables users to search, download, track, and analyze functional genomics experiments. The tool is designed for biology and bioinformatics applications, integrating with AI assistants for interactive data exploration.
