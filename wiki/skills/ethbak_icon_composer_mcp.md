This MCP server provides a programmatic interface to Apple's Icon Composer for creating .icon bundles with Liquid Glass effects, targeting iOS 26 and above. It includes 12 tools for icon creation, tuning glass effects, handling dark mode appearances, and exporting for the App Store. The server automates the generation of icons for developers, integrating directly with Apple's Icon Composer tool.
