> Manage Google Calendar events using `gcalcli`.

brainz-calendar is a tool for managing Google Calendar events via the command line. It wraps the popular gcalcli utility to simplify common calendar operations. Users can create, update, and delete events without a graphical interface. This makes it ideal for automation scripts and terminal-based workflows. The project aims to streamline calendar management for developers and power users.
