> ☕ 🏠 - Connect to any JDBC-compatible database and query, insert, update, delete, and more.

This project provides a Model Context Protocol (MCP) server that connects to any JDBC-compatible database. It allows querying, inserting, updating, deleting, and other database operations through the MCP interface. Built under the Quarkiverse umbrella, it integrates Quarkus with MCP for database interactions. The tool enables AI agents to interact directly with relational databases using standard JDBC drivers.
