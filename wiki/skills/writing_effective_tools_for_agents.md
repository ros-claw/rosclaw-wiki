> Anthropic's guidance on tool interfaces that are easier for models to call correctly and safely.

This project provides guidance from Anthropic on designing tool interfaces that AI agents can call correctly and safely. It emphasizes making tool definitions clear, consistent, and easy for language models to parse and execute. The advice helps reduce errors and misuse in autonomous agent scenarios by aligning tool design with model capabilities. The work is categorized under constraints and guardrails, highlighting its role in safe autonomy.
