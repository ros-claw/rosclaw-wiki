> 🐍 ☁️ - Query OpenAI models directly from Claude using MCP protocol

This project provides a server implementation that allows Claude (Anthropic's AI assistant) to directly query OpenAI models using the Model Context Protocol (MCP). It acts as a bridge between the two AI ecosystems, enabling users to leverage OpenAI's language models from within Claude's interface. The server is written in Python and uses the MCP standard for communication.
