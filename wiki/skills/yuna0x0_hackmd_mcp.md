> 📇 ☁️ - Allows AI models to interact with [HackMD](https://hackmd.io)

This project is an MCP server that enables AI models to interact with HackMD, a collaborative Markdown editor. It allows AI assistants to read, create, and manage HackMD notes programmatically through the Model Context Protocol. This integration extends the capabilities of AI models to access and manipulate cloud-based documentation.
