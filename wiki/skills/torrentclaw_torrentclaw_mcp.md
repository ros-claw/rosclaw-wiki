> 🎖️ 📇 ☁️ - Search and discover movies and TV shows with torrent links, quality scoring, streaming availability, and cast/crew metadata.

TorrentClaw MCP is a server implementation for searching and discovering movies and TV shows. It provides torrent links with quality scoring, streaming availability information, and cast/crew metadata. The tool enables users to find entertainment content with detailed information about sources and quality. It integrates into MCP-compatible environments for multimedia processing.
