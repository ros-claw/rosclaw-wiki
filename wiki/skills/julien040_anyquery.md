> 🏎️ 🏠 ☁️ - Query more than 40 apps with one binary using SQL. It can also connect to your PostgreSQL, MySQL, or SQLite compatible database. Local-first and private by design.

Anyquery is a single binary that lets you query over 40 different apps using SQL. It can also connect to PostgreSQL, MySQL, or SQLite databases. Designed to be local-first and private, it processes data without sending it to external servers. This makes it a versatile tool for aggregating and analyzing data from multiple sources in a unified way.
