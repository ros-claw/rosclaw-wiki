> 📇 🏠 🍎 🪟 🐧 - Turn a web API into an MCP server in 10 seconds and add it to the open source registry: https://open-mcp.org

wegotdocs/open-mcp is a tool that allows developers to quickly convert any web API into a Model Context Protocol (MCP) server in about 10 seconds. It is listed under aggregator-style server implementations and supports cross-platform use (home, Apple, Windows, Linux). The project also contributes to an open source registry at open-mcp.org, enabling sharing and discovery of such MCP servers. This simplifies integration of external APIs with MCP-compatible clients like AI agents.
