Convert, merge, redact, sign, OCR, watermark, and extract data from PDFs and Office documents via natural language. Works with Claude Desktop, LangGraph, and OpenAI Agents.

This MCP server integrates with the Nutrient DWS Processor API to allow natural language-driven PDF and Office document processing. Users can convert, merge, redact, sign, OCR, watermark, and extract data from documents using commands in plain language. It is designed to work seamlessly with Claude Desktop, LangGraph, and OpenAI Agents, enabling AI assistants to manipulate documents on behalf of users.
