> 🦀 🏠 - Justfile integration that enables LLMs to execute any CLI or script commands with parameters safely and easily, with environment variable support and comprehensive testing.

just-mcp is a server that integrates the Just command runner with the Model Context Protocol (MCP), enabling large language models (LLMs) to execute CLI commands or scripts defined in Justfiles. It allows safe and easy parameter passing, supports environment variables, and includes comprehensive testing. This tool is particularly useful for developers who want to delegate command-line tasks to AI agents in a controlled and predictable manner.
