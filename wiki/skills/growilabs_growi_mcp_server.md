> 🎖️ 📇 ☁️ - Official MCP Server to integrate with GROWI APIs.

This is an official MCP (Model Context Protocol) server that integrates with GROWI APIs. It allows AI agents to interact with GROWI, an open-source wiki platform, for reading and writing wiki pages. The server follows the MCP specification to provide tool access to GROWI's content management features. It is designed to be used with AI agent frameworks that support MCP, enabling seamless knowledge retrieval and editing.
