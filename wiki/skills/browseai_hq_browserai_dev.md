Real-time search with cited claims, confidence scores, and compare mode (raw LLM vs evidence-backed). MCP server, REST API, and Python SDK.

BrowserAI-Dev is an MCP server that enables AI agents to perform evidence-backed web research. It provides real-time search with cited claims and confidence scores, and includes a compare mode contrasting raw LLM outputs with evidence-backed results. The server is accessible via MCP protocol, REST API, and a Python SDK, making it easy to integrate into AI agent workflows.
