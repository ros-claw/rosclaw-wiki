> 📇 🏠 - An MCP server built on [markmap](https://github.com/markmap/markmap) that converts

This MCP server integrates markmap, a tool that renders Markdown as interactive mind maps, into the MCP ecosystem. It allows AI agents to convert markdown content into visual mind map representations, facilitating knowledge structuring and visualization. The server provides a straightforward way to generate interactive diagrams from structured text, enhancing understanding and exploration of information.
