Works across Claude, Cursor, Windsurf, and any MCP client.

Penfield is a persistent memory system designed for MCP clients like Claude, Cursor, and Windsurf. It uses hybrid search combining BM25, vector, and graph methods to retrieve information. The system supports knowledge graphs with 24 relationship types, context checkpoints for cognitive handoff, artifact storage, and a personality system. This enables long-term memory and structured knowledge management across different AI agent tools.
