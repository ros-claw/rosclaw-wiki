> Check Claude Code OAuth usage limits.

This project provides a tool to check OAuth usage limits for Claude Code, allowing developers to monitor their API consumption and avoid exceeding rate limits. It helps manage authentication tokens and quotas effectively. The tool is designed for use with Anthropic's Claude AI platform.
