> 🦀 📟 - A Model Context Protocol server for embedded debugging with probe-rs - supports ARM Cortex-M, RISC-V debugging via J-Link, ST-Link, and more

This is an MCP (Model Context Protocol) server designed for embedded systems debugging. It leverages the probe-rs library to provide debugging capabilities for ARM Cortex-M and RISC-V architectures. The server supports common debug probes like J-Link and ST-Link, enabling developers to interact with their embedded targets through the MCP protocol. It aims to streamline firmware development by integrating debugging tools into AI-assisted workflows.
