This project, hashicorp/provider-actions, is a collection of reusable GitHub Actions workflows and actions for Terraform provider development, maintained by the HashiCorp team. It helps automate testing, releasing, and maintaining Terraform providers in a standardized way. These actions are designed to streamline CI/CD pipelines for provider repositories. The project is used by the Terraform ecosystem to ensure consistent quality and release processes.
