> 📇 🏠 - MCP server with basic demonstration of getting weather from Hong Kong Observatory

This MCP server provides a basic demonstration of retrieving weather data from the Hong Kong Observatory. It is built as a tool integration within the Model Context Protocol ecosystem, allowing users to query current weather conditions for Hong Kong. The server serves as a simple example for creating MCP servers that interface with external APIs. It is listed under other tools and integrations in the project repository.
