ExpertVagabond/solmail-mcp is a Model Context Protocol (MCP) server that enables AI agents to send physical mail using Solana cryptocurrency for payment. AI agents can compose, price, and dispatch letters and postcards. The server integrates with the Solana blockchain to handle payments and uses an external mailing service to print and deliver the items. This allows automated systems to send real-world mail with digital currency.
