> 📇 ☁️ - Oracle Cloud Infrastructure pricing data with 602 products, cost calculators, and cross-provider comparisons. One-command install for Claude.

This project implements an MCP (Model Context Protocol) server that provides Oracle Cloud Infrastructure (OCI) pricing data, covering 602 products, cost calculators, and cross-provider comparisons. It is designed for easy one-command installation with Claude, enabling AI-driven cost analysis and cloud cost management. The tool simplifies accessing and comparing cloud pricing across providers, making it useful for cloud architects and financial operations teams.
