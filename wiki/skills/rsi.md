> Reads all commands and key project files to optimize AI-assisted development by streamlining the process, loading command context, and setting up for better development workflow.

/rsi is a slash command that reads all commands and key project files to optimize AI-assisted development. It streamlines the process by loading command context and setting up the environment for a better development workflow. This helps AI tools understand the project structure and available commands more effectively.
