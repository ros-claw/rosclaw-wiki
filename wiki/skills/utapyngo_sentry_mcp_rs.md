> 🦀 ☁️ - Fast and minimal Sentry MCP server written in Rust

This is a minimal, fast Model Context Protocol (MCP) server written in Rust for integrating AI agents with the Sentry error tracking platform. It enables tools and resources for querying Sentry issues, events, and projects, designed for performance and low resource usage. The server acts as a bridge between AI assistants and Sentry's monitoring capabilities, allowing automated debugging and alerting workflows.
