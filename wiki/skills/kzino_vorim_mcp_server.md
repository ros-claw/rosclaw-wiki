vorim-mcp-server is an MCP server that provides infrastructure for AI agent identity, trust, and audit trails. It includes 17 tools such as registering agents with Ed25519 keypairs, checking permissions in under 5 milliseconds, emitting tamper-evident audit events, verifying trust scores, delegating credentials, and managing ephemeral agents. The project has an associated IETF Internet-Draft (draft-vorim-vaip-00) and integrates with frameworks like LangChain, OpenAI, CrewAI, and Stripe ACP. It can be run via npx.
