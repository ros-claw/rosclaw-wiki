> 🐍 🏠 - An MCP server for interacting with VictoriaMetrics database.

This project provides a server implementation that bridges AI agents with VictoriaMetrics database via the Model Context Protocol (MCP). It allows large language models to execute queries and retrieve time-series metrics data directly from VictoriaMetrics. The server simplifies integration by offering a standardized interface for AI tooling to access monitoring and observability data.
