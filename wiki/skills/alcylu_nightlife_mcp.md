> [![nightlife](https://glama.ai/mcp/servers/alcylu/nightlife-mcp/badges/score.svg)](https://glama.ai/mcp/servers/alcylu/nightlife-mcp) 📇 ☁️ - MCP server for Tokyo nightlife event discovery, venue search, performer info, AI recommendations, and VIP table booking.

This project provides a Model Context Protocol (MCP) server that enables AI agents to discover Tokyo nightlife events, search for venues and performers, get AI-powered recommendations, and book VIP tables. It integrates with Tokyo's nightlife scene to offer real-time data and booking capabilities through a standardized MCP interface. The server is designed for use by AI assistants and agentic systems within the travel and transportation domain.
