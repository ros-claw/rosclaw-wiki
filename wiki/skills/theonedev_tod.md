> 🏎️ 🏠 - A MCP server for OneDev for CI/CD pipeline editing, issue workflow automation, and pull request review

This project is a Model Context Protocol (MCP) server for OneDev, a self-hosted Git server. It enables AI agents to edit CI/CD pipelines, automate issue workflows, and review pull requests directly through MCP. Users can integrate this server into their coding assistants to manage development tasks across OneDev projects. The tool simplifies complex operations like configuring build pipelines and managing issues via natural language or code.
