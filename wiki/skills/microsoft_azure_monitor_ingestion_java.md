This project is the Java SDK for Azure Monitor Ingestion, enabling Java applications to send logs and telemetry data to Azure Monitor. It provides a client library for uploading data to Log Analytics workspaces via Data Collection Rules. Developers can use this SDK to integrate custom logging and monitoring into their Java services. It is part of Microsoft's commitment to supporting Java developers in the Azure ecosystem.
