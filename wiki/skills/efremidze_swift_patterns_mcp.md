This project is an MCP server that delivers curated Swift and SwiftUI best practices, including patterns and real-world code examples from trusted iOS developer sources like Swift by Sundell and SwiftLee. The server is listed under Developer Tools in the MCP server implementations collection, supporting Apple platforms and Linux.
