> 🐍 ☁️ - Streams real-time cryptocurrency liquidation events from Binance.

This MCP server streams real-time cryptocurrency liquidation events from the Binance exchange. It enables AI agents and tools to access live liquidation data for trading signals or market analysis. Built with Python and designed for cloud deployment, it integrates seamlessly with MCP-compatible clients. The service provides a reliable, low-latency feed of liquidation events, including size, side, and symbol details.
