> 📇 ☁️ - MCP server for XERT cycling analytics — access fitness signature (FTP, HIE, PP), training status, workouts, activities with XSS metrics, and MPA analysis.

This project is a Model Context Protocol (MCP) server that provides access to XERT cycling analytics data. It enables AI agents to retrieve a rider's fitness signature, including FTP, HIE, and PP, as well as training status, workouts, activities with XSS metrics, and MPA analysis. The server integrates with the MCP ecosystem to allow language models to query cycling performance data for coaching and analysis purposes. It is categorized under sports server implementations within the MCP registry.
