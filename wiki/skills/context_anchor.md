> Recover from context compaction by scanning memory files.

Context-anchor is a tool that helps recover from context compaction in large language models. It works by scanning memory files to retrieve previously stored context that may have been lost or compressed. This allows users to maintain continuity in long conversations or tasks. The tool is likely used in conjunction with AI agents that need effective memory management.
