> 📇 ☁️ - An MCP server for Apify's open-source RAG Web Browser Actor to perform web searches, scrape URLs, and return content in Markdown.

This project is an MCP (Model Context Protocol) server that wraps Apify's RAG Web Browser Actor, enabling AI agents to perform web searches, scrape web pages, and retrieve content in Markdown format. It is designed to be used with AI models that need real-time web data for retrieval-augmented generation (RAG) tasks. The server provides a standardized interface for web scraping and search capabilities within the MCP ecosystem.
