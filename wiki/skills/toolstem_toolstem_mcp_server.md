Curated tools (`get_stock_snapshot`, `get_company_metrics`, `compare_companies`) that fan out to multiple financial data sources, derive human-readable signals (`UNDERVALUED`, `STRONG`, `ACCELERATING`), and pre-compute CAGRs, margin trends, and DCF upside. One call, one flat JSON response — no cross-endpoint stitching. Available on npm (`toolstem-mcp-server`), the Official MCP Registry, and the Apify Store.

This MCP server provides financial intelligence for AI agents by offering curated tools like get_stock_snapshot, get_company_metrics, and compare_companies. It aggregates data from multiple financial sources and derives human-readable signals such as UNDERVALUED, STRONG, and ACCELERATING. The server pre-computes metrics like CAGRs, margin trends, and DCF upside, returning a single flat JSON response without the need for cross-endpoint stitching. It is available on npm, the Official MCP Registry, and the Apify Store.
