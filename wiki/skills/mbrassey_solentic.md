Solentic is an MCP server that provides native Solana staking infrastructure for AI agents. It offers 18 tools for staking, unstaking, withdrawing, simulating, and verifying transactions, all without taking custody of funds. The server only creates unsigned transactions and targets approximately 6% APY via the Blueprint validator.
