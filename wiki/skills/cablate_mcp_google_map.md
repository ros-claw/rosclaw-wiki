> [![cablate/mcp-google-map MCP server](https://glama.ai/mcp/servers/cablate/mcp-google-map/badges/score.svg)](https://glama.ai/mcp/servers/cablate/mcp-google-map) 📇 ☁️ 🏠 - Google Maps MCP server with 8 tools (geocode, search, directions, elevation), stdio + StreamableHTTP transport, Agent Skill definitions, and standalone exec CLI mode.

This MCP server integrates Google Maps APIs into AI agent workflows, providing eight tools for geocoding, place search, directions, and elevation data. It supports both stdio and StreamableHTTP transport protocols, along with Agent Skill definitions for easy integration. The server also includes a standalone CLI mode for direct execution from the terminal, making location services accessible to MCP clients.
