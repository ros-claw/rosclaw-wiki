> 🎖️ 📇 ☁️ 🏠 - Interact with Flowcore to perform actions, ingest data, and analyse, cross reference and utilise any data in your data cores, or in public data cores; all with human language.

This project provides an MCP server that integrates with Flowcore, allowing users to interact with data cores through natural language commands. It enables actions such as data ingestion, analysis, cross-referencing, and utilization of data from both private and public data cores. The server acts as a bridge between human language and the Flowcore data platform, simplifying complex data operations.
