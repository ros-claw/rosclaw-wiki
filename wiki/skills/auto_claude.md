> Autonomous multi-agent coding framework for Claude Code (Claude Agent SDK) that integrates the full SDLC - "plans, builds, and validates software for you". Features a slick kanban-style UI and a well-designed but not over-engineered agent orchestration system.

Auto-Claude is an autonomous multi-agent coding framework built for Claude Code (Claude Agent SDK). It orchestrates multiple AI agents to handle the full software development lifecycle—planning, building, and validating software automatically. The framework features a kanban-style user interface for visualizing progress and a flexible agent orchestration system. It aims to be practical rather than over-engineered, integrating seamlessly with Claude's capabilities.
