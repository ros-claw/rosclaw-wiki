Find what you need locally instead of waiting for delivery. Remote MCP server (Streamable HTTP, no API key required).

Partle-MCP is a remote MCP server that enables searching for products and stores in nearby physical locations. It allows users to find items locally instead of waiting for delivery. The server uses Streamable HTTP and requires no API key, making it easy to integrate.
