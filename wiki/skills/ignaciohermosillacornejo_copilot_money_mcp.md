This MCP server integrates with Copilot Money, a personal finance app, to read and manage financial data. It provides 30 tools for handling transactions, budgets, accounts, recurring charges, investments, and goals. All read operations are performed locally from a Firestore cache, ensuring privacy and speed. Write operations (enabled with the --write flag) use Copilot's GraphQL API. The server is designed for users who want programmatic access to their Copilot Money data via the Model Context Protocol.
