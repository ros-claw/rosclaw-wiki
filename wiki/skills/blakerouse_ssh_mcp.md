> 🏎️ 🏠 🍎 🪟 🐧 - MCP server exposing SSH control for Linux and Windows servers. Allows long running commands and the ability to perform commands on multiple hosts at the same time.

This project implements an MCP server that provides SSH control capabilities to AI agents. It allows agents to execute long-running commands on remote Linux and Windows servers. Additionally, it supports running commands on multiple hosts simultaneously, making it useful for managing clusters or multi-server environments. The server integrates with the Model Context Protocol to enable coding agents to perform remote operations.
