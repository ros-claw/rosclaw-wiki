> 🐍 🏠 🍎 🪟 🐧 - A Model Context Protocol server providing web automation capabilities through Selenium WebDriver

This project is a Model Context Protocol (MCP) server that wraps Selenium WebDriver to enable browser automation tasks. It allows AI agents to control web browsers programmatically through standard MCP interfaces, supporting cross-platform execution on Windows, macOS, and Linux. The server provides tools for navigating pages, clicking elements, and extracting page data. It is designed to be used as a component in AI workflows that require web interaction.
