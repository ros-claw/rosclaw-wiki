This MCP server provides document intelligence services including invoice extraction, PII detection, and sentiment analysis. It uses x402 micropayments with USDC on the Base blockchain for pay-per-use access, starting at $0.01 per request. No API keys are required, making it an easy-to-use, decentralized payment model for AI document processing. The server is listed under Finance & Fintech in the MCP server registry.
