> 📇 🏠 - An MCP Server and VS Code Extension which enables (language agnostic) automatic debugging via breakpoints and expression evaluation.

Claude-Debugs-For-You is an MCP server and VS Code extension that enables automatic, language-agnostic debugging. It allows developers to set breakpoints and evaluate expressions interactively, with the AI (Claude) helping to diagnose issues. The tool integrates directly into the VS Code environment, streamlining the debugging workflow. It is designed to work across multiple programming languages without additional configuration.
