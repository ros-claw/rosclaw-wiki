> 🐍 ☁️️ - Contract and template management for drafting, reviewing, and sending binding contracts via the eSignatures API.

This project provides an MCP server that integrates with the eSignatures API for contract and template management. It allows users to draft, review, and send binding contracts directly through the API. Built in Python, the server exposes tools following the Model Context Protocol to streamline document workflows. It is listed under server implementations for other tools and integrations.
