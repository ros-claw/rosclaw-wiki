Includes a separate `sint-scan` CLI for preflight MCP tool-risk audits.

Sint Protocol is a security-focused governance proxy for MCP (Model Context Protocol) servers. It introduces capability tokens and a four-tier approval system (T0 to T3) to control tool execution. The proxy operates in a fail-closed mode and generates tamper-evident audit receipts for compliance. A companion CLI tool, sint-scan, performs preflight risk audits on MCP tools before deployment. This helps organizations securely manage AI agent tool access and meet security requirements.
