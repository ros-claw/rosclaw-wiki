This project is an MCP (Model Context Protocol) server that connects to the D2L Brightspace learning management system. It allows users to check grades, due dates, assignments, announcements, syllabus, rosters, discussions, and course content through a standardized interface. The server works with any school that uses Brightspace and can be quickly installed via npx. It is intended for students and educators who want to integrate Brightspace data into MCP-compatible applications, such as AI assistants.
