> 📇 🏠 - A Model Context Protocol (MCP) server that queries multiple Ollama models and combines their responses, providing diverse AI perspectives on a single question.

This is a Model Context Protocol (MCP) server that queries multiple local Ollama models simultaneously and combines their responses. It enables users to get diverse AI perspectives on a single question by aggregating outputs from different models. The tool is designed as a developer utility, allowing easy integration with MCP-compatible clients. It leverages Ollama's local model management to provide fast, private multi-model inference.
