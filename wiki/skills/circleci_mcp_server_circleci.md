> 📇 ☁️ Enable AI Agents to fix build failures from CircleCI.

This project provides an MCP server that integrates with CircleCI, allowing AI agents to interact with CircleCI builds. The primary goal is to enable agents to diagnose and fix build failures automatically. It is designed for use with developer tools and AI-assisted workflows. The server exposes CircleCI capabilities through the Model Context Protocol, making it easier for AI tools to manage CI pipelines.
