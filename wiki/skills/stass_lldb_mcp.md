> 🐍 🏠 🐧 🍎 - A MCP server for LLDB enabling AI binary and core file analysis, debugging, disassembling.

This project implements a Model Context Protocol (MCP) server that integrates with LLDB, the LLVM debugger. It enables AI assistants to perform binary analysis, core file analysis, debugging, and disassembly. The server is written in Python and supports Linux and macOS platforms. It facilitates automated debugging and reverse engineering tasks through AI tools.
