> 🚀 ☁️ - An MCP server application that sends various types of messages to the WeCom group robot.

WecomBot is an MCP server that enables sending various message types to WeCom (WeChat Work) group robots. It simplifies communication by providing a programmable interface for automated group messaging. This tool is useful for integrating notifications, alerts, or interactive messages into WeCom workspaces.
