securecode-mcp is a security-focused MCP server that serves as a secrets vault for Claude Code. It uses AES-256 encryption and audit logs to protect sensitive data, injecting secrets into local files so the AI never sees raw values. Additional security features include session lock, device approval, and per-model access policies. This tool helps developers securely manage credentials in AI-assisted coding workflows.
