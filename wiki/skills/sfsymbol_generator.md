> Generate an Xcode SF Symbol asset catalog .symbolset.

sfsymbol-generator is a tool for generating Xcode SF Symbol asset catalog .symbolset files. It automates the creation of custom SF Symbols for use in Apple platform apps. The tool likely converts vector artwork into the required metadata format. This helps developers extend the SF Symbols library with custom icons.
