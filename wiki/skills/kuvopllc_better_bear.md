> [![better-bear MCP server](https://glama.ai/mcp/servers/KuvopLLC/better-bear/badges/score.svg)](https://glama.ai/mcp/servers/KuvopLLC/better-bear) 📇 🏠 🍎 - MCP server for Bear notes via CloudKit — CRUD, tags, TODOs, attachments, search, front matter, stats, and health checks. Install via `npx better-bear`.

Better-Bear is an MCP (Model Context Protocol) server that provides CRUD operations for Bear notes through Apple's CloudKit. It supports managing tags, TODOs, attachments, searching notes, handling front matter, and generating stats with health checks. Users can install it easily via npx with the command 'npx better-bear', and it integrates with MCP clients to enable AI-powered note management. This tool is designed for productivity and workplace contexts, leveraging the Bear note-taking ecosystem.
