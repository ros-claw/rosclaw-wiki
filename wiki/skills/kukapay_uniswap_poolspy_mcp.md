> 🐍 ☁️ -  An MCP server that tracks newly created liquidity pools on Uniswap across multiple blockchains.

This tool is an MCP server that monitors the creation of new liquidity pools on Uniswap across multiple blockchains. It allows AI agents or users to receive real-time notifications or data about newly added trading pairs. By tracking pool creation events, it helps identify new tokens and trading opportunities in decentralized finance (DeFi). The server supports multiple chains, making it useful for cross-chain DeFi analysis.
