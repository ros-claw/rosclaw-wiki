> 🍎🪟🐧🏠🌊 - MCP server for Radare2 disassembler. Provides AI with capability to disassemble and look into binaries for reverse engineering.

r2mcp is a Model Context Protocol (MCP) server that integrates the Radare2 disassembler with AI agents. It enables AI systems to disassemble and analyze binary files for reverse engineering tasks. The project is cross-platform and supports security-focused analyses. By exposing Radare2 capabilities through the MCP interface, it allows AI tools to interact with binary code programmatically.
