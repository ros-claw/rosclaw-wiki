This project documents all parts of Claude Code's system prompt, including built-in tool descriptions, sub-agent prompts for Plan/Explore/Task, and utility prompts such as CLAUDE.md, compact mode, Bash commands, security review, and agent creation. It is updated for each Claude Code version, providing a complete reference for how the AI agent is instructed to behave. The resource helps users understand the underlying prompts that guide Claude Code's actions and workflows.
