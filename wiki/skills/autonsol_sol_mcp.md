Score any token by mint address (0-100 risk, risk_label, holder concentration, liquidity), detect graduation momentum (buy/sell ratio, velocity), and query trust attestations. Live API. Freemium — 4 free tools, PRO via x402 micropayments ($0.01/call USDC).

sol-mcp is an MCP server for Solana blockchain that scores token risk (0-100) and detects graduation signals on pump.fun. It provides tools to query token risk, holder concentration, liquidity, and momentum metrics. The service is freemium with 4 free tools and PRO access via x402 micropayments ($0.01 per call in USDC).
