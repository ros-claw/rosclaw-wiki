This is an unofficial MCP server that integrates the FortiMonitor v2 API, providing 241 tools for server monitoring, outage management, maintenance tracking, and metrics collection. It enables AI agents to interact with FortiMonitor's monitoring capabilities through the Model Context Protocol. The server is listed under MCP's monitoring server implementations and supports multiple operating systems including macOS, Windows, and Linux.
