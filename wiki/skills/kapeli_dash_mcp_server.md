Instant search over 200+ documentation sets.

This is a Model Context Protocol (MCP) server that integrates with Dash, a popular macOS API documentation browser. It allows MCP-enabled AI agents to perform instant searches across over 200 documentation sets, covering a wide range of programming languages and frameworks. Developers can use this server to retrieve relevant API documentation directly within AI-assisted coding environments, streamlining the lookup process.
