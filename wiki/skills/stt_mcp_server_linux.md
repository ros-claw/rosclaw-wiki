> A push-to-talk speech transcription setup for Linux using a Python MCP server. Runs locally in Docker with no external API calls. Your speech is recorded, transcribed into text, and then sent to Claude running in a Tmux session.

This project provides a push-to-talk speech transcription system for Linux that runs entirely locally. It uses a Python MCP server inside a Docker container to record and transcribe speech into text without any external API calls. The transcribed text is then sent to Claude running in a Tmux session, enabling hands-free interaction with the AI. The setup prioritizes privacy and offline operation by avoiding cloud services.
