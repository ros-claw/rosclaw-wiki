idapixl-web-research-mcp is an MCP server that provides pay-per-use web research capabilities for AI agents, built on the Apify platform. It supports searching via Brave and DuckDuckGo, fetching web pages and converting them to clean markdown, and conducting multi-step research with relevance scoring and key fact extraction. This tool enables AI agents to perform structured, cost-effective data gathering from the web.
