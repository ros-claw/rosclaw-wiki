> 📇 ☁️ - Azure DevOps integration for repository management, work items, and pipelines.

This project provides an MCP server that integrates Azure DevOps with AI agents, enabling them to manage repositories, work items, and pipelines directly through the Model Context Protocol. It allows AI tools to interact with Azure Boards, Repos, and Pipelines, streamlining DevOps workflows. The server acts as a bridge, exposing Azure DevOps resources as tools and resources for MCP-compatible clients.
