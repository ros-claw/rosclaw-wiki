QGIS MCP connects QGIS Desktop to Claude AI through the Model Context Protocol, enabling prompt-assisted project creation, layer loading, and code execution. This integration allows users to control QGIS via natural language commands through Claude. It is designed to enhance GIS workflows by combining AI assistance with geographic information system functionality. The tool is listed under server implementations for location services.
