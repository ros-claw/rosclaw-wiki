> A no-frills little library that adds delightful OS-native sounds to Claude Code via simple hooks. It really sparks joy.

Claudio is a lightweight library that enhances Claude Code by adding OS-native sound effects through simple hooks. It aims to bring delight to the command-line experience with minimal configuration. The library is designed to be unobtrusive and straightforward, integrating seamlessly with existing workflows.
