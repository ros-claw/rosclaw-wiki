> Apple Mail.app integration for macOS.

This project provides an integration layer for Apple's Mail.app application on macOS, enabling programmatic control and automation. It allows users to compose, send, retrieve, and manage emails from scripts or external applications. The integration is useful for automating email workflows, extracting data from emails, and connecting Mail.app with other tools. It leverages macOS native scripting capabilities like AppleScript or JavaScript for Automation to communicate with Mail.app.
