Runs fully locally — no API keys required.

This is an MCP server that provides semantic search and retrieval-augmented generation (RAG) capabilities for Apple Notes. It runs entirely on-device with local embeddings, requiring no API keys. The server supports full CRUD operations on notes, folder management, and fuzzy title matching through 10 tools. It is designed for productivity and workplace use, integrating with the MCP ecosystem.
