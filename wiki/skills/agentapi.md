> Browse and search the AgentAPI directory - a curated database of APIs designed for AI agents.

AgentAPI is a curated directory of APIs specifically designed to be used by AI agents. It provides a browsable and searchable collection, making it easier for developers to find interfaces that agents can call autonomously. The project helps bridge the gap between AI agent capabilities and available web services.
