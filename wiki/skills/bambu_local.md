> Control Bambu Lab 3D printers locally via MQTT.

This project allows users to control Bambu Lab 3D printers directly over a local network using MQTT, without relying on cloud services. It provides a way to monitor print jobs, send commands, and manage printers offline or in privacy-sensitive environments. The tool is useful for home automation enthusiasts and makers who prefer local control of their 3D printers.
