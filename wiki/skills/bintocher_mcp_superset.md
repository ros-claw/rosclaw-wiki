Supports HTTP, SSE, and stdio transports.

This project is an MCP (Model Context Protocol) server that exposes over 135 tools for interacting with Apache Superset, a business intelligence and data visualization platform. It enables AI agents to manage dashboards, charts, datasets, execute SQL queries via SQL Lab, and handle security features like users, roles, row-level security, and permissions auditing. The server includes 30+ built-in safety validations and supports HTTP, SSE, and stdio transports, making it suitable for deploying alongside LLM applications to automate Superset workflows.
