> 🐍 ☁️ - Biomedical research MCP server providing access to PubMed, ClinicalTrials.gov, and MyVariant.info.

biomcp is a server implementation based on the Model Context Protocol (MCP) that specializes in biomedical data retrieval. It provides tools to query PubMed for literature, ClinicalTrials.gov for clinical trial information, and MyVariant.info for genetic variant annotations. This allows AI agents to access up-to-date biomedical knowledge directly through MCP's tool calling interface. The server simplifies integration of life sciences data into conversational AI and automation workflows.
