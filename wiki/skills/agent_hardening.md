> Test your agent's input sanitization against common injection attacks.

Agent-hardening is a tool to test an AI agent's input sanitization against common injection attacks. It helps developers identify vulnerabilities in how their agents handle malicious inputs. By simulating various injection techniques, it ensures the agent's defenses are robust. This is important for maintaining security and trust in AI systems.
