> 🐍 🏠 🍎 🪩 🐧 - Central hub that aggregates tools from multiple MCP servers with unified BM25/regex search and deferred loading.

The rupinder2/mcp-orchestrator is an aggregator server that consolidates tools from multiple MCP servers into a single interface. It provides a unified BM25 and regex search across all aggregated tools. The system uses deferred loading to improve performance by only loading tools when needed. This allows clients to access a wide range of MCP tools without managing multiple server connections individually.
