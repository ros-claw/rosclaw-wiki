Create, validate, and send all 12 template types (text, image, video, document, location, authentication, carousel, coupon, catalog, MPM, limited-time offer, and flows) from any MCP client.

This project provides an MCP (Model Context Protocol) server that integrates with the WhatsApp Business API through Meta Cloud API. It enables AI agents to create, validate, and send all 12 supported types of WhatsApp message templates directly from any MCP client. The supported template types include text, image, video, document, location, authentication, carousel, coupon, catalog, MPM, limited-time offer, and flows. This allows seamless communication between AI assistants and users via WhatsApp, leveraging standard business messaging capabilities.
