ralph-wiggum-bdd is a standalone Bash script that implements Behavior-Driven Development (BDD) principles using a 'Ralph Wiggum Loop'. The script is designed to keep code and requirements synchronized, but in practice it still requires human supervision during unattended runs. It supports both interactive and automated modes. Being a single script, it can be easily modified and committed into a project's repository.
