> UK AISI's open-source evaluation framework with solver, scorer, sandboxing, tool-use, MCP, and log-viewer primitives for building reproducible agent eval harnesses.

Inspect AI is an open-source evaluation framework from the UK AI Safety Institute (AISI). It provides core components such as solvers, scorers, sandboxing, tool-use capabilities, Model Context Protocol (MCP) support, and a log viewer. The framework is designed to build reproducible agent evaluation harnesses for embodied-intelligence and AI-agent tooling. It is categorized under Evals & Observability.
