> 🐍 ☁️ - Bulk Spotify operations with confidence-scored song matching, batch playlist creation from CSV/podcast lists, and library exports for discovering your most-saved artists and albums.

This project is an MCP server that enables bulk operations on Spotify, such as creating playlists from CSV files or podcast episode lists. It includes confidence-scored song matching to handle ambiguous track identification. Users can also export their library to discover their most-saved artists and albums. It is written in Python and integrates with the Spotify API.
