> 🐍 🏠 - Exposes `.context/` folder files as MCP resources, giving Claude Code instant access to project documentation via `@` mentions.

The project-context-mcp server exposes the contents of a .context/ folder as MCP resources, enabling Claude Code to instantly access project documentation through @ mention syntax. This allows developers to maintain a local context folder with relevant documentation that the AI assistant can reference during conversations. By integrating as an MCP server, it provides a seamless way to inject project-specific knowledge into Claude's workspace without manual file uploads. The tool is designed to streamline developer workflows by making contextual information readily available within the coding environment.
