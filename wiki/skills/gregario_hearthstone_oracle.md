Hearthstone Oracle is an MCP server that provides tools for Hearthstone card search, deck analysis, and strategy coaching. It includes nine tools covering card lookup, deck decoding, archetype classification, class identities, matchup theory, and game concepts. The server relies on HearthstoneJSON data to deliver accurate and up-to-date information. It is designed to assist both casual and competitive players in improving their gameplay through data-driven insights.
