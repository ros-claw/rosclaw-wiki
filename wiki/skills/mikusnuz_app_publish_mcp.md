> [![mikusnuz/app-publish-mcp MCP server](https://glama.ai/mcp/servers/mikusnuz/app-publish-mcp/badges/score.svg)](https://glama.ai/mcp/servers/mikusnuz/app-publish-mcp) 📇 ☁️ - Unified MCP server for App Store Connect & Google Play Console — 91 tools for iOS/Android app management, TestFlight, builds, submissions, pricing, and sales reports.

This project provides a unified MCP server that connects to both Apple App Store Connect and Google Play Console. It offers 91 tools for managing iOS and Android apps, including handling builds, TestFlight testing, submissions, pricing, and sales reports. The server simplifies cross-platform app management by combining two major app store APIs into one interface for AI agents or automation tools. It is specifically designed for developers who need to programmatically manage their mobile app lifecycle.
