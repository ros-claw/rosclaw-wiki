The fcpxml-mcp-server is the first MCP (Model Context Protocol) server for Final Cut Pro, providing 53 tools to parse, edit, and generate FCPXML timelines. It offers health checks, flash frame detection, chapter markers, rough cuts, and NLE export capabilities. The server is built in Python, includes 912 tests, and is MIT licensed.
