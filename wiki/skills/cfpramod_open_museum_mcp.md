Strict-default-deny rights gate accepts only CC0 / Public Domain Mark. Tools: search, get, cite (full / caption / short), dynasty/region discovery. `npx -y open-museum-mcp`

This MCP server provides a federated search across major art museums (The Met, Cleveland, AIC) and cultural archives (Wikimedia Commons, Europeana). It enforces strict default-deny licensing, only returning results that are CC0 or Public Domain Mark. Tools include search, get, cite, and dynasty/region discovery. Aimed at integrating open-access cultural heritage into AI agents.
