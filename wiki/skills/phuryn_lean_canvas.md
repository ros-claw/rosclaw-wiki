Lean Canvas is a tool for creating and managing business model canvases. This project provides a TypeScript implementation for building lean canvases efficiently. It allows users to define problems, solutions, key metrics, and competitive advantages. The tool is designed for entrepreneurs and developers to quickly prototype business ideas. It integrates well with modern web development workflows.
