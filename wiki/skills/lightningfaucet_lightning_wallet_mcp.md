This MCP server enables AI agents to interact with a Bitcoin Lightning wallet, supporting payments using the Lightning Network. It includes L402/X402 paid API authentication, an operator/agent hierarchy with budget controls, and a command-line interface. The server is designed to give AI agents direct financial autonomy within defined limits.
