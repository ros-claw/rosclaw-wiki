> 📇 🏠 🍎 - A Model Context Protocol server for reading iMessage data from macOS.

wyattjoh/imessage-mcp is a server implementation for the Model Context Protocol that enables AI agents to read iMessage data on macOS. It provides a bridge between Apple's messaging platform and AI tools, allowing agents to access iMessage conversations and metadata. This is useful for integrating personal messaging into AI workflows, such as automation or data retrieval. The server runs locally and requires a macOS environment with iMessage configured.
