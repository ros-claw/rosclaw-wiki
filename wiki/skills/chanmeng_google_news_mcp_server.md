> 📇 ☁️ - Google News integration with automatic topic categorization, multi-language support, and comprehensive search capabilities including headlines, stories, and related topics through [SerpAPI](https://serpapi.com/).

This project implements an MCP server that provides Google News search capabilities. It uses SerpAPI to fetch news headlines, stories, and related topics. The server supports multi-language queries and automatic topic categorization. It is designed for integration with AI assistants that use the Model Context Protocol.
