> 📇 ☁️ 🍎 🪟 🐧 - Official SpeedOf.Me server for accurate internet speed tests via 129 global Fastly edge servers with analytics dashboard and local history

The SpeedOfMe MCP server provides accurate internet speed measurements using 129 global Fastly edge servers. It offers an analytics dashboard and stores local history for tracking performance over time. This server is designed for monitoring network speed and can be integrated into MCP-enabled applications. It supports multiple platforms including cloud, macOS, Windows, and Linux.
