> 🐍 🏠 🍎 🐧 - Read-only MCP server to help gather metrics from [Swarmia](swarmia.com) for quick reporting.

This is a read-only MCP (Model Context Protocol) server that connects to Swarmia, an analytics platform for software engineering metrics. It allows users to quickly gather and report on project data without modifying any underlying systems. The server is categorized under Developer Tools and supports multiple operating systems (macOS, Linux, Windows).
