> Interact with the Breeze yield aggregator through the x402 payment-gated HTTP API.

Breeze is a yield aggregator that provides an HTTP API gated by the x402 payment protocol. Users can interact with the Breeze system to access yield aggregation services by making payments via x402. The API likely enables automated yield optimization strategies while ensuring access control through per-request micropayments.
