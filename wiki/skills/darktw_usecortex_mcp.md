Two-way flow: read context into projects and write discoveries back. Structured by topic with AES-256 encryption.

The darktw/usecortex-mcp project provides a Model Context Protocol (MCP) server that acts as a persistent knowledge memory for AI agents. It enables a two-way flow of information: agents can read relevant context from the knowledge base into their projects and write back new discoveries. The knowledge is structured by topic and secured with AES-256 encryption. This tool helps AI agents maintain long-term memory across sessions.
