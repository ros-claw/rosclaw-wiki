Longhand is a persistent local memory server for Claude Code that indexes every session verbatim into SQLite and ChromaDB, enabling fast semantic recall (~126ms) across your entire history. It provides 17 MCP tools including fuzzy recall, deterministic session replay, and git-aware project status, with zero API calls and no summarization. Published on PyPI and registered in the MCP Registry, it runs entirely locally across Windows, macOS, and Linux.
