> A controllable world of apps and people for benchmarking interactive coding agents, with state-based and execution-based unit tests that surface harness quality around planning, code generation, and collateral-damage control.

AppWorld is a benchmark that provides a controllable environment of simulated apps and people. It is designed to evaluate interactive coding agents on tasks involving planning, code generation, and avoiding collateral damage. The benchmark uses both state-based and execution-based unit tests to measure agent performance. It aims to surface the quality of harness systems for interactive agents.
