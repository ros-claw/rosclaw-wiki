> 📇 🏠 - Firefox browser automation via WebDriver BiDi for testing, scraping, and browser control. Supports snapshot/UID-based interactions, network monitoring, console capture, and screenshots.

This project implements a Model Context Protocol (MCP) server that enables AI agents to control Firefox through the WebDriver BiDi protocol. It supports browser automation tasks such as testing, scraping, and advanced interactions using snapshots and unique identifiers. Key features include network monitoring, console log capture, and screenshot capabilities, making it suitable for headless or interactive browser control. The server provides a structured interface for AI agents to perform complex browser actions programmatically.
