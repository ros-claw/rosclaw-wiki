This server enables cross-platform ad management across Google, Meta, LinkedIn, Microsoft, Reddit, and TikTok through natural language commands. It supports creating campaigns, adjusting budgets, generating creatives, and pulling performance data. The server provides full read and write capabilities, making it a comprehensive tool for multi-channel advertising. It is listed under Marketing server implementations for the Model Context Protocol (MCP).
