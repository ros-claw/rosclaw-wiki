> VoiceMode MCP brings natural conversations to Claude Code. It supports any OpenAI API compatible voice services and installs free and open source voice services (Whisper.cpp and Kokoro-FastAPI).

VoiceMode MCP is a tool that integrates natural voice conversations into Claude Code using the Model Context Protocol. It supports any OpenAI API compatible voice service while also installing free and open-source voice services like Whisper.cpp for speech recognition and Kokoro-FastAPI for speech synthesis. This allows users to interact with Claude Code via voice commands instead of typing, making the developer experience more accessible and efficient. The tool is listed under 'Tooling > General' and is available for use with AI agent tooling environments.
