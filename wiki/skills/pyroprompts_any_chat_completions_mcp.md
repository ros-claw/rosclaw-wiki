> Chat with any other OpenAI SDK Compatible Chat Completions API, like Perplexity, Groq, xAI and more

This project provides an MCP server that enables chatting with various OpenAI SDK-compatible chat completion APIs such as Perplexity, Groq, xAI, and others. It allows users to switch between different providers easily. The server is designed for integration with AI agent tooling that uses MCP (Model Context Protocol). It simplifies access to multiple large language model providers through a unified interface.
