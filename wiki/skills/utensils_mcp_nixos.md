> 🐍 🏠 - MCP server providing accurate information about NixOS packages, system options, Home Manager configurations, and nix-darwin macOS settings to prevent AI hallucinations.

This MCP server provides precise and up-to-date information about NixOS packages, system options, Home Manager configurations, and nix-darwin macOS settings. It is designed to reduce AI hallucinations by grounding responses in authoritative NixOS documentation. Developers can use natural language queries to obtain reliable details for NixOS package management and system configuration. The server is categorized as a Developer Tools MCP implementation, helping avoid incorrect or fabricated suggestions in AI-powered workflows.
