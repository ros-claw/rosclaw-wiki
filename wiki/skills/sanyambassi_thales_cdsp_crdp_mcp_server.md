> 📇 ☁️ 🏠 🐧 🪟 - MCP server for Thales CipherTrust Manager RestFul Data Protection service.

This project implements an MCP (Model Context Protocol) server that interfaces with the Thales CipherTrust Manager RESTful Data Protection service. It allows AI agents to securely manage encryption keys, perform data encryption/decryption operations, and access key metadata through standardized tool calls. The server acts as a bridge between AI applications and enterprise data protection infrastructure.
