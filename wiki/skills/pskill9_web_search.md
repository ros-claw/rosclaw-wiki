> 📇 🏠 - An MCP server that enables free web searching using Google search results, with no API keys required.

pskill9/web-search is an MCP server that enables free web searching by scraping Google search results, requiring no API keys. It is categorized under browser automation tools and can be integrated with AI agents through the Model Context Protocol. The server provides a simple way to perform web searches without incurring costs or setting up external search API credentials.
