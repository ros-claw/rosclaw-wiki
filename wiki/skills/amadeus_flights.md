> Query flight offers (price, schedule, availability) via Amadeus API.

This tool provides an interface to query flight offers, including price, schedule, and availability, via the Amadeus API. It enables users to search for flights and retrieve structured data for integration into larger agent systems. The dataset facilitates automated travel planning and itinerary generation.
