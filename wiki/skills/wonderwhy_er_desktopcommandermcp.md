> 📇 🏠 🍎 🪟 🐧 - A swiss-army-knife that can manage/execute programs and read/write/search/edit code and text files.

DesktopCommanderMCP is a Model Context Protocol server that acts as a Swiss-army-knife for coding agents. It provides tools to manage and execute programs, as well as read, write, search, and edit code and text files. Designed for integration with AI coding agents, it enables direct control over the desktop environment for software development tasks.
