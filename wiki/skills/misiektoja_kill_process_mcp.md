> 🐍 🏠 🍎 🪟 🐧 - List and terminate OS processes via natural language queries

This project is an MCP (Model Context Protocol) server that allows AI agents to list and terminate operating system processes using natural language queries. It supports multiple platforms including Windows, macOS, and Linux. The tool integrates with coding agents to enable process management through conversational commands. It provides a simple interface for agents to inspect and kill processes without requiring direct system commands.
