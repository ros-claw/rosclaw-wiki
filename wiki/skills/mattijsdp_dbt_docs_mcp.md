> 🐍 🏠 - MCP server for dbt-core (OSS) users as the official dbt MCP only supports dbt Cloud. Supports project metadata, model and column-level lineage and dbt documentation.

The dbt-docs-mcp project is an MCP server for dbt-core (open source) users, providing project metadata, model and column-level lineage, and dbt documentation. It serves as an alternative to the official dbt MCP which only supports dbt Cloud. This tool integrates with the Model Context Protocol to offer data platform capabilities.
