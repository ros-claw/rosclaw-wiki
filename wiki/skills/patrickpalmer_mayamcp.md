> 🐍 🏠 - MCP server for Autodesk Maya

MayaMCP is an MCP (Model Context Protocol) server that connects AI assistants to Autodesk Maya, a leading 3D animation and modeling software. It allows AI tools to interact with Maya scenes, execute commands, and manipulate 3D assets programmatically. This integration enables artists and developers to automate workflows, generate scenes, or receive AI-assisted guidance within Maya. The project is listed under Art & Culture server implementations, highlighting its creative applications in digital content creation.
