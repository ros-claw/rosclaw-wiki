Nobulex is an MCP server that enforces proof-of-behavior for AI agents. It allows defining behavioral covenant rules (permit, forbid, require) and enforces them at runtime before any action is executed. The system generates tamper-evident audit logs using SHA-256 hash chaining, and enables independent compliance verification. It also supports a cross-agent verification handshake: no proof, no transaction. The project is MIT licensed and includes over 4,000 tests.
