> 🦀 🏠 🍎 🪟 🐧 - Playwright for terminals - interact with TUI/CLI applications through structured Terminal State Tree representation with element detection.

This MCP server enables AI agents to interact with terminal-based applications, much like Playwright does for web browsers. It provides a structured Terminal State Tree representation of the terminal's current state, including element detection, allowing agents to identify and interact with UI components in TUI/CLI applications. The server supports multiple platforms such as macOS, Windows, and Linux. It is specifically designed for coding agents and AI systems that need to control terminal tools or applications programmatically.
