> A comprehensive linter for Claude Code agent files. Validate CLAUDE.md, AGENTS.md, SKILL.md, hooks, MCP, and more. Plugin for all major IDEs included, with auto-fixes.

Agnix is a comprehensive linter designed for Claude Code agent files. It validates configuration files such as CLAUDE.md, AGENTS.md, SKILL.md, hooks, and MCP definitions. The tool includes plugins for all major IDEs and provides auto-fix capabilities to correct common issues. It helps developers maintain consistent and correct agent configurations.
