> 📇 🏠 🍎 🪟 🐧 — Full-featured utility to test Next.js projects for unused files and APIs, with an MCP server that exposes project analysis tools to AI assistants.

vibealive is a developer utility for detecting unused files and APIs in Next.js projects. It provides a comprehensive testing tool that identifies redundant code, helping developers streamline their codebase. Additionally, it includes an MCP server that exposes project analysis tools to AI assistants, enabling them to offer more informed suggestions for optimization and refactoring.
