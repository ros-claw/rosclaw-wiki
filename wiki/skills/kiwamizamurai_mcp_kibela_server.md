> 📇 ☁️ Powerfully interact with Kibela API.

This MCP server enables AI agents to interact with the Kibela API for team collaboration and knowledge management. It allows reading, writing, and searching wiki pages and comments via the Model Context Protocol. The server uses the official Kibela GraphQL API to perform operations. It is designed for integration with AI assistants like Claude, enabling natural language control of Kibela content.
