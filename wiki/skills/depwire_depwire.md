depwire provides a dependency graph and 15 MCP tools for AI coding assistants. It parses TypeScript, JavaScript, Python, Go, Rust, and C, and offers features like arc diagram visualization, health scoring, dead code detection, and temporal graph analysis. This tool helps AI assistants understand code structure, detect unused code, and monitor dependency evolution over time.
