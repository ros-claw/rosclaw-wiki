> 🐍 ☁️ - An MCP server to search Hacker News, get top stories, and more.

This server implements the Model Context Protocol to provide access to Hacker News data. It enables searching stories, fetching top stories, and retrieving details from Hacker News. The tool is designed for AI agents to interact with Hacker News programmatically. It is listed under Search & Data Extraction in the official MCP server directory.
