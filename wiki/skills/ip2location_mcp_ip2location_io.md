> 🐍 ☁️  - Official IP2Location.io MCP server to obtain the geolocation, proxy and network information of an IP address utilizing IP2Location.io API.

This project provides an official MCP server for IP2Location.io, allowing AI agents to query geolocation, proxy, and network information for any IP address. It uses the IP2Location.io API to return detailed location data, including country, region, city, and ISP. The server is designed for integration with AI systems that need IP intelligence for localization, security analysis, or network diagnostics.
