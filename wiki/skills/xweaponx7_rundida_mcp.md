rundida-mcp is an MCP server that provides AI agents with access to over 86 running-related calculators, including pace, time, and distance conversions, race time predictions using the Riegel formula, and heart rate training zones via the Karvonen method. It also offers data on 29 marathon events. No API key is required to use this server, making it easily accessible for agents needing running calculations.
