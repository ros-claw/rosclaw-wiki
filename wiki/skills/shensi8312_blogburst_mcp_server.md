> 📇 ☁️ - AI content generation, repurposing, and multi-platform publishing with [BlogBurst](https://blogburst.ai). Generate blogs, repurpose content for 9+ platforms (Twitter, LinkedIn, Reddit, Bluesky, Threads, Telegram, Discord, TikTok, YouTube), get trending topics, and publish directly.

This project is an MCP server for BlogBurst, an AI-powered tool that generates and repurposes content for multiple platforms. It enables publishing directly to platforms like Twitter, LinkedIn, Reddit, and more. Users can generate blog posts, automate content repurposing, and access trending topics. The server integrates with AI agents to streamline marketing workflows.
