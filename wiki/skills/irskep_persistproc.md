> 🐍 🏠 - MCP server + command line tool that allows agents to see & control long-running processes like web servers. Start, stop, restart, read logs.

Persistproc is an MCP server and command-line tool that enables AI agents to manage long-running processes such as web servers. It provides start, stop, restart, and log-reading capabilities, allowing agents to control persistent services. The tool is designed for coding agent environments where long-lived background processes are needed. It integrates with the Model Context Protocol (MCP) to give agents a standardized interface for process management.
