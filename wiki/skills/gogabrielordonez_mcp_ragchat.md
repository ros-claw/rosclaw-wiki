> 📇 🏠 - Add RAG-powered AI chat to any website with one command. Local vector store, multi-provider LLM (OpenAI/Anthropic/Gemini), self-contained chat server and embeddable widget.

This project provides a self-contained server and embeddable widget to add a RAG-powered AI chat to any website. It includes a local vector store and supports multiple LLM providers like OpenAI, Anthropic, and Gemini. The chat is designed to be easily deployed with a single command, making it accessible for non-technical users. It leverages the Model Context Protocol (MCP) for integration with AI agents.
