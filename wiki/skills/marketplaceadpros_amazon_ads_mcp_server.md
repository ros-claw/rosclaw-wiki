> 📇 ☁️  - Enables tools to interact with Amazon Advertising, analyzing campaign metrics and configurations.

This MCP server enables tools to interact with Amazon Advertising, allowing analysis of campaign metrics and configurations. It provides a standardized interface for integrating Amazon Ads data into AI agents and applications. The server supports querying ad performance, managing campaigns, and retrieving configuration details. It is listed under marketing server implementations, making it suitable for AI-driven marketing tools.
