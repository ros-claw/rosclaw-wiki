> 📇 ☁️ 🍎 🪟 🐧 - MCP server exposing the full Procore REST API (2,636 endpoints) for construction project management. Includes 7 discovery and execution tools covering projects, RFIs, submittals, daily logs, budgets, and more. Single-user OAuth with auto-refresh.

This MCP server exposes the full Procore REST API (2,636 endpoints) for construction project management. It includes seven tools for discovering and executing tasks related to projects, RFIs, submittals, daily logs, and budgets. The server uses single-user OAuth with automatic token refresh for authentication. It is designed to integrate Procore's capabilities into AI-agent workflows, enabling automated construction management interactions.
