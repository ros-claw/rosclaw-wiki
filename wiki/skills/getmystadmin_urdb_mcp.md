> [![urdb-mcp MCP server](https://glama.ai/mcp/servers/GetMystAdmin/urdb-mcp/badges/score.svg)](https://glama.ai/mcp/servers/GetMystAdmin/urdb-mcp) 📇 🏠 - Search URDB's product integrity database for integrity scores, enshittification events, and change tracking across consumer products

GetMystAdmin/urdb-mcp is an MCP server that provides access to URDB, a product integrity database for consumer products. It allows users to search for integrity scores, track enshittification events, and monitor changes over time. This tool helps evaluate product quality and reliability by querying the database through the Model Context Protocol.
