> 🎖️ 📇 ☁️ Enable AI Agents to fix Playwright test failures reported to [Currents](https://currents.dev).

Currents MCP is a server implementation that connects AI agents to Playwright test results managed by Currents, a test reporting platform. By exposing test failure data through the Model Context Protocol, it enables AI agents to analyze and automatically fix failing Playwright tests. This tool bridges the gap between test automation and AI-driven debugging, allowing developers to streamline test maintenance.
