AI-driven demo recording with scroll/click/hover interactions via Playwright + ffmpeg. `npx @mcpware/pagecast`

Pagecast is an MCP server that records any browser page as a GIF or video. It leverages Playwright to simulate user interactions like scrolling, clicking, and hovering, then uses ffmpeg for encoding. This tool is designed for AI-driven demo recording, making it useful for creating tutorials or documentation. It can be executed via npx with the command `npx @mcpware/pagecast`.
