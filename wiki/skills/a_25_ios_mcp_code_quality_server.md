> 📇 🏠 🍎 - iOS code quality analysis and test automation server. Provides comprehensive Xcode test execution, SwiftLint integration, and detailed failure analysis. Operates in both CLI and MCP server modes for direct developer usage and AI assistant integration.

This is a Model Context Protocol (MCP) server for iOS code quality analysis and test automation. It provides comprehensive Xcode test execution, SwiftLint integration, and detailed failure analysis. The tool operates in both CLI and MCP server modes, enabling direct developer usage and AI assistant integration. It helps maintain code quality in iOS development workflows by integrating static analysis and test automation.
