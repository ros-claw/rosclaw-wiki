> 🐍 ☁️ - MCP server for interacting with NetBox API.

This project provides a Model Context Protocol (MCP) server for interacting with the NetBox API. NetBox is an open-source tool for IP address management (IPAM) and data center infrastructure management (DCIM). The MCP server allows AI agents and MCP-compatible clients to query and manage NetBox resources such as devices, IP addresses, and sites. It enables seamless integration of NetBox data into AI-driven workflows and automation tasks.
