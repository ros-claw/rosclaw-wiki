> ☕ 🐍 ☁️ - MCP service for Tablestore, features include adding documents, semantic search for documents based on vectors and scalars, RAG-friendly, and serverless.

This project provides an MCP server for Alibaba Cloud Tablestore, enabling users to add documents and perform semantic search using vectors and scalar filters. It is designed to be RAG-friendly and operates as a serverless service, making it suitable for building retrieval-augmented generation applications. The server integrates with the Model Context Protocol to allow AI agents to access structured data stored in Tablestore.
