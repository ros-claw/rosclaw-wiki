> [![rancher-mcp-server MCP server](https://glama.ai/mcp/servers/mrostamii/rancher-mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/mrostamii/rancher-mcp-server) 🏎️ ☁️/🏠 - MCP server for the Rancher ecosystem with multi-cluster Kubernetes operations, Harvester HCI management (VMs, storage, networks), and Fleet GitOps tooling.

This project implements a Model Context Protocol (MCP) server for the Rancher ecosystem, enabling AI agents to manage multi-cluster Kubernetes operations, Harvester hyperconverged infrastructure (including VMs, storage, and networks), and Fleet GitOps tooling. It is listed under Cloud Platforms in the MCP server directory. Administrators can use it to orchestrate Rancher-managed clusters and resources programmatically through AI assistants.
