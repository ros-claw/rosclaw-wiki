> [![AiAgentKarl/solana-mcp-server MCP server](https://glama.ai/mcp/servers/AiAgentKarl/solana-mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/AiAgentKarl/solana-mcp-server) 🐍 🏠 - Solana blockchain data for AI agents — wallet balances, token prices, DeFi yields (Raydium + Orca), and token safety checks (RugCheck scores, holder concentration, insider detection).

This MCP server enables AI agents to query Solana blockchain data, including wallet balances, real-time token prices, and DeFi yields from liquidity pools on Raydium and Orca. It also provides token safety checks via RugCheck scores, holder concentration analysis, and insider detection. Designed for financial and fintech applications, the server helps agents make informed decisions based on on-chain data.
