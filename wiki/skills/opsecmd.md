> A swift reminder of both human and agent duties regarding operational security.

opsecmd is a tool that provides quick reminders about operational security for both human users and AI agents. It covers key duties and practices to maintain security in operations involving humans and autonomous agents. The project aims to prevent common security lapses by offering concise, actionable guidance. It serves as a reference for integrating security awareness into daily workflows.
