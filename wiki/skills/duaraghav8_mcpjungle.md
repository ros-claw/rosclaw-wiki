> 🏎️ 🏠 - Self-hosted MCP Server registry for enterprise AI Agents

MCPJungle is a self-hosted registry for MCP (Model Context Protocol) servers, designed for enterprise AI agents. It enables organizations to manage, discover, and share internal or private MCP server configurations securely. The project aggregates server listings and provides a central catalog for AI agents to consume, emphasizing self-hosting and enterprise control. It is listed under server implementation aggregators.
