> 🐍 🏠 🍎 🪟 🐧 An MCP server that indexes local code into a graph database to provide context to AI assistants with a graphical code visualizations for humans.

This MCP server indexes local codebases into a graph database to provide structured context to AI coding assistants. It enables AI tools to understand code structure, dependencies, and relationships within a project. Additionally, it offers graphical visualizations for human developers to explore the code graph. The tool supports multiple operating systems including macOS, Windows, and Linux. It is designed to enhance AI-assisted code understanding and navigation.
