> A community-driven leaderboard tool that enables developers to visualize, track, and compete based on their Claude Code usage statistics. It features robust data analytics, GitHub OAuth, data validation, and user-friendly CLI/web submission methods.

viberank is a community-driven leaderboard tool that allows developers to visualize, track, and compete based on their Claude Code usage statistics. It features robust data analytics, GitHub OAuth authentication, data validation, and both CLI and web submission methods. This tool fosters a competitive and engaging environment among developers by turning usage data into a game-like leaderboard. It is designed to be user-friendly and encourages community participation.
