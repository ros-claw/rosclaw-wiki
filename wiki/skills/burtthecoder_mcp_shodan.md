> 📇 🪟 ☁️ - MCP server for querying the Shodan API and Shodan CVEDB. This server provides tools for IP lookups, device searches, DNS lookups, vulnerability queries, CPE lookups, and more.

This is an MCP server that connects to the Shodan API and Shodan CVEDB, enabling users to query IP information, search for devices, perform DNS lookups, find vulnerabilities, and look up CPE data. It's designed for security researchers and network administrators to integrate Shodan's threat intelligence into AI agents and automated workflows. The server exposes tools that can be used directly from AI assistants like Claude.
