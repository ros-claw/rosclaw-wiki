> 🐍 🏠 - Compresses ~100K-token HTML into 2-5K-token structured maps while preserving every actionable element. AI agents can read and interact with any web page at 97% fewer tokens.

Pagemap is a tool that compresses large HTML documents (approximately 100,000 tokens) into compact structured maps of only 2,000-5,000 tokens, while preserving every interactive or actionable element. This enables AI agents to read and interact with web pages using up to 97% fewer tokens, greatly reducing costs and improving efficiency in browser automation tasks.
