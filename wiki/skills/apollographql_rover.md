Rover is a command-line tool for managing Apollo GraphQL schemas and federated services. It allows you to validate schema changes, compose supergraphs, and interact with Apollo Studio's schema registry. Rover simplifies the workflow for teams using Apollo Federation by providing commands for schema checks, composition, and publishing. It is designed to integrate into CI/CD pipelines to enforce schema governance.
