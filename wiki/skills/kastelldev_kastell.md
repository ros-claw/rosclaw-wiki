This MCP server is a comprehensive security auditing and hardening toolkit. It performs 413 security checks across 29 categories such as SSH, firewall, Docker, TLS, and HTTP headers. It maps results to compliance standards like CIS, PCI-DSS, and HIPAA, and includes a 19-step production hardening process. The server also supports fleet management, forensic evidence collection, and works with multiple cloud providers.
