> 🏎️ 🏠 🍎 🪟 🐧 - MCP server which provides utilities to work with time and dates, with natural language, multiple formats and timezone convertion capabilities.

TheoBrigitte/mcp-time is a Model Context Protocol (MCP) server that provides time and date utility functions. It supports natural language parsing of dates and times, handles multiple input/output formats, and offers timezone conversion capabilities. Designed to integrate with AI agents, it enables them to perform time-related operations easily.
