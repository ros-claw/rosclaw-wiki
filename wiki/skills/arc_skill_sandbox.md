> Test untrusted skills in an isolated environment before installing.

This project provides a sandbox environment for testing untrusted skills before installation. It aims to prevent potential security risks by isolating skill execution from the main system. Users can evaluate skill behavior and performance without affecting production settings. The tool is likely intended for AI agents or systems that support skill extensions.
