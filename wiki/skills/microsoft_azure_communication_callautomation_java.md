This is a Java SDK for Microsoft Azure Communication Services Call Automation, allowing developers to build automated call workflows such as interactive voice response (IVR) systems. It provides APIs to manage calls, play audio, recognize input, and integrate with other Azure services. The library is designed for server-side applications needing programmable telephony features.
