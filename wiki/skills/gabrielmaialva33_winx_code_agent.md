> 🦀 🏠 - A high-performance Rust reimplementation of WCGW for code agents, providing shell execution and advanced file management capabilities for LLMs via MCP.

This project is a high-performance Rust reimplementation of the WCGW tool, designed for AI coding agents. It enables large language models to execute shell commands and perform advanced file management operations through the Model Context Protocol (MCP). The system focuses on providing efficient and reliable access to system-level operations for autonomous code agents.
