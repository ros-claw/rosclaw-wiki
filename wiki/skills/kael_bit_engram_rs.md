Single Rust binary, zero external dependencies.

engram-rs is a hierarchical memory engine for AI agents implemented in Rust. It features automatic memory decay and promotion, semantic deduplication, and a self-organizing topic tree. The system runs as a single Rust binary with zero external dependencies, making it lightweight and portable. It is designed to provide AI agents with structured, long-term memory capabilities for improved context retention and knowledge organization.
