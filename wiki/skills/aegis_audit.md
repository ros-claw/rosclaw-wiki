> Deep behavioral security audit for AI agent skills and MCP tools.

Aegis-audit is a tool designed for deep behavioral security audits of AI agent skills and MCP (Model Context Protocol) tools. It goes beyond static code analysis to examine how agents and tools behave in practice, identifying potential security risks in their actions and interactions. The audit focuses on detecting unsafe patterns, privilege escalation, data leakage, and other behavioral vulnerabilities. This helps developers ensure their AI agents operate securely and as intended.
