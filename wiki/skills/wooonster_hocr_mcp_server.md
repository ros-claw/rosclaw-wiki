> 🐍 🏠 – A fastAPI-based FastMCP server with a Vue frontend that sends uploaded images to VLM via the MCP to quickly extract handwritten mathematical formulas as clean LaTeX code.

This project provides a FastAPI-based server that implements the FastMCP protocol, paired with a Vue frontend. It allows users to upload images of handwritten mathematical expressions, which are then sent to a Vision Language Model via MCP to generate clean LaTeX code. The tool is designed for developers needing quick and accurate formula extraction from images, integrating a modern web interface with an AI backend. It falls under the developer tools category and aims to streamline the conversion of raw handwriting into structured mathematical notation.
