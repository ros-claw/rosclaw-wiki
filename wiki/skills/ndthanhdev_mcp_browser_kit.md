> 📇 🏠 - An MCP Server that enables AI assistants to interact with your local browsers.

This project is a Model Context Protocol (MCP) server that allows AI assistants to control and interact with local browsers. It provides tools for navigating web pages, clicking elements, filling forms, and extracting page content. The server acts as a bridge between AI agents and browser automation, enabling tasks like web scraping, testing, and automated workflows. It is designed to work with MCP-compatible clients such as Claude Desktop and other AI assistants.
