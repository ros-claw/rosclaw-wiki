> 🌊 🏠 📟 🐧 🪟 🍎 - A single-binary MCP server that converts source code into AST, regardless of language.

This MCP server converts source code from any language into an Abstract Syntax Tree (AST) as a single binary. It supports multiple operating systems including Linux, macOS, and Windows. Designed for integration with coding agents, it provides a standardized way to analyze code structure regardless of programming language. The server aids in automated code understanding, refactoring, and tool-assisted development workflows.
