> 📇 🏠 🍎 - Connect to Perplexity Comet browser for agentic web browsing, deep research, and real-time task monitoring.

This project, comet-mcp by hanzili, provides a server implementation that connects to Perplexity's Comet browser via the Model Context Protocol (MCP). It enables agentic web browsing, allowing AI agents to perform deep research and real-time task monitoring through the browser. The integration leverages the Comet browser's capabilities for automated, intelligent web navigation and data collection. This tool is aimed at developers building browser automation and AI-driven research workflows.
