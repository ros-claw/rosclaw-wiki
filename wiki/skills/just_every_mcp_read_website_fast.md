> 📇 🏠 - Fast, token-efficient web content extraction for AI agents - converts websites to clean Markdown while preserving links. Features Mozilla Readability, smart caching, polite crawling with robots.txt support, and concurrent fetching.

This project provides a fast web content extraction tool designed for AI agents. It converts website content into clean Markdown format, preserving links, while minimizing token usage. Key features include Mozilla Readability for article extraction, smart caching to reduce redundant fetches, polite crawling with robots.txt compliance, and concurrent fetching for speed. It is particularly useful for AI systems that need to efficiently ingest web data.
