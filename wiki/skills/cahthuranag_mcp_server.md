> [![cahthuranag/mcp-server MCP server](https://glama.ai/mcp/servers/cahthuranag/mcp-server/badges/score.svg)](https://glama.ai/mcp/servers/cahthuranag/mcp-server) 📇 ☁️ - AllRatesToday currency exchange rates: real-time mid-market rates for 160+ currencies (Reuters/Refinitiv), historical data (1d/7d/30d/1y), currency list, and multi-target lookups. Free tier, no key needed for the simple-rate endpoint. Install: `npx @allratestoday/mcp-server`.

This project provides a MCP server that gives access to real-time mid-market currency exchange rates for over 160 currencies using data from Reuters/Refinitiv. It also supports historical rate lookups for periods of 1 day, 7 days, 30 days, and 1 year, along with a currency list and multi-target rate comparisons. The free tier is available without an API key for a simple rate endpoint. Installation is done via npx, making it easy to integrate into MCP-compatible applications.
