> 🐍 ☁️ - Implementation of MCP server for [Kestra](https://kestra.io) workflow orchestration platform.

This Python package implements an MCP (Model Context Protocol) server for the Kestra workflow orchestration platform, enabling AI agents to interact with Kestra. It allows agents to manage workflows, executions, and other Kestra resources through standardized MCP tools. This integration facilitates automation and intelligent orchestration within the Kestra ecosystem. The server is listed under Cloud Platforms in the MCP server implementations directory.
