> ![GitHub stars](https://img.shields.io/github/stars/supratikpm/gemini-autoresearch?style=social) - Gemini CLI skill that generalises autoresearch to any measurable goal. Gemini-native: uses Google Search grounding as a live verification source inside the loop, true headless overnight mode via --yolo --prompt, and 1M token context. Also works in Antigravity IDE via .agents/skills/.

This project is a CLI skill for Google's Gemini that automates research towards any measurable goal. It uses live Google Search grounding for verification and supports fully autonomous headless operation with —yolo —prompt flags. The tool can handle up to 1 million tokens of context and integrates with the Antigravity IDE via an agents skill file. It generalizes autoreasearch into a flexible tool for automated data collection and analysis.
