Schema Markup is a TypeScript library for generating structured data markup for web pages. It focuses on creating schema.org JSON-LD formats to improve SEO. The library provides simple APIs to define entities and their properties. It aims to make schema markup easier for developers. This project is part of the TypeScript Skills sponsorship program.
