> 🎖️ 🏎️ 🏠 - Provides comprehensive integration with your [VictoriaLogs instance APIs](https://docs.victoriametrics.com/victorialogs/querying/#http-api) and [documentation](https://docs.victoriametrics.com/victorialogs/) for working with logs, investigating and debugging tasks related to your VictoriaLogs instances.

This MCP server provides comprehensive integration with VictoriaLogs instance APIs, allowing users to query, investigate, and debug logs. It connects to VictoriaLogs documentation and HTTP APIs for log management tasks. Listed under Databases, it enables efficient log analysis and troubleshooting. The server acts as a bridge between MCP clients and VictoriaLogs for real-time log operations.
