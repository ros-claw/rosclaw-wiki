> 🐍 ☁️ - Access Chess.com player data, game records, and other public information through standardized MCP interfaces, allowing AI assistants to search and analyze chess information.

This project is an MCP server that allows AI assistants to access public data from Chess.com, including player statistics and game records. It provides standardized interfaces for searching and analyzing chess information. The server can be integrated with MCP clients to enable AI-driven chess data queries.
