The harvest-mcp-server is a server implementation of the Model Context Protocol (MCP) that integrates with the Harvest time tracking service. It provides over 40 tools to manage time entries, projects, clients, and tasks directly from AI assistants. The server also enables generating time reports via the Harvest API v2, making it easy to track work hours and productivity within AI-powered workflows.
