> Sync OpenRouter models used by OpenClaw into this installation's config.

This tool synchronizes the OpenRouter models used by the OpenClaw agent into the configuration of the current installation. It helps keep the list of available models up to date by fetching the latest models from OpenRouter and updating a config file. This ensures that OpenClaw can access the correct set of models without manual configuration. It is designed for users of OpenClaw who rely on OpenRouter for language model access.
