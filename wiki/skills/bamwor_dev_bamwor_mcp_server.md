Powered by Bamwor API.

This MCP server provides world geographic data for AI agents. It includes information on 261 countries with over 20 statistics each, and 13.4 million cities with population, coordinates, and timezone data. The data is powered by the Bamwor API, allowing AI agents to access location-based information easily.
