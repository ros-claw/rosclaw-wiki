> [![Wireshark-MCP MCP server](https://glama.ai/mcp/servers/bx33661/Wireshark-MCP/badges/score.svg)](https://glama.ai/mcp/servers/bx33661/Wireshark-MCP) 🐍 🏠 - Wireshark network packet analysis MCP Server with capture, protocol stats, field extraction, and security analysis capabilities.

Wireshark-MCP is an MCP server that integrates Wireshark's network packet analysis capabilities, enabling capture, protocol statistics, field extraction, and security analysis through the Model Context Protocol. It provides a programmatic interface for automation tools to interact with network traffic data. This project is listed under the Security category of server implementations. It simplifies incorporating deep packet inspection into AI-agent workflows.
