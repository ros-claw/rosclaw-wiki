> 🏠 - Gradle integration using the Gradle Tooling API to inspect projects, execute tasks, and run tests with per-test result reporting

This project implements a Model Context Protocol (MCP) server for Gradle, enabling AI agents to interact with Gradle projects. It uses the Gradle Tooling API to inspect project structures, execute tasks, and run tests with detailed per-result reporting. This allows AI tools to automate build tasks, analyze test outcomes, and integrate with Gradle-based workflows.
