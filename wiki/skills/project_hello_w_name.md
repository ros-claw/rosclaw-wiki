> Creates customizable greeting components with name input, demonstrating argument passing, component reusability, state management, and user input handling.

This project demonstrates how to create customizable greeting components that accept a name input. It illustrates core programming concepts such as passing arguments, reusing components, managing state, and handling user input. The example serves as a learning tool for building interactive, reusable UI elements in a command-based or slash-command environment.
