> 📇 ☁️ 🍎 🪟 - Get Confluence data via CQL and read pages.

This MCP server enables AI agents to retrieve data from Atlassian Confluence using Confluence Query Language (CQL) and read page contents. It serves as an integration point for AI tools to access enterprise knowledge bases. The server supports multiple operating systems including cloud, macOS, and Windows platforms. It is part of the Model Context Protocol ecosystem, specifically as a server implementation.
