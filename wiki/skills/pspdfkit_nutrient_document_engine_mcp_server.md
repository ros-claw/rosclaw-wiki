On-premises document processing with natural language control — designed for HIPAA, SOC 2, and GDPR compliance.

This project is a self-hosted MCP server for Nutrient Document Engine, enabling on-premises document processing with natural language control. It is designed to meet HIPAA, SOC 2, and GDPR compliance requirements, making it suitable for sensitive data environments. The server allows users to manage documents through natural language commands while keeping data on their own infrastructure.
