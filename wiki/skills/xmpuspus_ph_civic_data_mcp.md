> [![xmpuspus/ph-civic-data-mcp MCP server](https://glama.ai/mcp/servers/xmpuspus/ph-civic-data-mcp/badges/score.svg)](https://glama.ai/mcp/servers/xmpuspus/ph-civic-data-mcp) 🐍 ☁️ 🍎 🪟 🐧 - Philippine government data as agent-callable tools: PHIVOLCS earthquakes + volcano alerts, PAGASA weather + typhoons, PhilGEPS procurement, PSA 2020 Census population + poverty, AQICN air quality. Install: `uvx ph-civic-data-mcp`.

This MCP server provides AI agents with access to various Philippine government datasets. It includes tools for retrieving PHIVOLCS earthquake and volcano alerts, PAGASA weather and typhoon data, PhilGEPS procurement information, PSA census population and poverty statistics, and AQICN air quality measurements. The server is designed for research purposes and can be installed using the command `uvx ph-civic-data-mcp`. By exposing civic data as agent-callable tools, it enables automated analysis and decision-making.
