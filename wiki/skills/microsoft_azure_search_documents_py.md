This is the official Python SDK for Azure Cognitive Search (now Azure AI Search). It enables developers to create, manage, and query search indexes with features like vector search and semantic ranking. The library supports integration with AI agents for retrieval-augmented generation (RAG) workflows. It provides client classes for indexing documents and performing search queries asynchronously. This tool is essential for building AI-powered search capabilities into applications.
