> A Skill for searching hotels and querying prices via AIGoHotel MCP (searchHotels / getHotelDetail / getHotelSearchTags)

aihotel is a skill for AI agents to search hotels and query prices using the AIGoHotel MCP (Model Context Protocol). It provides three main functions: searchHotels, getHotelDetail, and getHotelSearchTags. This allows an AI agent to assist users in finding and comparing hotel accommodations. The skill integrates with the AIGoHotel service to fetch real-time data. It is designed to be used within an AI agent framework that supports MCP.
