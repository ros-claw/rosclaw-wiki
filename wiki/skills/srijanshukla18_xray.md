> 🐍 🏠 - Progressive code-intelligence MCP server: map project structure, fuzzy-find symbols, and assess change-impact across Python, JS/TS, and Go (powered by `ast-grep`).

This is a Model Context Protocol (MCP) server that provides progressive code-intelligence capabilities for developers. It maps project structures, allows fuzzy-finding of symbols, and assesses the impact of changes across Python, JavaScript/TypeScript, and Go codebases. Under the hood, it uses the ast-grep tool to perform static analysis. This server helps developers understand, navigate, and modify code more efficiently within their IDEs or tools that support MCP.
