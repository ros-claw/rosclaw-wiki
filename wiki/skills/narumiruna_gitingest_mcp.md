> 🐍 🏠 - A MCP server that uses [gitingest](https://github.com/cyclotruc/gitingest) to convert any Git repository into a simple text digest of its codebase.

gitingest-mcp is a server that implements the Model Context Protocol (MCP) to convert any Git repository into a plain text digest of its codebase. It uses the gitingest library to extract and summarize code files, making them easily consumable by AI assistants. This tool helps developers quickly provide context about a repository to large language models without manual file selection.
