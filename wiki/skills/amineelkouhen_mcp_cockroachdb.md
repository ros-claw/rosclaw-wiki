> 🐍 ☁️ - A Model Context Protocol server for managing, monitoring, and querying data in [CockroachDB](https://cockroachlabs.com).

This is an MCP server that enables AI agents to manage, monitor, and query CockroachDB databases. It allows AI assistants to execute SQL queries and perform database operations through a standardized protocol interface. The server is listed under the databases category of MCP server implementations.
