> Automatic security gate that checks packages against a vulnerability database before installation.

Agentaudit-skill is a tool that acts as an automatic security gate for AI agents. It checks any package before installation against a vulnerability database to prevent the use of insecure dependencies. This helps ensure that only safe and vetted packages are added to an agent's environment. It is designed to integrate into the package installation pipeline of AI agents, providing real-time security checks.
