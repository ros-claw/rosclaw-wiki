This is the Azure Management Library for Bot Service for Python, part of the Azure SDK for Python. It provides Pythonic APIs to create, update, delete, and manage Azure Bot Service resources programmatically. Developed and maintained by Microsoft, it enables developers to automate bot service lifecycle in the Azure cloud.
