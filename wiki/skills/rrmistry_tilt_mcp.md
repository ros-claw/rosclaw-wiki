> 🐍 🏠 🍎 🪟 🐧 - A Model Context Protocol server that integrates with Tilt to provide programmatic access to Tilt resources, logs, and management operations for Kubernetes development environments.

tilt-mcp is a Model Context Protocol server that connects to Tilt, a tool for local Kubernetes development. It enables LLM agents to access Tilt resources, logs, and management operations programmatically. This allows AI assistants to interact with Kubernetes development environments through Tilt's API. The server is useful for automating development workflows and debugging in cloud-native development.
