Nine Read tools: manager search, holdings lookup, portfolio similarity, consensus portfolio, market regime, sector flows. SEC EDGAR-sourced. Install `uvx the13f-mcp`.

The13f-mcp is an MCP server that provides institutional 13F intelligence tools for AI assistants like Claude Desktop, Cursor, and VS Code. It offers nine read tools including manager search, holdings lookup, portfolio similarity, consensus portfolio, market regime analysis, and sector flow data, all sourced from SEC EDGAR filings. This enables users to query and analyze institutional investment data directly through their AI-powered coding or chat interfaces.
