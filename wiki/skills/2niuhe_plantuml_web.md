> 🐍 🏠 ☁️ 🍎 🪟 🐧 - A web-based PlantUML frontend with MCP server integration, enable plantuml image generation and plantuml syntax validation.

PlantUML web is a web-based frontend for PlantUML that integrates with an MCP server. It enables users to generate UML diagrams from PlantUML code and validate PlantUML syntax. The tool is designed to run across multiple platforms including Python environments, cloud, Apple, Windows, and Linux. It provides a convenient interface for creating and checking diagrams without needing a local PlantUML installation.
