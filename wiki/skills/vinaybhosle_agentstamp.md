AgentStamp is a trust intelligence system for AI agents, offering identity stamps, reputation scoring (0-100), a registry, forensic audit trails, and A2A passports via x402 micropayments. It is implemented as an MCP server under the Security category. The service aims to enhance security and trust in agent-to-agent interactions by providing verifiable identity and reputation mechanisms. It enables forensic tracking of agent actions and supports micropayment-based access control.
