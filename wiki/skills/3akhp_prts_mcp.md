Designed for fan-creation (同人創作) AI agents. Python (stdio/Docker) and TypeScript (Streamable HTTP) implementations.

This is an MCP server for the game Arknights that allows AI agents to query the PRTS Wiki API for game data. It serves auto-synced operator archives and voice lines, making it useful for fan-creation tools. Implementations are available in both Python and TypeScript, supporting stdio/Docker and Streamable HTTP transports. The project is designed to assist AI-driven content creation related to Arknights.
