> Creates isolated git worktrees with smart directory selection and safety verification.

This project provides a tool for creating isolated Git worktrees, which allow you to work on multiple branches simultaneously without switching directories. It features smart directory selection to automatically determine where to create the worktree, and includes safety verification to prevent accidental data loss. The tool streamlines the use of Git worktrees for developers managing multiple parallel tasks or features.
