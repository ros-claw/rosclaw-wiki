This is a full-featured open-source MCP server that integrates with both Jira and Confluence. It provides 24 tools covering issue CRUD operations, sprint management, comments, transitions, user management, and wiki page editing. Designed for support and service management workflows, it allows AI agents to interact directly with Atlassian products. The server is listed on Glama.ai and is suitable for teams using MCP for tool integration.
