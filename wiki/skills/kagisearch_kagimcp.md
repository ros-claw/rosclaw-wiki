> ☁️ 📇 – Official Kagi Search MCP Server

Kagimcp is the official Model Context Protocol (MCP) server for Kagi Search. It allows AI agents to perform web searches, retrieve summaries, and fetch content through Kagi's API. This server integrates seamlessly with MCP-compatible tools, enabling efficient search and data extraction within AI workflows. It is listed under Search & Data Extraction in the MCP server directory. The project is maintained by Kagi.
