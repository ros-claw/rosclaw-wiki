ContextPulse is a local-first desktop context server for AI agents that captures screen content via OCR, voice via Whisper, keyboard/mouse activity, and clipboard. It exposes 35 MCP tools for screen capture, voice transcription, activity history, semantic memory, and project detection. Designed to run locally with zero cloud dependency, it enables AI agents to understand and respond to the user's real-time desktop environment. The project is licensed under AGPL-3.0 and targets workplace and productivity use cases.
