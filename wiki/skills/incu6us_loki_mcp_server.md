This MCP server enables direct querying of Grafana Loki for monitoring and log analysis. It supports a discovery-first workflow, allowing users to explore labels, values, and series. It executes LogQL queries without requiring the Grafana UI. It is suitable for integration with AI agents and tools that need log data.
