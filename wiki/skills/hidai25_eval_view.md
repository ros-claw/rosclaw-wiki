> [![hidai25/eval-view MCP server](https://glama.ai/mcp/servers/hidai25/eval-view/badges/score.svg)](https://glama.ai/mcp/servers/hidai25/eval-view) 🐍 🏠 🍎 🪟 🐧 - Regression testing framework for AI agents. Save golden baselines, detect behavioral drift, and block regressions in CI. Works with LangGraph, CrewAI, OpenAI, Claude, and any HTTP API.

The project provides an MCP server for regression testing of AI agents, allowing users to save golden baselines, detect behavioral drift, and block regressions in CI pipelines. It integrates with popular AI frameworks like LangGraph and CrewAI, as well as language model APIs from OpenAI and Claude. The tool helps maintain consistent agent behavior over time by comparing new outputs against saved baselines.
