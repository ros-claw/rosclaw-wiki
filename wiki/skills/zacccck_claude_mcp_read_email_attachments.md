This is an MCP server that lets Claude read email attachments from Outlook via Microsoft Graph. It can parse PDF, Word (including embedded images for multimodal analysis), Excel, and text files. The server processes attachments in memory and returns structured content directly to Claude. It is categorized as a communication server implementation.
