Navigation, references, diagnostics, rename, and file sync for AI agents.

godotlens-mcp is a Model Context Protocol (MCP) server that provides 15 semantic analysis tools for GDScript, leveraging Godot's built-in Language Server Protocol (LSP). It enables AI agents to navigate code, find references, perform diagnostics, rename symbols, and sync files within Godot projects. This integration allows developers to combine AI-driven assistance with Godot game development workflows. The tool is listed under Developer Tools in the MCP server registry.
