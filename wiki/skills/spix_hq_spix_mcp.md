Spix is an MCP server that enables AI agents to make and receive phone calls, send emails, and manage contacts using 26 tools. It provides a real phone number and voice for agents, with voice latency around 500ms using Deepgram, Claude, and Cartesia. The server can be installed via pip and offers a free tier.
