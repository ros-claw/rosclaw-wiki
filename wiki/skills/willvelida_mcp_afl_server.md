> ☁️ - MCP server that integrates with the Squiggle API to provide information on Australian Football League teams, ladder standings, results, tips, and power rankings.

This MCP server integrates with the Squiggle API to provide data on the Australian Football League, including team information, ladder standings, match results, tips, and power rankings. It is designed for use with MCP-compatible clients to query AFL data. The server allows users to access real-time and historical AFL information through a standard interface.
