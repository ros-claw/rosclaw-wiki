> 📇 ☁️ 🍎 🪟 🐧 - Access 30+ AI models (GPT-5, Claude, Gemini, Grok, DeepSeek) without API keys. Pay-per-use via x402 micropayments with USDC on Base.

This project is an MCP server that aggregates over 30 AI models, including GPT-5, Claude, Gemini, Grok, and DeepSeek. It allows users to access these models without needing API keys by using a pay-per-use model with x402 micropayments. Payments are made using USDC on the Base blockchain. The server acts as a centralized gateway for multiple AI services, simplifying access and billing.
