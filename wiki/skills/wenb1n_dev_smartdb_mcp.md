> 🐍 🏠 - A universal database MCP server supporting simultaneous connections to multiple databases. It provides tools for database operations, health analysis, SQL optimization, and more. Compatible with mainstream databases including MySQL, PostgreSQL, SQL Server, MariaDB, Dameng, and Oracle. Supports Streamable HTTP, SSE, and STDIO; integrates OAuth 2.0; and is designed for easy customization and extension by developers.

SmartDB_MCP is a universal MCP server that connects to multiple databases simultaneously, including MySQL, PostgreSQL, SQL Server, MariaDB, Dameng, and Oracle. It provides tools for database operations, health analysis, and SQL optimization. The server supports Streamable HTTP, SSE, and STDIO transport protocols and integrates OAuth 2.0 for secure authentication. Designed for easy customization and extension, it offers a unified interface for managing diverse database systems.
