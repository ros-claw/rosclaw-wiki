ReplenishRadar/MCP is a Model Context Protocol server that provides multi-channel inventory intelligence for Shopify and Amazon sellers. It offers 28 tools covering stockout risk analysis, demand forecasts, purchase order lifecycle management, and sales analytics. A key feature is human-in-the-loop: all write operations only create drafts, requiring human approval before execution. This helps sellers make informed decisions while maintaining control over inventory operations across multiple sales channels.
