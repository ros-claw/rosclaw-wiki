3dprint-oracle is an MCP server that provides a comprehensive knowledge base for 3D printing filaments and materials. It contains data on over 6,900 filaments from SpoolmanDB, including material properties, print settings, manufacturer details, and troubleshooting guides. The server offers eight tools for searching filaments, comparing materials, and diagnosing print issues. It is designed to assist users in selecting the right filament and optimizing print settings for better results.
