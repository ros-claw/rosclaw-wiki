> 📇 ☁️ - Retrieve context from your [Ragie](https://www.ragie.ai) (RAG) knowledge base connected to integrations like Google Drive, Notion, JIRA and more.

This project implements an MCP server that connects to Ragie, a RAG (Retrieval-Augmented Generation) knowledge base. It allows AI agents to retrieve context from enterprise data sources such as Google Drive, Notion, and JIRA. By exposing these integrations through the Model Context Protocol, it enables assistants to query relevant information from connected platforms. The server acts as a bridge between AI tools and an organization's existing knowledge repositories.
