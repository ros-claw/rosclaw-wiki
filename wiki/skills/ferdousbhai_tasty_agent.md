> 🐍 ☁️ - Tastyworks API integration to handle trading activities on Tastytrade

tasty-agent is a Python project that integrates with the Tastyworks API to automate trading activities on the Tastytrade platform. It provides programmatic control for managing trades, checking account information, and executing orders. Designed for algorithmic traders and financial automation enthusiasts, it enables custom trading strategies and bot integration. The open-source tool simplifies interaction with Tastytrade's brokerage services.
