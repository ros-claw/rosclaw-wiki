auth0-vue is an official Auth0 library for integrating authentication into Vue.js applications. It provides composables and components to add login, logout, user profile, and route protection. The library supports OAuth2, OpenID Connect, and token management, designed for both Vue 2 and Vue 3. It is sponsored as part of TypeScript skill development resources.
