> 🐍 - AI Agents framework with 64+ built-in tools for search, memory, workflows, code execution, and file operations. Turn any AI assistant into a multi-agent system with MCP.

PraisonAI MCP is a framework for building multi-agent AI systems, leveraging the Model Context Protocol (MCP). It includes over 64 built-in tools for tasks like search, memory, workflows, code execution, and file operations. The framework enables turning any AI assistant into a multi-agent system, facilitating complex interactions and tool use. It is listed under Frameworks and is designed for extensibility and ease of use. This allows developers to quickly create sophisticated agent-based applications.
