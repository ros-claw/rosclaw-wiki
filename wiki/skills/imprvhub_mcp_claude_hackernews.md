> 📇 🏠 ☁️ - An integration that allows Claude Desktop to interact with Hacker News using the Model Context Protocol (MCP).

This project provides a Model Context Protocol (MCP) server that allows Claude Desktop to interact with Hacker News. It enables users to search and retrieve data such as top stories, comments, and user information directly through Claude's interface. The integration is listed under Search & Data Extraction in the MCP server implementations directory. It simplifies accessing Hacker News content within the Claude Desktop environment.
