> 🎖️ 📇 🏠  - Look up IP address geolocation, network information, detect proxies and VPNs, and find abuse contact details using IPLocate.io

This is an MCP server that provides IP address geolocation and network information via IPLocate.io. It can detect proxies and VPNs, and retrieve abuse contact details for IP addresses. The server integrates with the Model Context Protocol to allow AI agents to look up location data for any IP. It supports batch lookups and returns structured data including city, region, country, and ISP. This tool is useful for security analysis, content localization, and network diagnostics.
