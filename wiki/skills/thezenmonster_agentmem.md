SQLite + FTS5, zero infrastructure. `pip install quilmem[mcp]`

Agentmem is a governed memory system for coding agents that manages knowledge through a trust lifecycle from hypothesis to active to validated to deprecated. It includes conflict detection, staleness tracking, and health scoring to maintain reliable agent memory. Built on SQLite with FTS5 full-text search, it requires zero infrastructure and can be installed via pip. It is implemented as an MCP (Model Context Protocol) server, suitable for integration with AI coding assistants.
