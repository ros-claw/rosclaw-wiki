> 🐍 🏠 - A framework for creating multi-agent systems using MCP for coordinated AI collaboration, featuring task management, shared context, and RAG capabilities.

Agent-MCP is a framework for creating multi-agent systems that use the Model Context Protocol to coordinate AI collaboration. It includes features for task management, maintaining shared context among agents, and retrieval-augmented generation (RAG). This enables multiple AI agents to work together efficiently on complex tasks. The framework is specifically designed as a server implementation for coding agents.
