> 🏎️ ☁️ - An MCP server for managing your repositories on Forgejo/Gitea server.

forgejo-mcp is a Model Context Protocol (MCP) server that provides an interface for managing repositories on Forgejo or Gitea servers. It allows AI agents or MCP-compatible clients to perform actions such as creating, listing, and configuring repositories. The server streamlines interaction with Forgejo/Gitea by exposing their API through the MCP standard. This enables automated workflows and tool integrations with these Git hosting platforms.
