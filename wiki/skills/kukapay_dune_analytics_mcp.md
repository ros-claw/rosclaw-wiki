> 🐍 ☁️ -  A mcp server that bridges Dune Analytics data to AI agents.

This MCP server enables AI agents to query Dune Analytics, a blockchain data platform. It allows agents to submit natural language queries and retrieve on-chain metrics, DeFi data, and NFT analytics. The server bridges the gap between AI tools and Dune's rich data sets, making it straightforward for agents to access financial and blockchain information.
