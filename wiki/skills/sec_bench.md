> A benchmark for evaluating LLM agents on real-world software security tasks including vulnerability reproduction and patching, stressing harness design around code execution, containerized environments, and security-aware tooling.

SEC-bench is a benchmark designed to evaluate LLM agents on real-world software security tasks. It focuses on vulnerability reproduction and patching, requiring agents to work within containerized environments and use security-aware tooling. The benchmark stresses the design of harnesses for safe code execution and emphasizes practical security scenarios.
