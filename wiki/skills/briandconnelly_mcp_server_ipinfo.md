> 🐍 ☁️  - IP address geolocation and network information using IPInfo API

This project is an MCP server that provides IP address geolocation and network information using the IPInfo API. It allows AI agents and tools to look up details such as location, ISP, and ASN for any given IP address. The server is implemented in Python and can be integrated with any MCP-compatible client. It is listed under Location Services in the server implementations registry.
