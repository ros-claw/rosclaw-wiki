Liquidiction/liquidiction-mcp is an MCP server that provides live data from Hyperliquid's HIP-4 prediction markets. It offers 10 tools for accessing odds, orderbooks, candles, trades, and portfolio positions, making it the first MCP server for on-chain prediction markets. No API keys are required to use it, lowering the barrier for AI agents to interact with decentralized finance data.
