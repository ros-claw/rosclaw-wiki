Auto-discovers Gmail, Outlook, Yahoo, iCloud. 5 composite tools: search, read, send, reply, forward. Multi-account support.

better-email-mcp is an MCP server that provides email capabilities to AI agents using IMAP/SMTP and app passwords, without requiring OAuth2. It automatically detects server settings for major providers like Gmail, Outlook, Yahoo, and iCloud, and offers five composite tools: search, read, send, reply, and forward. The server supports multiple email accounts simultaneously, enabling seamless email management within AI workflows. This simplifies integration for agents that need to handle email tasks securely and efficiently.
