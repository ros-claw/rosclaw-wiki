> ☁️ - MCP server for Blockchain Data. It provides access to Tatum's blockchain API across 130+ networks with tools including RPC Gateway and Blockchain Data insights.

This project is a Model Context Protocol (MCP) server that provides access to Tatum's blockchain API. It supports over 130 blockchain networks and offers tools such as an RPC Gateway and Blockchain Data insights. Developers can use it to integrate blockchain data into AI agents and applications, enabling fintech and finance use cases. The server simplifies querying balances, transactions, and other on-chain information across multiple blockchains.
