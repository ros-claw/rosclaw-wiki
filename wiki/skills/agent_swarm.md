> IMPORTANT: OpenRouter is required.

Agent-swarm is a project that enables the orchestration of multiple AI agents in a swarm configuration. It relies on OpenRouter as a required dependency to route requests to various AI models. The tool allows for coordinated multi-agent behavior, likely for tasks that benefit from parallel or collaborative AI processing. OpenRouter integration simplifies model selection and API management for the swarm.
