Install via `npx rakuten-mcp`.

rakuten-mcp is a Model Context Protocol (MCP) server that integrates with Rakuten, Japan's largest e-commerce platform. It enables AI agents to search for products, book hotels and travel, and look up recipes via Rakuten's API. The server can be quickly installed using npx rakuten-mcp. This tool is categorized under E-Commerce server implementations.
