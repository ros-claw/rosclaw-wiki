AgentPay is a payment gateway designed for autonomous AI agents. It provides a single gateway key for tool discovery, auto-provisioning, and pay-per-call metering. It supports both Stripe for traditional payments and x402 USDC for fully autonomous wallet funding. This enables AI agents to pay for tools on a per-call basis without human intervention.
