> Query the BCRA (Banco Central de la República Argentina) Central de Deudores API to check the credit status.

This tool provides a simple way to query the BCRA Central de Deudores API, which stores credit information for individuals and businesses in Argentina. It allows users to check the credit status of a person or company by looking up their tax ID (CUIL/CUIT). The API returns data such as outstanding debts, defaults, and other credit-related details. This client simplifies authentication and request handling, making it easier to integrate this financial data into applications.
