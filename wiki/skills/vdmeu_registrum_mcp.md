This MCP server provides access to UK Companies House data through the Registrum API, enabling users to search for companies and retrieve enriched profiles. It parses structured financials from iXBRL filings, tracks director histories, and generates corporate network graphs. Designed for financial analysis and due diligence, it integrates with AI agents via the Model Context Protocol.
