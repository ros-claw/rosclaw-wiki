> [![substack-mcp MCP server](https://glama.ai/mcp/servers/conorbronsdon/substack-mcp/badges/score.svg)](https://glama.ai/mcp/servers/conorbronsdon/substack-mcp) 📇 ☁️ - MCP server for Substack — read posts, manage drafts, publish Notes, get comments, and upload images. Safe by design: cannot publish or delete posts.

The Substack MCP server provides an interface to interact with Substack, enabling reading posts, managing drafts, publishing Notes, retrieving comments, and uploading images. It is built with safety in mind, intentionally omitting capabilities to publish or delete posts. This server is categorized under social media integrations for MCP, making it a useful tool for content management on the Substack platform.
