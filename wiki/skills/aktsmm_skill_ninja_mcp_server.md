> 📇 🏠 🍎 🪟 🐧 - Agent Skill Ninja for MCP: Search, install, and manage AI agent skills (SKILL.md files) from GitHub repositories. Features workspace analysis for personalized recommendations and supports 140+ pre-indexed skills.

This is an MCP server that helps AI agents search, install, and manage skills (SKILL.md files) from GitHub repositories. It features workspace analysis to provide personalized skill recommendations and supports over 140 pre-indexed skills. The server works across Mac, Windows, and Linux platforms, and is categorized under Developer Tools.
