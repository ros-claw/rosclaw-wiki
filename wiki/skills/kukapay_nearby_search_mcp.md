> 🐍 ☁️ - An MCP server for nearby place searches with IP-based location detection.

This project provides an MCP (Model Context Protocol) server that enables nearby place searches using automatic IP-based location detection. It exposes tools for AI assistants to find points of interest around the user's current location without manual coordinates. The server integrates with standard MCP clients, making it easy to add location awareness to AI agents. It likely supports configurable search radius and categories for flexible queries.
