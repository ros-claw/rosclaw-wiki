This MCP server enables fetching content from login-protected web pages such as Notion, Google Docs, Jira, and Confluence. It works by opening a real browser to handle authentication and caches the session persistently, avoiding repeated logins. This tool is categorized under browser automation in the MCP server catalog and is useful for automated content retrieval from authenticated sites.
