> Real-time cost observability for OpenClaw agents — track tokens, costs, messages, and model usage. Includes Claude Code [skill](https://github.com/mnfst/manifest/blob/main/skills/manifest/SKILL.md) for guided setup. Self-hosted, OTLP ingestion, 28+ LLM models. ([Website](https://manifest.build))

Manifest is a real-time cost observability tool designed for AI agents, particularly those using Claude. It tracks tokens, costs, messages, and model usage across 28+ LLM models. The tool is self-hosted and ingests data via OpenTelemetry (OTLP). It includes a guided setup skill for Claude Code. Manifest helps developers monitor and optimize their AI agent expenses.
