> Spawn and control multiple Claude Codes in parallel from your phone or desktop. Happy Coder runs Claude Code on your hardware, sends push notifications when Claude needs more input or permission, and costs nothing.

Happy Coder is a free orchestration tool that lets users spawn and control multiple Claude Code instances in parallel from a phone or desktop. It runs Claude Code on the user's own hardware and sends push notifications when Claude requires input or permissions. This tool falls under the category of orchestrators, which manage and coordinate multiple AI coding agents.
