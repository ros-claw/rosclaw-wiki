> 🏎️ ☁️ 🐧 - A simple memory tool for coding agents using DuckDB and VoyageAI.

simplemem is a lightweight memory tool designed for AI coding agents, enabling them to store and retrieve contextual information over time. It uses DuckDB as a local database backend for efficient storage and VoyageAI for generating embeddings to enable semantic search. The tool is intended to provide persistent, simple memory capabilities that can enhance the reasoning and context-awareness of coding agents.
