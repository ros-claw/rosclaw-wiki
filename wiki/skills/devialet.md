> Control Devialet Phantom speakers via HTTP API.

Devialet is a project that allows users to control Devialet Phantom speakers through an HTTP API. It provides a programmatic interface to adjust volume, power, and other speaker settings. This enables integration with home automation systems or custom scripts.
