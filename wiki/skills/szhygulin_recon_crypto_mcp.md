recon-crypto-mcp is an MCP server that lets AI agents manage self-custodial cryptocurrency portfolios. It reads EVM wallet balances, ENS names, token prices, and DeFi positions across Ethereum, Arbitrum, Polygon, and Base. It supports major protocols like Aave V3, Compound V3, Morpho Blue, Uniswap V3 LP, Lido, and EigenLayer, and provides health-factor alerts and protocol risk scores. The tool prepares unsigned transactions for actions like supply, borrow, repay, withdraw, stake, send, and LiFi swaps/bridges, which are then signed on a Ledger via WalletConnect, ensuring private keys never leave the hardware wallet.
