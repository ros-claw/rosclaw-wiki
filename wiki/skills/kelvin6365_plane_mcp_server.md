> 🏎️ 🏠 This MCP Server will help you to manage projects and issues through [Plane's](https://plane.so) API

This MCP server integrates with Plane.so's API to allow AI agents to manage projects and issues directly. It provides a tool-based interface for creating, updating, and retrieving project tasks within the Plane platform. The server is listed under 'Other Tools and Integrations' in the MCP server ecosystem. This enables automated workflows and AI-assisted project management through natural language commands.
