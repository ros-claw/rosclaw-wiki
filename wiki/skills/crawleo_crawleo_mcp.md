> ☁️ 🐍 – Crawleo Search & Crawl API

Crawleo-MCP is a server implementation that connects to the Crawleo Search & Crawl API, allowing AI agents to perform web searches and data extraction via the Model Context Protocol. It enables automated crawling of web pages and retrieval of search results in a structured format. This tool is useful for agents needing up-to-date information from the web. The server is written in Python and designed for cloud deployment. It falls under the Search and Data Extraction category of MCP servers.
