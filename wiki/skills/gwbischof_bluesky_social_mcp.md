> 🐍 🏠 - An MCP server for interacting with Bluesky via the atproto client.

This project implements a Model Context Protocol (MCP) server that enables AI agents to interact with the Bluesky social network. It uses the AT Protocol (atproto) client to perform actions such as posting, reading timelines, and managing account data. The server integrates Bluesky functionality into AI workflows and applications, making it easier for agents to access social media capabilities. It is categorized under social media server implementations for the MCP ecosystem.
