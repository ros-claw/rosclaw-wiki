auth0-fastify is a Fastify plugin that provides Auth0 authentication and authorization for Fastify applications. It simplifies integrating Auth0's JWT verification and user management into Fastify routes. The plugin handles token validation, user profile extraction, and protects endpoints based on Auth0 scopes and permissions. It is designed for TypeScript projects and works seamlessly with the Fastify ecosystem.
