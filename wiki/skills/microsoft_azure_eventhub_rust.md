This project provides a Rust crate for interacting with Azure Event Hubs, a scalable event streaming platform. It allows developers to send and receive events efficiently using asynchronous Rust. The library is part of Microsoft's Azure SDK for Rust, enabling integration of Rust applications with Azure's event processing infrastructure.
