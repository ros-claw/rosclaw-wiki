> 🐍 ☁️ – A Dockerized Python MCP server that bridges your local AI (e.g., Claude Desktop, etc) with the QuantConnect API—empowering you to create projects, backtest strategies, manage collaborators, and deploy live-trading workflows directly via natural-language prompts.

This is a Dockerized Python MCP server that connects local AI systems like Claude Desktop to the QuantConnect API. It enables users to create projects, run backtests, manage collaborators, and deploy live trading strategies using natural-language commands. The server simplifies algorithmic trading by allowing AI agents to interact directly with QuantConnect’s platform. It is listed under Server Implementations for Finance & Fintech.
