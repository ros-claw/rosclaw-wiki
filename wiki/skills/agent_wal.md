> Write-Ahead Log protocol for agent state persistence.

Agent-wal is a write-ahead log protocol designed for persisting the state of AI agents. It ensures that agent state changes are recorded durably before execution, enabling crash recovery and consistent resumption. The protocol supports reliable state management for long-running or failure-prone agent workflows. It aims to decouple state persistence from agent logic, making agents more robust and auditable.
