> 🐍 🏠 - Local MCP server that provides structured Git repository analysis (project status, recent activity, code map, and risk hotspots) for AI coding agents.

This project implements a local MCP (Model Context Protocol) server specifically designed to give AI coding agents structured insights into Git repositories. It analyzes project status, recent activity, code structure, and identifies risky code hotspots. By doing so, it helps AI tools better understand the current state and history of a codebase, enabling more informed suggestions and actions. The server runs locally and integrates with any MCP-compatible agent.
