> A benchmark that evaluates web agents on realistic, time-consuming research tasks requiring multi-step tool use and information synthesis, making it a good proxy for harness quality in long-horizon web scenarios.

AssistantBench is a benchmark designed to evaluate web agents on realistic, time-consuming research tasks. These tasks require multi-step tool use and the synthesis of information from various sources. The benchmark serves as a proxy for measuring the quality of agent harnesses in long-horizon web scenarios.
