> 📇 ☁️ - Real-time on-chain market prices using open and free Dexscreener API

This MCP server provides real-time on-chain market prices by leveraging the free and open Dexscreener API. It enables AI agents to access current trading data for tokens across various decentralized exchanges. Listed under finance and fintech, it simplifies fetching live market prices without requiring paid subscriptions. The tool is designed for integration with the Model Context Protocol.
