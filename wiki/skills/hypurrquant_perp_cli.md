This project is a Model Context Protocol (MCP) server that enables AI agents to trade perpetual futures across multiple decentralized exchanges (DEXs) including Pacifica (Solana), Hyperliquid (HyperEVM), and Lighter (Ethereum). It provides 18 tools for market data retrieval, trade execution with a dry-run safety mode, funding rate arbitrage scanning, portfolio analytics, and cross-exchange comparison. The server simplifies integrating multi-DEX perpetuals trading into AI-driven applications by offering a standardized interface through the MCP protocol.
