> 📇 🏠 - 17 MCP tools for the food industry. Describe food in plain English and get structured, content-addressed data blocks back. Covers actors, places, ingredients, products, transforms, transfers, and observations. Works standalone with zero config via `npx foodblock-mcp`.

This project offers 17 MCP tools tailored for the food industry, enabling users to describe food in plain English and receive structured, content-addressed data blocks. It covers key domains such as actors, places, ingredients, products, transforms, transfers, and observations. The tool works standalone with zero configuration and can be run via the `npx foodblock-mcp` command. It is designed to simplify data creation and structuring for food-related applications.
