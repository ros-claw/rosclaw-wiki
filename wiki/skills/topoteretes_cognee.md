> 📇 🏠 - Memory manager for AI apps and Agents using various graph and vector stores and allowing ingestion from 30+ data sources

Cognee is a memory manager designed for AI applications and agents, enabling persistent knowledge through various graph and vector stores. It supports ingestion from over 30 diverse data sources, allowing agents to maintain contextual memory over time. The tool helps AI systems store, retrieve, and update information efficiently, enhancing their ability to recall past interactions and learn from new data.
