This is a Go-based MCP server that bridges GenieACS, a TR-069 Auto Configuration Server (ACS). It exposes device data, firmware management, and CPE actions like reboot and firmware download over JSON-RPC. AI agents can use it to monitor and manage network devices. The server is available as a Docker image for easy deployment.
