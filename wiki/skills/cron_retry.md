> Auto-retry failed cron jobs on connection recovery.

cron-retry is a tool that automatically retries failed cron jobs when the network connection is restored. It helps improve reliability in scheduled tasks by handling temporary connectivity issues. This reduces manual intervention for recurring jobs that fail due to transient network problems. The project is useful for systems where cron jobs depend on external services.
