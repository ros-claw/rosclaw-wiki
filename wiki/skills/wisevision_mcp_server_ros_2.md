> 🐍 🤖 - MCP server for ROS2 enabling AI-driven robotics applications and services.

This project is an MCP (Model Context Protocol) server for ROS2, allowing AI agents to interface with robotic systems. It enables AI-driven robotics applications by providing a bridge between language models and ROS2 services. The server facilitates control and communication with robots using natural language or AI reasoning.
