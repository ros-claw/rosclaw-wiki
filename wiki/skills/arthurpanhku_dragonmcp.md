DragonMCP is an MCP server that integrates with major Greater China local life service platforms. It supports food delivery via Meituan and Ele.me, ride-hailing via Didi and Meituan, payments via WeChat Pay and Alipay, maps via Amap and Baidu Maps, high-speed rail booking via 12306, e-commerce via Taobao, JD, and Xianyu, and Hong Kong government e-services. This server allows AI assistants using the Model Context Protocol to interact with these services directly for tasks like ordering food, booking rides, and making payments.
