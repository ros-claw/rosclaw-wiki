> 🎖 📇 ☁️ 🏠 📟  - FIX Protocol (send orders, market data, etc.) written in TypeScript.

A TypeScript library for parsing and constructing FIX Protocol messages, used in financial trading for sending orders and market data. It provides a type-safe implementation suitable for server-side applications in the finance and fintech sector. The project aims to simplify integration with FIX-based systems by offering robust message handling in a modern JavaScript environment.
