> 📇 ☁️ - MCP server for comprehensive market and financial news search with advanced filtering by symbols, industries, countries, and date ranges.

MarketAuxMcpServer is an MCP (Model Context Protocol) server that provides comprehensive market and financial news search capabilities. It allows users to filter news by symbols, industries, countries, and date ranges, making it useful for financial monitoring and analysis. This server enables AI assistants to access real-time financial news through the MarketAux API.
