This repository provides a collection of reusable skill modules for AI agents to interact with Three.js, enabling agents to create, manipulate, and render 3D scenes programmatically. It is designed to be integrated into larger AI frameworks or platforms, allowing agents to perform tasks such as object placement, animation, and scene composition within a 3D environment. The skills are modular and can be combined to build complex 3D interactions. This project is listed as a community contribution within the CloudAI-X ecosystem.
