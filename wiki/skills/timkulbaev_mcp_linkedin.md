Dry-run by default, SKILL.md included, CLI-first design for AI automation workflows.

MCP-linkedin is a server implementation for the Model Context Protocol (MCP) that allows AI agents to interact with LinkedIn through the Unipile API. It supports publishing posts, commenting, and reacting, with a dry-run mode for safe testing. The tool is CLI-first and includes a SKILL.md for agent instructions, making it suitable for AI automation workflows on LinkedIn.
