Smriti is a self-hosted knowledge store and memory layer for AI agents. It provides a knowledge graph with wiki-links, full-text search (using FTS5), and agent memory with configurable namespaces and time-to-live (TTL). The server is available on multiple platforms (including macOS, Windows, Linux) and integrates as an MCP server. Its goal is to give AI agents persistent, structured memory for better context and reasoning.
