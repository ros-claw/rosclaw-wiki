> Solve CAPTCHAs using 2Captcha service.

This project provides a client library to solve CAPTCHAs using the 2Captcha service. It allows automated submission of CAPTCHA challenges, such as image-based CAPTCHAs and reCAPTCHA, to the 2Captcha platform where human workers solve them and return the answer. The tool is commonly used for web scraping and automation tasks that require bypassing CAPTCHA protections.
