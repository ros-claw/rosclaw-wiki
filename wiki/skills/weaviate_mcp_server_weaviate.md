> 🐍 📇 ☁️ - An MCP Server to connect to your Weaviate collections as a knowledge base as well as using Weaviate as a chat memory store.

An MCP server implementation that connects to Weaviate, a vector database. It allows using Weaviate collections as a knowledge base for AI agents. Additionally, it can serve as a chat memory store, storing and retrieving conversation history. This enables AI assistants to have persistent memory and access to structured knowledge.
