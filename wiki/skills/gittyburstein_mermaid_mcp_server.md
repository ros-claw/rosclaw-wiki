> 🐍 ☁️ - MCP server that turns local projects or GitHub repositories into Mermaid diagrams and renders them via Kroki.

This project is a Model Context Protocol (MCP) server that automatically generates Mermaid diagrams from local projects or GitHub repositories. It analyzes code structure and produces visual diagrams such as architecture diagrams, dependency graphs, or flowcharts. The diagrams are rendered using Kroki, a service that converts text-based diagram formats into images. It simplifies documentation by turning codebases into clear, editable diagrams.
