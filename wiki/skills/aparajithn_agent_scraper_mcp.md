Agent Scraper MCP is a web scraping server designed for AI agents, implementing the Model Context Protocol (MCP). It provides six main tools: clean content extraction, structured scraping using CSS selectors, full-page screenshots via Playwright, link extraction, metadata extraction (Open Graph and Twitter cards), and Google search. The server offers a free tier supported by x402 micropayments. It aims to enable AI agents to efficiently scrape and process web data.
