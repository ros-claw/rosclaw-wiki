> 🎖️ 📇 ☁️ - MCP server that provides [AgentQL](https://agentql.com)'s data extraction capabilities.

AgentQL-MCP is a server implementation that integrates AgentQL's data extraction capabilities into the Model Context Protocol (MCP). It enables AI agents to perform structured data extraction from web pages, such as scraping product details or search results. The server is listed under 'Search & Data Extraction' tools within the MCP ecosystem, providing a bridge between AgentQL's API and MCP-compatible clients.
