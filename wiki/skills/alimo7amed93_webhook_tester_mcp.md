> 🐍 ☁️ – A FastMCP-based server for interacting with webhook-test.com. Enables users to create, retrieve, and delete webhooks locally using Claude.

This is a FastMCP-based server that allows users to interact with the webhook-test.com service. It enables creating, retrieving, and deleting webhooks directly from Claude or other MCP-compatible tools. The server provides a local interface for managing webhook endpoints, making it easier to test webhook integrations. It is designed for developers who need to simulate and debug webhook events without external dependencies.
