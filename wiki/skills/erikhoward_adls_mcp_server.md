> 🐍 ☁️/🏠 - MCP Server for Azure Data Lake Storage. It can perform manage containers, read/write/upload/download operations on container files and manage file metadata.

This is an MCP server for interacting with Azure Data Lake Storage (ADLS). It provides capabilities to manage storage containers and perform file operations like reading, writing, uploading, and downloading. The server also supports managing file metadata. It is listed under Cloud Platforms in the MCP server implementations.
