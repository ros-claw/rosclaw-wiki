Read/edit buffers, run commands, send keys, query LSP diagnostics, and annotate code with highlights. No plugin required.

This MCP server enables AI assistants to fully control Neovim instances using msgpack-RPC. It allows reading and editing buffers, executing commands, sending keystrokes, querying LSP diagnostics, and annotating code with highlights. No Neovim plugins are required, simplifying setup. It is designed to integrate AI into developer workflows for enhanced code editing and navigation.
