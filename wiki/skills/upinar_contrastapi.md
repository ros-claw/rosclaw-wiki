UPinar/contrastapi is an MCP server that provides 31 security intelligence tools. It offers CVE/EPSS/KEV lookup, domain reconnaissance (DNS/WHOIS/SSL/subdomains/CT logs), IOC and threat intelligence, OSINT for email/phone/username, and code security scanning for secrets and injection vulnerabilities. The service is free with a rate limit of 100 requests per hour. This server is listed under 'Server Implementations' with a security focus.
