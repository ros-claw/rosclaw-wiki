> Scans recent X posts for the most debated/hot topic right now in a given category (e.g., crypto, tech, sports.

This project is a skill for the BetBud platform that scans recent posts on X (formerly Twitter) to identify the most debated or hot topic in a given category, such as crypto, tech, or sports. It helps users find trending discussions that might be useful for making predictions or bets. The tool focuses on real-time social media analysis to capture emerging trends.
