> 📇 🏠 - CLI tool for testing MCP servers

mcp-cli is a command-line tool designed for testing MCP (Model Context Protocol) servers. It allows developers to interact with MCP servers directly from the terminal, sending requests and inspecting responses for debugging and validation. The tool supports various MCP operations and provides a convenient sandbox environment for server testing without additional infrastructure. It is especially useful for prototyping and verifying server implementations during development.
