Search logs, traces, stream schemas, and dashboards without requiring the Enterprise license.

This is an MCP server that provides read-only access to the OpenObserve Community Edition via its REST API. It allows users to search logs, traces, stream schemas, and dashboards without requiring the Enterprise license. The server is designed for monitoring and observability workflows, enabling integration with AI agents through the Model Context Protocol.
