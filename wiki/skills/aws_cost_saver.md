> Automated AWS cost optimization with 173 checks across EC2, RDS, S3, Lambda, and more. ML-powered recommendations and real pricing from AWS API.

aws-cost-saver is an automated tool that helps reduce AWS spending by running 173 checks across key services like EC2, RDS, S3, and Lambda. It uses machine learning to generate recommendations and fetches real-time pricing from the AWS API to provide actionable advice. The project integrates as a plugin under the DevOps & Performance category.
