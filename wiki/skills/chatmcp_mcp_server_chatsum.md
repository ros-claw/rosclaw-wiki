> Query and summarize your chat messages with AI prompts.

This MCP server enables querying and summarizing chat messages using AI prompts. It is designed for knowledge and memory retrieval, allowing agents to access historical chat data through natural language queries. Users can extract summaries or specific information from past conversations, enhancing agent memory. The tool is categorized under Knowledge & Memory in server implementations.
