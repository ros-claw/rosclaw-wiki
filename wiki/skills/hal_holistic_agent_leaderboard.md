> A benchmark and leaderboard for agent systems with attention to reliability, cost, and broad task coverage, making it useful for comparing end-to-end harness behavior.

HAL is a benchmark and leaderboard that evaluates agent systems holistically, focusing on reliability, cost, and broad task coverage. It allows comparison of end-to-end harness behavior across different agents. The project provides a standardized way to assess agent performance in real-world scenarios, making it useful for developers and researchers.
