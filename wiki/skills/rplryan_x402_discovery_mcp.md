x402-discovery-mcp is a runtime discovery layer for x402-payable APIs. It enables AI agents to find and route to pay-per-call endpoints based on capability, with results ranked by quality and trust scores (0-100). Agents pay per query using the x402 protocol. The project includes an MCP server, a Python SDK, and a CLI tool.
