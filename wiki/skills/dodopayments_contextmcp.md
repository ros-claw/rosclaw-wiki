> 📇 ☁️ 🏠 - Self-hosted MCP server that indexes documentation from various sources and serves it to AI Agents with semantic search.

ContextMCP is a self-hosted MCP server that indexes documentation from multiple sources. It provides semantic search capabilities to AI agents, enabling them to retrieve relevant knowledge. The server is designed to be run locally, giving users control over their documentation and data. It fits within the Knowledge & Memory category of MCP implementations.
