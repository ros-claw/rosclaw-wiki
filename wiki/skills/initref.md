> Initializes reference documentation structure with standard doc templates, API reference setup, documentation conventions, and placeholder content generation.

/initref is a slash command that initializes a reference documentation structure for a project. It automatically sets up standard documentation templates, API reference configuration, and documentation conventions. It also generates placeholder content to help developers start writing documentation quickly. This reduces manual setup overhead and ensures consistency across projects.
