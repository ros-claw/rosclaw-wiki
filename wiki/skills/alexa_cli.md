> Control Amazon Alexa devices and smart home via the `alexacli` CLI.

Alexa CLI (alexacli) is a command-line tool that enables users to control Amazon Alexa devices and smart home devices. It provides a terminal interface to interact with Alexa, allowing for voice command emulation or direct device control. This tool is useful for developers and power users who prefer CLI over voice or app interfaces.
