> ☕ ☁️ 🏠 - Turn your Spring Boot application into an MCP server instantly by reusing existing Swagger/OpenAPI documentation.

This project provides a Spring Boot starter that automatically transforms existing Swagger/OpenAPI documentation into a Model Context Protocol (MCP) server. It allows developers to expose their REST API endpoints as MCP tools without additional coding. By leveraging standard API documentation, it simplifies the integration of MCP in applications built with Spring Boot. The starter is listed under Server Implementations for Developer Tools, targeting rapid prototyping and interoperability.
