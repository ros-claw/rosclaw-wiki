> 🏎️ ☁️ 🍎 🪟 🐧 MCP Server to connect your preferred model with https://rae-api.com, Roya Academy of Spanish Dictionary

rae-api-com/rae-mcp is a Model Context Protocol (MCP) server that connects language models to the official Spanish dictionary provided by the Real Academia Española (RAE) via the rae-api.com service. It enables AI agents to look up word definitions, meanings, and other lexical information directly from the authoritative source of the Spanish language. The server is designed to be cross-platform, supporting Windows, macOS, Linux, and cloud environments as indicated by the emojis in its description. This integration enhances Spanish language understanding in AI tools, making it useful for applications like translation, language learning, and content analysis.
