This is an AI-native content management system that exposes 72 MCP tools for managing websites through natural language. It supports creating and publishing content, managing templates, assets, snippets, themes, collections, redirects, and multi-site forks. It includes full content versioning and semantic search capabilities. It integrates with the Model Context Protocol to enable AI assistants to interact with the CMS.
