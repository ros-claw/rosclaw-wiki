> Query MeetGeek meeting intelligence from CLI - list meetings, get AI.

MeetGeek is a CLI tool that allows users to query meeting intelligence from the MeetGeek platform directly from the command line. It enables listing meetings, retrieving AI-generated summaries, and accessing other insights without leaving the terminal. This tool is designed for developers and power users who want to integrate meeting data into their workflows or automate reporting. The project provides a simple, scriptable interface to extract value from recorded meetings efficiently.
