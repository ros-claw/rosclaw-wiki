> Run AIMLAPI LLM and reasoning workflows through chat completions with retries, structured outputs, and explicit.

This project provides a tool for executing LLM reasoning workflows using the AIML API. It supports chat completion endpoints with built-in retry logic for reliability. The tool enables structured output formats, allowing users to extract specific data from model responses. It also includes explicit reasoning capabilities, likely for chain-of-thought or step-by-step inference. The project is designed to streamline integration with AIML's language models for various reasoning tasks.
