> [![timergy-app/timergy MCP server](https://glama.ai/mcp/servers/timergy-app/timergy/badges/score.svg)](https://glama.ai/mcp/servers/timergy-app/timergy) 📇 ☁️  - Create scheduling polls (like Doodle/When2Meet) from AI agents. No auth required. Tools: `create_poll`, `get_poll`, `vote_on_poll`, `get_results`, `finalize_poll`.

Timergy is an MCP server that allows AI agents to create and manage scheduling polls, similar to Doodle or When2Meet. It provides tools for creating polls, retrieving poll details, voting, viewing results, and finalizing polls. No authentication is required, making it simple to integrate with AI agents for workplace productivity tasks.
