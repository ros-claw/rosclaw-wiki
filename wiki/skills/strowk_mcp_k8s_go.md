> 🏎️ ☁️/🏠 - Kubernetes cluster operations through MCP

This project is a Go-based server that implements the Model Context Protocol (MCP) for Kubernetes cluster operations. It allows AI agents to interact with and manage Kubernetes clusters, such as deploying applications or inspecting resources. The server can run in cloud environments or on-premises, making it flexible for various deployment scenarios. It bridges AI agents with Kubernetes infrastructure through a standardized protocol.
