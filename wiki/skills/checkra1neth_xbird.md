> 📇 ☁️ 🏠 🍎 🪟 🐧 - Twitter/X MCP server with 34 tools — post tweets, search, read timelines, manage engagement, upload media. No API keys needed, uses browser cookies. Pay per call from $0.001 via x402 micropayments.

xbird is a Model Context Protocol (MCP) server for Twitter/X that exposes 34 tools for posting, searching, reading timelines, managing engagement, and uploading media. It eliminates the need for official API keys by using browser cookies for authentication. The service charges per API call via x402 micropayments, starting at $0.001 per request. It is listed under social media server implementations for AI agent integration.
