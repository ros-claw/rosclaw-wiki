> 🐍 🏠 ☁️ - An MCP server for accessing all of CustomGPT.ai's anti-hallucination RAG-as-a-service API endpoints.

This project implements an MCP (Model Context Protocol) server that wraps the CustomGPT.ai API, enabling easy access to its retrieval-augmented generation (RAG) endpoints. It is designed to reduce AI hallucinations by grounding responses in retrieved data. The server can be integrated into AI agents, chatbots, and other applications that require reliable, context-aware answers. It is listed under end-to-end RAG platforms in the MCP server ecosystem.
