> 🐍 🏠 🍎 🪟 🐧 - Geospatial tools for AI agents: geocoding, routing, elevation, spatial analysis, and file I/O (Shapefile, GeoJSON, GeoPackage)

This project is a Model Context Protocol (MCP) server that provides geospatial tools for AI agents. It supports geocoding (address to coordinates and reverse), routing, elevation data retrieval, and spatial analysis. It can read and write common geospatial file formats like Shapefile, GeoJSON, and GeoPackage. The server is cross-platform, running on Linux, macOS, and Windows. AI agents can use it to answer location-based questions and perform geographic operations.
