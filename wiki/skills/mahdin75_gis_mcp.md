> 🏠 – A Model Context Protocol (MCP) server implementation that connects Large Language Models (LLMs) to GIS operations using GIS libraries, enabling AI assistants to perform accurate geospatial operations and transformations.

This project implements a Model Context Protocol (MCP) server that connects large language models to geographic information system (GIS) libraries. It enables AI assistants to perform accurate geospatial operations such as coordinate transformations and spatial queries. By integrating LLMs with GIS tools, it allows natural language commands to drive location-based data processing.
