> 🐍 ☁️ - Bridge to Google Gemini API. Access Gemini Pro and Flash models through MCP.

This project provides a bridge between the Model Context Protocol (MCP) and Google's Gemini API. It allows MCP-compatible agents to access Gemini Pro and Flash models for generating responses. The server is implemented in Python and is categorized as an aggregator, meaning it combines multiple AI services under a unified MCP interface. It enables users to leverage Gemini's capabilities without direct API calls, simplifying integration with MCP-based tools.
