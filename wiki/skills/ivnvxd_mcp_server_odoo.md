> 🐍 ☁️/🏠 - Connect AI assistants to Odoo ERP systems for business data access, record management, and workflow automation.

This project provides a Model Context Protocol (MCP) server that enables AI assistants to interact with Odoo ERP systems. It allows AI agents to access business data, manage records, and automate workflows within Odoo. The server acts as a bridge between AI assistants and Odoo, facilitating natural language queries and actions. It supports both cloud and on-premise Odoo instances. This integration streamlines ERP tasks through conversational AI.
