> 🎖️ 📇 🏠 - Official Next.js MCP server for coding agents. Provides runtime diagnostics, route inspection, dev server logs, docs search, and upgrade guides. Requires Next.js 16+ dev server for full runtime features.

Next DevTools MCP is an official MCP server for Next.js that integrates with coding agents. It provides runtime diagnostics, route inspection, dev server logs, documentation search, and upgrade guides. The server requires a running Next.js 16+ dev server to unlock its full runtime features. It helps developers debug and optimize their Next.js applications directly from the agent's environment.
