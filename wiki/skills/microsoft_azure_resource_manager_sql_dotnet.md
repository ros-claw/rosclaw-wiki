This project provides .NET libraries for managing Azure SQL resources using Azure Resource Manager. It enables developers to programmatically create, update, and delete SQL databases, servers, and firewalls. It is part of the Azure SDK for .NET and is used in cloud infrastructure automation. It simplifies interacting with Azure SQL through declarative templates or direct code.
