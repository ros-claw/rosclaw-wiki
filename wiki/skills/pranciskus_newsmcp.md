Free, no API key. `npx -y @newsmcp/server`

This MCP server delivers real-time world news specifically for AI agents. It automatically clusters events from hundreds of sources, classifies them by topic and geography, and ranks them by importance. The service is free to use and does not require an API key. It can be launched via npx without any installation.
