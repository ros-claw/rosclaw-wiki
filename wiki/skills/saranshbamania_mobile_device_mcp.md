AI visual analysis (Claude + Gemini), Flutter widget tree inspection, smart element finding (<1ms), video recording, and test script generation. `npx mobile-device-mcp`

This MCP server enables AI agents to control Android devices and iOS simulators through 49 tools. It supports visual analysis using Claude and Gemini, Flutter widget tree inspection, and sub-millisecond smart element finding. Additional features include video recording and test script generation. It is primarily aimed at developers automating mobile app testing and interaction.
