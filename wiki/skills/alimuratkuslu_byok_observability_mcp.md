This MCP server provides a unified interface for interacting with multiple observability tools including Grafana, Prometheus, Kafka UI, and Datadog. It implements a 'Bring Your Own Key' (BYOK) security model, allowing users to use their own API keys and credentials. The server enables AI agents to query metrics, manage dashboards, and monitor infrastructure through a standard MCP protocol. It is designed to integrate seamlessly into existing monitoring workflows and supports multiple platforms.
