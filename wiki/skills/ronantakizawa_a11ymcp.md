The a11ymcp project is a web accessibility testing MCP server that uses axe-core to analyze URLs and HTML for compliance with WCAG 2.0, 2.1, and 2.2 standards. It provides tools for checking color contrast, validating ARIA attributes, and detecting orientation locks. This server helps developers ensure their web applications meet accessibility requirements.
