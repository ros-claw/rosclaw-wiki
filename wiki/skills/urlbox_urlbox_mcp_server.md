> 📇 🏠 A reliable MCP server for generating and managing screenshots, PDFs, and videos, performing AI-powered screenshot analysis, and extracting web content (Markdown, metadata, and HTML) via the [Urlbox](https://urlbox.com) API.

The urlbox-mcp-server provides a Model Context Protocol (MCP) interface to the Urlbox API for capturing screenshots, generating PDFs, and recording videos of web pages. It also supports AI-driven analysis of screenshots and extraction of web content as Markdown, metadata, or HTML. This server is categorized under Search & Data Extraction, indicating its primary use for retrieving and processing web data. By leveraging Urlbox, it offers a reliable way to automate visual captures and content extraction for agents and applications.
