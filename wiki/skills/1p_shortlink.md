> Create short URLs and submit feature requests using 1p.io.

The 1p-shortlink project is a URL shortening service that allows users to create short URLs using the 1p.io domain. It also provides a mechanism for submitting feature requests related to the service. This tool likely simplifies sharing links and gathering user feedback. It is targeted at developers or teams who need quick link management and a basic feedback channel.
