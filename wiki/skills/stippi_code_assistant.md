> 🦀 🏠 - Coding agent with basic list, read, replace_in_file, write, execute_command and web search tools. Supports multiple projects concurrently.

This project provides a coding agent implemented in Rust, capable of handling multiple concurrent projects. It includes tools for basic file operations such as listing, reading, and writing files, as well as executing commands and performing web searches. Designed for server-side deployment, it integrates with coding agent workflows to assist with code-related tasks.
