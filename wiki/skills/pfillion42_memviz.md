> 📇 🏠 🍎 🪟 🐧 - Visual explorer for [MCP Memory Service](https://github.com/doobidoo/mcp-memory-service) SQLite-vec databases. Browse, search, filter, edit memories with dashboard, timeline, UMAP projection, semantic clustering, duplicate detection, and association graph.

This tool provides a visual interface for exploring databases created by the MCP Memory Service, which stores memories using vector embeddings in SQLite. It allows users to browse, search, and edit memories with advanced features like a timeline, UMAP projection for dimensionality reduction, semantic clustering, duplicate detection, and an association graph. The dashboard offers an overview of the memory data for easy navigation and analysis. It is designed for systems that use the Model Context Protocol (MCP) for persistent memory.
