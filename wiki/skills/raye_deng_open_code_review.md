MCP Server + CLI + CI/CD integration.

Open Code Review is an MCP server and CLI tool that acts as an AI code quality gate. It detects issues like hallucinated packages, phantom dependencies, stale APIs, and other AI-specific code defects. The tool integrates with CI/CD pipelines to catch these problems before deployment, improving code reliability by catching common mistakes made by AI-generated code.
