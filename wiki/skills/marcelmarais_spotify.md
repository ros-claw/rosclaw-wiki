> 📇 🏠 Control Spotify playback and manage playlists.

This project is a server implementation that allows AI agents to control Spotify playback and manage playlists through the Model Context Protocol (MCP). It provides endpoints for playing, pausing, skipping tracks, and organizing playlists. Users can integrate it with MCP-compatible clients to enable voice or text-based music control. The tool leverages the Spotify Web API to interact with the user's Spotify account. It is listed under Other Tools and Integrations in the MCP server ecosystem.
