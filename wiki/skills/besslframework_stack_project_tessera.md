Project Tessera is an MCP server that provides persistent, local workspace memory for Claude Desktop by indexing documents like Markdown, CSV, and session logs into a vector store using FastEmbed and LanceDB. It supports hybrid search, cross-session memory, auto-learning, and knowledge graph visualization without requiring external dependencies such as Ollama or Docker. This enables offline, privacy-preserving memory augmentation for AI assistants.
