> Transcribe audio to text using ElevenLabs.

A tool that leverages ElevenLabs' speech-to-text API to transcribe audio files into text. It provides a simple interface for converting spoken content from various audio formats into accurate text transcripts. This is useful for applications like podcast transcription, meeting notes, or accessibility features. The tool handles the API integration, making it easy for developers to add transcription capabilities without dealing with raw API calls. It abstracts away authentication and request formatting.
