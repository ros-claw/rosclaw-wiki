> 🎖️ 📇 ☁️ 🍎 🪟 🐧 - Leverage AI-driven observability, security, and automation to analyze anomalies, logs, traces, events, metrics.

This project is a Model Context Protocol (MCP) server that integrates with Dynatrace, a platform for AI-driven observability, security, and automation. It enables AI agents to analyze anomalies, logs, traces, events, and metrics from Dynatrace. The server facilitates root cause analysis, incident investigation, and automated monitoring workflows. It is listed under monitoring server implementations and leverages Dynatrace's capabilities for intelligent observability.
