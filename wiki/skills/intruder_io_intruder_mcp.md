> 🐍 ☁️ - MCP server to access [Intruder](https://www.intruder.io/), helping you identify, understand, and fix security vulnerabilities in your infrastructure.

This project provides a Model Context Protocol (MCP) server that integrates with Intruder, a security platform for identifying and fixing vulnerabilities in cloud and infrastructure environments. It exposes Intruder's security scanning capabilities through the MCP interface, allowing AI agents to access vulnerability data and remediation insights. The server helps automate security workflows by enabling tools to query vulnerabilities, get details, and understand fixes.
