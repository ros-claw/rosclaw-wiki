> 🐍 ☁️ - An MCP server for [DIDLogic](https://didlogic.com). Adds functionality to manage SIP endpoints, numbers and destinations.

This is a Model Context Protocol (MCP) server that integrates with the DIDLogic API to manage telephony resources. It allows AI agents to programmatically control SIP endpoints, phone numbers, and call destinations through standardized tools. The server is written in Python and provides a bridge between conversational AI and cloud telephony services. It enables automated phone number provisioning, routing configuration, and SIP management within AI-driven workflows.
