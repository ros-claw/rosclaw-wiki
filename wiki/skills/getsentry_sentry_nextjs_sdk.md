The Getsentry Sentry Next.js SDK provides official integration of Sentry's error tracking and performance monitoring into Next.js applications. It offers features like automatic instrumentation for server-side and client-side errors, source map uploads, and release tracking. The SDK simplifies setup with minimal configuration and supports both pages and app router structures.
