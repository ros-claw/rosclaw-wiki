> 📇 ☁️ - MCP server for EchoRift infrastructure primitives (BlockWire, CronSynth, Switchboard, Arbiter). Makes EchoRift's agent infrastructure callable as MCP tools so any MCP client can treat EchoRift like a native capability layer.

This MCP server exposes EchoRift infrastructure primitives as tools for any MCP client. It integrates EchoRift's agent infrastructure (BlockWire, CronSynth, Switchboard, Arbiter) into the Model Context Protocol ecosystem. This allows users to leverage EchoRift capabilities like task scheduling, data routing, and decision-making through standard MCP interfaces. The server acts as a bridge between EchoRift and MCP-compatible development tools.
