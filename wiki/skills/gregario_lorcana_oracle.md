> [![lorcana-oracle MCP server](https://glama.ai/mcp/servers/gregario/lorcana-oracle/badges/score.svg)](https://glama.ai/mcp/servers/gregario/lorcana-oracle) 📇 🏠 - Disney Lorcana TCG card search, deck analysis, ink curves, lore generation, and franchise browsing. 7 tools, 2,710 cards embedded.

This project is an MCP server that provides tools for searching and analyzing Disney Lorcana Trading Card Game cards. It offers seven tools including card search, deck analysis, ink curves, and lore generation. The server has embedded over 2,700 cards from the game. It is useful for players and developers building applications around Lorcana.
