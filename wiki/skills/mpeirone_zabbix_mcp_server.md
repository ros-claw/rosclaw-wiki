> 🐍 ☁️ 🐧 🪟 🍎 - Zabbix integration for hosts, items, triggers, templates, problems, data and more.

This project implements a Model Context Protocol (MCP) server for integrating with Zabbix, a widely-used open-source monitoring platform. It provides tools to query and manage Zabbix entities such as hosts, items, triggers, templates, and problems. The server enables AI agents to interact with monitoring data and infrastructure through standard MCP interfaces. It is categorized under server implementations for monitoring within the MCP ecosystem.
