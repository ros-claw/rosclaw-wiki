> 📇 ☁️ 🍎 🪟 - Read jira data via JQL and api and execute requests to create and edit tickets.

This project implements an MCP server for interacting with Jira, allowing users to read issue data using JQL queries and the Jira API. It also supports creating and editing tickets programmatically. Listed under Server Implementations, it integrates with various environments including cloud, Apple, and Windows. This tool serves as a bridge between AI agents and Jira project management systems.
