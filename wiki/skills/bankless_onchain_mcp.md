> 📇 ☁️ - Bankless Onchain API to interact with smart contracts, query transaction and token information

bankless/onchain-mcp is an MCP server that provides an onchain API for interacting with smart contracts, querying transaction details, and retrieving token information. It is designed for use in the finance and fintech sector, enabling applications to access blockchain data through the Model Context Protocol. The server supports reading on-chain data across various networks, making it useful for DeFi and crypto applications.
