ModelSafetyMCP is an MCP server that scans machine learning model artifacts for security threats such as unsafe serialization, malicious code patterns, and risky packaging. It supports scanning local files, directories, and remote URLs using tools like ModelScan, PickleScan, and heuristic inspection. This server helps prevent supply chain attacks from untrusted models by identifying vulnerabilities in model files before use.
