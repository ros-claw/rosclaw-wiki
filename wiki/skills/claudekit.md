> Impressive CLI toolkit providing auto-save checkpointing, code quality hooks, specification generation and execution, and 20+ specialized subagents including oracle (gpt-5), code-reviewer (6-aspect deep analysis), ai-sdk-expert (Vercel AI SDK), typescript-expert and many more for Claude Code workflows.

Claudekit is a command-line toolkit designed to enhance Claude Code workflows. It provides features like auto-save checkpointing, code quality hooks, and specification generation and execution. The toolkit includes over 20 specialized subagents, such as an oracle (GPT-5), a deep-analysis code reviewer, an AI SDK expert, and a TypeScript expert. These tools help developers automate and improve their coding processes when using Claude Code.
