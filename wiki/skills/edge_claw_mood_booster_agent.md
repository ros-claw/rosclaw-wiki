This MCP server implements an AI agent that sends uplifting, mood-boosting messages to users. It uses Server-Sent Events (SSE) transport and integrates with blockchain technology for on-chain USDC tipping and reputation feedback via the ERC-8004 standard. The agent can be discovered and interacted with across six different blockchain networks, combining emotional support with decentralized finance (DeFi) capabilities.
