This MCP server supports Health Economics and Outcomes Research (HEOR) by offering seven tools for literature searching across 41 medical databases (e.g., PubMed, NICE, CADTH, ICER), cost-effectiveness modeling (Markov, PartSA, PSA), and HTA dossier preparation. It is designed for pharmaceutical and biotech teams to streamline evidence generation and economic evaluation. The server integrates with Model Context Protocol to provide these capabilities as reusable tools.
