Built-in Qwen3 embedding, no API keys required.

wet-mcp is a Model Context Protocol server that provides web search, content extraction, and library documentation indexing. It uses an embedded SearXNG instance for web search and combines FTS5 full-text search with semantic embeddings using the built-in Qwen3 model. The server requires no external API keys because the embedding model runs locally. This enables hybrid search across both code documentation and general web content.
