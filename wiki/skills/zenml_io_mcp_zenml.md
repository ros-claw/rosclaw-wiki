> 🐍 🏠 ☁️ - An MCP server to connect with your [ZenML](https://www.zenml.io) MLOps and LLMOps pipelines

This MCP server enables integration with ZenML, a machine learning operations platform, allowing AI agents to interact with ML and LLM pipelines. It is designed for developer tools, providing a bridge between MCP-compatible clients and ZenML's infrastructure. This facilitates automated pipeline management and observability for machine learning workflows.
