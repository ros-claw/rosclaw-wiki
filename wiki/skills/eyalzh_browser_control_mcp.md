> 📇 🏠 - An MCP server paired with a browser extension that enables LLM clients to control the user's browser (Firefox).

This project provides an MCP server paired with a Firefox browser extension, enabling LLM clients to control the user's browser. It allows automation of tasks such as navigation, data extraction, and form filling through commands sent via a socket connection. The extension bridges the LLM with the browser, making it suitable for AI-driven browser automation under the Model Context Protocol framework.
