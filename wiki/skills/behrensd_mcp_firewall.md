> 📇 🏠 🍎 🪟 🐧 - Deterministic security proxy (iptables for MCP) that intercepts tool calls, enforces YAML policies, scans for secret leakage, and logs everything. No AI, no cloud.

mcp-firewall is a deterministic security proxy for the Model Context Protocol (MCP), similar to iptables for network traffic, that intercepts tool calls and enforces YAML-based security policies. It scans tool invocations for secrets leakage, logs all activity, and operates without any AI or cloud dependencies. The tool runs on Windows, macOS, and Linux.
