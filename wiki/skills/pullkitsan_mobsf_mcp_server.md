> 🦀 🏠 🍎 🪟 🐧 - A MCP server for MobSF which can be used for static and dynamic analysis of Android and iOS application.

This project provides a Model Context Protocol (MCP) server that interfaces with MobSF (Mobile Security Framework) for performing static and dynamic analysis on Android and iOS applications. It enables security researchers and developers to integrate MobSF's capabilities into MCP-compatible toolchains and assistants. The server facilitates automated mobile security assessments, making it easier to analyze app binaries and runtime behaviors. It supports both static analysis of source code and binaries as well as dynamic analysis through runtime inspection.
