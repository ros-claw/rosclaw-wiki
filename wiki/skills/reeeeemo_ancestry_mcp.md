> 🐍 🏠 - Allows the AI to read .ged files and genetic data

This MCP server enables AI agents to read and parse GEDCOM genealogy files (.ged) along with genetic data. It bridges family tree information and genetic markers into AI workflows. Ancestry-MCP facilitates ancestry research by allowing AI tools to process genealogical records and DNA data. The integration supports use cases like family history analysis and genetic genealogy.
