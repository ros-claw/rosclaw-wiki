safe-docx is an MCP server that enables surgical editing of existing Word .docx files. It preserves formatting, supports tracked changes, comments, footnotes, and document comparison. The server is designed for AI agents to manipulate .docx files with precision. It runs on macOS, Linux, and Windows. This tool is categorized under File Systems in the MCP server ecosystem.
