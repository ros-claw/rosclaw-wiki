> 🏎️ 🖥️ - Fast SSH connection manager with TUI dashboard and MCP server for discovering, searching, and executing commands on remote hosts.

Hop is a fast SSH connection manager that provides a terminal user interface (TUI) dashboard for discovering, searching, and executing commands on remote hosts. It includes an MCP (Model Context Protocol) server, enabling AI agents or other tools to programmatically interact with SSH connections. The tool supports command-line usage and aims to streamline remote server management.
