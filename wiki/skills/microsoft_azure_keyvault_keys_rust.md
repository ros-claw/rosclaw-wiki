A Rust client library for interacting with Azure Key Vault keys. This library enables management and usage of cryptographic keys stored in Azure Key Vault, including operations like signing, verification, encryption, and decryption. It is part of the official Azure SDK for Rust, providing idiomatic Rust bindings for Azure services. Developers can use this library to securely integrate Azure Key Vault key operations into Rust applications.
