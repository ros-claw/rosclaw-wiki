> 🏠 📇 - An MCP server for basic local taskwarrior usage (add, update, remove tasks)

This project implements an MCP server that integrates with the local Taskwarrior task management tool. It enables basic operations such as adding, updating, and removing tasks through the Model Context Protocol. This allows AI agents and assistants to manage a user's local task list directly. The server provides a simple interface for task automation and productivity workflows.
