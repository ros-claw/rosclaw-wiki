> Interactive plan review UI that intercepts ExitPlanMode via hooks, letting users visually annotate plans with comments, deletions, and replacements before approving or denying with detailed feedback.

Plannotator provides an interactive UI for reviewing AI-generated plans. It intercepts the ExitPlanMode hook to allow users to visually annotate plans with comments, deletions, and replacements. Users can then approve or deny the plan with detailed feedback. This tool enhances the human oversight process for plan generation.
