> 🐍 ☁️ - Internet speed testing with network performance metrics including download/upload speed, latency, jitter analysis, and CDN server detection with geographic mapping

This project provides an MCP server for internet speed testing. It measures network performance metrics such as download/upload speed, latency, and jitter. Additionally, it includes CDN server detection with geographic mapping capabilities. Designed for monitoring use cases, it integrates with the Model Context Protocol to provide real-time network diagnostics.
