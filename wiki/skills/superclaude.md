> A versatile configuration framework that enhances Claude Code with specialized commands, cognitive personas, and development methodologies, such as "Introspection" and "Orchestration".

SuperClaude is a configuration framework designed to enhance Claude Code, a tool by Anthropic. It adds specialized commands and cognitive personas to tailor the AI's behavior. The framework supports development methodologies such as Introspection and Orchestration. This allows developers to customize their AI interactions for improved productivity.
