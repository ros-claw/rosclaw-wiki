> Bun runtime capabilities for filesystem, process.

The bun-runtime project provides capabilities for interacting with the filesystem and managing processes within the Bun JavaScript runtime. It offers APIs to perform file operations and execute system commands efficiently. This tool enables developers to leverage Bun's high-performance runtime for server-side tasks, such as reading/writing files and spawning child processes.
