gpu-bridge/mcp-server is a unified GPU inference API that aggregates 30+ AI services (LLM, image generation, video, TTS, Whisper, embeddings, reranking, OCR) into a single MCP server. It provides these capabilities as MCP tools, allowing easy integration into AI workflows. The service operates on a pay-per-use basis, supporting x402 USDC micropayments or traditional API key credits. This eliminates the need to manage multiple provider APIs, offering a single endpoint for diverse AI tasks.
