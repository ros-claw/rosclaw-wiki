> 📇 🏠 - A Model Context Protocol (MCP) integration that provides Claude Desktop with autonomous browser automation capabilities.

This project integrates the Model Context Protocol (MCP) with Claude Desktop to give it autonomous browser control. It builds on the standard MCP server interface to expose tools for navigation, clicking, form filling, and page data extraction. The agent can execute multi-step browsing workflows without human intervention, enabling tasks like automated web research and testing. It offers a flexible foundation for adding new browser-based capabilities.
