> ![GitHub stars](https://img.shields.io/github/stars/jsegov/autoresearch-win-rtx?style=social) - Windows-native RTX fork focused on consumer NVIDIA GPUs, with explicit VRAM floors and a practical desktop setup path.

This project is a fork of a research automation tool (likely AutoGPT) optimized for Windows systems and consumer NVIDIA RTX graphics cards. It adds explicit VRAM floor settings to prevent out-of-memory errors on typical desktop GPUs. The fork provides a practical desktop setup path for running autonomous agents on Windows without requiring enterprise hardware. It targets users who want to run AI research assistants on their personal Windows computers with RTX GPUs.
