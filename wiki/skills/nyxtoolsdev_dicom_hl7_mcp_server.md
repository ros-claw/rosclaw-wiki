This MCP server uniquely bridges DICOM, HL7v2, and FHIR standards in a single package. It provides cross-standard mapping, generates Mirth Connect channels, and decodes vendor private tags from GE, Siemens, and Philips systems. Developed by a 19-year healthcare IT veteran, it aims to simplify integration patterns. Installation is via pip install dicom-hl7-mcp.
