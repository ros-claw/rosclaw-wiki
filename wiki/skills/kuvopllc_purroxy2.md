Replays browser actions in headless Playwright with encrypted credentials and AI-powered selector healing.

Purroxy2 is a browser automation tool that records user actions on websites and replays them using headless Playwright. It securely stores encrypted credentials and uses AI-powered selector healing to adapt to changes in web page structure. This enables reliable automation of web tasks over time. It is implemented as an MCP server, fitting into the ecosystem of server implementations for AI agents.
