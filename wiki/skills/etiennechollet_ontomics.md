Ontomics is a semantic code index that extracts domain concepts, naming conventions, and behavioral similarity from codebases. It is implemented as an MCP server, allowing AI agents to understand codebases with a single tool call instead of many, reducing token usage significantly. The tool is written in Rust and supports macOS, Linux, and Homebrew installations. It aims to improve codebase understanding for AI agents by providing high-level semantic information.
