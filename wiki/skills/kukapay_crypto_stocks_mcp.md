> 🐍 ☁️ - An MCP server that tracks real-time data for major crypto-related stocks.

This project is an MCP server that provides real-time stock data for major companies tied to the cryptocurrency industry. It allows AI agents to query current prices, changes, and other financial metrics for stocks like Coinbase, MicroStrategy, and mining firms. The server integrates with the Model Context Protocol, enabling large language models to access this financial data on demand. It is designed for finance and fintech applications where up-to-date market information is needed.
