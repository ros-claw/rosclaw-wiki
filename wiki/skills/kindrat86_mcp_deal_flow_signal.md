This MCP server analyzes GitHub engineering activity to generate venture capital deal flow signals. It tracks startup metrics such as commit velocity, contributor growth, and repository expansion across 20 industry sectors. Designed for seed and Series A investors, it helps identify promising startups based on real technical development momentum. No API key is required and it can be installed via npx.
