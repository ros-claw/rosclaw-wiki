> Open-source Python SDK for agent monitoring, session replay, cost tracking, benchmarking, and tracing across common LLM and agent frameworks.

AgentOps is an open-source Python SDK that provides monitoring and observability for AI agents. It enables session replay, cost tracking, benchmarking, and tracing for common LLM and agent frameworks. The tool helps developers debug and optimize agent performance by recording and analyzing interactions.
