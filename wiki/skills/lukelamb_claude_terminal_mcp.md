Zero npm deps, pure Node.

This MCP server provides tools for Claude Desktop to interact with the terminal, filesystem, and run background jobs on Linux and macOS systems. It is built with pure Node.js and has no npm dependencies, making it lightweight and easy to set up. Users can execute shell commands, manage files, and handle long-running tasks directly from Claude. This enables Claude to assist with system administration, development workflows, and automation tasks.
