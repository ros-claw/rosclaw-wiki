> Presents an innovative AI-human collaboration framework with Model Context Protocol for bidirectional LLM-markdown communication and flexible knowledge structure for complex projects.

Basic Memory is a framework for AI-human collaboration that uses the Model Context Protocol to enable bidirectional communication between LLMs and markdown. It provides a flexible knowledge structure to manage complex projects by allowing AI agents and humans to interact seamlessly through markdown files. The project aims to scaffold development workflows by integrating AI tools with structured memory systems.
