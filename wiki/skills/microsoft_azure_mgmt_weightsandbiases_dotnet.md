This project is an Azure management SDK for .NET that enables developers to programmatically manage Weights & Biases resources in Azure. It provides a client library for creating, updating, and deleting W&B instances integrated with Azure. As part of the broader .NET Skills initiative, it simplifies cloud-native ML experiment tracking and model management. The library follows Azure SDK design guidelines for .NET developers.
