> Control Anova Precision Ovens and Precision Cookers (sous vide)

This project provides a Python library and command-line interface for controlling Anova Precision Ovens and Precision Cookers (sous vide devices). It enables users to monitor and adjust cooking parameters such as temperature, time, and cooking modes programmatically. The library handles communication via Bluetooth or WiFi, allowing integration with home automation systems or custom cooking scripts. It is designed for developers and makers who want to automate sous vide and oven cooking processes.
