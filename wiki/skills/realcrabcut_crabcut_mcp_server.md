AI-powered highlight detection, subtitle generation, 9:16 reframing, and direct download URLs via the Crabcut API.

This MCP server allows AI assistants to convert YouTube videos into short-form clips. It uses AI for highlight detection, subtitle generation, and 9:16 aspect ratio reframing. The server provides direct download URLs via the Crabcut API. It is designed for multimedia processing and integrates into various AI workflows.
