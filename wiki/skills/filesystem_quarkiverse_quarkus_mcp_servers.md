> ☕ 🏠 - A filesystem allowing for browsing and editing files implemented in Java using Quarkus. Available as jar or native image.

This project provides a file system implementation for the Model Context Protocol (MCP), built with Java and Quarkus. It enables browsing and editing files on the server's file system, making it available as a JAR or native image. It is listed under File Systems in MCP server implementations.
