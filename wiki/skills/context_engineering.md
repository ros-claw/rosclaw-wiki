> This skill should be used when the user asks.

Context engineering is a skill used to manage and optimize the context provided to AI agents when processing user requests. It involves structuring prompts and background information to improve the relevance and accuracy of AI responses. This technique is essential for handling complex or multi-step tasks where maintaining coherent context is critical. The skill ensures that the AI system can effectively interpret user intent and generate appropriate outputs.
