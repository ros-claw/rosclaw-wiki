> 🐍 ☁️️ 🍎 🪟 🐧 - A Model Context Protocol (MCP) server for querying NIST National Vulnerability Database (NVD) API endpoints.

This project provides a Model Context Protocol (MCP) server that allows querying the NIST National Vulnerability Database (NVD) API. It is built with Python and supports multiple platforms including macOS, Windows, and Linux. The server enables automated retrieval of vulnerability information, making it useful for security assessments and integration into AI-agent workflows. It serves as a bridge between AI systems and authoritative vulnerability data.
