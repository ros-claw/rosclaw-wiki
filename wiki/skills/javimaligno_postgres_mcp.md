> 🐍 🏠 - PostgreSQL MCP server with 14 tools for querying, schema exploration, and table analysis. Features security-first design with SQL injection prevention and read-only by default.

JaviMaligno/postgres_mcp is a PostgreSQL MCP server offering 14 tools for querying, schema exploration, and table analysis. It prioritizes security with built-in SQL injection prevention and a read-only mode by default. Designed for integration with AI agents, this server enables safe and structured database interactions.
