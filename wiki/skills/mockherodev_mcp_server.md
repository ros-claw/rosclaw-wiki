> [![mockhero MCP server](https://glama.ai/mcp/servers/dinosaur24/mockhero/badges/score.svg)](https://glama.ai/mcp/servers/dinosaur24/mockhero) 🏠 - Generate realistic synthetic test data via MCP. 156 field types, 22 locales, relational data, sub-50ms responses. Free tier: 1,000 records/day.

mockherodev/mcp-server is a server implementation that generates realistic synthetic test data using the Model Context Protocol (MCP). It offers 156 field types and supports 22 locales for localized data generation, with sub-50ms response times for rapid prototyping. The tool can create relational data structures and provides a free tier of 1,000 records per day. It is listed under Developer Tools in the MCP server ecosystem.
