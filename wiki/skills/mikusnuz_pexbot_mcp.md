pexbot-mcp is an MCP server that simulates cryptocurrency trading using real-time prices from Upbit, a South Korean exchange. It provides 11 tools for user registration, trading, and autonomous AI-driven investment with a virtual balance of 100 million KRW. Designed for experimentation and learning, it allows AI agents to execute trades without real financial risk. The server can be launched via npx and integrates with AI assistants like Claude.
