> 🐍 ☁️ - Web search using DuckDuckGo

This project implements an MCP (Model Context Protocol) server that provides web search functionality using the DuckDuckGo search engine. It allows AI agents to perform web searches and retrieve results through a standardized interface. The server is intended for use with AI tooling that requires real-time web search capabilities. By integrating DuckDuckGo, it offers a privacy-focused alternative for fetching online information.
