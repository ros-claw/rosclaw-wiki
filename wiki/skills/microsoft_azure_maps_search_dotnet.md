This .NET library provides client bindings for the Azure Maps Search service, enabling developers to integrate geocoding, reverse geocoding, and points of interest search into .NET applications. It is maintained by Microsoft and listed under the .NET Skills sponsorship category. The package simplifies calling Azure Maps REST endpoints from C# and other .NET languages.
