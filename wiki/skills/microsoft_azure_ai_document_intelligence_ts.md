This is a TypeScript library from Microsoft for interacting with Azure AI Document Intelligence (formerly Form Recognizer). It allows developers to extract text, key-value pairs, tables, and other structured data from documents using prebuilt or custom models. The library is part of the Azure AI ecosystem and is aimed at TypeScript/JavaScript developers.
