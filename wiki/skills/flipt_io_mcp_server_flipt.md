> 📇 🏠 - Enable AI assistants to interact with your feature flags in [Flipt](https://flipt.io).

This project implements an MCP server for Flipt, an open-source feature flag management platform. It enables AI assistants to interact with and manage feature flags through the Model Context Protocol. The server exposes tools and resources to list, create, update, and delete feature flags, segments, and rules. This allows AI agents to query flag states, toggle flags, or retrieve flag configurations during conversations. It is useful for developers integrating AI into DevOps or feature management workflows.
