> Daily self-improving questionnaire that learns about the user and refines agent behavior.

This project implements a daily questionnaire that adapts to the user's responses over time. By learning from user interactions, it personalizes questions to better understand preferences and behaviors. The ultimate goal is to refine the behavior of an AI agent based on collected data. This system aims to create a self-improving loop between user feedback and agent performance.
