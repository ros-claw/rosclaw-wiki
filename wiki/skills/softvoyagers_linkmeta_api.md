> 📇 ☁️ - Free URL metadata extraction API (Open Graph, Twitter Cards, favicons, JSON-LD). No API key required.

This project offers a free, no-API-key-required service for extracting metadata from URLs. It supports Open Graph, Twitter Cards, favicons, and JSON-LD data. The API is designed for easy integration and is listed under Search & Data Extraction in server implementations. It provides a simple way to retrieve structured metadata from any webpage.
