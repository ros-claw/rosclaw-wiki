This MCP server generates app icons, favicons, logos, and wordmarks from text prompts. It routes each request across over 30 image generation models without requiring an API key, using free tiers from Cloudflare Workers AI, NVIDIA NIM, HuggingFace, or Stable Horde. Three operating modes are available: inline SVG generation, external prompt-only, or full API integration. The system validates each output for contrast, OCR text accuracy, and color palette before returning the final asset.
