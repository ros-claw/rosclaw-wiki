> [![mcp-server-cloudflare MCP server](https://glama.ai/mcp/servers/ofershap/mcp-server-cloudflare/badges/score.svg)](https://glama.ai/mcp/servers/ofershap/mcp-server-cloudflare) 📇 ☁️ - Manage Cloudflare Workers, KV, R2, Pages, DNS, and cache from your IDE.

This MCP server enables managing Cloudflare services directly from an IDE, including Workers, KV storage, R2 object storage, Pages, DNS, and cache. It integrates with the Model Context Protocol to provide tooling for Cloudflare platform operations. Developers can use this server to deploy and manage Cloudflare resources without leaving their coding environment.
