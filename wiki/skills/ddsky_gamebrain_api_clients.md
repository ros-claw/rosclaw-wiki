> ☁️ - Search and discover hundreds of thousands of video games on any platform through the [GameBrain API](https://gamebrain.co/api).

This project provides client libraries for the GameBrain API, enabling developers to search and discover hundreds of thousands of video games across multiple platforms. It is listed under gaming server implementations and offers a cloud-based interface to access game metadata. Users can integrate game discovery features into their own applications using these API clients.
