Cortex is an MCP server that provides persistent memory for Claude Code, inspired by computational neuroscience principles. It implements memory mechanisms like thermodynamic decay, hippocampal-cortical consolidation, and predictive-coding write gating for intelligent storage and retrieval. Built on PostgreSQL with pgvector, it offers 33 MCP tools and 7 lifecycle hooks, and achieves 97.8% recall@10 on the LongMemEval benchmark. It is designed to give AI agents long-term, context-aware memory grounded in scientific models of human cognition.
