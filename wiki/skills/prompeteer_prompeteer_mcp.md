Score quality across 16 dimensions and manage your prompt library with PromptDrive.

This MCP server generates high-quality prompts for over 130 AI platforms including ChatGPT, Claude, and Midjourney. It scores prompt quality across 16 dimensions to help users improve their prompts. Users can manage their prompt library with PromptDrive integration. The tool is designed for workplace productivity, streamlining prompt creation and optimization.
