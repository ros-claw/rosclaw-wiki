> 🐍 ☁️ - An MCP server for Oura, an app for tracking sleep

Oura MCP Server provides an MCP interface to the Oura API, enabling AI agents to access sleep, activity, and readiness data from Oura ring users. It allows AI tools to retrieve metrics like sleep scores, heart rate variability, and activity levels. This server simplifies integration of Oura health data with MCP-compatible AI assistants.
