This project is an MCP server that provides tools for the One Piece Trading Card Game (TCG). It includes card search, deck analysis, cost curves, leader browsing, and counter strategy tools. The server offers six distinct tools and contains embedded information about 4,348 cards. It is classified under gaming server implementations.
