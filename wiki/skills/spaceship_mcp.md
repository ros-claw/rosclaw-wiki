> 📇 ☁️ - Manage domains, DNS records, contacts, marketplace listings, and more via the Spaceship API

Spaceship MCP is a server implementation of the Model Context Protocol that provides an interface to the Spaceship API. It enables AI agents to manage domains, DNS records, contacts, and marketplace listings programmatically. This tool allows automated domain and hosting operations within AI-driven workflows, integrating cloud platform management directly into conversational or agent-based systems.
