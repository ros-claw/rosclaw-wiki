The ellmos-ai/n8n-manager-mcp project provides an MCP server that enables AI assistants to manage n8n workflows. It supports CRUD operations on workflows, synchronization, inspection, and execution. This integration allows users to control n8n automation through natural language. It is categorized under Workplace & Productivity. The tool is useful for automating workflow management without manual UI interaction.
