> 📇 ☁️ - Atlassian Confluence Cloud integration. Enables AI systems to interact with Confluence spaces, pages, and content with automatic ADF to Markdown conversion.

This project is an MCP (Model Context Protocol) server that integrates with Atlassian Confluence Cloud. It allows AI systems to interact with Confluence spaces, pages, and other content. The server automatically converts Atlassian Document Format (ADF) content into Markdown, making it easier for AI tools to process. It is listed under developer tools and is designed for use with AI agents that need access to Confluence knowledge bases.
