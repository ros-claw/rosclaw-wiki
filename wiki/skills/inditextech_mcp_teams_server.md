> 🐍 ☁️ - MCP server that integrates Microsoft Teams messaging (read, post, mention, list members and threads)

This project implements a Model Context Protocol (MCP) server that integrates with Microsoft Teams. It enables AI agents to read messages, send posts, mention users, list team members, and manage threads within Teams. Built with Python, it leverages the Microsoft Graph API to interact with Teams data. This server can be used as a tool for conversational AI systems to access Teams communication.
