> 📇 ☁️ - Model Context Protocol server for the JSR (JavaScript Registry)

This project provides a Model Context Protocol (MCP) server that allows AI assistants, such as Claude, to interact with the JavaScript Registry (JSR). It enables discovering packages, retrieving package information, and querying the registry directly through natural language or tool calls. Developers can use this server to integrate JSR package lookup capabilities into MCP-compatible AI tools. This facilitates tasks like finding packages, checking versions, or exploring documentation without leaving the chat interface.
