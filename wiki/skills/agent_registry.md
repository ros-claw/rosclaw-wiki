> MANDATORY agent discovery system for token-efficient agent.

agent-registry is a system designed for mandatory agent discovery, focusing on token-efficient agents. It provides a registry where agents can be listed and discovered by other components, likely in a multi-agent environment. The goal is to improve coordination and reduce redundant token usage in agent interactions. This tool is relevant for building efficient AI agent ecosystems.
