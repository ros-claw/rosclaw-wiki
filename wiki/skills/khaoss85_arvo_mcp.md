> 📇 ☁️ - AI workout coach MCP server for Arvo. Access training data, workout history, personal records, body progress, and 29 fitness tools through Claude Desktop.

Arvo MCP is a server that provides an AI workout coach, allowing users to access training data, workout history, personal records, body progress, and 29 fitness tools through Claude Desktop. It is listed under sports server implementations and integrates with the Arvo platform. The server enables AI-driven fitness coaching by connecting to external data sources via the Model Context Protocol (MCP).
