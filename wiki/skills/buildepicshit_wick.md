Wick is a native C# Model Context Protocol (MCP) server for the Godot Engine, offering 53 tools across five core areas: Roslyn-enhanced exception telemetry, scene tree inspection, C# symbol navigation, MSBuild orchestration, and GDScript analysis. It runs on .NET 10 and communicates via a TCP JSON-RPC bridge, with a comprehensive test suite of 219 tests. This server enables developers to integrate Godot engine capabilities with MCP-compatible clients, streamlining game development workflows.
