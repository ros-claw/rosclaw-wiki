The Azure AI Content Safety Python SDK is a client library for detecting harmful content in text and images. It enables developers to moderate user-generated content by identifying categories such as hate speech, sexual content, violence, and self-harm. The library integrates with Azure's responsible AI services and is designed for easy use in Python applications. It helps build safer online environments by automating content filtering.
