> 📇 - An MCP server using Playwright for browser automation and webscrapping

This project is a server implementation of the Model Context Protocol (MCP) that uses Playwright for browser automation and web scraping. It allows other tools or agents to control a web browser programmatically via MCP endpoints. The server can navigate pages, extract data, and perform actions like clicks and form fills. It is designed to integrate with AI agents that need live web interaction.
