> Implements Test-Driven Development by analyzing feature requirements, creating tests first (red), implementing minimal passing code (green), and refactoring while maintaining tests.

This tool implements Test-Driven Development (TDD) by guiding the user through the red-green-refactor cycle. It first analyzes feature requirements to generate failing tests (red), then helps write minimal code to pass those tests (green), and finally supports refactoring while keeping tests green. It aims to enforce TDD discipline within development workflows.
