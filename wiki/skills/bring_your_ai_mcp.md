> Public harness-migration reference for Claude Code to Codex moves, with installable auditor artifacts and explicit validation notes for hooks, MCP config, and instruction-file differences.

Bring Your AI MCP is a reference tool for migrating from Claude Code to Codex environments. It provides downloadable auditor artifacts and detailed validation notes to ensure proper setup of hooks, MCP configuration, and instruction files. The project serves as a public harness-migration reference to streamline transitions between these AI coding assistants.
