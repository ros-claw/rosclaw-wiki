This MCP server provides access to Chinese A-share financial statements, allowing users to retrieve annual reports and conduct automated accounting cross-checks that are aware of industry-specific norms. It also enables peer comparison with auto-calculated average equity Return on Equity (ROE). The server is part of the Finance & Fintech category and is built on the Model Context Protocol, making it suitable for integration with AI agents. It can be used to analyze corporate financial health and detect potential accounting irregularities.
