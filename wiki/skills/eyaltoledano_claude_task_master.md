> 📇 ☁️ 🏠 - AI-powered task management system for AI-driven development. Features PRD parsing, task expansion, multi-provider support (Claude, OpenAI, Gemini, Perplexity, xAI), and selective tool loading for optimized context usage.

Claude Task Master is an AI-powered task management system designed for AI-driven development. It parses Product Requirement Documents (PRDs) and expands them into structured tasks. The system supports multiple AI providers including Claude, OpenAI, Gemini, Perplexity, and xAI, allowing flexibility. Its selective tool loading feature optimizes context usage by only loading necessary tools. This tool helps developers break down complex requirements into manageable tasks.
