## 二、后端 API 变更说明

### 2.1 新增端点

```
GET /wiki/v1/graph
```

**无需认证**，返回完整 wiki 页面图谱：

```json
{
  "status": "ok",
  "nodes": [
    {
      "id": "embodied_ai",
      "title": "Embodied AI",
      "type": "concept",
      "confidence": 0.92,
      "link_count": 135
    }
  ],
  "edges": [
    { "source": "unitree_g1", "target": "embodied_ai" }
  ]
}
```

**关键字段**:
- `nodes[].link_count` — 节点度数（入链+出链），用于控制节点大小
- `nodes[].type` — 节点类型：`entity` | `algorithm` | `concept` | `skill` | `unknown`
- `edges` — 真实的 wikilink 引用关系（已去重）

### 2.2 现有端点更新

| 端点 | 变更 |
|------|------|
| `GET /wiki/v1/hub/stats` | `global_stats.total_code_graph_nodes` 已过滤（1,811），`total_code_graph_edges` 已过滤（20,612） |
| `GET /v1/health` | `backend: "seekdb"` 表示正常 |

### 2.3 认证方式

所有需要认证的端点统一使用 Header:
```
X-API-Key: rw_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Key 通过 `POST /wiki/v1/auth/exchange`（传 email）获取，存入 localStorage。

#### Sigma 渲染器配置

```typescript
const renderer = new Sigma(graph, container, {
  renderEdgeLabels: false,
  labelSize: 11,
  labelColor: { color: '#cbd5e1' },
  hideEdgesOnMove: true,
  defaultNodeType: 'circle',  // ← 强制使用 circle program

  // 悬停高亮：非相邻节点淡化
  nodeReducer: (node, attrs) => {
    if (hoveredNode && hoveredNode !== node) {
      const isNeighbor = graph.neighbors(hoveredNode).includes(node);
      if (!isNeighbor) {
        return { ...attrs, color: '#1e293b', label: '', zIndex: 0 };
      }
    }
    // 类型过滤
    if (activeFilter !== 'all' && attrs._type !== activeFilter) {
      return { ...attrs, hidden: true };
    }
    return attrs;
  },

  // 悬停高亮：非相关边淡化
  edgeReducer: (edge, attrs) => {
    if (hoveredNode) {
      const [src, tgt] = graph.extremities(edge);
      const isConnected = src === hoveredNode || tgt === hoveredNode;
      if (!isConnected) {
        return { ...attrs, color: 'rgba(30,41,59,0.3)' };
      }
      return { ...attrs, color: 'rgba(148,163,184,0.5)', size: 1.2 };
    }
    return attrs;
  },
});
```

### 3.3 力导向布局（纯 JS，无需外部库）

> graphology-layout-forceatlas2 没有 UMD 浏览器构建，不能直接在 Next.js 客户端使用（除非通过 npm 安装并 bundler 处理）。这里提供一个零依赖的替代方案。

```typescript
function runLayout(g: Graph, iterations: number) {
  const nodes = g.nodes().map(id => ({
    id,
    x: g.getNodeAttribute(id, 'x'),
    y: g.getNodeAttribute(id, 'y'),
    vx: 0, vy: 0
  }));
  const nodeMap: Record<string, any> = {};
  nodes.forEach(n => nodeMap[n.id] = n);

  for (let iter = 0; iter < iterations; iter++) {
    // 斥力（节点间相互排斥）
    for (let i = 0; i < nodes.length; i++) {
      for (let j = i + 1; j < nodes.length; j++) {
        const a = nodes[i], b = nodes[j];
        let dx = a.x - b.x, dy = a.y - b.y;
        let dist = Math.sqrt(dx * dx + dy * dy) || 0.01;
        const f = 60 / (dist * dist);
        const fx = (dx / dist) * f, fy = (dy / dist) * f;
        a.vx += fx; a.vy += fy;
        b.vx -= fx; b.vy -= fy;
      }
    }
    // 引力（边连接的节点相互吸引）
    g.forEachEdge((_edge, _attrs, source, target) => {
      const s = nodeMap[source], t = nodeMap[target];
      if (!s || !t) return;
      let dx = t.x - s.x, dy = t.y - s.y;
      let dist = Math.sqrt(dx * dx + dy * dy) || 0.01;
      const f = dist * 0.006;
      const fx = (dx / dist) * f, fy = (dy / dist) * f;
      s.vx += fx; s.vy += fy;
      t.vx -= fx; t.vy -= fy;
    });
    // 应用速度 + 中心引力（防止飘走）
    for (const n of nodes) {
      n.vx *= 0.6; n.vy *= 0.6;
      n.vx -= n.x * 0.002;
      n.vy -= n.y * 0.002;
      n.x += n.vx;
      n.y += n.vy;
    }
  }

  for (const n of nodes) {
    g.setNodeAttribute(n.id, 'x', n.x);
    g.setNodeAttribute(n.id, 'y', n.y);
  }
}
```

### 3.4 右侧详情面板

```typescript
function showDetailPanel(nodeId: string) {
  const attrs = graph.getNodeAttributes(nodeId);
  const node = graphData.nodes.find(n => n.id === nodeId);

  // 标题和类型徽章
  setDetailTitle(attrs._title || nodeId);
  setDetailBadge(attrs._type, TYPE_COLORS[attrs._type]);

  // 元数据
  setDetailMeta({
    links: attrs._linkCount,
    confidence: (attrs._confidence || 0).toFixed(2),
  });

  // 出链列表
  const outgoing = graphData.edges
    .filter(e => e.source === nodeId)
    .map(e => {
      const target = graphData.nodes.find(n => n.id === e.target);
      return { id: e.target, title: target?.title || e.target };
    });
  setDetailOutgoing(outgoing);

  // 入链列表
  const incoming = graphData.edges
    .filter(e => e.target === nodeId)
    .map(e => {
      const source = graphData.nodes.find(n => n.id === e.source);
      return { id: e.source, title: source?.title || e.source };
    });
  setDetailIncoming(incoming);

  // 打开面板
  setDetailPanelOpen(true);
}
```

**点击链出/链入节点时的导航**:
```typescript
function focusNode(nodeId: string) {
  if (!graph.hasNode(nodeId)) return;
  const attrs = graph.getNodeAttributes(nodeId);
  const camera = renderer.getCamera();
  camera.animate(
    { x: attrs.x, y: attrs.y, ratio: 0.3 },
    { duration: 400 }
  );
  showDetailPanel(nodeId);
}
```

### 3.5 搜索与图谱联动

```typescript
async function handleSearch(query: string) {
  // 1. 调用 API 搜索
  const res = await fetch(`${API_BASE}/v1/search`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': apiKey,
    },
    body: JSON.stringify({ query, search_type: 'hybrid', top_k: 5 }),
  });
  const data = await res.json();

  // 2. 如果有结果，定位到第一个匹配的图谱节点
  if (data.results?.length > 0) {
    const first = data.results[0];
    if (graph.hasNode(first.file_path)) {
      focusNode(first.file_path);
      showToast(`已定位: ${first.title}`);
      return;
    }
  }

  // 3. API 无结果时，在图谱中本地搜索
  const matches = graphData.nodes.filter(n =>
    (n.title || '').toLowerCase().includes(query.toLowerCase()) ||
    (n.id || '').toLowerCase().includes(query.toLowerCase())
  );
  if (matches.length > 0) {
    focusNode(matches[0].id);
    showToast(`已定位: ${matches[0].title || matches[0].id}`);
  } else {
    showToast('未找到匹配的页面', 'error');
  }
}
```

## 六、注意事项

1. **Sigma.js 的 `defaultNodeType: 'circle'` 必须设置**，否则自定义 `type` 属性会导致 WebGL program 错误
2. **节点属性 `type` 必须改为 `_type`** 或其他非保留名，Sigma 会拦截 `type` 作为渲染类型
3. **graphology-layout-forceatlas2 不要使用 CDN 直链** — 该包无 UMD 构建，使用上述纯 JS 布局替代
4. **边需要去重** — `/wiki/v1/graph` 已返回去重边，但 Sigma.js 的 `graph.addEdge` 对重复边会抛异常，需 try-catch
5. **相机动画** — Sigma.js 2.4 的 `camera.animate()` 支持平滑过渡，比直接设置位置更流畅
